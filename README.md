# 《镇冢秘术》

中文长篇悬疑冒险小说，苏衍第一人称。当前阶段是：**唯一 canon 已完成第二轮因果审计，第 1—271 章已经同步封版；第 272 章开写前，须继续保持小说检察官硬错误为零，并人工复核叙事质量。**

## 开工只读这套入口

1. `00_第一铁律_GitHub为准_必读.md`：确认工作对象是 GitHub 最新提交。
2. `设定/00_镇冢秘术_唯一总圣经.md`：**唯一剧情权威**，CANON-ID `ZM-CANON-20260722-101`。
3. `设定/01_镇冢秘术_逐章施工与伏笔回收表.md`：逐章状态、修复理由和后续回收点。
4. `设定/canon事实库.json`：总圣经的机器镜像，只负责拦错，不能反过来发明剧情。
5. `正文/`：已经实际发生的场景；若与总圣经冲突，必须回修原场，不能靠后文圆成两个版本。

`设定/99_镇冢秘术_废案墓地.md` 记录旧资料的来源价值和已经废止的内容。其余旧设定文件均为**历史创作资料**，可以追溯作者思路，不能单独作为 canon 引用。

## 已锁定的总骨架

- 禹铸九鼎象九州，九州是九脉在人间的影子；禹一州一鼎、钉九根桩镇九脉；赵阙一件东西也没造过——他夺鼎改制、改线并缆，并把数座鼎连根拔起押离本州（豫移骊山为罪账头一笔）。鼎的出身是九州，鼎的岗位是九脉。
- 天下气运本来会自然循环；赵阙用九鼎劫持循环，苏玄微在事后另造三台回滚系统。后门装得上只因公输是原厂；四脉无一干净。
- 现代结构是八座外鼎实体、苏衍体内的第九鼎心、骊山第九鼎空座；不再出现两个实体第九鼎。
- 苏衍自幼望气；地窖合玉只是低功率认证，骊山入槽才是终局主回路。
- 古玉只用冷、温、热、灼反馈近距离同源浓度，不认人、不探敌意、不导航、不自行位移。
- 古尸是苏玄微，但不长爷爷的脸，也不存在跨两千年遗传痣或后天伤疤。
- 赵阙不能夺舍；霍钧掌暗线，黎东来掌现代明线；黎东来清醒作恶并承担法律责任。
- 钱满不是公输血脉或秘密传人；真正的当代保图人尚待正文登场。
- 沈鸢的本领来自训练，不是魔法血统；她在第 58 章第三日清早告诉苏衍姓名，第 57 章只由电视先揭出黎东来。
- 终局不是换一个人永坐阵眼，而是让自然循环复原。完整结局只服从唯一总圣经。

## 仓库结构

- `设定/`：唯一总圣经、逐章施工表、废案墓地、机器事实库及历史资料。
- `正文/`：第 1—72 章 Markdown 正文。
- `工具/`：小说检察官、提示词系统、阅读器同步工具。
- `阅读器/`：由正文和设定同步生成的全本 HTML，不是独立稿源。

## 校验与阅读器同步

正文或 canon 改动后依次运行：

```bash
python3 工具/同步全本阅读器.py
python3 工具/同步全本阅读器.py --check
python3 工具/同步全本阅读器.py --selftest
python3 工具/小说检察官.py --doctor
python3 工具/小说检察官.py --selftest
python3 工具/小说检察官.py
```

写下一章前生成开拍简报：

```bash
python3 工具/小说检察官.py --开拍 73
```

只要总圣经缺失、CANON-ID 不匹配、章节断档、阅读器未同步，或旧废案重新混入正文，检察官都不得给出“全绿”。
