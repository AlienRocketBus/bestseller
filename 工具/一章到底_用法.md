# 一章到底.py · 用法

## 它做什么
**把每轮开头那七八条命令压成一条，并把诊断结果一次铺完。**
它做的是【量】，不是【判】——真伤是哪一根、刀怎么落、判活判死，仍须人。

## 四条命令

```bash
# 每轮开头：跑闸＋核台账＋判本轮＋全部机械扫描
python3 工具/一章到底.py --诊断 136

# 落刀之后：改检＋同步＋存版＋自测＋全书检＋双绿推（一条走完）
python3 工具/一章到底.py --收轮 136 "第1轮·⑤感官庭：真伤＝…；补…"

# 开新章之前：到期账列单＋重复立账扫描＋已付扫描
python3 工具/一章到底.py --账单 137

# 净重逾限时：三步法拆点测算
python3 工具/一章到底.py --拆点 136
```

## --诊断 铺出来的九项
1. **并发闸** —— 别路是否已进账
2. **台账** —— 真轮已跑哪几轮，**本轮＝下一个未跑之轮**（并印出该轮之镜头）
3. **硬项** —— 禁词／破折／半角／五逗／章号泄漏／第三人称窜入／亮点段病
4. **软项** —— 净重、三密度（机器计＋实计）、长段、顿悟、人声、最长串
5. **逐块三密度** —— 每十二段一块，**三感全零者标⛔，即真伤之候选**
6. **器物总账** —— 十五物点数，零字者标出待判
7. **相对日词** —— 逐处列出，逾三处即警（依135之律须列表核）
8. **四字串六现以上** —— 自造重复之候选
9. **拆点预测** —— 净重逾上限时自动给真中点近处之候选

## 两条计量之律（皆由实战抓出，已写进工具）
- **嗅之机器计只认 味/鼻/闻**，而文中多以 腥/馊/甜/潮/焦/酸 写出 → 工具双计，**以实计判达标，不得强灌"味"字**（133立）
- **触之机器计只认 凉温烫硬软摸按贴**，而文中多以 硌/压/掂/蹭/撑/捏/搓 写出 → 同上（136立）

## 它替代不了的
- 判定真伤（第2、4、8轮尤须通读）
- 写那一刀
- 自造重复之判活判死（人名与固定说法判活）
- 招式库十招比对
- 到期账之"已付／重复"之最终裁定（机器只给候选，且有假阳）
