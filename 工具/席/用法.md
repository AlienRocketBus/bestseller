# 三张席之模子（2026-09-08 立·案 #14 与十九件未了之案所炼）

> **这三张不是工具，是「怎么派一个人去干活」的模子。**
> 本仓的 `.py` 是**机器判得死的**那一路；这三张 `.js` 是**机器判不死、只能由人（席）判**的那一路。
> 令§十三②：**闸须判得死；判不死的不许做成闸**——而判不死的那些，就交给这三张席。

## 一·`读席.js` —— 只读白文，判落到拍号（**不改一字**）

**其位**：**第11轮·四方庭之「读者席」**。
★**其立之由（拿账说）**：`工具/看官.py` 立器之日自记——
「第11轮四方庭跑过八章，**四庭俱过九回，判不过零回**……**那只『读者之眼』看的不是文，是我自己的轮记**。」
★★**故此席之头一条硬律是「不许看」**：不许看本章骨记、不许看设定册子、不许看版本轮记；
只读白文，外加前一章白文（只为知道昨天）。**读得到答案，就判不出堵。**
★★★**第二条硬律**：**判必须落到拍号**。「读者会觉得闷」不算判；「拍93至106连十四拍无一动作」才算。
★★★★**第三条硬律**：**允许判「它不弱」**。

**其实证（0908·三十二章）**：诸席点名「掉下去」三十二章，读席逐章读毕——
**判弱 10 章，判不弱 22 章（点名之误 69%）**。若照原名单一律回修，等於拿刀去削二十二章好文。
**同日四把机器之尺（外事率／复读率／虚拍连行／原地率）拿同一批章去打，四把全败**（见 机制总审§三十）。
**——这一席是本仓唯一一样量得准「好不好看」的东西。**

用法：`Workflow({scriptPath:'工具/席/读席.js', args:[184,188,191]})`

## 二·`修席.js` —— 照读席之判落刀，只许删／挪／换

**其位**：读席之後。**一章一席**。
★**三样刀法，一样也不许多**：**删**（整拍，只删短拍不删长段）｜**挪**（整拍搬位）｜
**换**（删去一句替读者把感觉做完的判语，**只删那一句，不另造说法**）。
**绝不许补新拍、补新句、改写一句成另一句。**「换」是删，不是改写。
★★**落刀之前三问**：①这一条落下去读者丢东西吗（那几拍里有没有只此一处的物件／数字／人名／日子）？
②它是不是读席举出的「最好的那一拍」（是就不许动一个字）？③「挪」有没有把日子挪乱？
★★★**头一件事是自己把拍号数一遍**——读席的拍号是读出来的，不是数出来的，**对不上就拒**。
★★★★**其末一句写死**：**「为了把读席那条判交掉而落的笔，一笔也不许落。交白卷比交一刀假的强。」**

**其实证（0908·三十二章）**：**落 105 条，拒 71 条——拒率 40%**；194 一章交了整章白卷。
拒得最好的几条：208 拿自己的祖案（削长段）挡住新刀；191 逮出读席数错一个拍号；
182 落刀後亮点对表当场红（要删的那句是骨记一整节的节名）；
188／184 各逮出一处「是自己这一刀推上去的棘轮红」，当场复原。

用法：`Workflow({scriptPath:'工具/席/修席.js', args:[184,188]})`
（它自己去 `设定/读席_*.md` 取本章那一节；故读席之判须先入册。）

## 三·`案席.js` —— 一案一席，跨档统裁

**其位**：凡一条崩要跨两章以上、或要动锁定行／canon／圣经者。
★**其律之要**：**正文自改，册子只报**（几席同时写圣经／canon 必撞车，故册子由本坐统一落）；
**不许 git stash／checkout／restore／reset／add／commit**；
**据不够就停手**（坑㉗）——**而「界不够」也是据不够的一种**：
0908 之 #44 与 #26 两席各自裁明而一刀未落，因同裁之界不在其手；**它们停得对**。
★★**并须自己复核本坐派下去的据**——0908 本坐两回引错据（一条查不实的 canon 行号、一个数错的账），
**两回都是案席替我逮住的**。故律里写死：**本坐派案时写的据，与案席写的据受同一条律管。**

用法：`Workflow({scriptPath:'工具/席/案席.js', args:[{id,title,body,files}]})`

## ★★★★★三张席共用的那一条

**凡为了让一个数好看而落的笔，一笔也不许落。**
——**这一条两头都管**：不许为了把数做高而添笔，**也不许为了把数保住而留一笔废话**（302 祖案·棘轮旧账附二）。

## 四·`一章.js` —— **起一章新章之全程**（0908 立·作者令「以后每一章还要不要发提示词」）

**其位**：**作者只说「写第 N 章」，本坐跑这一份。** 八段：定位→三魂竞→起草→机闸→读席→修席→极限→案席。
★**其立之由**：提示词记在人脑子里，而人会忘；848 处落治、三十坑之目，没有人能在每章动笔前全想起来。
★★**故这一份不抄令**——每一席的提示里都写着「**当场去读 `设定/起草令_每章必发.md`**」。
   **摘抄会过期，令不会。** 这是立此席时定死的第一条。
★★★其中读席那一段是 `workflow({scriptPath:'工具/席/读席.js'}, [N])` 直接调的，不是另抄一份。
★★★★案席是**唯一许动 git 的一席**（余席禁 commit／add／stash／checkout／restore／reset）。

用法：`Workflow({scriptPath:'工具/席/一章.js', args:{章:306}})`
另见：`设定/一章之令_作者只需说一句话.md`（作者那一头要不要做什么、写完之後那一遍通读怎么跑）

## 五·`答表.js` —— **补答某章诸轮之必答表**（0909 立·十一轮覆盖查所逼）

**其位**：一轮一席，跑 `十轮精进.py --必答 N R` 取题 → 逐项去正文里核 → 逐项裁定 → 落进该轮轮记。
★**其立之由**：`--十一轮 306` 之乙3·覆盖查逐轮报 0%——**器一直在，是本坐的席没去问它**。
★★**今後不必再用它**：`一章.js` 之诸轮席已各自接了必答表（0909 改）；
　**此席只为补旧章之欠**（306 是头一个，也但愿是唯一一个）。
★★★**其末一条禁写死**：不许为了让覆盖率好看而编一句裁语——
　**一项没核过就写「判合」，比不答更坏：不答只是欠着，编一句裁语是把欠条撕了。**

用法：`Workflow({scriptPath:'工具/席/答表.js', args:{章:306, 轮:[3,4,5,6,7,8,9,11,12,13]}})`

## 六·`深掘.js` —— **治「十几轮只在删和改，没有一轮在长」**（0909 立）

**其位**：第4轮·深掘轮之专席，三路并跑（物／数／人）。**与修席相反：它是唯一许补的席。**
★**其立之由**：`--十一轮 306` 报「自起版至峰值一字未长（+0）」「无真伤之轮达10个」
　「尽力查未过——其治不是补字，是回第4轮深掘」——**器自己开的药方。**
★★**挖到一层之判得死（三样缺一不算）**：①是白文里已有的东西之下一层，不是从外头搬新事进来；
　②落成一个动作或一个物，不是落成一句判语；③有原场撑（凡引必印·坑㉕）。
★★★**补的是一层，不是一段**：能用一拍说完的不许用三拍；
　**补完那一拍若删得掉而全章不塌，它就不是一层，是废话。**
★★★★**不许为了让「长了几个字」这个数好看而补**——挖不出就写「本路已到底」并写明问到哪一步。

用法：`Workflow({scriptPath:'工具/席/深掘.js', args:{章:306}})`

## 七·`连贯席.js` —— **一段十来章之线走得顺不顺**（0909 立·作者令「从第一章到最后一章剧情要连贯」）

**其位**：一段一席，只读白文，判落到章号与拍号。**与读席同族而所读者不同**：
读席读一章之内的堵，**连贯席读章与章之间的线**。
★**其立之由**：`接口验.py` 只验「上一章末句 vs 圣经之锚」——**句子层面的缝**；
　而「从头到尾这条线走不走得顺」它查不到，**且四把机器之尺同日全败**（机制总审§三十）——
　**能量准的只有不许看答案的那只眼。**
★★**只找三样**：断层（立了没交代去哪儿）／失速（连着几章没有一样东西往前动一格）／
　倒挂（后头当理所当然的，前头从来没给过——**读者手里没有那张牌，而书当他有**）。
　★事实之相犯不归它（那有器在守），**它守的是「读者手里有没有牌」。**
★★★另交两样：**spine**（这一段的脊，一句话）——**写不出来本身就是最大的一条判**；
　**best_join**（接得最好的那一处章与章之交）。

用法：`Workflow({scriptPath:'工具/席/连贯席.js', args:{段:[[296,305],[286,295]]}})`

## 七·`无伤席.js` —— **治「无真伤之轮达N个」**（0909 立）

**其位**：一轮一席，回去重读那一轮。★**其立之由**：`--十一轮` 报
「无真伤之轮达N个（≥5）——远低於全书基线（**全书152份回执实测：各轮含真伤之比例 60%—76%**），
**须逐轮说明何以皆无，否则视为应付**」。
★★**二者必居其一**：①逮出那一轮本该逮着的真伤（能只删不添地治就治）；②写出**它凭什么无伤**，须有可数之据。
★★★**「本轮无真伤」五个字本身不算答**，「已核过一遍」「判合」亦不算——**那正是这道闸为之而立的那一样。**
★★★★**说不出可数的东西就写「答不出，缺哪一样据」**——那是有用的答案。

用法：`Workflow({scriptPath:'工具/席/无伤席.js', args:{章:309, 轮:[1,2,5,6,7,8,9,10,11,12]}})`

## 八·`救章.js` —— **治总核之三红：无真伤之轮≥5／层薄／对数不足**（0911 立·连三章同形逼出来的）

**其位**：**十一段席跑完、而 `跑轮.py --总核 N` 不过**——这一席接在那儿。
★**其立之由（实账，非推想）**：**310／311／312 连三章栽在同一形上**（无真伤之轮 11／12／10 个）——
**同一形连三章，那就不是这三章的事，是流水线的事**；而本坐这三章各手搭了一遍同样的救法，
**第三遍搭完才明白：它该是一件常在的器，不是每回临时拼的。**
★★**其形**：**深掘三路（物／数／人）＋无伤席十轮**，两段并行。
　· 深掘落层须过**三条判死**：白文有下一层可依／落成动作或物／有原场撑；
　　⛔**挖不出是可以交的答案；挖一层假的不是。**
　· 无伤席**二者必居其一**：逮出真伤，或交**可数之凭**——
　　⛔**「本轮无真伤」六个字不算答，「逐条核过皆合」也不算。拿数说话，不拿形容词说话。**
★★★**并钉一条**：⛔**不许为了「有所获」而造一处伤——造出来的伤比没有更贵。**

用法：`Workflow({scriptPath:'工具/席/救章.js', args:{章:313}})`
★**跑毕须办三件**（本坐三回皆栽在这上头）：①`git add -A && git commit`
②`跑轮.py --补存 N "终版回补·…"`（不然总核报「正文与末版已偏」）
③**把各轮所逮写回「## 第N轮」那一块里**——⛔**写在末尾那一节不算**：
**器读的是块，不是行号；东西写对了，位子放错了，在账上就等於没写**（0910 本坐实栽一回）。

## 九·`收尾.js` —— **总核过了而全测仍红者**（0911 立）

**其位**：**总核与第十一轮俱过、而 `全测.py` 仍红**——这一席接在那儿，直办到推成为止。
★**其职之要害是分病**：每一条红先判它是**闸之病／测之病／真账之欠**，三者之治各不相同：
　· **真账之欠** → **干活**（立档、补记、登还）——**判据一字不动**（0911 之销立门、站账闸皆此类）；
　· **测之病** → 治那一份测，**并写清「它何以今日方红」**（0911 之 FS认账、承前闸皆此类）；
　· **闸之病** → 照第一律：**活干完再动闸，且同日立负测、旧局回灌须照旧判红**。
★★⛔**不许 ZM_SKIP_HOOK、不许 --no-verify、不许改闸自赦。**
★★★**办毕四条须真跑**：`存底 --存／--标 N／--演 N`＋`云端验.py`——
　**`--演` 是真去克隆一份下来逐档比：没有演过的备份不算备份。**
★★★★**凑不出、办不成者，照实说「我今天走不出来」并写明卡在哪一条**——
　**0911 之铁底即此形：312 缺 79 字，它择了豁免而照实说「我答不出第四条深掘」，那是对的。**

用法：`Workflow({scriptPath:'工具/席/收尾.js', args:{章:313}})`

## §十 `一路.js`（单派深掘之一路·0912 立）

**何时用**：**第4轮三路并跑，而有一路之轮记在盘上不在了**——
⛔**三席同写一档，後写者把先写者盖没了**（0912·321 之实：物路、人路俱在，**数路一个字不剩**，
其活遂等於没干，而 workflow 报 0 error——**它跑过，只是写没了**）。

**怎么用**：`Workflow({scriptPath:'工具/席/一路.js', args:{章:N, 路:'数'}})`（路取 物／数／人）。

**它与救章席之别**：**救章席三路全跑＋无伤席十轮**（整章抢救）；
**一路席只补一路**（⛔**别路已落之笔一字不许动**）——**丢哪一路补哪一路，不重跑已办之工。**

★**而其根已同日治在 `一章.js` 里**：**三路各自起块（`## 第4轮·深掘·X路`），
落笔毕须 `grep -c` 自验其块在不在，得 0 即当场重写再验**——
**器按轮号归块，三路同号自会并成第4轮一块，故各起各的块不碍其归并。**
