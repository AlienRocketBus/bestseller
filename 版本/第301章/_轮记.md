## 〇·六问（净重<5000须逐条答毕·质量三闸①之e）

1. **本章之一事**：**他今天非核一个旧数不可；而核它只有一样不靠手的东西；而那一样东西一量，他这一百多天量出来的数就都得重问一遍。**
2. **本章翻掉了什么**：**翻掉的是「他量出来的数就是那样东西的数」这一条**——★**这一条二九九还在用**（**水下十处、顶住三处、三天二十九二十五十**，逐个都是那只手报的）；★★**今天他拿一根不会变的针一比，那一条就不作数了**；★★★**而翻掉它的不是一个道理，是指甲边上白了的那一圈。**
3. **手上那件事摆完了没有**：**摆完了。**★**其序自水上起（细纹十层／十一处／顶住四处）→ 要写第八行 → 写之前得先知道第七行在哪儿 → 指甲搁进去 → 三处松而昨天两处松 → 而今天只多写了一行 → 指甲白了一圈 → 借针 → 两个数不一样 → 十个数一个也重量不了 → 三样都没落 → 同一根针量担架 → 记下一针加一掐 → 明天再量一回**；★★**每一步都在手上，无一步在心里。**
4. **有没有一样是从别处来的**：**没有。**★**那根针是钱满自二九三起擦过、包过、拿它听过的那一根**（**场里现成的一样死物**·冷轮二九七之硬条其二明禁天降）；★★**担架、毡子、刘二擦手之次序，四样俱出二九一之原场，逐样 grep 过**；★★★**而本章无一件新物。**
5. **还有哪一层是我知道、却没写进去的**（**六问之要害**）：**有一层，本轮有意不写。**
   ★**那一层是**：**若他这一百多天的数量的是他自己那只手，那么二九九那一句「我数到第几处，就是第几处」，说的也不是水底下那样东西，是他数数的那个法子**；★★**即：他重立的那一副法，立的可能还是同一把尺**；★★★**而本轮不写它之由有二**：**其一，冷轮二九七之硬条其三明禁一章之内既撞见又解决**——**这一层一落，他就得当场另立一副法**；**其二，这一层是第4轮·深掘该掘的，本轮先掘出来写进正文，第4轮就没有底可探了**（**掘到底再写，不是写完再掘**）。
   ★★★★**故本轮只把它记在此处，留第4轮。**
6. **收章只留一样，留的是哪一样**：**留的是「明天这一行底下会有第二行；而上头那十个数没有第二行」**——★**不是留一个悬念，是留一个格子**：**一把新尺量出来的头一个数，它的价值不在它准，在它明天还量得着**；★★**而那十个旧数的价值今天没有减一分，只是它们各是一行，各自一行，谁也证不了谁。**
