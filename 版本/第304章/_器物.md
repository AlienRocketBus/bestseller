# 第304章 · 器物册（第6轮·资源庭所立）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号
#   ★「出」只认去处，不认变，也不认在场；★★而每一格之拍号，那一拍的白文里须真有其名。
#   第6轮立册时全章 166 拍。

碗｜入=67｜用=68｜出=110
册子｜入=16｜用=123｜出=160

★ **逐件之注（引文逐字取自白文）**

★ **碗**：入＝拍67（碗端到床边）｜用＝拍68（她一只手托着他的后脑，托起来一寸，一只手把碗沿贴上去）｜出＝拍110（水从碗口那一边先出去，铺开，走到印子的边上停了一停，才漫过去）。
★★ **而本章之碗有二回来去，此册只立其一，其由须写死**：**头一回是药碗**（入67／用68／出90·碗端出去，走到墙根那儿泼）；**第二回是水碗**（入99·她把碗拿回屋，在缸里舀了一碗／用101至102·端着碗站到门口，碗里的水没有动／出110）。
★★★ **而二回同一只碗，非二物**——★**故不作二行**（**若作二行，则「碗」这一件在一章之内入两回出两回，读来是两只碗**）；★★**取其第二回为册上之三格，其由是「本章之判落在第二回」**：**头一回泼在墙根，那一处她一回也没读过；第二回泼在门口，而门口那一圈正是本章之器。**
★★★★ **而头一回之出（拍90）不销，其位在尾节**：**它是本章唯一一处「泼而不读」，与第二回之「泼了才读得出」正相对。**

★ **册子**：入＝拍16（她起来，把手在裤子上擦干，从怀里把册子抽出来，翻到八十四页）｜用＝拍123（她把册子举高一点，指头从那一页最上头那一行往下走）｜出＝拍160（她把笔搁回册子旁边，笔尖朝里。册子合上，塞回被子角里，卷口朝里，掖了两下）。
★★ **而其第二回之取在拍139（她回屋，把册子摊在膝上），第三回之举在拍150（她把册子举到窗那边看）**，**同一件事之第二、三回，不另立一格**。

★ **笔**：入＝拍143（她把笔尖蘸了）｜用＝拍143（在那个「五」底下写：一）｜出＝拍160（她把笔搁回册子旁边，笔尖朝里）。
★★ **而其入与用同在一拍，此係本章之实，非漏格**：**蘸与写是一个动作的两半**；★★★**而它全章只出现三拍（30、143、160）**——★**拍30 之「末一笔」是石头上那一半木头之笔画，不是这一支笔**（**同名异物，故不计入其来去**）。

★★★ **尾节·不入册者，逐样写明其由**（其式承303之尾节）

★ **柴**（占拍1、32、42、53、56、78、163、164）——★**不入册，且其数是本章之骨**：**它没有「入」**——**门口没有柴，昨天没有，前天三根，大前天没有**；★★**故本章之柴只有「用」与「尽」**（半根塞进灶膛／柴是她自己少放的／灶边上没有柴了）；★★★**而一件只出不进的东西，册上那三格填不满**——**这一样不是漏报，是本章之事**：**明天煨药，她还得有柴。**
★ **罐**（占拍3、44、46、50、57）——★**不入册**：**它一天没有离过灶**；★★**其读数是水开数到几（一百三十三），不是来去**。
★ **缸**（占拍99、100）——★**不入册，而其读数今日头一回出现**：**缸里的水到了这一格，比早上低半指**；★★**它是本章唯一一样「她没有量而顺手看了一眼」的东西**——★★★**记此，其位留与后章。**
★ **瓢**（占拍1、43）——★**不入册**：**「一瓢水」是本章之题，而白文里她端的是碗**；★★**拍43「她端了半瓢水进屋」係煨药之水，其量词非其物。**
★ **「鞋」**（占拍11、12、14、25·身上的尺）——★**不入册，入尾节**：**它长在她脚上，没有来去**；★★**而本章之判之半落在它上头**：**她把鞋搁上去挨着比，它比她的鞋长出一节，鞋尖朝里**；★★★**其读数**：**长出一节（拍12）｜脚后跟离印子的尾还有一截，这一截够她的指甲搁进去两回（拍25）**。
★ **「指甲」**（占拍26、108、147、149、156·身上的尺）——★**不入册，入尾节**：**同上，长在她手上**；★★**其读数**：**够搁进去两回（拍26）｜掐进去半点（拍147）｜比头一道短（拍149）｜刮出来的是一片毛，比原来那一道宽（拍156）**。
★ **「手」**（身上的尺·占拍2 等处·器所提之疑，当场答）——★**不入册，入尾节**：**它是本章诸尺之根**（**鞋、指甲、指头，逐样长在它上头**）；★★**而本章之判正落在它上头**：**抹得掉的那一样，是她抹的**——**那一瓢水是这只手泼的，那两道掐是这只手掐的**；★★★**其读数**：**她拿手比了一下（拍2·量灶边那半根）｜她拿手背在灰上按了一下，按下去不烫（拍42）｜她把手在裤子上擦干（拍16）｜她把短的那一道拿指头按平，按不平（拍155）**；★★★★**故它一天之内量了四样，而末了那一样它按不平**——**这只手今天头一回按不动自己刚做出来的东西。**

★ **石头上那一半木头**（占拍29、37、38、39）——★**不入册**：**她挪开一点又搁回去，其位未动**；★★**而它是本章之判的第三身**：**看它就得挪它，而挪了它底下那一块浅的就没了；她把它盖回去。**
★ **被子**（占拍80、81、82、160）——★**不入册**：**它今天在床上那一个人身上，不在她手上**；★★**而其末一处（塞回被子角里）係册子之去处，不是被子之用。**
