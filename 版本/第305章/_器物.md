# 第305章 · 器物册（第6轮·资源庭所立）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号
#   ★「出」只认去处，不认变，也不认在场；★★而每一格之拍号，那一拍的白文里须真有其名。
#   第6轮立册时全章 137 拍。

钥匙｜入=11｜用=47｜出=131
针｜入=59｜用=66｜出=129

★ **逐件之注（引文逐字取自白文）**

★ **钥匙**：入＝拍11（那把钥匙搁在最底下，齿口朝里，红绳绕了两圈压在柄上）｜用＝拍47（我把钥匙的齿口抵在页边上，往下走……十个数走下来，钥匙停了十回）｜出＝拍131（那把钥匙我没有收回油布）。
★★ **而其「出」之去处写在下一拍**（拍132：**我把它搁在本子外头，齿口朝外，红绳那一头压在下面**）：★**取拍131 为其格，係因器逐字验其名在，而拍132 之白文只作「它」**；★★**二拍是一件事的两半：先说它没有回哪儿，再说它去了哪儿。**
★★★ **而此一件之来去，正是本章之判在物上的样子**：**它早上从油布里出来（拍11·齿口朝里，挨着油布）**；**它晚上没有回去（拍131至133·齿口朝外，红绳那一头压在下面；昨天它在油布里头，齿口朝里）**——★**同一件东西，朝向掉了个个儿**；★★**而末了那一句「我不知道明天它在哪儿」（拍134），是本章唯一一处他连一个位子也报不出来的东西。**

★ **针**：入＝拍59（钱满坐在石头上，那块布摊在膝上，针横在布上）｜用＝拍66（我把手抽回来，换针。针尖顶上去，耳朵贴针尾）｜出＝拍129（下。而下去要带两样：手和针）。
★★ **而此一格须当场说破，不许拿绿糊过去**（§一⑤）：**器所验者只两样——那一拍上有没有「针」这个字、三格之序倒没倒**；★**而「针还了没有」它验不着。**
★★★ **其实**：**本章之针没有还给钱满**——★**而303 之针是当章还的（303拍38：我把针还给钱满。他接过去，横回布上）**；★★**故此处是本书借针之礼头一回没有走完。**
★★★★ **而它不是漏写，是白文自己报了出来**（拍129：**下去要带两样：手和针**）——★**读者看得见他手上还攥着别人的东西**；★★**而这一样今日不治，留第10轮·收官轮再问一回**（其器仍係 `python3 工具/器物点名.py 305`，★**而须连 303 之实一并比**）。

★★★ **尾节·不入册者，逐样写明其由**（其式承304之尾节）

★ **本子**（占拍25、113、122、132、137）——★**不入册，入尾节，其由是它今天没有「出」**：**入＝拍25（本子摊在膝上）｜用＝拍123（翻到第八行底下那一空行，写今天那一行）**；★★**而其三格填不满**：**303 之本子当章收了（303拍149：本子合上，收回怀里）**；**本章之本子合过一回（拍113），而後又打开（拍122），末了没有再收。**
★★ **而这一样不是漏报，是本章之事**：**明天那两行要写在它上头**（拍129：**一处两个数，写两行**）；★**故今天它不必回怀里**；★★**而全章末一句正落在它上头**（拍137：**本子上多出来的是十道白**）——**一本没有收起来的账，末一句还在往上添东西。**
★★★ **而三件器物合看，本章有一样是共的**：**钥匙没有回油布，针没有还钱满，本子没有收回怀里**——★**今天没有一件东西回到它来的地方**；★★**其由在拍128至129**：**这一天没有完**——**他早上那一问到这会儿才有答，而答是「下」。**

★ **油布**（占拍2、5、9、11、14、15、18、131、133）——★**不入册**：**它是那三样东西的处所，不是他手上过的东西**；★★**而其读数是本章之起手**（**外头那一层有一块是软的｜昨天不软｜按到底下第二层才停｜里头那一层干的**）；★★★**器另提「布」占10拍**——★**其中拍59、60 之「布」係钱满膝上那块，与油布非一物**（**同名异物，故不计入其来去**）。

★ **红绳**（占拍11、19、132、136·器所提之「绳」占4拍）——★**不入册**：**它绕在钥匙柄上，不离其身**；★★**而它是本章唯一一样自己在变的东西**：**颜色比头一回见它的时候浅（拍19）｜比早上又浅一点（拍136）**——★★★**一天之内量了两回，而两回都不是他动手量的，是眼睛看出来的**；★**故它与本章之判正相对**：**本章满章都是「拿什么量的」，而它是那一样不用尺也看得出在变的。**

★ **「手」**（身上的尺·占拍7、12、35、43、45、64、65、66、88、96、99、100、103、129·器所提「什么」（拍76）之疑，当场答）——★**不入册，入尾节**：**它长在他身上，没有来去**；★★**而器所疑之「什么」（拍76：我写它们的时候，没有写拿什么量的）不是一件器物，是本章之一事的问法本身**——★**故不入册，亦不入尾节之尺**；★★**而本章真正那把「身上的尺」是指甲**（拍26、43、45、89、90、96、101、102）：★★★**其读数**：**卡进去半分就到底（拍43）｜掐进去半分，纸上那一道白起了毛（拍90）｜磨掉了一点，边上有一线白（拍101）｜这一线是弯的，纸上那十道白是直的（拍102）**；★★★★**故这一片指甲今天做了两样事**：**量了钥匙，又在纸上留了十道**——**而它自己也磨掉了一点。**

★ **石头**（占拍17、58、59、114、135）——★**不入册**：**它是本章之场**；★★**而其读数有二**：**它比钥匙暖（拍17·石头一夜下来是从底下凉上去的，摸久了手底下会回一点温）｜日头上到坡顶那块石头（拍135·本章唯一一处天光之钟）。**
