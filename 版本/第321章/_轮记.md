# 第321章 · 轮记

## 〇·六问（0912·321案席补记於轮记之首；⛔净重 2,185＜5,000，故此六问非虚文，须逐条举证）

1. **本章之一事**：**她为取那只底平的罐，头一回把靠墙那一堆柴挪开，量出它到墙上哪一道。**（拍38「罐底平。」起意→拍41 走到墙那一头→拍48 挪柴取罐→拍50—59 松手、手停在旧高度、平移贴墙、指甲划第二道。⛔**全章之量只此一个**，合 COLD318 §三②「数与比择一」。）
2. **这一事把什么翻掉了**：翻掉的是她那本册子的记法。**第107章立「本子上写下的每一个数，都是别人身上的」**，而 318 立「她那一行只盛三样」——今天第四样没有格子（拍75—79：一行三格，填上一格，空着两格），**因为它是头一个会自己往下走的数**。⛔**这一层白文一个判字也没有**（「她这才明白」「原来只剩这些了」逐类亲数皆零）。
3. **该摆的都摆完了没有**：摆完了，逐样点名——**其一**，取之由（拍34—37：一只手托人、一只手端碗、第三只手按册子；床沿窄、碗底圆、搁上去要倒）；**其二**，柴堆之位（拍40「第一百一十日抱进来的那三根，立的就是那一处」，承 `318:37` 唯一一处「靠墙立着」）；**其三**，`F028` 之滞（拍48「那一条胳膊往上送，送到一半停了一下」，方向翻了而滞还在）；**其四**，两道印子各由其自己那一拍报出（拍57 蹭出来的／拍58 她亲划的），白文无一拍把它们合起来再说一遍。
4. **有没有一样是别处来的（本章担不起而硬塞进来的）**：**有二，皆已挡在门外**。**其一**，「一指」——係在役量器（`312:152`／`319:61`／`319:73` 等十余处），定魂席当场弃之，改由那只手自身充当尺（白文「一指」亲数 **0**）。**其二**，大问「寨里那些人」＋「寨老」——其线已挂沈鸢，本章确有位可兑，⛔**而不塞（与一事争位，且二册相犯未裁·据不够）**，逐笔写进悬账交作者裁（白文「寨老」亲数 **0**）。
5. **还有哪一层是我知道、却没写进去的**（⛔此问最要紧，须说实话）：**有三层，逐层说明何以不写**。**其一，那一堆为什么会矮**——她一根未烧（拍7「灶边上没有添一根」、拍67「灶边上那一块地方还是那一块」），故它只进不出而仍矮，这一层白文一个字不解说；⛔**其所以不写：一写即是替读者把减法做完（COLD318 §三③明禁）**；★**而本席认它是全章最薄的一根承重**，原样报上，不拿一句话把它焊死。**其二，那个搁柴的人**——他今天来没来、他为什么送、他手上那些刀口，白文一字不及（「他没有来」四字永禁·亲数 0）；⛔**其所以不写：圣经明令「老头未禁然宜缓——一开即收不回」。**　**其三，他那边的事**——那把钥匙、水退了半掌、他捏了第三回，**她一个字也不知道**（`圣经:7408②` 二线不通消息；苏衍／刘二／东头／钱满／钥匙／地窖白文逐名亲数皆 **0**）。
6. **若只留一样给读者带走，留哪一样**：**留拍52—53 那只手**——「她的手没有跟着下来。／手还停在原来那个高度上，指头虚虚地拢着，拢着一把已经不在那儿的柴。」★**其所以留它**：全章唯一一处把抽象接住而不说破的地方——「这一堆会烧完」这一整个念头白文零字，全落在一只停在已经没有东西的高度上的手；★★**且它不是一句好看的独句，是下一拍的来路**：正因手还停在那个高度，拍55 才平移贴墙，拍57 那一道才量得出来，拍95 才有得比。

#### 刀一 · **正文 93 行（拍23）——两个数的日号对调了**　【坑①相对日词／坑⑬这个数是谁的账】
