# 第326章 · 器物册（第10轮·收官·器物总账庭重立；原册係第3轮·机闸席所立）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加 ｜主=人名）
#   ★「出」只认去处，不认变，也不认在场；★★每一格之拍号，那一拍的白文里须真有其名（不是「它」）。
#   ★★★名照白文之名取，不另造（坑㉚）。
#   ★★★★立册时全章 54 拍。★第2轮·四堂会审删一拍（「那两行是空着的，行距是照着上头那些行留的」·越权近交尽），54→53；
#     ★★本轮·逐段生死复删一拍（「昨天鼓起来的是布，昨天扣了两下」·全章唯一一拍纯回想，且係替读者接账），53→52。
#   ★★★★★**本册之号不是拿旧号减出来的，是重扫一回白文取的**（303第11、12两轮所立之法）：
#     本子 出53→51｜那把铜 入46→45、用46→45、出48→47｜绳 入35→34、用36→35、出52→50｜那一样东西 入31→30、用34→33、出51→49。
#     （重扫之法：正文按「＊」切拍，逐名 `in` 亲搜，见本轮轮记所印之表。）

★ **逐件之注（引文逐字取自白文·本席亲印）**

★ **本子**（占拍1、4、5、10、47、51）：入＝拍1（**本子昨夜压在那件叠起来的衣裳底下。**）｜用＝拍5（**本子摊开在膝头上，摆正。**）｜出＝拍52（**我把本子合上，拿布包住，塞回那件叠起来的衣裳底下。纸边露在外头一线。**）｜主＝我。
★★ **三格填满，礼走完，且这一件正是本章所销之悬账**：第三百二十四章之器物册自书「本子 出=拍57（开口：白文只书合上，未书搁回哪儿去）」——本章拍1 交昨夜之去处、拍52 交今夜之去处，**昨夜与今夜是同一处**（衣裳底下），那一格自此闭合。
★★★★ ⚠**案席当笔改齐一处·全册拍号自拍39起顺延一号**：本册立於第10轮（其时全章52拍），⛔**而第13轮·升华定稿轮在旧拍三十八之後新落一拍**（**本子还摊在我膝上。前头那一叠鼓着，本子在膝上摆不平，靠水那一边高。我拿手按了一回，松开，还是高那么些。**＝新拍39），**全章由52拍成53拍**；★**极限席自书「器物册四件十二格重算」而实未改，遂有全测「器物册·逐章回灌」报红：本子之「出」指拍51 而那一拍白文无「本子」三字**。★★**案席重扫一回白文亲数**（`in` 逐名搜，非拿旧号加出来）：**本子占拍1、4、5、10、39、48、52｜那把铜占拍4、46、48｜绳（刘二）占拍34、35、37、38、51｜那一样东西占拍30、33、50**——⛔**凡拍号≥39者各加一，其下者一个不动。**★★★**并及新拍39 亦是本子之一现**：**它摊在膝上、鼓着、按一回还是高那么些**——⛔**其「用」格仍取拍5（摊开摆正），不取拍39**：拍39 那一下手按的是本子之**厚薄**，与拍48「鼓的不是那把铜，是本子」同类，**係以厚薄现形，不是被手拿着去办一件事**。
★★★ ⛔**并记一处「不是它」**：拍48「**鼓的不是那把铜，是本子**」——本子在那一拍上是以**厚薄**现形，不是被手拿着；故其「用」格不取拍48。

★ **那把铜**（占拍46、47）：入＝拍46（**我把那把铜拿起来，摊开油布。**）｜用＝拍46（同上·取起即摊布要裹）｜出＝拍48（**鼓的不是那把铜，是本子。**）｜主＝我。
★★ ⚠**三格之号只取白文里真有「那把铜」三字的那两拍**（§一⑤·坑㉕之反面）：**裹与扣落在拍47（「三层裹好，扣上内袋。」），而那一拍上「那把铜」三字不在**——⛔本席不把拍47 填进格里：**一个抄来的号比一个空格坏。**
★★★ **而「出」取拍48 不是将就**：那一拍是隔着内袋外头按下去的，**它以名报回来的正是它的去处（已在袋中，且鼓的不是它）**——去处有其名，礼走完了。

★ **绳**（刘二之绳·占拍34、35、37、38、50）：入＝拍34（**刘二从石头上把绳取下来。**）｜用＝拍35（**他把绳上左肩。**）｜出＝拍51（**他走到石头跟前，没有把绳搭上去，绳还在手上。**）｜主＝刘二。
★★ ⛔**这一件之礼没有走完，本席当场写出来，不拿绿糊过去**（§一⑤）：**它早上从石头上下来（拍34），夜里没有回石头上去（拍51）**——★**器只验「绳」这个字在不在、三格之序倒没倒，它验不着「还回原处没有」**；★★**而白文自己把这一样报了出来**：「没有把绳搭上去，绳还在手上」——**读者看得见他手上攥着一样本该搁回去的东西**，这与第三百〇五章「针没有还给钱满」是同一种没走完；★★★**不同的是**：305 那一件是漏在暗处，**本章这一件是当面写的**（叙者把「没有搭上去」写成了动作），故**不是账上的缺，是下一章的口**。
★★★ ⚠**同名异物，本席当面报出器之一处盲**：器数「绳」占7拍（4、34、35、37、38、41、50），★**其中拍4 之「红绳」係压在钥匙柄下那一根**，★★**拍42 之「绳」係钱满拿来绕纸卷的那一根**——**三者同名而非一物**；⛔**本册三格只认刘二那一根**（承305「钱满膝上那块布与油布同名异物，故不计入其来去」之例）。

★ **那一样东西**（占拍30、33、49）：入＝拍30（**他把那一样东西拿起来，翻了个个儿，窝朝下扣在石头上。**）｜用＝拍33（**水面上的光……挪到那一样东西跟前。扣着的那一面不吃光。**）｜出＝拍50（**那一样东西在我左手边，窝朝下。**）
★★ ⚠**这一件之「用」格须当面说破，不许含糊**：拍33 不是一只手在用它，**是光在验它**——★**全章没有一只「我」的手碰过它**；★★而本席仍取此号为「用」格，其由是**本章验它的尺就是光**：窝朝上时（第三百二十四章）「窝里头亮起来一线」，窝朝下时光从旁边过去、它底下那一块不亮——**同一盏尺，读数掉了个个儿**；★★★**若後庭判此格当空，本席不驳**：空格比假号好，而器所验者只名之在否。
★★★ **无主**：⛔**本章不许替它认主**——翻它的那个人「没有把它拿走」（拍31），末了它在「我」左手边而不在我手上（拍50）；**谁的东西，第三百二十二章立限至今未答，本章亦不代答。**
★★★★ **物位账随之走**：第三百二十二章第二百一十七行「窝朝上」，第三百二十四章仍窝朝上，**本章起窝朝下**（拍30 立、拍50 复验，一日之内头尾各一回）。

★★★ **尾节·不入册者，逐样写明其由**（其式承304、305之尾节）

★ **那张纸／那一卷**（钱满·占拍42、42）——⛔**不入册，而这是本章第二件礼没走完的东西，本席一并当面报出**：**入＝拍42（他把那张纸卷起来，卷到头，拿绳绕了两道）**；★**而「用」与「出」两格取不着号**：拍43 白文作「**那一卷**」，「那张纸」三字不在——⛔**本席不拿「那一卷」去顶「那张纸」的格**（坑㉚·名照白文之名取，不另造），**宁可报一个取不着，不报一个凑出来的号**。
★★ **其礼之实**：**卷了、绕了两道、立在腿边上、倒了一点、扶正、又倒、他就让它倒着**（拍43）——★**没有收，没有交给谁，没有搁回哪儿**；★★**而这一件与刘二那根绳合看，本章有一样是共的**：**绳没有回石头，纸卷没有立住也没有收，本子回了衣裳底下，铜回了内袋**——★★★**他自己的两样东西今天都回了原处；别人手上那两样都没有。**

★ **布**（占拍1、4、45、51）——★**不入册，其由是同名两物**：**拍1 与拍52 之「布」係裹本子那一块（今早先摸着它，今夜拿它包住）**；**拍4 与拍46 之「布」係「油布」二字里的布，非一物**。★★**而裹本子那一块之三格若强填，必是「用＝出＝拍52」**——⛔**一拍顶两格，本席不填**。

★ **钥匙**（占拍4·红绳同拍）——★**不入册**：**本章它一次也没有过手**，只报其位（**搁在本子外头，齿口朝外，红绳那一头压在下面。照旧不进油布。**）；★★**而这一句是在役规矩之执**（承第三百二十章）：★★★**它是全章唯一一样「今天没有动」的东西**——**满章都在量变，它在报不变。**
★★ ⛔**红绳一天比一天浅本章明写不执**：**它今日压在钥匙底下，一次也没有拿起来**；⛔不补一句「又浅一点」把账做平。

★ **油布**（占拍4、45）——★**不入册**：**它是那把铜的处所，不是他手上过的一件事**；★★**其两处正好一反一正**：**拍4「照旧不进油布」（钥匙不回它）｜拍46「摊开油布」（铜回它）**——**同一块布，一样进，一样不进。**

★ **指甲**（身上的尺·占拍20、21、22、24）——★**不入册，入尾节**：**它长在他身上，没有来去**（承305之例）；★★**而本章之量全在它与拇指两样上**：**塞得进（拍20）→碰上字脚→翻过来用背上那一条窄的再塞→还是碰上→移到那两行空的中间（拍22）→也塞不进（拍23）→拿指甲背再试一回，一样（拍24）**；★★★**而它自己也在这一趟里取走了一样东西**：**甲面上沾了一道纸灰，白的（拍21）**——★**这一道白是本章唯一一样从那一叠上下来、落到今天这只手上的东西**；⛔**而白文一个字没有说它是什么、也没有说它要紧**。

★ **拇指**（身上的第二把尺·占拍11、12、13、27）——★**不入册**：同上；★★**其读数**：**头一页刮手，刮得最重；第二页轻一点；再往下，轻一点；抹到某一页上，拇指底下是平的，不刮了（拍12）｜往回推半寸再抹一回，还是在那一页上没了（拍13）｜翻回来的时候那一层毛擦着我的拇指，擦过去，不刮手（拍27）**——★★★**一件东西被同一根指头量了三回，三回的读数一样**；★**故末拍那一句（拍53：纸边上不刮手的那一页，我今天头一回抹到了）不是判语，是这三回量出来的那一个数。**
