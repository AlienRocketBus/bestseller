# 式：器物名｜入=拍号｜用=拍号｜出=拍号（每器一行）
#   ★「出」只认去处，不认变，也不认在场。
#   ★★每一格之拍号，那一拍的白文里须真有其名（不是「它」「那一沓」「七张」）。

# ★★★★本轮之拍号係本席重扫白文取的，⛔一格也没有从别章之册减出来。
#   其法：白文止於「【本章亮点】」之前，`正文.split('＊')`（与 `工具/器物点名.py::分拍` 同一句）；

# ⛔**本席当面不填之四格，逐条写明，不掩**（其法承 版本/第341章/_器物.md 之裁）：
#   **笔｜本子｜带子｜那一副**——**四样皆无「去处」之拍**，故一样也不入册，只入尾节。
#   ①**笔**：白文占 6 拍（9・11・19・20・22・23），其末一拍逐字「划到一半笔尖陷了一线」——**是用，不是去处**；
#     **全章没有一拍写它搁回本子里**，⛔**故不许拿拍23 填「出」去换一个绿**。
#   ②**本子**：只 2 拍（9・26），拍26 逐字「这一样叫什么，本子上没有一个字」——**是在场**，无去处。
#   ③**带子**：2 拍（14・29），拍29 逐字「扣带子的时候我左手扶在捆的一头」——**是用，不是去处**。
#   ④**那一副**：占 4 拍（2・12・25・27），**不在这一双手上**（是刘二与东头抬的），承 305 油布之判，不入册。
#   ★★**并及「那一样」（手上那一件与柄头那一件）白文无名**，⛔**不许本席替它造一个名入册**——承坑㉚。

捆｜入=2｜用=3｜出=31
纸｜入=7｜用=11｜出=12

★ **逐件之注（引文逐字取自白文）**

★ **捆**：入＝拍2（**我背着捆，跟在他们後面**）｜用＝拍3（**我把捆卸到石上，没有放平**）｜出＝拍31（**上肩，走三步，站住。捆没有晃**）。
★★ **其「用」取拍3 而不取拍13**：**拍13（我解开重打了一遍）是重办，拍3 才是今日这一件头一回被这一双手办**——
　**而拍3 那一下正是本章立得住的那一处**：⛔**不放平**，立着靠石，朝上那一面还朝上；
　其由白文当场自书「**昨天在坡上放平过一回，放平以後结就落到底下去，手得伸到底下去摸**」。
　★**故拍4 得「一挑就着，手没有伸到底下去」——昨天不成今天成，成的是同一双手改了一个放法。**
★★★ **其「出」取拍31 而不取拍13**：**两拍皆有「上肩」，而拍13 之後它又被卸下来一回（拍17「我把捆卸到路边」）**；
　**拍31 是全章末一次上肩，其後不再落地**，⛔**故取它，不取中途那一次。**

★ **纸**：入＝拍7（**乌的地方纸薄，举起来对着天光，那一块比别处透**）｜用＝拍11（**我在那个点上划，笔尖从左下往右上走**）｜出＝拍12（**我把摊在石上的纸按方才那个次序收起来……一齐压回结底下**）。
★★ ⛔**「入」这一格本席当面报一处不圆满，不掩**：**这一沓真进手是在拍5（「那一沓抽出来的时候次序没有乱」）**，
　**而拍5 白文通篇作「那一沓」「一张一张」「七张」，「纸」这个字一次也没有**；
　★**式之明文写着「那一拍的白文里须真有其名」**，⛔**故不许把「入」填到拍5 去**；**「纸」这个字头一回出现是拍7。**
　★★**并及此非白文之病，是白文在守坑二十八之先说後数**：**七这个数头一回出现在拍5「数：七。」，其後方用定指。**
★★★ ⛔**「出」这一格亦当面报其不尽**：**拍12 是真去处（压回结底下），而它不是末一次**——
　**拍17 又「解结，把那一沓取出来」，拍31 再「七张一齐压回结底下」**；
　★**而拍31 白文作「七张」，无「纸」字**，⛔**故末一次那一格填不得**；**本席取拍12，并把这一段来回原样写在此处，不作绿论。**
　★★**这一来一回本身正是本章之咬合**：**对纸的活被换肩截断（拍12），走了一段，停下重取（拍17），
　　而回过头去接的那一拍是拍18——⛔其接不是接着往下对，是先把已划的一张一张再数一遍（「三张。三个。」）。**

# ★★★★★第10轮·收官·器物总账庭（重扫一回，非从旧册减出）

★ **本轮之刀只一处，且不在拍界上**：拍32 删十一字（「在下头那一行，压在底下，」），
　**全章仍 33 拍**，`工具/器物点名.py 342` 重跑亲印「全章 33 拍」，
　★**故上头二行之六格拍号一格未动**，本席另逐格 `awk` 复印其名在：
　捆 拍2「**我背着捆，跟在他们後面**」／拍3「**我把捆卸到石上，没有放平**」／拍31「**上肩，走三步，站住。捆没有晃**」；

★★ **⛔本庭当面报一件「礼没走完」（§一⑤·305 之祖案在此落第二例）——笔离了本子，而没有回本子。**
　★**其据全在白文，不是本席推的**：拍9 逐字「**笔在本子里夹着，我把笔抽出来，本子没有跟着出来**」；
　　其後笔占拍11、19、20、22、23，**末一拍逐字「划到一半笔尖陷了一线」**——⛔**是用，不是去处**；
　　**全章无一拍写它回过本子。**
　★★**而这一样在本书里是有礼的**，`grep -rn "笔插回" 正文/*.md`（去骨记之行）**亲数白文十处，散在十章**，逐字皆同一个动作：
　　`274:545`「我把笔插回布条里。」／`276:475`／`278:493`「我把笔插回布条，插到底，尾抵结。」／
　　`281:329`「笔插回夹缝，插到底」／`283:507`／`288:413`「把笔插回夹缝。」／
　　`284:565`「写完把笔插回夹缝。这一回插得松，待会儿还要抽。」／`285:369`「我把笔插回夹缝。今天插得比昨天紧。」／
　　`287:508`「我把笔插回去，还插那一处。」／`275:481`「她把笔插回夹缝，比抽出来紧」
　　——★**十处之中有四处还拿「插得紧／插得松」当一把尺用**（`275`／`281`／`284`／`285`）；**342 这一把尺今日一个数也没有报。**
　　★★**并及其中数处係二线之她（275・283・288），而其礼同**——**这一个收法两条线上都在守。**
　★★★**⛔故本册不许拿拍23 填「出」去换一个绿**（第3轮已立此禁，本庭复核，仍立）；
　　**而第3轮只说了「填不得」，没有说「这是一桩没走完的礼」**——★**今补这一句，并及其不是漏写**：
　　**拍26 本子出来（「我把本子拿出来，翻到今天那一页，写了两行」），写完亦未收回怀里**；
　　★★**笔与本子今日各自单走，而两样一样也没有回去**——**其形与 305 之判正是同一样：今天没有一件随身的东西回到它来的地方。**
