# 第三百六十九章 坎

《镇冢秘术》

第三百六十九章　坎

天亮起来的时候，门槛上那一个框先亮。三道墨线吃在木头里，一夜过去，颜色跟那个旧点一样黑，毛边还是毛的，没有往外再走。框里头是木头本来的颜色，纹从这一边横到那一边，当中一道粗些，发暗，别的都是细的。

＊

她坐在昨天挪过去的那个地方，膝头离框一掌。笔横在框这一边，笔尖还朝着框。册子在笔的那一边，封皮朝上，四个角齐着。她伸手拿起册子，没有掀，搁到身子另一侧的地上，封皮还朝上。又把笔拿起来，换到右手捏着。

＊

她把笔尖凑进框里，停在离木头一线的地方，照着纸上写字的样子比了一比。笔尖底下是那道粗纹。往下一点，笔尖会顺着它斜出去。她把笔提回来，搁回原处。

＊

左手的拇指翻过来，指甲朝下，落进框里，落在挨着左边那一竖的地方，贴着墨线的里侧。她往下压，压到指甲那一截泛白，拇指甲往框的里边吃进去一丝。她不抬，顺着墨线往外沿那一头拖。木头比她想的硬，指甲走一下，停一下，碰着一道细纹就往边上一偏，她把它拨回墨线边上再走。走过的地方留下一道浅白，比头发粗，比墨线细，底下的木头翻起来一点毛，拿指腹一抹就倒了。

＊

拖到一半，拖到那道粗纹上。指甲顶在纹的这一边，过不去，她又压下去一分。

床那一头响了一下，不是床板，是皮肉落在木头上的声音，闷的，一下，没有第二下。

她的拇指甲还压在木头里。先是头转过去。然後左手抬起来，指甲从那道浅白里出来，浅白停在粗纹跟前，断在那儿。她起身，右手的笔搁回框边，没有看笔尖朝着哪边。

＊

被子外头那只手不在被面上了。它从被沿滑出去，顺着床沿垂下来，手背贴着床沿的木头，五根指头朝着地，指尖离地还有一拃。垂下来的那一下，腕子磕在床沿上，磕出来的就是那一声。

她蹲下去，两只手从底下把那只手兜住，托起来。手是凉的，沉，整条胳膊的分量都坠在她掌心里。腕子上磕着的那一处先红了一块，红的当中是白的。她托着往上抬，抬过床沿，搁回被面上，搁在被子正中，离被沿有一掌远。手背朝上，指头松着，她拿自己的指头把那五根一根一根捋直了。

那一颗头在枕上，没有动。她等着。喉结那儿一起一落，一口咽下去了。

＊

她在床沿上坐下，没有带册子，也没有带笔。

腕子上磕红的那一块，挨着腕根。骨节是从腕根数起的，头一个就在红的边上。她的食指伸过去，到红的边上停住，没有落。红的当中那一点白，先是一个指甲盖大，慢慢往里收，收成一粒米，白没了，红还在，比先前淡。她的手悬在那儿，悬着不动，门槛那一头的框、框里那半截浅白，都在她身子後头。她没有回头。红从边上往里褪，褪到跟腕子别处差不多的颜色，只剩一道印子，比别处暗一点，摸上去也不高。她这才把食指落下去。

左手食指搭上那只手的腕根，从头一个骨节往那一头走，不数，走到第五个上停住。第五个底下昨天那一个陷，今天不在了，皮是平的，平得跟它两边一样。她把食指压下去，压着，嘴里数：一。二。三。松开，指头不抬，指腹贴着。

底下没有东西往上来。她往下接着数：四。五。六。七。八。九。十。

数到十，指腹底下还是空的。昨天数到这儿，她停过。今天她没有停，嘴唇接着动：十一。十二。十三。十四。十五。

数到十六，指腹底下有一丝往上顶，很轻，顶了一下，就不顶了。她把指头抬起来。那一点跟四周一样平。

十六她没有出声，压在舌头底下。

她把食指挪回第五个上，再按一回。压下去，一。二。三。松开，贴着。嘴唇动着往下走，走过十，走到十四，十五，底下还是空的。十六上没有东西。她不停，十七。到十七上，那一丝才顶上来，跟方才一样轻。

她的指头贴在那儿，没有抬。十六还压在舌头底下，十七跟着上来，两个挨着。她把指头抬起来，看了看那一处，又看了看那只手搁着的样子：手背朝上，指头松着，跟头一回按的时候一样，没有人动过它。

两个数她都含着。

第六个她没有碰。她的食指从第五个上退下来，退到腕根，从腕根离开，悬在被面上头一寸，没有搁下。

＊

她起身，回到门槛。那根食指还悬着，指头上是那一片皮的凉。她没有坐回原处，就蹲在框跟前，左手的拇指先伸出去，落进框里，落在左边那一竖跟前，落进那一道浅白的头上。

＊

指甲落进浅白里，底下有一道坎，小，可是有。她顺着往外沿拖，指甲的尖埋在坎里，左右都不偏，碰着细纹也不偏，那几道细纹从指甲底下过去，一道一道，她觉得出来，可指甲没有跟着它们走，一路顺着坎往前走，走得比她头一回划的时候快，走到粗纹跟前，坎到了头，底下一空，指甲从坎里出来，往粗纹那一边斜过去半个指甲盖，在木头上擦出一声，很小。她把拇指收回来一点，收回到坎的断头上，指甲尖抵着断头那一点毛茬，不往回退，也不挪到框角去重起。她就从断头上压下去，压过那道粗纹，粗纹硬，她压了两下才压进去，一丝木屑翻起来，粘在指甲缝边上。过了粗纹，後面的细纹又挡了几下，她一下一下拨过去，一直拖到框的那一头，拖到外沿的棱上，指甲从棱上落出去，悬空。

＊

她把拇指挪回框角，从头再落一次。指甲进了坎，从左边那一竖起，一路走，走到粗纹那儿，底下是接起来的，前头那一截浅，後头那一截深，接口上多一个小疙瘩，指甲在疙瘩上跳了一下，没有出来，接着走，走到棱上。

她把拇指抬起来，翻过来看指肚。指肚上一道印子，直的，一头浅一头深，横在指纹当中，把几道指纹截断了。

＊

她坐下来，坐回离框一掌的地方。右手去拿笔。笔还横在框边，笔尖朝着门框那一头，是她起身时搁歪的。她把它拿起来，笔尖先不往框里落，先落在坎上。

笔尖落进坎，墨从笔尖上下来，沿着坎往两头走了一点，停住。她顺着坎往前带了半寸，笔尖不偏。她把笔提起来，往坎的上头挪一指，落下去，写：十。

一横落在木头上，没有顺着那道粗纹斜出去，它是贴着坎平着走的。一竖从横的当中落下，落到坎上收住，墨在坎里汇成一小颗，没有往下洇。

十写完，框里靠左这一边就满了。靠右那一边还空着，空出来半指。她把笔往右挪，挪进那半指里，写：六。六的那一点落得重，末了两笔往两边分开，右边那一笔的脚挨着框的墨线，差一丝没有碰上。

＊

她把笔尖往下挪，挪到坎的底下。坎跟外沿那道棱中间只剩一窄条，比一个字矮。她把字压扁了写：拿数数量的。笔尖往右接着走，走到该写量两回的地方，停了。停了一口气的工夫，没有写那三个字，写：第一百三十六日。七个字挤着，一个比一个小，末一个日字的最後一横落在框右边那一竖的脚下，挨着墨线，没有压上去。

＊

她把笔搁下，搁在框这一边，笔尖朝框。墨干得慢，她蹲着看。十六两个字从亮往暗走，先是六的那一点暗了，然後是十的那一竖。坎里那一小颗墨最後干，干了，坎还在它底下，看得出一道。

＊

十七还在她嘴里。框里没有地方了，三边的墨线里，横的竖的全是字。她的眼睛从框右边那一竖往外挪，挪到框外头。那一截门槛是光的，纹从框底下钻出来，接着往门框那一头走，上头什么也没有。她把笔拿起来，笔尖朝那一截木头伸出去，伸了半截，停住，又收回来，搁回框边。

身子另一侧，册子还在地上，封皮朝上。她没有去拿。

＊

她把左手的拇指落进坎里，从左边那一竖起，一路拖到棱上。在接口那儿，指甲跳了一下。

拇指从坎里抬起来，指甲缝里卡着一丝木头。

【本章亮点】

- 日号：第一百三十六日（日字式·367:51「第一百三十五日」加一；白文出一处，在第87行框下之注）。白文「昨天」三处：①「昨天挪过去的那个地方」指 367:87 挪坐；②「第五个底下昨天那一个陷」指 367:31「陷着…没有回来」；③「昨天数到这儿，她停过」指 367:39／:43「数到十…她不数了」。三处皆第一百三十五日，皆 367 所载。
- 之魂：367 留下的空框，读者当是册子写满後续出来的「明天那一格」；本章把它翻成一把尺——拇指甲沿框里侧划出一道坎，数从此不靠手去卡，存进门槛的木头里。册子全章不开（搁在地上，封皮朝上），367:99「册子没有再打开」是退场，不是歇气。
- 咬合：回门槛，拇指甲落回半截坎的断头接着划，不从头起（拍号：第67行·逐字「指甲尖抵着断头那一点毛茬，不往回退，也不挪到框角去重起」）。前一件（划坎）于第27行断在粗纹跟前（逐字「浅白停在粗纹跟前，断在那儿」），中间插进第二件（那只手顺床沿滑垂、托回、按第五个骨节得数），两件都得办，手只一双。
- 量法四比：①同一片拇指甲，先在无坎处碰细纹即偏、再在半截坎里不偏、到断头出坎、接划後一路到棱（367:83「底下没有坎…往两边滑」之今日新样）；②拇指肚之印：367:95 是「一道一道木头的纹」，本章是「一道…直的，一头浅一头深」；③墨：367:71 顺纹洇开，本章「贴着坎平着走」「在坎里汇成一小颗，没有往下洇」；④数：367 数到十即停，本章数过十，到十六指腹底下才有一丝往上顶。
- 数：十六，按第五个骨节时当场数出，此前不提（坑㉘）。框比册格宽出的那半指，给了「六」。照在役之规「量两回」（367:51），第二回数到十七；两回不合，框下注只写「拿数数量的」「第一百三十六日」，「量两回」三字停笔不写——十七没有落处，含在嘴里。第六个骨节不碰。
- 第二件咬进来的事：那只手自己顺床沿滑垂、腕子磕红，红挨着腕根头一个骨节；她悬着食指等红褪了才按（门槛上半截坎在身後等着），此为两件事争一双手之处。
- 床上那一个：女，活着（「咽了」），全篇只作「那只手」「那一颗头」，不作「他」。
- 卡口：两指全章不岔（367:39 退场），只用一片拇指甲。「一日一格」之说不立。
- 二线：368 之物 0 进；白文无「沟」字；苏衍、老头、钱满、黎东来 0 现。
- 悬念哨 SUS-C-照着做：她今天第一次不照纸上的格子做，照木头上的坎做；框已满（十六占尽其宽），十七没有落处——笔尖朝框外那一截光木头伸出半截又收回，下一个数记在哪里，交 371。
- 收章：「拇指从坎里抬起来，指甲缝里卡着一丝木头。」367 带回来的是纹，本章带回来的是木头。
