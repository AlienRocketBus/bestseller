# 第374章·总编辑预令（0926）

- 线：主线（苏衍镜）。
- 质量三闸④：「沈鸢」二字白文末见 291:455，至 372 已 81 章（限 80）。暗线白文永禁其名，故其名只能在主线由人口里出。
- CHAR-370A：刘二、东头缺席，限 374。**二事并为一事**：刘二或东头回到量沟之场，须有其由（往回那一程之肩、带来的东西、或来问账）；其口里提一句她（例：问「沈家那丫头那边有没有信」一类，措辞由执笔定），⛔只一句，⛔不开她的线、不带暗线之物、不讲她的近况（二线不通消息：主线之人不知她今日如何）。
- ⛔不许为销账硬塞人；若定魂席判此来无由，须当面写明，改由他法（例：本子上旧页里她的名字被他翻到）落其名——亦须有物有由。
