# 第381章 · 轮记

- **本章之一事**（开镜卡问三，照抄入轮记之首）：门口没有柴；那孩子抱一捆柴来，搁在门口，不进，不出声——她认得那站法；她把自己那把小刀揣进袖子，头一回跟出去，到坡下慢半拍那一家，一样一样看过去，手没往刀上去，只说一句「她不行了」，问那孩子一句，得两句：「我爹说，不许叫。」「我娘要是喊我，那就不是我娘。」（D6 六审主案 §四之五 381 行）
- **翻掉了什么**（以下五问，总编辑据盘上正文＝v01 作答·1013）：床上那人的「不出声」。前几章她只读作不能出声、只会跟着人走的一双眼（221:161、221:181）；拍二 :27—31 母见子而子不见（「床上那双眼睛一直在他身上，眨也没有眨」），到 :91「我娘要是喊我，那就不是我娘」整个翻面——她不喊，原来是这一层（盲读：「後背一凉」）。一并翻掉的是搁柴之人：从门外的木屑与掰口（298:41、318:33）成了一张脸，正是 201:113「慢了半拍」那一个（:51）。
- **事摆完了没有**：摆完了。晨（:5—17：露水是整的、无木屑无拖痕、三勺一勺、写第一百四十二日）｜送柴（:21—37：站法、母见子而子不见、揣刀、截口一齐顶手心）｜下坡（:41—53：石棱磨光、三家两家关门、鞋後跟新折、那张脸、转过去这一下）｜屋里（:57—65：木屑、柴码在一臂之内而手不伸、削了一半的勺、离床最远之墙上的钥匙）｜一句（:69—79：「她不行了」、吹火之气断、眼去了钉子）｜两答（:83—93）｜回（:97—105：让门、眼在柴上）。七拍各有物作证，没有一拍悬着；钥匙开什么、他上不上坡，是留给後章之钩，⛔在本章说破。

## 造式·盲读

（盲读者：只读正文第379、380、381章；未读任何轮记、裁、说明、构思、行家评、开镜卡、章料。）

**① 读不读得懂（understood／confused）**：大体读懂，主线没有掉；以下几处卡住——
1. 「这个站法她见过。第四十四页上那一个，手里攥的是一张纸。」——卡在「第四十四页」。她记事是写在坎外头的木头上，不是本子；这个「页」是什么的页？她手里有本册子，还是指很久以前的某一回？回头读了两遍也没找到着落，读完仍不明白，读着像是一句从书外头漏进来的话。
2. 「那天你怎么不进去。」——「那天」是哪一天，得倒回去自己对：是这孩子先前来过门口、站着没进屋的那一回？是第四十四页那一回？还是一百多天前那一回？只能猜。
3. 钥匙：「离床最远的那面墙上钉着一根钉子，挂一把钥匙。钉子底下的墙皮蹭白了一道」，听见「她不行了」，他的眼睛先去了那根钉子。我知道这一下要紧，但这把钥匙开什么，读完仍不明白（当钩子可以，但拿不准是不是我漏了前文）。
4. 斗沿上「一周都是牙印，有深有浅，挨得密」——谁咬的？饿的？还是床上那个人从前咬的？拿不准。
5. 「他把脸转过去，对着墙。转过去这一下，她记了一百多天。」——要回头再读一遍：先以为说的是眼前这一转，再读才明白是一百多天前那一回他也这么转过去，她记到今天。

**② 读错之处（misread）**：
1. 开头她天一亮先去门口，「门槛外头那块地方是空的……没有木屑。拖痕也没有」——我先以为她在查夜里有没有什么东西来过（书名镇冢，前头又有尸动），读到「搁的正是柴一向搁的那一块地方」才明白：她查的是那个天天送柴、在石头上削木头的人今天没来。
2. 「拖痕也没有，深的浅的，一道都没有」——先读成拖柴留下的印子；等看到他脚踝肿得发紫、鞋後跟踩塌的折痕是新的，才回过味来，深一道浅一道，可能是他拖着那只伤脚上坡留下的。至今拿不准是哪一个。
3. 「勺柄的尾巴削得圆，抵着她的掌根」——开头读过去没在意，到灶沿上那把削了一半、「柄尾已经削圆了，圆得不挂手」，才发现她手里那把勺也是他削的。（这是好的「後来才发现」。）
4. 前两章我一直把床上那个人当成跟她是一家的；读到「她不行了」才知道是个女的，读到「我娘要是喊我，那就不是我娘」才知道是这孩子的娘、是坡下那家撂下的人。

**③ 想不想立刻读下一章（want_next／why_next）**：想。「我娘要是喊我，那就不是我娘」一句把前几章床上那双不出声、只会跟着人走的眼睛整个翻了个面——她是不能喊、不敢喊，还是喊了就「不是」了？再加上他眼睛钉在那把钥匙上没下来，我想知道他会不会拖着那只脚上坡。

**④ 这一章发生了什么（happened）**：天亮门外没有柴也没有木屑，一个半大孩子抱来一抱截口齐整的柴，床上那个人睁眼一直盯着他；她揣上刀跟他下坡，在坡下那家见到脚伤躺床的男人——一百多天前答话慢半拍、这些日子给她送柴削勺的那个——对他说「她不行了」，孩子说出「我爹说，不许叫」「我娘要是喊我，那就不是我娘」；她回屋把门口让开，床上那双眼睛一直落在门外那抱柴上。

**⑤ 最记得哪一拍（remember）**：「我娘要是喊我，那就不是我娘。」——孩子说完就把手里那根柴塞进灶口，一个字不多；回头再想门口那一幕，「床上那双眼睛一直在他身上，眨也没有眨」，她不出声，原来是这个缘故（或者不是），後背一凉。次记得的一拍是削了一半的勺：「拇指停在那个圆上，不走了。」

### soft

### 读误之判
盲读者所读之事（柴、孩子、揣刀、坡下伤脚之男人即答话慢半拍者、「她不行了」、孩子两句、回屋让门）与开镜卡一事逐件同；与全员之账无相抵（床上那人存、女，201:13 已立）。其读错四处：1 先疑尸动，至 :23「柴一向搁的那一块地方」自正；2「拖痕」所指有 327:5 原场，读者未读前文故疑，不与卡相抵；3 勺之後觉係作者所图；4「当成跟她是一家的」係盲读只读三章，全书读者已有 201:13。**misread=false。**
