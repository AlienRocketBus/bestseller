# 第389章 · 轮记
- **承前之判**（同线前章 388 收句之骨逐样落判·`封版.py 389 --前` 开轮十六检⑮所列四样·记席 1015）：「顺着梁脚」「往这边来」（388:119「他空着手，顺着梁脚往这边来。」）——**翻作其源**：389 不回指那人之身（黎东来只见纸，硬门槛「山上之物一字不许进」；白文「梁」0），而交其所以空手回来带话之因：:181「那我给下头那个小的打个电话，叫他把杆子挪过去。」:183「打吧。」——388 黄昏那一句的笔，落在这一头两个字上。「手伸进怀」「指头先碰」（388:121「我把一只手伸进怀里。指头先碰着的，是内衬上那道口子。」）——**搁下**：苏衍之身与内衬口子係山上之物，⛔进黎东来镜；本章手上最重的一下另有其源——:195「他拿食指在方框底下那一行印的小字上按了一下。指肚底下，是「本人」两个字。」承 365:127「这一格他没有碰。」，⛔与 388:121 作回声。388 收句「上头来电话，点往西挪两公里。」——**认而交其源**：:111「说明那一格，写：西移二公里。」、:157「往西挪两公里，是今天就挪？」、:159「今天。」——同日同数，一个数源（388:127）。


- **本章之一事**（开镜卡问三，照抄入轮记之首）：暗·第一百四十六日，黎东来案上同一个地方两张纸——来文（章盖得端正，签发人空着）与一张热线线索登记（365:9 那一路之热敏纸）；他照 365 之令（365:229「谁要是在路上拦那几个人，别叫他拦。」）出更正单（坐标录入有误，西移二公里）、扣下隐患单不往上走；热线那一条是全书头一条合「见到本人，并当面认过」（365:123）的——付款条上，计价单位那一格，他把 365 划掉的那个「人」写回来，就写在那一道划旁边，不涂；来文、隐患单、更正单压进抽屉，在 365 配送单之上，⛔归档（D3 主案:92；段案 389）。本章之物皆为这一张来文所出：点位、热线、更正单、隐患单、付款条、抽屉。
- **翻掉了什么**（以下五问，记席据盘上正文＝v01 作答·1015）：365 那一道划。365:147「只划一道，不涂。这张条子要归档，划掉的字底下得还看得见。」——读者一直当它是把人从账上抹了、按窝付钱；今天翻过来，那一道划是留着的：:191「划底下的字还看得清清楚楚」，:199「他在那一道划的旁边，又写了一个人。」。一并翻掉三样：365:127「这一格他没有碰。」→:195 食指按在「本人」上；365:175「笔尖挪到第四行，停在那一格上头。」（停了没落）→:107「改哪一个，笔尖没有停」（改假的那一位不停）与 :81「停了一停，提起来了」（只留一个墨点）；388:91「报上去……过些天有人来处置。」→:171「原先那个点是错的。错的点上报的，不算。」——苏衍本子上加了引号的「处置」（388:97），在这一头已被一个签了全名的人判死。
- **事摆完了没有**：摆完了。开镜卡一事逐件：两张纸点位相同（:33—35「长的那一行，一个数码不差。」「也不差。」）→热线合口径（:13 所见两眼、:19—21 方框里一个勾）→章端正、签发空（:29）、叠窗透名又空（:69—75）→隐患单翻扣、不转（:95）、「不算」「不退」（:171、:177）→更正单「坐标录入有误」「西移二公里」、抄送不填、签全名（:107—115）→付款条「人」写回划旁、不涂（:199）→三张压进抽屉，在配送单之上（:217—219），付款条「放着」不回档（:207）。卡外只多一件——录入的那个担假账（:139—151），出自更正单之「录入有误」，同一张纸的价，不成二事。
- **哪一样是别处来的**：热敏纸「两边往里卷」承 365:9；镇纸与翘起的两个角承 365:293；来文「来文单位那一格填着字，一个红章压在字上，盖得端端正正」「签发人那一格，空着」承 386:49、:51；所见两眼承 386:57；「不挪窝」对 386:41「一步也没挪」；旧来文「签发人那一格里都有字，都是同一个名字」承 277:85「签自己的字」；配送单与「那几份调出来重看过的东西」承 365:285；付款条诸格承 365:139（「印了十行」）、:143、:147、:151、:167、:171、:175、:219（「报了两遍」）、:237（右下角签字）；「库里那一批启事」承 365:289；「处置」承 388:91；「两公里」承 388:127；「下头那个小的」即 388 测绘年轻人（D3:91）；口径「见到本人，并当面认过」承 365:123。
- **还有哪一层是我知道、却没写进去的**：①段案之钩「这一张，章是真的，字没有」——白文零，只给透名（:71）、批办一墨点（:83）、签发人空（:221）；②透出来的那个名字是霍钧（277:81）——白文只「同一个名字」；③来电人就是 388 按平笑脸的那个年轻人（D3:91）——白文只「说是在外头干活的」与那两眼；④他为什么写回：365:229 之令与他自己签过的口径（365:123）——白文只给方框挨着计价单位、食指按「本人」，零解；⑤挪二公里是叫处置那一头扑空、不拦——白文只「坐标录入有误」；⑥接线的说「当天就要往上报」，他答「我这边」而章末未报——那个人从此只记在他一个人手里，⛔说破；⑦谁能不经那人签字用这枚章（391 管章的人之拇指、411 露底）——零。
- **若只留一样**：留 :199「他在那一道划的旁边，又写了一个人。」——同一张条子、同一支笔、同一格；365 划掉的那一个今天回来了，一个「人」字也是一个人；划不涂，「窝」也不涂，两样都还在纸上，写字的是他。

## 造式·盲读

**① 读不读得懂（understood：是，主线读懂；confused 如下）**
主线读懂：黎东来截下了热线上「见到本人」那一条，把点改西两公里，扣下隐患单。要回头再读、或读完仍不明白的几处：
1. 「他留下一份，把新的那一份压在它上头……空着的那一格里，透出来一个名字」——读第二遍才明白：新来文的章、手填字跟旧来文严丝合缝，是照旧的套出来的，单把签发人抹了；第一遍只当是在对笔迹。
2. 黎东来是哪一头的人——热线表往他这儿「传上来」，来文盖的是「这边的收文章」，测绘的隐患单又要他签「转报」，启事付款条右下角也是他的名字。他坐在哪个单位、上头是谁，读完仍拿不准。

4. 「明细印了十行，头三行写着：头一个，第二个，第三个。第四行空着」「印好的那个「人」上横着一道划……旁边是一个「窝」」——看得出「人」被改成了「窝」，跟热线上「不挪窝」对着；可头三个是谁、九百按什么算、那一道划是谁划的，不明白。

**② 有无读错（misread）**

2. 「他在那一道划的旁边，又写了一个人。」——第一遍读成他在空着的第四行又添了一个人（第四个）；回头看「在那一道划的旁边」，才改成：是把被划掉的那个「人」字重新写上。前文那个「人」带括号，这一句不带，两种读法至今都还在我脑子里。
3. 388 末尾那人回来「背心胸口那个兜，是平的」——当时以为三封信叫他交给上头了；389 里他是匿名打的热线，还问「找着了，那个人怎么办」。信到底寄没寄，至今拿不准。
