# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—9行｜拍2=13—15｜拍3=19—85｜拍4=89—97｜拍5=101—113｜拍6=117—147。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★「木匣」「纸条」「印泥」「章匣」只拍3 或拍5 一见，原处不动或随章去，不入册；「拇指」「指肚」「口子」係身上之物，不入册。
#   ★器物点名所疑「笔」「布」：「笔」係笔画（一笔一画、有一笔没有出来），「布」係布卷、垫布、章把上那道布、蓝布面，皆非过手之器，不入册。
