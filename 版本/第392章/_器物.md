# 第392章 · 器物册（造式二代·合稿席立｜照 391 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 7 拍：拍1=正文5—19行｜拍2=23—27｜拍3=31—57｜拍4=61—73｜拍5=77—81｜拍6=85—89｜拍7=93—125。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★只拍3 一见、去处当拍已书或随身而去者不入册：「纸包」「针」（刮毕随钱满）、「那一叠」（收皮子的那一个揣进怀里）、「那张纸」（印与兖在其上，钱满揣进贴身那一兜；其後账见轮记交下之账）、「那一本黄纸的」（白文又作「本子」，他揣回去）、「铅笔头」；只拍4 一见：「那一捆」（东头之捆，留沟沿）；只拍7 一见：「油布」（裹本子揣回）。
#   ★「平石」「扁石头」「石堆」係场上之物，不过手，不入册；「拇指」「指头肚」「指甲」「鞋底」「心口」係身上之物，不入册。
#   ★器物点名所疑：「笔」於拍3 係收皮子的那一个之「铅笔头」，与我之笔两物，册只记我之笔；「绳」两物：玉之绳（拍4、拍6）与东头那一截绳头（拍4、拍7），分两行；「布」係「油布」，只拍7 一见；「拿什么量的」係本子上那一小格之名（358：95），「什么」非器。
