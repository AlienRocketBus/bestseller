# 第392章 · 轮记

- **承前之判**（同线前章 390 收句之骨逐样落判·记席 1015·开轮⑮所列「走的」「过去」「对着老头」「先欠着」）：390:121「它也是会走的。」（**走的**）——**认**：水照它的期回来，钱满天亮前就下沟守（:5），为买那一张误了这一回，「水已经漫过他在盐壳上划的那一痕了」（:63）——会走的东西今天走在了他前头。390:123「他把脸转过去，对着老头。」（**过去**、**对着老头**）——**翻**：钱满今天不再对着老头，只「从老头跟前过的时候，脚底下慢了半步」（:61）；对着人的换成老头的眼睛对着我的手：390:111「老头那只眼睛睁着，在那把尺上」→:71「从北边挪下来，落在我手上」、:87「我的手往哪儿落，它就往哪儿去」。390:125「那声师父，先欠着。」（**先欠着**）——**搁下**：段案⛔再提，白文「先欠着」「师父」0（python 亲数），欠只落在 :61 那半步上。收句 390:127「老头没应。」——**认**：老头全章零句（:13「眼睛没有睁」、:17「朝着北边」），人人绕着他做事。

本章之一事：主·第一百五十四天，收皮子的那一个（第十七天在石头跟前没等着人）顺北这一条寻到梁下；钱满拿听针照 382:119 刮一道「收这个的，在哪儿收」，自己付价得一张纸：一枚印、纸角一个字「兖」；我拿玉把本子上那一道一处一处点出来，刘二背老头随我上梁，点收向梁北头那块平石；掌按不认，二指不找，径直落进两枚并排小窝，一捏，认了；往下一沉，脚底下往东南去的那一道远处跟着紧了一线；我把手松开，它也松了（段案 392·1015 改；开镜卡末节「势之裁之改」）。

- **翻掉了什么**（以下五问，记席据盘上正文＝v01 作答·1015）：386:111「像谁捏过一下」——人人当它是谁留下的印子；今翻作留给人捏的地方：两根指头不找就落进去，一捏「两个窝底一齐往上顶了一顶」（:113—119）。一并翻掉四样：382:115「拓片递进去，没见出来过」——今天出来了一张条子（:43「条子在我这儿」）；382:119「隔了一会儿」——:37「这一回，没有隔那一会儿」；388:17「我往哪儿带，他往哪儿去」——领路之位到了我手上（:87「我的手往哪儿落，它就往哪儿去」）；358:95 每天那一小格写「拿什么量的」——:101「这一回，我没有写」。
- **事摆完了没有**：摆完了。开镜卡一事逐件：来人（:23）→一刮一问（:37—39）→条子与价（:43）→纸、印、兖（:49—51）→收点上梁（:77—89）→收向平石、十一（:99—101）→掌按不认（:109）→二指不找（:113）→一捏（:117—119）→一沉、东南紧一线（:121—123）→一松（:125）。卡外多一件——钱满为这一张丢了一回水（:27、:63），係咬合之价，出在同一张纸上，不成二事。
- **哪一样是别处来的**：钱满下沟守水承 390:55、:99—105；指头落回承 390:43、:83；刘二那一块承 390:65、:109；页头承 390:17；收皮子的那一个之来承 356:117、:193，其卷承 358:55，黄纸本那一格承 358:87、:91；一刮承 382:119；「收这个的」承 382:115；论张要钱反 354:131；推印之指甲承 346:65；盐壳那一痕承 384:23；绳头承 390:23、:73；两手合不拢承 388:25；量法承 382:65、390:39，晌午失效承 390:87；老头气停承 390:7；领路承 388:17；裤子两个洞承 388:9；後脖梗承 378:111；那一小格承 358:95；平石、扁石头承 386:107—111、388:7；看不出来承 390:91；不响承 390:47；够不着承 388:87。
- **还有哪一层是我知道、却没写进去的**：①两粒之左右与拇食所落正相反——白文只钉手（:115），396「这张，反了」兑；②东南那一道是什么、通到哪儿——一捏，千里外霍钧那口气一口九（393 同弦），394 按到底、风哨停——白文只「紧了一线」「也松了」；③兖是什么地方、那一路是谁（E6 兖鼎·⛔公输）；④为什么是我的手——闸先认旧主（D5），叙者零解；⑤收皮子的那一个卖进去那一张是何物、黄纸本另起那一行写了什么——永不回；⑥老头为何上梁、为何眼睛跟着我的手——零句，E7 揭瞒。
- **若只留一样**：留 :113「两根指头没有找，自己就落进去了。」——其前全章一路都在找、都在量（针、指甲、玉、气数、十五回、那一小格），这一句一个「没有找」把一天之找收住；章首蚂蚁「没找着一个口子下去」（:15）与它白文不比，读者自会合上。

## 造式·盲读

**① 读得懂否（understood：主线懂，有卡处）**

1. 「第十七天，日头起来，我在石头跟前。坐到日头过了梁。」「我本子上那一行，还是二十。」——卡在：这个「第十七天」是谁的、从哪天数起？本子上那一行「二十」记的是什么？390 末刚有「十九跟二十二挨着……同一天，出水以後」，这里又差三。我拿不准这是同一笔账（又是一个「早上／出水以後」之差），还是另一件事。读完仍不明白。
2. 「他拿针尖在两个人中间一块石头面上刮过去，刮到头，往回拐了一下。这一回，没有隔那一会儿。」——「那一会儿」是哪一回的哪一会儿，这三章里找不到。「收这个的」里的「这个」，是指针、指那一道刮痕，还是指刮痕代表的某样货？要读到「卖进去过一张」「四张皮子的钱」，才猜出是带这记号的一张东西。回头读了一遍才大致对上：印当中那一笔「跟着拐了一下，拐得短」，跟针尖刮的那一拐像是一路手。可那「两粒，芝麻大」，钱满各按一息，认出了什么？他「推完了，没有说话」，我也就无从知道。读完仍不明白。
3. 拳头量法那段要回头读一遍：「数到七不凉，就还在那一道上；数过十口，比心口上还温的，落一个点。」——390 里只有温、凉两档，这里多出「比心口上还温」一档，点是落在这一档上的。头一遍我滑过去了，以为每按一回就落一个点。
4. 「两个窝底一齐往上顶了一顶……脚底下那一道往东南去的，远处跟着紧了一线。」——「紧了一线」是脚底下觉出来的，还是眼睛看见的？紧的是那一道本身，还是那一头的沟、那摊水？读完不明白，不过这是让人想往下读的那种不明白。
5. 小处：「眼睛没有睁。」中间只隔一只蚂蚁，就接「老头那只眼睛睁着，朝着北边。」我停下来回头看，是不是同一刻。

**② 读错处（misread）**

- 「刘二那一块还在他脚边那块石头上。」——390 末「刘二那一块还在他脚边石头上，边上一个牙印也没有」，我读成是刘二自己脚边、他自己不吃。到 392 这句紧跟在老头那一段後头，才觉出「他」大概是老头，是刘二把自己那块搁在老头脚边留给他。至今拿不准是哪个。直到「刘二把脚边那一块拿起来，咬了一口」，才确定这块一直没人动过。
- 「第十七天」我头一眼当成「今天是第一百五十四天」那种数法，以为收皮子的那个记错了日子。後来才觉出是另一套数法，是从某件事起数的第几天。哪件事，至今拿不准。

**③ 想不想读下一章（want_next：想）**

末了一捏一沉，往东南那一道「远处跟着紧了一线」，那一头正是还蹲在水边不上来的钱满跟那把尺。我想知道这一紧，沟里的水怎样了。

**④ 这一章发生了什么（happened）**

第一百五十四天早上，收皮子的那个上来，卖给钱满一张条子，条子上盖着铜钱大的印，角上写着「兖」；钱满看过印，回沟里守水。「我」攥着玉，顺石面上那道干痕往北一路量、一路落点。刘二吃了那块硬饼，背起老头跟着，老头两个腕子叫东头拴在他胸前。一路歇了十五回，上到梁上平石跟前，共落十一个点。晌午以後那几个点是手自己落的，「拿什么量的」那一格没有写。老头的指头指着平石，「我」两根指头落进平石那两个窝里，一捏一沉，脚底下往东南那一道远处紧了一线；手一松，它也松了。

**⑤ 最记得哪一拍（remember）**

「两根指头没有找，自己就落进去了。」接着是：「我往下一沉。脚底下那一道往东南去的，远处跟着紧了一线。我把手松开，它也松了。」其次是刘二吃饼：「身後咯的一声。」「第三口他整个塞进嘴里，腮帮子鼓着，背过身去」，以及「起到一半，停了停，嘴里那一口咽下去，才直起腰。」
