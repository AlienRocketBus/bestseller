# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—21行｜拍2=25—51｜拍3=55—87｜拍4=91—117｜拍5=121—123。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★只拍3 一见、去处当拍已书者不入册：「木匣」（白文又作「匣」，塞回案下）、「布卷」（结照原样打好，放回匣里）、「上半截」（只剩那一行，卷回布里）、「笔」（搁回砚边上）、「砚」（在右手边，不挪）、「线」（扎那卷钱，随钱去）；「包袱皮」「灯油」係旧事里之物，不在场，不入册。
#   ★「案」「窗纸」「院门」「屋门」係场上之物，不过手，不入册；「拇指」「无名指」「指节」「胸口」係身上之物，不入册。
