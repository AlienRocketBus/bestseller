# 第三百九十四章 蹭痕
那一夜，我没有再去碰那两个窝。
东头上来的时候，日头还没有落。那一捆在他背上，绳勒着两个肩膀。他走一段，站一站，手撑着膝盖喘几口，再走。上到石堆跟前，他把捆卸下来，靠着石堆放倒。柄从捆上支出来，柄上那个窝冲着平石那边。
他没有坐，先到老头跟前蹲下了。老头两个腕子搁在膝盖上，腕子上一道一道的印子，红的，还没有退。那截绳头撂在老头脚边，是刘二挑开扣以後扔下的。东头捡起来，捏着一头，在手里捋。绳上留着四道弯，捋过去，又弯回来。他捋了两回，不捋了，绕成一小把，揣进捆里。
日头沉下去，风跟着起来了，从北边来，石堆缝里一阵一阵地响。又过了一阵，南边远远地来了那一声。起头低，往上走，拖住，一落，歇了。隔着这么远，听着细。东头靠着他那一捆，脸偏向南边，左手在绳头上捻。那一声起来，那两根指头停住了。那一声歇了，又一下一下捻起来。
天黑透以後，我在石堆底下躺着，数自己的气。老头那口气隔一阵停一下，数到三十几口，就停一回，比白天停得长。停的时候，我就不数了。星底下看不清他，只听得见。停着的时候，刘二那边也没有声音，连翻身都没有。有一回停得比哪一回都长，我听见刘二坐起来了。那口气出来以後，他没有躺回去。他摸过去蹲下，两只手伸到老头胳肢窝底下，把人架到背上。起来，往石堆後头走。我听着他的脚，十几步，停了。
“这边背风。”他说。
他把人放下，自己也挨着躺下了。石堆後头那口气，还是隔一阵停一下，隔着一堆石头，听得轻了。停的时候，我还是不数。东头那边，绳头一下一下捻着。後半夜，我睡过去了一阵。
＊
天边发白，我醒了，先往石堆後头看。
背风那一面，刘二侧躺着，一只胳膊伸在外头，搭在一块空石头上。
老头在平石边上。
他侧躺在平石外头那一边，脸朝着石堆，右手搁在石面上，那根食指又落在那一道上。指头尖离外头那个窝，隔着一个指甲盖。昨天，那中间空着一个人蹲得下的地方。
从石堆後头到平石边上，石面上一道蹭痕，贴着石堆的脚绕过来，一截一截的。蹭痕两边，隔一截一个手掌印，五个指头张着，掌心按得最实。断开的地方，灰让什么压过，平平的一小片。大的那几片，有一个人趴下那么长。我顺着那道蹭痕走回去，一步一步数，走到刘二那只胳膊跟前，十六步。蹭痕断了六回。
我走回来，蹲在他腿边上。裤子膝盖那两个洞又磨大了，线头往外支着。洞底下的皮破了，粘着石头渣，渣子缝里是黑的血。他那只眼睛睁着。
东头靠着他那一捆坐着，眼睛也睁着，左手在绳头上捻。我顺着蹭痕走过去，又走回来，他的眼睛跟着我走了一趟，嘴没有动。
刘二醒了。他要坐起来，伸着的那只胳膊撑了一下，没有撑住。他拿另一只手把它搬回来，搁在膝盖上，看着那块空石头。过了一阵，他起来，走到蹭痕跟前蹲下，把右手按进一个手掌印里。他的手大，五个指头盖过去，还长出一截。他看了一会儿自己那只手，走回去坐下，右手绕到後脖梗上，按着。他没有往平石这边来。
我把本子掏出来，翻一张白的，页头上落：今天是第一百五十五天。笔尖在底下停了一会儿，没有往下写。本子合上，揣回去。
＊
我把玉从脖子上摘下来，绳在右手腕子上绕了两道，攥进手心。
左手张开，拇指尖抵着他那根指头的指甲，小指顺着那一道往外伸，伸直了，是一拃。拳头落在小指尖那儿，按实了，数。数到七，手心里那一块，跟石面一样凉了。
昨天，拳头落在那一道上，七口不凉。
我往回挪了半拃，再按，再数。数到七，还是凉的。
我挪到头，拳头挨着他那根指头按下去。数到七，没有凉。手心里那一块，比在心口上的时候还温。
我拿手背碰了一下他那根指头。
凉的。
我把玉贴回心口。
＊
我蹲到平石跟前，还是昨天那地方，背後是石堆。
掌心先按下去。石头隔了一夜，是凉的。两个窝在掌心底下，挨不着肉。
我把手拿起来，两根指头落进窝里。拇指在靠石堆那一个里，食指在外头那一个里。食指边上，隔着一个指甲盖，是他那根指头。
两个窝底一齐往上顶了一顶，顶住两个指头肚，比昨天顶得硬。
我往下按。按下去一点，它顶回来一点。
东南那一道，远处又紧了一线，比昨天那一线紧。
食指边上，他那根指头的指甲盖白了。
我停住了。手没有松，也没有再往下去。
我往东南看。梁脊，梁根，石面，沟，来的那一路一截一截矮下去。哪一截也看不出什么。
老头那只眼睛在我脸上。
我的眼睛从东南回到他那根指头上。
他那口气又停了。
我没有数。
我按到底。
指头底下响了一声，轻。窝底不顶了。
东南那一道绷直了。
他那口气回来了。
那根指头自己离了石面，悬着，没有落回去。指甲盖上的白，退了。
我把手松开，它没有松。
＊
我在平石跟前坐下，数他的气。
从一数起，一口跟着一口。数过一百，没有停。
刘二过来了。他在平石边上蹲下，看那根指头。他的手伸过去，在那根指头上头停住了。停了一阵，缩回去，在自己膝盖上搓了两下。
数过两百，没有停。那根指头一直离着石面，指头肚底下透着亮。数到二百几十口，那只眼睛合上了。他的气还是一口跟着一口，不长，也不停。
我把绳从腕子上解下来，玉挂回脖子上，手在心口上停着。心口那一块，我拿指头从软的那一头推过去，推到边上，指头停了一下。
那一停，轻了。
我把本子掏出来。今天那一页，页头底下还白着。我往前翻，翻过昨天落了十一个点的那一张，一张一张往前，翻到画着圈的那一张。
五在圈里，墨吃得深。六、七、八浮在右边，都是点一下就起来的。末一个钉在当中，挨着头一个，压得比哪一个都重，洇开的那一片早干了。我把笔尖搁到圈边上，往东南拉出去。拉得慢，拉到当中那个重的点边上，停住了，没有挨着它。
我在这一道旁边写：我在给一样东西上弦。
写完，本子合上，拿油布裹好，揣回去。
＊
日头到了头顶，钱满上来了。
尺插在後腰，尺头上糊的泥干成了灰白的。他从老头跟前过，站住了。蹲下去，脸低到跟那根指头一般高，看指头底下那一线亮。看了好一阵，他起来，把眼睛挪到我脸上。
“今早那一回，两竿。”
他靠着石堆坐下，尺没有抽出来，眼睛又回到那根指头上去了。
後半晌，石堆的影子挪过来，盖住了老头。那根指头在影子里，也一直离着石面。他睡着。我数他的气，数一阵，丢下，过一阵再数，哪一回都没有停。
东头过来了，在老头脚边坐下，左手捻着绳头，眼睛在那根指头上。坐了好一阵，他起来，回到他那一捆跟前，把捆上的绳一道一道解开。
＊
日头往梁上沉的时候，东头那一捆已经摊开了。
他抽出一盘绳，又把那一小把掏出来，散开。四道弯还在。他把那一截跟长绳接上，打了个死结，拿牙咬着一头勒紧了。四道弯那一截，他搁在当中，留着拴腕子。刘二过来，背朝着他蹲下。东头把绳从刘二两个肩膀上过去，在胸口前头交一道，比了比。又拿绳头到老头腿弯底下去比。比到第二回，老头那只眼睛睁开了，看了看东头的手，又合上了。东头扎得慢。右肩那边使不上劲，绳头都是左手往里塞。
日头沉到梁上了。风从北边起来，石堆缝里一阵一阵地响，跟昨天一个钟点。
刘二蹲着，背上搭着那半截背带。
东头扎到一半，手停了。左手捏着绳头，没有往里塞。他的头偏向南边。
“不叫了。”
【本章亮点】
一·日与接：主线第一百五十五天（天字式），承 392：19「今天是第一百五十四天」加一，合总纲：318「主·155」。二线之差 155 减 149 得 6，白文无此数。日号一处，在拍二页头。接 392：125「我把手松开，它也松了。」首句「那一夜，我没有再去碰那两个窝。」相对日词四处。「昨天，那中间空着一个人蹲得下的地方」指 392：107。「昨天，拳头落在那一道上，七口不凉」指 392：77。「比昨天顶得硬」「比昨天那一线紧」指 392：119、123。「跟昨天一个钟点」指本章拍一之日落。
二·魂（不说）：老头拿身子垫那一道，全章无一人说破。刘二只说「这边背风。」。老头不出声，夜里贴着石堆爬回。东头夜里醒着，看我走那一趟，嘴不动。刘二拿手按进掌印，不再背。我不数。页头底下一字不写，只在画着圈的那一张上写上弦。钱满只报那一回。东头只说不叫了。读者从绕法里自己合上。
三·券：「他那口气又停了。我没有数。我按到底。」券兑。前句「我的眼睛从东南回到他那根指头上。」後句「指头底下响了一声，轻。」无心里话。全章数得最勤，唯这一口不数。
四·叫绝：其一按到底，托以三物。背开十几步而那口气照旧停，天亮蹭痕十六步、断六回、掌印五指张着。玉一拃外凉，半拃外凉，挨着他比心口还温。此係 382：65 之复，今天看得见，并翻 392：77 七口不凉。手背碰他那根指头，凉。按时他那片指甲盖白了，按到底後白退了，垫与不垫只在一片指甲上。其後「我把手松开，它没有松。」翻 392：125，叙者不比。对标拍库 10、38，翻 380：75 之落回。其二「不叫了。」拍一东头听那一声，两根指头停，歇了又捻，立其底。拍八手先停，嘴在後，叙者不报那一声没来。对标拍库 36、37，翻 384：77「我没应」。
五·问六：老头夜里背开，天亮自己回到线上，零句不拦。按後指离石面不回，那口气不再停，眼睛头一回合上。腿弯一比，睁眼看东头的手又合上。刘二背开那双手，四字。天亮胳膊压麻，手按进掌印长出一截，不再背。指头上头停手不碰。东头之事五样：上梁、捡绳头、听、看指头、扎背带。开口三字。钱满蹲到与指头一般高看那一线亮，一句一数。我知情而按，页上写明。
六·392 悬账逐条：④治，全章零水，白文不提。⑤治，拍一东头捡绳头，四道弯捋不直，揣捆。拍八散开接长绳，四道弯留在当中拴腕。⑥治，只写离了石面、悬着、没有落回去。⑦治，「还是昨天那地方，背後是石堆」，拇指靠石堆、食指外头不动。⑧治，「比昨天顶得硬」「按下去一点，它顶回来一点」，按到底後「窝底不顶了」。⑨治，392 那一张只翻过，那一小格不补。⑩治，东南只写紧一线、绷直、松手不松。⑬⑭治，东头日头未落背捆上梁，钱满日头到顶上来。⑱零。
七·到期账与大审：悬哨甲不出。往回那一页 390：109 已在四底下挪下一行落零，「从三续」与此行相牵，所数之物料未给。今夜梁上无灯不记账，禁凭半边据落数，挂 396。悬哨乙带一笔，拍一「柄上那个窝冲着平石那边」，同不同零判。大审第二十三条：钱满「今早那一回，两竿。」390：55 是「日头已经离了梁顶一竿高」。390：99 六个时辰零一刻，隔两天四回，一回晚一刻，合一竿。零解，不专开拍，落在他上梁照面一瞬。冷轮係记席之职。
八·量表与量必出数：页头第一百五十五天。出数：十几步｜十六步｜六回｜三十几口｜一拃、半拃｜七｜一个指甲盖｜一百、两百、二百几十口｜四道弯｜两竿。不出：按到底那一口，即「我没有数」；心口那一块只给「那一停，轻了」。量表五格。东南紧一线即松，翻作绷直不回。那口气隔一阵停，翻作两百口不停。那根指头落回原处，翻作离了石面不回。圈着的五，往东南拉出一道、旁写一行。山口那一声照来，翻作到了钟点东头手停。
九·收：三拟：「“不叫了。”」｜「刘二蹲着，背上搭着那半截背带。」背带先抢了三字｜「那根指头，还离着石面。」镜头回老头，夺东头之耳。取一。
十·守令：白文「霍钧」「沈鸢」「黎」「点户」「处置」「总口」「水」「饼」「一指」「一圈」零；393 之物零。「弦」只一处，在本子那一行。开口：刘二一句四字，钱满一句，东头三字，老头与我零句。在场：拍一我、刘二、老头在石堆，东头日落以前上来，钱满在沟。拍六起五人俱在。
十一·裁（律⑳）：①东头上梁定在第一百五十四天日落以前，钱满定在第一百五十五天晌午。卡令夜里东头侧耳，又令钱满守水回来照面，各从其令。②卡「一指远」与禁「一指」相抵，取「一个指甲盖」，并添昨天那一截空为比。③卡「又大了一圈」与禁「一圈」相抵，取「又磨大了」，读数落在破皮上。④净重：执笔令主线之带二千五至三千五，卡问五令过三千五。本稿事尽於此，不为三千五添拍；到期账四〇五交总编辑（主会话）裁，倾向本块不以添字担。
