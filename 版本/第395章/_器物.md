# 第395章 · 器物册（造式二代·合稿席立｜照 394 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—23行｜拍2=27—43｜拍3=47—73｜拍4=77—97｜拍5=101—123。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★只一拍一见、去处当拍已书者不入册：「两根细的」（续进她屋里的灶）、「一根」（那孩子添进那一家的灶口）。
#   ★「钉子」「钥匙」「蹭白」「那块石头的光面」「门柱」「横档」「一小堆柴」「那一把草」係场上之物，不过手或不挪，不入册（钥匙之还账见骨记七）；「中指」「拇指」「左手背」「脚跟」「手腕」「勒痕」「湿点」係身上之物或身上之迹，不入册；「裹布」随他爹那只脚，白文不过手，不入册。
#   ★器物点名所疑：「被子」三物：她夜里坐的那床（拍1、拍4）、她屋里床上盖的那一床（拍2 掀开）、那一家床上那一床（拍3、拍5），只第一物过手挪位，入册。「火钳」二物：她屋里那一把（拍1）、那一家那一把（拍3），分两行。
