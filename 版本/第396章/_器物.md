# 第396章 · 器物册（造式二代·合稿席立｜照 395 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—33行｜拍2=37—57｜拍3=61—117｜拍4=121—165。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★「饼」拍一称饼，拍二、拍三称「那一块灰白」，三拍白文皆有「灰白」二字，故以之为别名；拍四刘二黑里摸着「还攥着」，那只手往老头怀里塞了塞，饼之名白文不书。
#   ★「那盏灯」两物：我那一捆里那一盏（拍一磕一声，钱满不让点）入册；院子门口那一盏（拍三、拍四照着我半边身子）係场上之物，不入册。
#   ★「平石」「两个黑点」「石堆」「盐壳」「那条路」「房子」「院墙」「门口那盏灯」「墙上那一层压一层的纸」「车」「车窗」「烟头」「车斗」「麻袋」「後挡板」「车帮」係场上之物，不过手或不挪，不入册；「手背」「指头」「後脑勺」「肩膀」「有疤的那一边」「指根」「下巴」係身上之物，不入册；「柄上那个窝」随东头那一捆，不另入。
#   ★394 册上之「玉」「钢尺」本章白文不书，其位照 394 之出（玉挂回脖子上、尺插回後腰），不入册。
