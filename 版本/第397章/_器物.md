# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—21行｜拍2=25—45｜拍3=49—75｜拍4=79—93。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★「抽出的那几张」：拍3 照那一格抽出、攥进右手手心里，白文不书其名；拍4 方作「右手手心里那几张」，故入=4。
#   ★「兖字那半截」「路费」承 393 册之名（393 出=4：点户揣进怀里）；本章拍2 白文作「半截纸」、拍4 作「那半截纸」，以「半截纸」为别名；路费白文作「钱卷」（拍2、拍3）。
#   ★「线」「结」随钱卷，不另入；「鞋垫」随鞋，不另入。
#   ★「条石」「钉」「钉帽」「那一圈红漆」「挡墙」「出水眼」「青苔」「泥手印」「那一行印子」「铁道」「锅」「票价牌」「窗台」「玻璃」「抽屉」「网兜」「编织袋」係场上之物，不过手或不挪，不入册；「右手」「食指」「拇指」「虎口」「胳膊」「脚後跟」「袜子」「衣襟」係身上之物，不入册。
