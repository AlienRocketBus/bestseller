# 第398章 · 器物册（造式二代·合稿席立｜照 397、396 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—21行｜拍2=25—57｜拍3=61—87｜拍4=91—117｜拍5=121—139。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 396 册：「背带」「东头那一捆」「捆里那盏灯」「本子」「油布」「笔」「那张纸」。「背带」拍2、拍3 白文作背带与两个套，拍5 只作「两个套」，三拍皆有「两个套」，以之为别名；「那张纸」本章白文作「纸」；「笔」白文作「笔尖」；「捆里那盏灯」白文作「我那一捆里有灯」，以「灯」为别名；「油布」拍5 白文作「油布包」「油布」。
#   ★「碗」是门里那个人端出来的，碗里的水随碗，不另入；「针」包回纸里，随「纸包」揣回怀里，两物各入。
#   ★「门槛」「门槛当中凹下去那一块」「门楣」「那一枚纹」「门环」「门板」「门闩」「门缝」「门框」「门框的影子」「那块石头」「墙」「车斗」「麻袋」「铁皮」「麻袋毛」「车帮」「货场」「货场门口那面墙」「秤」「旧书旧本子」「门缝底下那一线灯」係场上之物，不过手或不挪，不入册；「指头」「拇指」「食指」「指节」「指根」「指尖」「膝盖」「肩膀」「嘴唇」「衣襟」「贴身那一兜」「鞋」「鞋尖」係身上之物，不入册；「柄上那个窝」随东头那一捆，不另入。
#   ★396 册上之「饼（灰白）」本章白文不书（卡：本拍⛔写），其位照 396:129（那只手往老头怀里塞了塞）；「褂子」本章白文不书，其位照 396:27（刘二穿在身上）；「自己那一捆」本章白文作「我那一捆」，只为灯之所在，不另入；「钱」「火柴」本章白文零，不入册。
