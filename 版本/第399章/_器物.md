# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—33行｜拍2=37—49｜拍3=53—67｜拍4=71—93｜拍5=97—115。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 389 册：「镇纸」「来文」「付款条」「笔」「登记表」，俱无主，照旧。热线那一张本章白文只作「热线那张热敏纸」「热敏纸」，以「热敏纸」为别名；本章「登记」二字另指用印登记，⛔混。
#   ★389 册之「底稿」係录入的那个捏着的那一张（主=录入的那个）；本章别在来文上的是他自己的「传真底稿」，另一物，⛔借 389 之名。传真底稿与「回单」别、钉在来文上，「作业单」钉在来文後头，「调档单」夹在付款条角上，皆随其主件，不另列（照 389 册）。
#   ★附件三份：「用印登记」影印两页（拍2）、「请假条」影印一张（拍3）、手抄「封皮」上的「目录」（拍4）；拍5 白文只作「三份」，以一件立，各件之用见其拍。回过来的那一张拍1 白文作「最上头那一张」「这一张」，拍5 作「回过来的那一张」，以「那一张」为别名。
#   ★「抽屉」「笔筒」「桌上的电话」「听筒」係屋里之设，不入册；「笔帽」随笔；「指头」「指肚」「食指」「眼睛」「鞋底」係身上之物，不入册。
