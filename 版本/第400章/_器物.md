# 第400章 · 器物册（造式二代·合稿席立｜照 399、398 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—37行｜拍2=41—65｜拍3=69—77｜拍4=81—97。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 398 册：「本子」「油布」「笔」「背带」「东头那一捆」「碗」「拓片」，主照旧。「背带」本章白文作「背带」与「两个套」，以「两个套」为别名；「东头那一捆」本章白文作「墙根那一捆」，以「那一捆」为别名；398 册之「笔（笔尖）」本章白文只作「笔」，别名去。
#   ★398 册之「捆里那盏灯」（主=我）本章白文不书；本章之灯是门里条案那一头那一盏，另一物，名「条案上那盏灯」，以白文「那盏灯」为别名，⛔借 398 之名。灯之「玻璃罩子」「灯芯」「灯座」与灯座跟前「三小截剪下来的黑头」随灯，不另入。
#   ★398 册之「那张纸」（主=钱满）本章在钱满兜里，白文不书，⛔出；本章白文「那张纸」「那张折着的纸」指门里那个人手边那一张，另一物，名「那张折着的纸」，以「折着的纸」为别名，⛔借 398 之名。
#   ★398 册之「纸包」「针」「那一包（内袋）」本章白文不书，其位照 398（揣回怀里；三层裹回，扣上内袋）。
#   ★「门闩」「门」「门缝」「门轴」「门槛」「门槛当中那一凹」「门框」「门板」「条案」「条案沿」「长凳」「墙」「墙根」「那块石头」「扫帚印子」「秤」「门缝底下那一线亮」係场上之设，不过手或不挪，不入册；「指头」「拇指」「拇指肚」「食指」「指头肚」「指甲」「指甲盖」「指根」「胳膊肘」「巴掌」「膝盖」「肩膀」「嗓子」「怀」「心口」係身上之物，不入册；「柄上那个窝」随东头那一捆，碗底那一线水随碗，不另入。
