# 第401章 · 器物册（造式二代·合稿席立｜照 400、397 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—17行｜拍2=21—33｜拍3=37—47｜拍4=51—63｜拍5=67—77｜拍6=81—93。骨记照开镜卡作八拍：拍1＝卡之拍一｜拍2＝拍二、拍三｜拍3＝拍四｜拍4＝拍五、拍六｜拍5＝拍七｜拍6＝拍八。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 397 册：「兖字那半截」本章白文作「那半截」（拍1、拍2、拍4），以「那半截」为别名；「路费」本章白文作「一卷钱」（拍1），以「一卷钱」为别名；「饼」「布包」「票」照旧；397 册之「找回来的钱（找回来的）」本章拍1 作「找回来的那几张」，397 之开口今交：抽出一张，余者白文不书其收处。
#   ★395 册之「两面那张纸」本章白文作「三折的」「三折打开」「折回三折」（拍1、拍4），以「三折」为别名；拍3「隔着衣裳按了按那一层」只隔衣按一按，没有往里伸，不作用；拍5「缝里塞不进一张纸」、拍6「纸味」之「纸」非此物。
#   ★397 册「刀本章白文零」，本章交其去处（大审 #57）：白文作「鞘口」「鞘」「刃」「刃尖」，「刀」字零；鞘、皮带、刃分三行。
#   ★「找头」係拍1 买铅笔头找回之钱，与「找回来的钱」同在兜里，分两行；「抽出的那一张（那张钱）」係递给摊子上的人那一张，⛔借 397 册「鞋垫底下那张钱」。
#   ★「车」「车厢」「出口」「铁栏杆」「担子」「绳」「小摊」「烟」「火柴」「铁皮盒」「石头」「石堆」「石缝」「坑」「土」「鞋摊」「油布」「砖」「小凳」「板车」「门楣」「门」「门板」「门缝」「门框」「门槛」「书」「秤」「秤砣」「後门」「高墙」「巷口」「槽」「槽口」「小窗」「闩」「闩头」「闩槽」「架子」「麻线」「墙根」係场上之物，不过手或不挪，不入册；「袖口」「袖子」「小臂」「衣裳」「鞋帮」「鞋尖」「後跟」「膝盖」「心口」「怀」「兜」「手背」「指头」「指头肚」「拇指」「拇指肚」「食指」「巴掌」「腿」係身上之物，不入册。
