# 第402章 · 器物册（造式二代·合稿席立｜照 401、400 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—47行｜拍2=51—77｜拍3=81—107｜拍4=111—129｜拍5=133—143。骨记照开镜卡作六拍：拍1＝卡之拍一、拍二｜拍2＝拍三｜拍3＝拍四｜拍4＝拍五｜拍5＝拍六。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 400 册：「本子」「笔」「碗」「拓片」「剪子」「背带」「东头那一捆」「条案上那盏灯」「那张折着的纸」，主照旧。「背带」本章白文作「两个套」「肩上的套」「右肩上那个套」，以「套」为别名；「东头那一捆」本章白文作「门边立着的那一捆」「门边那一捆」，以「那一捆」为别名；「条案上那盏灯」本章白文作「灯」（拍1「没有点灯」、拍5「把灯点上了」），以「灯」为别名；灯芯、灯座跟前那三小截黑头与後半夜剪下的那一截随灯，不另入。
#   ★名与主承 401 册：「布包」「刃」「两面那张纸」，主照旧。「刃」本章白文不名，作「一把刃」「刃尖」（拍1），以「那个尖」为别名，⛔名其来历（大审第五十七笔）；401 册之「鞘」「皮带」本章白文零（403 鞘口作数）。「两面那张纸」本章白文作「一张纸」「纸」「纸角」「那张纸」，以「纸」为别名；401 册之别名「三折」本章白文零（只「打开一折，又打开一折」）；「兖字那半截」本章白文零（大审第二十八笔）。
#   ★「壶」係本章新物，门里那个人从後屋提出来，壶底是黑的，主=门里那个人。
#   ★400 册之「油布」本章白文不书，其位照 400。「回字牌」只在门里那个人一句话里，不在场，不入册。「当中那一点」「那一页」「页头」「那一鼓」「那一个点」随本子，不另入；「那一枚」係两面那张纸背面之纹，随纸，不另入；碗底那一圈印子随碗，柄上那个窝随那一捆，不另入。
#   ★「门」「门缝」「後屋的门」「条案」「条案沿」「凳」「墙根」「架子」「窗纸」「小窗」「门板」「担子」「扁担」「秤」係场上之设与路人之物，不过手或不挪，不入册；架上码满的纸、窗纸之「纸」非两面那张纸。「指头」「食指」「指头肚」「指甲盖」「指甲缝」「拇指肚」「膝盖」「胳膊」「肩膀」「嗓子」「怀」「衣裳」「鞋尖」「手掌」「两条腿」係身上之物，不入册。
