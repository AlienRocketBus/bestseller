# 第403章 · 器物册（造式二代·合稿席立｜照 402、401 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—23行｜拍2=27—45｜拍3=49—99｜拍4=103—115。卡作六拍：拍1＋拍2＝卡之拍一（早上倒水、验刃｜日号截断、捧簿）｜拍3＝卡之拍二至拍五｜拍4＝卡之拍六。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 401、402 册：「布包」「刃」「鞘」「皮带」「铅笔头」「找头」「兖字那半截」「壶」，主照旧。「刃」本章白文作「袖子底下那一截硬的」「刃把」（拍1），以「刃把」为别名；402 册之开口（刃之收处）於拍1 交：刃把坐在鞘里。「鞘」本章白文作「鞘口」，以之为别名；「那一圈铜」「铜上那一笔」随鞘口，不另入。「兖字那半截」本章白文作「那半截」，以之为别名。
#   ★「壶盖」係本章自壶析出之物：他提壶回去，盖子留在她这一头，主=门里那个人。
#   ★「出门簿」係本章新物（卡之称），白文只作「簿子」「簿」，以「簿子」为别名；门里那个人家自家之账，从架子最底下那一层的底下捧出，又推回原处，主=门里那个人。簿上之字、扁圈、斜笔、火那一行旁那一道印子随簿子，不另入。
#   ★「两面那张纸」本章白文零（拍2 只「那一层是平的」），其位照 402 册：前屋条案那一头，一夜没有人收（402:143），本章不入格。402 之物（本子、笔、碗、拓片、剪子、灯、套、那一捆、那张折着的纸）本章白文零。
#   ★「饼」随布包，不另入。「闩」「闩槽」「门板」「门洞」「架子」「麻线」「纸捆」「窗洞」「砖」「灰」係场上之设，不过手或不挪，不入册；「袖子」「袖口」「拇指」「指头」「膝盖」「小臂」「手腕」「鞋尖」「腿」係身上之物，不入册。
