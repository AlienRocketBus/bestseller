# 第404章 · 器物册（造式二代·合稿席立｜照 403、402 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—43行｜拍2=47—73｜拍3=77—93｜拍4=97—105。卡之四拍与之一一相当（拍1 文书·三天｜拍2 街口·钉｜拍3 画钉·老头一句｜拍4 两处）。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 402 册：「本子」「笔」「碗」「拓片」「剪子」「背带（套）」「东头那一捆（那一捆）」「条案上那盏灯（灯）」「两面那张纸（纸）」，主照旧。「背带」本章白文作「左肩上的套」「右肩上那个」「左肩那个套」，以「套」为别名；「东头那一捆」本章白文作「门边那一捆」，以「那一捆」为别名；「两面那张纸」本章白文作「那张纸」「纸角」，以「纸」为别名（拍1 之「那张纸」兼指文书，册中分开）。
#   ★402 册之「壶」本章白文零：402:129 他提着又给我倒满了，其後放回何处白文不书，本章没有拿出来，碗是满的即那一壶。
#   ★402 册之「那张折着的纸」本章白文零：402:25 他揣进了怀里，本章没有拿出来。
#   ★402 册之「布包」「刃」本章白文零：还在後屋她身边（403 册），她不出後屋，我之叙不带。
#   ★「征集文书（文书）」係本章新物（卡之称），白文作「征集的文书」「一张纸」「那张纸」，以「文书」为别名；夹公文包的从门缝竖着递进来，门里那个人捏住，看过、压过、收起来回那一头，主=门里那个人。
#   ★「那一套拓（拓）」係本章新物（卡之称）：门里那个人家里那一套，一张一张递给钱满照，照完一张收回一张；白文拍1 作「一张拓」，拍3、拍4 只作「一张」「下一张」「那一张」，主=门里那个人。
#   ★「我那一捆」承 398:123（「我那一捆里有灯，没有点。」），本章首交其位，主=我；里头那盏灯随它，不另入。
#   ★「包」係夹公文包的那只包，白文只「包上的搭扣」（拍1），跟着他回街口，主=夹公文包的。
#   ★「钉」「扁石」「石头堆」「鞋摊」「锤子」「皮子」「铁拐子」「板车」「铁管子」「秤」「铜丝」「门槛」「门板」「门缝」「条案」「凳」「後屋的门」係场上之设与路人之物，不过我们的手，不入册；钉与扁石之位：还在街口石堆脚底下，我没有碰（409）。
#   ★「页头」「那一页」「两道线」「七道短横」「两个点」「小方块」「小圈」「那个圈」「红字」「扁的」「墨」随本子，不另入；「纸角」随两面那张纸；碗底那一圈印子随碗；柄上那个窝随那一捆；「搭扣」随包；灯头、那一缕烟随灯。
#   ★「指头」「食指」「拇指」「指甲盖」「指头肚」「手掌」「手背」「膝盖」「下巴」「胡子」「鞋」「鞋尖」「鞋面」「鞋帮」「大衣兜」「袖子」「肩」係身上之物，不入册。
