# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—11行｜拍2=15—37｜拍3=41—47｜拍4=51—75｜拍5=79—89。卡之四拍与前四拍一一相当（拍1 掐指·院门｜拍2 登记｜拍3 勾单｜拍4 烧账·数息），拍5 係点户取单与收。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 393 册：「停收之纸（停收的纸）」「名册」（主=管档的）「档柜（柜）」照旧。
#   ★393 册之「她那封信（那封信）」「竹片（那片竹）」本章白文零：393:119、:101 留在案上，本章没有拿起。
#   ★393 册之「兖字那半截（那半截纸）」「路费（钱）」本章白文零：393:101 点户揣进了怀里；本章那人两只手垂着，空的（拍5），不复书。
#   ★「用印登记（登记）」只拍2 见，而係跨章之物：段案物之计「用印登记→霍钧案头（411）」，入册以交其位；主照名册，作管档的。
#   ★「目录那一页」係名册之页，撕下出了屋，另入；主=霍钧（他勾的，他交出去的）。白文拍3 作「目录那一页」「压在砚底下」，拍5 作「砚底下那一张」，两拍共有之字只「砚底下」，以之为验名（别名格）。
#   ★「兖那一页」係名册之页，叫绝之物，另入以交其位；主照名册。名册其余诸页、「蓝布面」（拍4）、「那张布面」「那一角红」（拍5 灶膛里还红着一角，旋暗）、「册边磨白的那一道」随名册，不另入。
#   ★只一拍一见、去处当拍已书者不入册：「纸条」（拍2·搁进柜里，横在当中）、「火柴」（拍4·在灶台上）。「笔」只拍3 一见（早上写条子那一支，在砚边上拿起，勾毕放处白文不书），小物，随砚，不另入。
#   ★「灶」「灶台」「灶膛」「案」「窗纸」「院门」「插销」「屋门」係场上之物，不入册；「拇指」「指节」「胸口」「膝盖」「袖口」「怀」係身上之物，不入册；「旧灰」「新灰」不入。
