# 第406章 · 器物册（造式二代·合稿席立｜照 405、404 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行｜拍2=29—47｜拍3=51—63｜拍4=67—77。骨记八拍与之相当：骨记拍一（倒走与撕）与「一夜与天亮」在拍1｜骨记拍二（写路）、拍三（十口气·点）、拍四（推）在拍2｜骨记拍五（他一句·钥匙）、拍六（她走）在拍3｜骨记拍七（我那一页）、拍八（钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 404 册：「本子」「笔」「碗」「剪子」「背带（套）」「东头那一捆」「条案上那盏灯（灯）」「两面那张纸」「征集文书（文书）」「那一套拓（拓）」，主照旧。「东头那一捆」本章白文拍1 作「门边那一捆」「柄上那个窝」，拍4 只作「柄窝」，以「柄」为别名；「两面那张纸」本章白文只拍3 一见，作「她那张纸」，以之为别名（「纸」字本章遍见於土纸、拓纸，不取）。
#   ★404 册之「拓片」（主=我）、「我那一捆」、「包」本章白文零：拓片、我那一捆照 404 之位，包随夹公文包的走了；本章钱满照的是那一套拓（白文「拓纸」「下一张拓」）。
#   ★「撕下那一页（那一页）」係本章新物：本子上我该写第一百六十一天的那一张，拍1 撕下（白文作「这一张」「那一张」，:19—23），拍2 写路、点、掉头推过去（白文作「那一张」「那一页」），拍3 他搁钥匙、她折三折攥着进了後屋（白文作「那一页」）。拍1 白文之「那一页」係 :15 前天那一页（402），字同物异；本器验名只认一个别名，取「那一页」，拍1 之实据在 :19—23。主=我（我写的，我推过去的；照 405 册目录那一页之例，主为交出之人）。
#   ★「钥匙」係本章新物：门里那个人腰上一串七八把里褪下来的一把，铁的，比我的中指长一截，齿上一层黄锈（非铜，不与 340 那一把铜钥匙混）；他搁在那一页第六行上，她拿起来攥进手心，带进了後屋（409）。主=门里那个人。一串里剩下那几把与环随他腰上，不另入。
#   ★「页头」「缝线」「毛茬」「小黑点」「第四行」「那两个点」「三圈」「红字」随本子或撕下那一页，不另入；手填的「四个字」随文书；油、灯头随灯；柄窝随东头那一捆；齿、黄锈随钥匙。
#   ★「条案」「案沿」「案面」「凳」「後屋的门」「门缝」「门板」「锤子」「墙」係场上之设与路人之物，不过我们的手，不入册。
#   ★「指头」「食指」「拇指」「甲盖」「指头肚」「手掌」「手心」「袖口」「小臂」「膝盖」「肩」「肩膀」「腰」「鞋」「鞋帮」「鞋尖」「怀」係身上之物，不入册。
