# 第四百零六章 十口气
笔在昨天那一页里夹了一夜。本子搁在我手底下，我的手也在上头搁了一夜。
夜里，那一头的灯一直点着。灯捻他剪过两回，剪一回，灯头矮一下，又起来。他一张一张往外递拓，钱满一张一张地照。照完一张，他收回去，才递下一张。剪子跟着挪，一张挪一回，挪的时候在条案上擦一下。
凳上，老头坐着，没有躺下。老头的脸冲着门，冲了一夜，那口气一夜都是匀的。刘二在老头脚跟前，头歪在凳腿上睡着了。後半夜，东头把右肩上那个套又套了回去。套上的时候，那一边肩膀往下沉了一沉。天亮以前，东头起来过一回，到门边把那一捆转了个向，又回到凳上。
也是後半夜，车站那边过了两趟车。轮子压着铁，一节一节过去，过了好一阵才过完。头一趟过去，到第二趟来，那一头递出去十一张。後屋那边，一夜没有一点响动。两趟车，我都是醒着听完的。
天亮了，灯还没有吹。他手边那一沓拓，夜里有一指来厚，这会儿剩了一小半。那张文书压在那一沓底下，叠过一回的折痕朝上。门缝外头，街上头一家在卸门板，一块响一声。
我把笔抽出来，翻过一张。
这一张是白的，正面背面都是白的。页头那一行的地方，我看了一阵。
这一张，我没有写页头。
我把本子按平，左手压着订口，右手捏住这一张的上角，往下撕。头一下没有撕动。线吃着劲，纸跟着往上拱，角上折了一道。我把手挪下来，捏着它贴紧订口，一点一点往下走。土纸撕起来不脆，声音是闷的。一截连着一截，从页头响到页脚。
订口里留下一道茬，毛的，比指甲盖还窄。我拿拇指捋了一下，它倒下去。拇指一离开，它又立了起来。撕下来的这一张，挨着订口的那一边也是毛的。
那一头，他手里攥着的那一张停了一停，才递出去。钱满接过去，把剪子挪到它的角上，眼睛没有起来。刘二醒了，抬了一下头，又低下去，眼睛落在自己的鞋上。东头两个肩上，两个套。门边那一捆还靠墙立着，柄上那个窝冲着後屋的门。後屋的门开着，出来的那一块灰亮落在条案那一头，落在她那张纸上。那张纸翘着的角，比昨天低了一点。碗在我手边，是空的，碗底那一圈印子朝着上头。老头那只左手搁在膝盖上，指头弯着。
＊
我往回翻了一张。昨天那一页上，两道线画到头往两边一分。那两个点都在街口外头的右手。小圈旁边那几道圈花了一边，红字还在。挨着它是那块扁的，只画着朝上的那一面。我看了一眼，又翻了回来。
撕下来的那一张，我铺在後一张白页上。两张纸叠着，一样大，上头那一张多一道毛边。毛的那一边冲着订口，我拿左手压住它。
头一行，我写：明天後半夜，头一趟车过去。
文书上那个日子，是後天。
那一头，他又递出去一张。
第二行：出後门，往里，过五道门槛。
後巷那一溜门槛，那天在口子外头，我数过，十三道。这一家在前街，是第八家。
第三行：祠堂檐下，候第二趟车。
这三行，笔走得快。土纸吃墨。笔走得快，字就细；走得慢，墨往两边吃，字就胖。三行都是细的。
第四行，我写：出口子，石头跟前，停。
写到停字，笔尖起来了，悬在纸上头。
我自己喘气，一口一口地数。头两口快了，我压了一压，才匀下来。门缝外头，远远的，是街口那边的锤子。一下一下，有一阵隔得长，我数过两口，它才又落下来。数到第十口，锤子落了七下。
笔尖落下去，写：十口气。
气字写完，笔尖没有起来，贴着纸挪到了它後头。
笔尖在纸上按住，停了一下才起来。
一个点。点得不轻。
笔尖起来的时候，扯起一丝墨，断了。墨往纸里吃，那一点胖出去一圈，比笔尖还大。
第五行：往北，拐三回。
往北，是街口往左。
第六行：到库，取匣。
第七行，一个字：回。
七行字都是细的。胖的，只有那一点。页头那一行的地方，空着。
我把笔搁在本子边上，两只手搁到了条案上。那一头又递出去一张。
＊
笔一搁下，後屋门里出来的那一块灰亮，暗了一块，有一个人那么宽。暗的那一块，往这一头挪过来了。
她顺着条案往这一头走。我的眼睛低着，看见的是她的鞋。鞋落在地上，一点声音也没有。鞋帮上那一层黄土还在，跟我那天回来的时候一样黄。他把手里那一张放下，让了半步，跟在她後头。她走到条案这一头，站在我对面。
我把那一页掉了个头，推了过去。
它从本子上滑下来，在条案上走了一半。她的手先到了，按住了那一头。那一页在两只手当中，绷平了一下。
我那只手拿了回来，搁在本子上。
钱满在条案当中挪了一回剪子，眼睛跟着剪子走。
我看得见的是她按着纸的那只手，指甲缝是黑的。那只手先把那一页翻了过去。背面是白的，当中偏下透着一个点，比正面那一个小。那七行，一行也没有透过来。她又把它翻了回来。
她低下头去看。按着纸边的那根拇指，顺着纸边一行一行往下挪。挪到第四行，停了一停，又往下去了。到了第七行，拇指回到头一行上，又往下挪了一遍。这一遍，到第四行没有停。
他在她旁边弯下腰，膝盖上那一块灰还在。他的眼睛先到了页头上。页头是空的，眼睛在那儿停了一停，才往下走。走过第四行，到第六行，停住了。
“那边的匣子，是空的。”
条案当中，钱满的剪子停了一停，才压下去。凳上，老头的脸还冲着门。她那根拇指在纸边上按着，没有动。
他腰上拴着一把钥匙，拴绳的结打得死，他拿指甲抠了一阵才抠开。钥匙是铁的，柄上一个圈。圈里磨得发亮，齿上起了一层黄锈。他把它搁在第六行上，压住了取匣两个字，手就拿开了。绳他留在手里，缠回了腰上。
她先拿的是钥匙。钥匙一起来，取匣两个字又露了出来。她拿拇指在钥匙齿上抹了一下，抹下来一点黄。钥匙落进她的手心，那只手往下沉了一点，才合上。另一只手把那一页拿起来，折一折，再折一折，折成了三折。她拿指甲在折痕上刮了一回，揣进了怀里。
她顺着条案回去了。走过那一头，她那张纸翘着的角跟着动了一下，她的眼睛没有往那上头去。後屋门里的灰亮，又是整整一块了。
刘二抬起头，看着後屋的门。
过了一阵，後屋里响了一声，是纸打开的声音。又过了一阵，才又响了一声，折上了。
他回那一头去了，把放下的那一张拿起来，递给了钱满。我的手一直搁在本子上。
＊
我把手从本子上拿开。
这一页是白的。当中偏下，有一个点。是那一页上透下来的，比它背面那一个还小一圈，正落在第四行的位子上。我把拇指甲盖挨过去比了比，它还没有指甲盖的一半大。是干的。
我拿起笔，在页头写：今天是第一百六十一天。订口里那道茬立着，碰着我左手的腕子。这一行，我写得慢，字都胖了。
底下一行，我写：天下等不起。笔走得快，五个字都是细的。
这一行跟那个点中间，空着两行。
我把笔夹进这一页，合上本子。油布一层一层裹回去，我把它揣进了怀里。
凳上，老头搁在膝盖上的那只左手抬起来一点，又搁回去了。
【本章亮点】
一·日与接：主线第一百六十一天，天字式。日号只落在拍六我自己那一页的页头，全章末一样写。承四百零四第一百六十天加一。与四百零七暗线第一百五十五日同一天，差六。接四百零四末句：笔在昨天那一页里夹了一夜。抽出来翻过一张，是四百零四：9之式；这一张页头不写，撕了。页上明天後半夜，指第一百六十二天之夜。文书一月八日是第一百六十三天，叙者只一句「是後天」。年数零。
二·魂（物证路）：页撕给了她，点透在我本子上。土纸吃墨，按久了背面能透（110：353至359）。拍二先立一个读者量得出的性：笔走得快字细，走得慢墨往两边吃字胖。七行都细，胖的只那一点。两张纸叠着一样大，透下来落在哪儿由此定。拍五她把那一页翻过去，背面白的，只当中偏下透着一个点。七行一行没透。拍六我把手拿开，自己那一页上又是一个点。它比她那一页背面那一个还小一圈，落在第四行的位子上。我拿拇指甲盖去比，不到一半大，是干的。404：65钉帽比我的指甲盖大一点，同一把尺，叙者不并。页走了，点留下。我在它上头写页头，写天下等不起。页头写得慢字胖，那一行写得快字细，用的是拍二那一把尺。这一行跟那个点中间空着两行，空的是她那一页上第二、第三行的位子。110：345「又空了一行」与402：87「空了一行，点了一个点」那一个形，一行、空、一点，由物自己回到我的账上。叙者零比零解。
三·点之第三面：110：433定点之义是知道没写。402她看懂这一形是护一个不写的名字。今天第四行写的是出口子、石头跟前、停十口气。那一堆石头是她压票之处（401：29至31），她那一面当它是护。点底下是钉（404：65）。老头那一句「钉过的，门里的不用」（404：89）我亲耳听见。同一个点，两样所知，读者两样都握着。⛔画钉。⛔点旁添字。⛔叙者说我不说之由。
四·拍一（夜与撕）：夜里灯点着，灯捻剪过两回。他一张一张递，钱满一张一张照，是四百零四：37之续。老头坐着没躺，脸冲门一夜，气匀。刘二头歪在凳腿上睡。东头後半夜把右肩那个套又套回去，天亮前到门边把那一捆转了个向。後半夜车站过两趟车，承402：7车站之声。两趟之间那一头递出去十一张。她那一条之钟由此来，叙者不说是钟。天亮灯未吹，那一沓由一指来厚剩一小半，未照完，留四百一十二。文书压在那一沓底下。街上头一家卸门板，是400：55早上之钟。这一张正面背面都白，页头之处我看了一阵，不写。撕是全书头一回。头一下没撕动，线吃劲纸拱；换手贴紧订口一点一点走。土纸撕起来闷。订口一道茬比指甲盖窄，捋倒又立起，叙者不说伤。屋里诸人绕着走：他递拓停一停，钱满眼不起，刘二眼落在鞋上，老头指头弯着。碗空，印子朝上，承404：41。
五·拍二与拍三（七行与一点）：翻回昨天那一页看一眼。他那两个点都在街口外头的右手。她那一条往北，是街口往左，是其反向，叙者只交左右。花了一边的圈、红字、只画得出朝上那一面的扁的，入眼不解。七行之数各有来处。头一趟与第二趟出自夜里两趟车。五道出自那天在口子外头数的十三道与前街第八家，十三减八，叙者不算，与401：51至53互算。写的当中那一头又递一张，屋里照旧。第四行写到停字，笔尖悬起。我照自己的气数，头两口快了，压一压才匀。锤子有一阵隔得长，数到第十口，街口锤子落了七下。404：93那一把锤，今天作量她在石头跟前那一阵之尺。笔尖落下写十口气，气字後头按住，停了一下才起来，是110：351逐字之式。一个点，点得不轻。笔尖起时扯起一丝墨断了，墨吃开，比笔尖大。对标拍库第二拍（笔尖）、第三十三拍（同尺量）。
六·拍四与拍五（推与钥）：灰亮暗了一个人那么宽，暗的那一块挪过来，她来。我眼低，看见的是她的鞋，鞋帮黄土跟我那天回来一样黄。这是404：49先看见的是鞋之翻面，那两双鞋上没有这条街的土。「我把那一页掉了个头，推了过去。」券句原字。400：69我两只手捏本子掉头推到那只手跟前，说你看看。今天一页纸，推到一半她的手先到，是403：69之性。我的手拿回来搁在本子上，正盖着那一处，是400：73两只手拿回挨着碗之变。钱满眼睛跟着剪子走，是400：77眼睛跟着本子之反，不见页。她指甲缝是黑的，照402：83，不解。她翻背面看一眼，是110：355我翻背面之式，今天在她手上。她的拇指顺纸边往下，头一遍到第四行停一停，第二遍不停。他弯腰，膝上那一块灰还在，照404：31入眼不解。他先看页头，是404：27之习；页头是空的，眼睛停一停才往下。走过第四行不停，到第六行，说「那边的匣子，是空的」。她由此知是饵，叙者零书。钱满的剪子停一停才压下，老头的脸还冲着门，她的拇指按着不动。钥匙铁的，结打得死，指甲抠开。柄圈磨亮，齿上黄锈，常带少用。搁不递，压住取匣两字，绳留他手。她先拿钥匙，两字复露。她拇指抹齿，抹下一点黄。钥匙落进手心，手往下沉一点才合上。页折三折，指甲刮折痕，揣怀。回去时她那张纸翘着的角动一下，她不看，那张纸她不回手。刘二抬头看後屋的门，是404：91刘二抬头看老头之续。後屋里纸开一声、折一声，接四百零七她照那页算。我的手一直搁在本子上。
七·收：我写完页头与那一行，笔夹进去，本子合上。油布裹回揣怀，是400：69油布之收。拍七老头左手抬起一点又搁回，400：77逐字。那一回抬在我推本子求人看之时。今天抬在页已在她怀里、本子已在我怀里之後。知而不问，叙者零书。以一个动作收，不收在点上，「没有」之态句零。三拟：一拟收在空着两行，是盘点之形，弃。二拟收在本子揣进怀里，重在我，弃。取三。
八·人：我零句，与她零句。她零句，只有手：先拿钥、抹齿、翻背面、拇指两遍、折、刮、揣、走。她的眼不往自己那张纸上去。他一句，眼先到页头，绳留手里。老头零句，左手一抬一搁，脸冲门一夜。钱满零句，眼不离拓纸，剪子停一停。东头零句，夜里套回右肩那个套，天亮前转了那一捆。刘二零句，抬头又低，後看後屋的门。
九·悬账逐条：大审限四百零五两笔（第五十四、第五十五），已治於四百零五。本章零碰，驳其挂於本章。看官账限本章零笔。悬念哨甲东头之套，治：後半夜右肩那个又套回去，那一边肩膀往下沉了一沉。两个肩上两个套，由一变二；疤不书。悬念哨乙柄窝，治：东头天亮前把门边那一捆转了个向，柄窝冲後屋的门。位子未挪，窝之来历不书。冷轮四百零四於本章到期，交记席回执销之。悬念哨丙本章零碰。大问爷爷照卡挂，交总编辑裁，倾向四百零八，本章不担。402：103悬指，本章他的眼睛走过第四行未停，悬仍不落，挂限四百零七。收「本子推过去」（400）。收「钉过的，门里的不用」（404·由在页上）。收「点得不轻」（110）。收「我知道，我没写」（110·点之义第三面·零引）。埋：第四行之点，收於四百零七。那边的匣子是空的与铁钥匙，收於四百零九。撕下那一页之毛边与三折，收於四百一十六。天下等不起，收於四百四十。我那一页上透下来那一点与它上头空着的两行，收於四百四十翻回之时。
