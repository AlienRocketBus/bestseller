# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—29行｜拍2=33—53｜拍3=57—65｜拍4=69—85。骨记六拍与之相当：骨记拍一（照页走数）、拍二（按那一点·叫绝）在拍1｜骨记拍三（翻半截抄）、拍四（数两遍）在拍2｜骨记拍五（门缝）在拍3｜骨记拍六（拐角·钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 406、403 册：「撕下那一页（那一页）」「本子」主=我；「钥匙」「碗」「剪子」「那一套拓（拓）」「条案上那盏灯（灯）」主=门里那个人；「铅笔头」「找头」「兖字那半截」「鞘」主=她。「兖字那半截」本章白文作「那半截」，以之为别名；「找头」本章白文作「找回来的那几张」，以之为别名；「鞘」本章白文拍1 作「鞘口那一圈铜」、拍4 只作「那一圈铜」，以「那一圈铜」为别名。
#   ★「票」承 401（401:29 票背写「往左推一指，从右头掀」，401:31 折两折搁进坑里，扁石坐回）：本章白文拍1「底下压着她那张票」，不过手；拍2「买票找回来的那几张」之票字係找头之来历，不另计。
#   ★「後门之闩」本章过她的手（拍4 左手托着闩身、右手捏着闩头往外抽），故入册（403 册以其不过手不入）；闩头、闩身、槽随闩。
#   ★「鞋摊」係街口之物，不过我们的手；本章以其开与收交 405 之果（白文撤字零），故入册以记去处；油布、两块砖、矮凳、铁拐子、黑鞋黄鞋、锤子随鞋摊，不另入。
#   ★406 册之「文书」「东头那一捆」「背带（套）」「两面那张纸（她那张纸）」、403 册之「刃」「皮带」「布包」「壶」「壶盖」「出门簿」本章白文零，照其前册之位。
