# 第408章 · 器物册（造式二代·合稿席立｜照 407、406 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—41行｜拍2=45—67｜拍3=71—87｜拍4=91—103。骨记四拍与之相当：骨记三·拍一（出门）在拍1｜四·拍二（叫绝）在拍2｜五·拍三（玉背·掌心）在拍3｜六·拍四（走·收）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承 407、406 册：「撕下那一页（那一页）」「本子」「笔」主=我；「碗」「征集文书（文书）」「那一套拓（拓）」主=门里那个人；「背带（套）」「东头那一捆（柄）」主=东头；「铅笔头」主=她。「那一套拓」本章白文作「拓纸」，取「拓」为别名；「东头那一捆」本章白文作「门边那一捆」「柄上那个窝」，取「柄」为别名。
#   ★「玉」係我贴身之物（1:33、2:59、380:25）：拍1 我拇指过其背；拍3 我弯腰挡雨，滑出半截背面朝她，我拇指照她划的路摸出回字；拍4 她从我的拇指底下托起来，塞回我的领口。主=我。
#   ★「前门之闩（闩）」係前屋临街那扇门之闩：拍1 我抽出，门带严以後门里头又进了槽。与 407 册「後门之闩」异物；後门之闩本章白文零，照 407:75 之位（409 起手回槽）。
#   ★「门板上那几张纸（几张纸）」係对面门板上贴的那几张（§三#17，398:29 墙上所贴之同类），当中一张印着我的脸；不过我们的手，以其见与不见交三天不出门之由，入册以记去处。
#   ★「隔壁那盏灯（灯）」係祠堂隔壁那一家窗里之灯，檐下唯一之亮，拍2 之翻、写与拍3 之划、认俱在其光里；不过我们的手，以其为一章之光源，入册。前屋条案上那盏灯（407:71 点上）本章白文只作「屋里的亮」，零名，照 407 之位。
#   ★407 册之「钥匙」「兖字那半截（那半截）」「找头（找回来的那几张）」「票」「鞘（那一圈铜）」「剪子」「鞋摊」、406 册之「两面那张纸（她那张纸）」本章白文零：钥匙随那一页在她贴心口那一层（409）；那半截、找头在她怀里；票在扁石底下；鞘在她小臂上（拍1 她的手到了袖口上又下来，鞘字零）；剪子在钱满手里；鞋摊 407 夜已收；她那张纸在条案那一头。
#   ★「祠堂」「檐」「门」「门缝」「石阶」「石堆」「口子」「门板」「门框」「街口」「凳」「墙」係场上之设，不入册；「指头」「指肚」「指头肚」「食指」「拇指」「手心」「手腕」「手背」「袖子」「袖口」「领口」「脖子」「肩膀」「膝盖」「鞋」「鞋尖」「鞋帮」「怀」「兜」係身上之物，不入册。
