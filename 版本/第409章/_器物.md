# 第409章 · 器物册（造式二代·合稿席立｜照 408、407 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—7行｜拍2=11—41｜拍3=45—59｜拍4=63—93。骨记诸拍与之相当：骨记一（日与接·回屋）在拍1｜骨记拍一（过街）、拍二（叫绝）、拍三（不往回）在拍2｜骨记拍四（伏·伤）在拍3｜骨记拍五（库房·匣）、拍六（一挥·出）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同线章 407 册：「撕下那一页（那一页）」主=我；「钥匙」「後门之闩（闩）」主=门里那个人；「票」「鞘（那一圈铜）」主=她。「刃」承 403 册，主=她。
#   ★「後门之闩」係後巷第八扇之闩：拍1 她托着送回了槽里，没有响（407:75 抽出之回）。与拍4「库房後门之闩」异物。
#   ★「扁石」「钉」本章过她的手（拍2 两只手扳住扁石往左推一指、往右送回一指；左手指头肚搁在钉上，没有按下去），故入册（407 册以扁石不过手作场上之设）。钉本章白文只拍2「有没有钉」一见，余作「一样东西：凉的，边是利的」。
#   ★「短铁管」拍3 只作「一样东西……是硬的」，拍4 方见其名，故入=4。「那一道亮」拍3 作「巷子口上亮了」，拍4 方见拿亮的那一个。
#   ★「手腕上那一圈绿的」係 407:63 左边那个捋袖看过的手腕上之物，夜里只剩一圈绿的点子：拍3 墙根底下一闪、攥她时就在她眼睛底下；拍4 指头缝里透出一点绿的。
#   ★408 册之「门板上那几张纸」本章白文零（致命一治：往北那一条不是那一家门前那一条）；407 册之「兖字那半截（那半截）」「找头（找回来的那几张）」「铅笔头」本章白文零：那半截、找头在她怀里，铅笔头在兜里（408:55）；那一页背面小城一行与好字折在里头，本章零展读。
#   ★「石堆」「石缝」「口子」「门板」「门洞」「巷子」「墙角」「库房」「架子」「卷着的纸」「门」「锁眼」「门缝」「房梁」係场上之设，不入册；「指头」「指头肚」「中指尖」「手心」「手背」「拳头」「指缝」「膝盖」「肋下」「肩膀」「小臂」「袖口」「袖子」「领口」「胸口」「衣裳」「鞋尖」「鞋底」「贴心口那一层」「怀」係身上之物，不入册。
