# 第410章 · 器物册（造式二代·合稿席立｜照 409、408 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行｜拍2=29—43｜拍3=47—61｜拍4=65—67。骨记诸拍与之相当：骨记三（拍一）在拍1｜骨记四（拍二）在拍2｜骨记五（拍三·叫绝）在拍3｜骨记六（拍四·钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同线章 408 册与异线章 409 册：「後门之闩（闩）」主=门里那个人；「那一道亮」主=拿亮的那一个；「短铁管」主=拎铁管的那一个。
#   ★「前门之闩」係前屋之门之闩（408:13 我出门後门里头又进了槽）；「後门之闩」係後巷第八扇之闩（409 物位：她夜里再出时抽下，白文零书，在槽外、门虚着），本章拍3 钱满手搭闩头又拿下，照留；二者异物。第二处之闩只闻其声，係场上之设。
#   ★「短铁管」本章白文只作「一声是铁的」；「那一道亮」本章白文作「一道白的亮」「那道亮」。
#   ★「笔」係我右手里那支（408:101 掉过头试掌之笔）；拍3「文化口的那一支笔」係官家兜里摸出来的，异物。
#   ★「单子」两张：一张收进公文包，一张留在碗边；单子抽出来时底下早盖好了两个章。
#   ★409 册之「撕下那一页」「钥匙」「刃」「鞘」「匣子」「匣盖裂下来的那一截」与 408 册之「玉」「铅笔头」，本章白文零（她不在屋，409 之物一字不进）；「那一道毛茬」係撕下那一页留在本子缝线里之根，在我手上，故入册。
#   ★「灯」「灯头」「门板」「门楣」「门楼」「门环」「夹道」「灶膛」「後屋的门」「条案」「案沿」「石阶外沿」「石堆」「墙根」与拍1 那七道门槛係场上之设，不入册；门楼底下那道门槛叫钱满抬起又落回，故入册。「拇指」「指甲盖」「手心」「胳肢窝」「膝盖」「巴掌」係身上之物，不入册。
