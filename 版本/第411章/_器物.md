# 第411章 · 器物册（造式二代·合稿席立｜照 410、405 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 7 拍：拍1=正文5—11行｜拍2=15—25｜拍3=29—35｜拍4=39—53｜拍5=57—67｜拍6=71—77｜拍7=81—91。骨记诸拍与之相当：骨记一、二（门与叶）在拍1｜四（拍二）在拍2｜五（拍三）在拍3｜六（拍四·叫绝）在拍4｜七（拍五）在拍5｜八（拍六）在拍6｜九（拍七）在拍7。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同镜前章 405 册：「档柜（柜）」「用印登记（登记）」（主=管档的）「砚」（主=霍钧）照旧；「停收之纸」405 册别名作「停收的纸」，本章白文作「停收的那张纸」，别名随之。
#   ★405 册之「名册」「兖那一页」已烧尽，本章白文只「名册压过的那一块」，係案上之痕，不入；「目录那一页」405:83 叫点户揣怀连夜去了，本章零。
#   ★「章匣」係 391:113 推盖之匣（391 册「章」之匣，匣里那一枚白文零书），与 409 册库房地上之「匣子」异物，本名以别；「册里夹着的那张纸」与 410 册「那张折着的纸」（异线条案沿上）异物，本名以别；「缺角章」白文只作「一样硬的」「那一样」，零掏、零名，本名只在册上。
#   ★只一拍一见、去处当拍已书者不入册：「笔」（拍2·点墨写来字，放处白文零）。「糨子」随封条；「结单」「末了一枚红章」「附一纸那一行」「封皮」係那一册之页面，随其物；「半枚红印」係那张纸之面；「两个红印」係停收之纸之面。
#   ★「院门」「插销」「屋门」「门槛」「门框」「案」「案沿」「案面」「灶」「灶膛」「窗纸」「床板」「抽屉」「档室的门」「叶子那一溜」「霜」「印子」「後墙」「墙角」係场上之设，不入册；「拇指」「指节」「指肚」「指甲根」「膝盖」「袖口」「怀」係身上之物，不入册。
