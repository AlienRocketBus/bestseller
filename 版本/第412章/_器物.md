# 第412章 · 器物册（造式二代·合稿席立｜照 410、411 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—19行｜拍2=23—39｜拍3=43—63｜拍4=67—77。骨记诸拍与之相当：骨记三、四（拍一）在拍1｜五、六（拍二）在拍2｜七、八（拍三）在拍3｜九（拍四·叫绝）、十（钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同线章 410 册：「前门之闩（闩）」「後门之闩（闩）」「碗」「留下的那一张单子（单子）」「那张折着的纸」主=门里那个人；「扣着的那一张」「左手边那一摞拓纸」主=钱满；「套（那个套）」主=东头；「本子」主=我；「门边那一捆（那一捆）」「两个包」「两枚章」无主，照旧。别名随本章白文：「两枚章（那一枚）」「两个包（包）」「那张折着的纸（那张纸）」「左手边那一摞拓纸（那一摞）」「扣着的那一张（那一张）」。
#   ★「拓片」承 400 诸册，主=我（73 钱满所拓、398 我从门缝底下推进去的那一张，400 不还，本章仍在那一头手边）。「剪子」410 册作主=钱满、400 诸册作主=门里那个人，本章只压一角，不书主。
#   ★「条子」係 392 收皮子的那一个卖进去那一张之条子（392 册作「那张纸」，未入册），本章白文作「条子」「叠成巴掌大的一块纸」，主=钱满，入册。
#   ★「两个包」之内：头一个包里一摞画墨道道的，第二个包里一摞按着两枚指印的，随包；「麻绳」「油布」係包之捆裹，随包；拍4 包里的两摞各卷一卷、拿麻绳扎好。
#   ★「笔」本章白文零（写页头，笔字不书），不入册。「纸」字诸处各随其物：拍1 条子，拍2—4 那张折着的纸，拍3 蒙纸之拓，拍4 前屋响的是钱满怀里那三卷。
#   ★「灯」「灯头」「条案」「凳子」「架子」「纸摞」「窗纸」「小窗的破洞」「前门」「後门」「门缝」「门边」「门槛」「门板缝」「槽」「墙」「墙根」「高墙」「露了砖的地」係场上之设，不入册；「後门」虚着一指之态见拍4（413）。「鞋印」「印子」「霜」「一道白」「一星锈」係场上之痕，不入册。「印」係条子与单子之面、「记号」係那张折着的纸之面、「指印」「道道」係包里那两摞之面，各随其物。
#   ★「拇指」「指甲」「指头」「食指」「指肚」「手掌」「膝盖」「肩」「右肩」「眼睛」「眉毛」「胳肢窝」「腿」係身上之物，不入册；「柄」「窝」係那一捆之部、「白麻线」係套之部，各随其物。
