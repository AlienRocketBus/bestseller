# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—13行｜拍2=17—21｜拍3=25—33｜拍4=37—45｜拍5=49—59｜拍6=63—65。骨记诸拍与之相当：骨记三（拍一）在拍1｜四（拍二）在拍2｜五（拍三）在拍3｜六（拍四·叫绝）在拍4｜七（拍五）在拍5｜八（收）在拍6。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同线章 409 册：「撕下那一页（那一页）」主=我；「钥匙」「後门之闩（闩）」主=门里那个人；「匣子」「匣盖裂下来的那一截」无主，照旧。「门边那一捆」承 412 册，无主。「铅笔头」承 407 册，主=她（409 册白文零，在兜里）。别名随本章白文：「匣盖裂下来的那一截（匣盖那一截）」「门边那一捆（一捆）」。
#   ★「後门之闩」係後巷第八扇之闩：412 册出=横在槽外头（413）；本章拍4 她右手托着闩身送进槽里，拍6 门缝里的灰亮到它上头，闩在槽里。库房後门本章零闩（拍1 摸到了後门，拍2 从那道缝里出去）。
#   ★「鞋」409 册作身上之物不入册；本章拍4 脱下来搁在门轴那一边，成场上之物（414 他凭鞋认），故入册，主=她。拍3 冻泥里三样鞋底係那三个人的鞋印，场上之痕，不入册。
#   ★「刃」「鞘」本章白文零（拍4「她的手到了袖口上」「从袖口上下来了」，袖里之物零书），不入册。
#   ★「架子」「横木」「架子腿」「库房」「後门」「缝」「门洞」「墙根」「石堆」「口子」「门板」「门槛」「门框」「门轴」「槽」「砖」「车」係场上之设，不入册；「灰」「纸渣」「霜」「冻泥」「土」「鞋印」「印子」「一道白」係场上之痕，不入册。
#   ★「衣裳」「领口」「袖口」「兜」「怀」「贴心口那一层」「肋下」「指头」「指头肚」「指甲」「拇指」「指甲盖」「掌心」「膝盖」「手腕」「嘴唇」「袜底」係身上之物，不入册；「柄」「窝」係那一捆之部，随其物；「纸」「褶」「钩」係那一页之面，随其物。
