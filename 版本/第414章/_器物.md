# 第414章 · 器物册（造式二代·合稿席立｜照 412、413 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—23行｜拍2=27—53｜拍3=57—77｜拍4=81—111。骨记诸拍与之相当：骨记三、四（拍一）在拍1｜五至八（拍二·叫绝）在拍2｜九至十二（拍三）在拍3｜十三、十四（拍四）、十五（钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同线章 412 册：「後门之闩（闩）」「前门之闩（闩）」「碗」「那张折着的纸（那张纸）」主=门里那个人；「套（那个套）」主=东头；「本子」主=我；「左手边那一摞拓纸」主=钱满；「门边那一捆（那一捆）」「两个包」无主，照旧。「鞋」承 413 册，主=她。「那一道亮（亮）」「短铁管（铁管）」承 409 册，主=拿亮的那一个、拎铁管的那一个（拍2 白文作「拿亮的那只手」「一截铁管」）。别名随本章白文：「两个包（那三卷）」「左手边那一摞拓纸（那三卷）」，412 拍4 包里的两摞各卷一卷、他照的那一摞卷一卷，三卷拿麻绳扎好，本章白文只作「那三卷」。
#   ★「後门之闩」本章拍1 只见其在槽里，我的手在它上头搁了一会儿，没有动它（关门进闩 413 已尽）。「前门之闩」拍2 刘二的手搭上去、攥住，没有抽；拍3 前门开过（东头背老头出去、刘二出去泼水），闩之动白文不书。
#   ★「白布」係缠在那一只手腕上之物，「大衣」「袖子」「布鞋」「後跟」係门外诸人身上之物，不入册；「柴灰」係那只手指头上之痕，不入册。
#   ★「铜」拍2 只闻其声（她鞘口那一圈铜·409:55），其物白文零，不入册；「刃」「鞘」本章白文零。「线」係拍4 梦里那只手所攥，梦中之物，不入册。
#   ★「扣子」「领口」「衣裳」「拇指」「指肚」「指头」「指头肚」「手心」「手腕」「腕子」「膝头」「肩」「右肩」「背」「胳膊」「脚背」「眼睛」係身上之物，不入册；「柄」「窝」「当腰」係那一捆之部，「白麻线」係套之部，各随其物。
#   ★「砖」「门边」「门框」「门缝」「门槛」「凹」「门轴」「槽」「架子」「纸摞」「後屋」「前屋」「里门」「前门」「门板」「墙」「条案」「凳子」「街口」「隔壁」「灯」係场上之设，不入册；「印子」（鞋帮上泡过的那一道、碗搁过的那一圈）「白棱」「灰」「白」（气之白、亮之白、管头之白）「褶」係场上、身上之痕，不入册。
