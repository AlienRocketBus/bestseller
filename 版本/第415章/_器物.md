# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—31行｜拍2=35—53｜拍3=57—75｜拍4=79—89。骨记三、四在拍1｜五、六在拍2｜七、八在拍3（八之末接拍4）｜九在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承上一同镜章 399 册：「镇纸」「笔」俱无主，照旧。399 册「附件三份（三份）」係回函之附件，399 拍5 与来文一并放回抽屉；本章拍2「抽屉底下压着三份」係 277：581 之三份，另一物，⛔借其名、⛔以「三份」入册：上头那一份以「照片」立，最底下那一份即「那一卷」，当中一份白文零书。389 册之「底稿」主=录入的那个；本章抽屉里那一沓是他自己的传真底稿（399：17 之式），另一物，以「空白的底稿」为本名、「底稿」为别名。
#   ★「印好的表」拍1 白文又作「底下那一张」「盖好的那一张」；拍3、拍4 白文只作「早上盖了章的那一张」，眼看一回、底稿压上去一回，其身未挪，入、用、出俱落拍1（去处已定在右手边那一摞上头）。「那一卷」拍2 白文作「最底下那一份」，拍2 至拍4 白文俱见「卷皮」，以之为白文之名。「签收」拍4 白文只在「两张纸」里（会签单同在其中），⛔以「两张纸」为别名，出落在拍3。
#   ★「那一卷」里头一张「表」（伤情、在场人员、处置方三栏）随那一卷，卷皮合上一半盖住在场人员那一栏。「笔帽」随笔；「印泥」随印台；「勾」係第四十张右上角之痕，随第四十张；「红印」係印好的表上之痕，随表；拍3 之「章」係会签单霍钧那一栏之印，纸上之痕，随会签单，与本册「章」（他抽屉里那一枚）别。
#   ★「抽屉」「笔筒」「传真机」「案」「案角」「案沿」「窗户」係屋里之设，不入册（照 399 册「抽屉」「笔筒」「桌上的电话」之例）；「指肚」「指头」「手腕」「手掌」「袖口」「眼睛」係身上之物，不入册。
