# 第416章 · 器物册（造式二代·合稿席立｜照 414、415 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—43行｜拍2=47—63｜拍3=67—87。骨记三至七（拍一、拍二）在拍1｜八、九（拍三）在拍2｜十至十二（拍四、拍五、收）在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 414 册与 406、409、413 册：「撕下那一页（那一页）」「本子」「笔」主=我；「钥匙」「碗」主=门里那个人；「套（那个套）」主=东头；「门边那一捆（那一捆）」无主；「两个包（那三卷）」无主、「左手边那一摞拓纸（那三卷）」主=钱满，照 414 册。「钥匙」拍1 白文又作「那把铁钥匙」，「铁钥匙」只拍1 一见，⛔作别名（别名格须三拍俱有其名），照 406、409、413 册只作「钥匙」。
#   ★「一串钥匙」係那一头腰上那一串（406：57 环上剩下的那几把），与「钥匙」别，主=门里那个人；本章只拍1 响一声、他的手捂着。
#   ★「挑子」拍3 门外过去，扁担吱扭吱扭的；拍1「是挑水的」係街上人声，⛔并作一物。
#   ★「钩」「回字」「好字」「那一块」「那一点」「小黑点」「折痕」「褶」「干泥」係那一页、本子上之痕，随其物；「毛茬」「缝线」「纸里的筋」係本子与那一页之部，各随其物；「柄」「窝」係那一捆之部，「麻线」「白麻线」係套之部，「齿」「柄」「黄锈」係钥匙之部，各随其物。
#   ★「袜子」「袜底」「袜尖」「下摆」「袖口」「头发」「衣裳」「心口」「手心」「指头」「拇指」「食指」「膝头」「胳膊」「肩膀」「颧骨」「眼睛」係身上之物，不入册。
#   ★「门板」「里门」「前门」「後门」「门框」「门槛」「条案」「案沿」「凳子」「凳」「砖」「架子」「纸摞」「後屋」「街」係场上之设，不入册；「亮」「一线」「那一圈印子」係场上之光与痕，不入册。
