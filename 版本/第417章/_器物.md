# 第417章 · 器物册（造式二代·合稿席立｜照 409、413、416 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—17行｜拍2=21—63｜拍3=67—93。骨记三（拍一）在拍1｜四（拍二）在拍2｜五（拍三）在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 409、413 册：「匣盖裂下来的那一截（那一截）」无主，照 409 册；「刃」「鞘」「铅笔头」「鞋」主=她，照 409、413 册。「鞘」409 册别名作「鞘口的铜」，本章白文作「鞘里」「鞘口那一圈铜」，无「鞘口的铜」四字，故只作「鞘」。
#   ★「车票（票）」係拍2 新买那一张，与 409 册「票」（扁石底下她那张票）别：那一张与「钉」「扁石」本章白文零其名（拍1 只「顶上那块扁的」），石下照旧，零解零动，不入册。
#   ★「找回来的那几张（一沓）」係她那几张钱，拍2「她捏成一沓」，拍3「往里是那一沓」；数零，留 459。
#   ★「鞋」413 册出=门轴那一边（414）；416 白文零见；本章拍1「鞋底踩上去」，已穿在她脚上，故入册收其去处。
#   ★「盘纹」係後门门板上之刻（401），场上之痕，不入册。「後门」「门轴」「框」「後巷」「墙根」「门洞」「石堆」「鞋摊」「铺子」「烟囱」「车站」「炉子」「炉口」「窗口」「洞」「牌子」「柱子」「轨」「车」「车门」「蹬子」「扶手」「座」「椅背」「窗户」「窗台」「过道」「灯」「候车的那间屋子」「发车的钟点」「出站口」「木头架子」「墙」係场上之设，不入册；「霜」「那一片湿的」「热气」「风」「田埂」「房顶」係场上之象，不入册。
#   ★「刃柄」「刃口」「刃尖」係刃之部；「鞘口」「那一圈铜」係鞘之部；「小口」係车票上之痕；「毛刺」「木纹」「第一道」係那一截之部与痕；「棉被」係桶之盖：各随其物。
#   ★「袖口」「袖子」「胳膊」「肋下」「手心」「掌心」「指头」「手指头」「指甲」「手腕」「腕子」「膝头」「肩膀」「眼皮」「怀」係身上之物，不入册。
