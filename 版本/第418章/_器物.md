# 第418章 · 器物册（造式二代·合稿席立｜照 416、417 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—51行｜拍2=55—69｜拍3=73—107。骨记三、四（拍一之前、拍一）在拍1｜五、六（拍二、拍三）在拍2｜七至十（拍四至收）在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 416 册与 406 至 414 诸册：「钥匙」「碗」「一串钥匙」「那张折着的纸」主=门里那个人；「本子」「玉」主=我；「套（那个套）」主=东头；「门边那一捆（那一捆）」「两个包（那三卷）」无主；「左手边那一摞拓纸（那三卷）」主=钱满，照 416 册。「一串钥匙」拍3 白文只作「那一串」，故作别名格，拍1「那一串钥匙」两名俱有。
#   ★「公输那一卷（那一卷）」係那一头从後屋一排架子最底下那一层的底下抽出之卷，本名取卷头二字，以别於前册「那一卷（卷皮）」（主=黎东来，异线异物）；白文作「那一卷」「一卷」。
#   ★「画墨道道的那一摞」「按着红指印的那一摞」係两个包所摊之两套（412:43 结构、校准）；「钱满照的那一摞」即左手边那一摞拓纸所摊，随其物。「画墨道道的那一摞」三拍俱见，又是钥匙末了所搁之处，故另立一行；「按着红指印的那一摞」挨着钥匙，两枚红指印之距收 420，故另立一行。
#   ★「头一张」「画玉那一张」「负匣那一张」「那一方」「架子」「格子」「座」「半个回字」「仿」係画墨道道的那一摞上之纸与画；「两枚红指印」係按着红指印的那一摞上之痕：各随其物。
#   ★「黑了的麻绳」「绳」「那根绳」係公输那一卷之部；「扎着的麻绳」係那三卷之部；「捆它的绳子」「柄」「窝」係那一捆之部；「麻线」係套之部；「齿」「锈」係钥匙之部；「第一百四十八天那一张」「鼓着的那一处」「那一圈墨」「当中那一点」「欠那一页」係本子之部；「玉背」「断口」係玉之部：各随其物。「绳」「架子」各只见於拍1、拍3。
#   ★「袖子」「怀」「领口」「胸口那一兜」「衣裳」「後腰」「肩膀」「手心」「手掌」「指头」「指头肚」「指头背」「拇指」「食指」「膝头」「眼睛」係身上之物，不入册；钱满衣裳後腰那三道发亮的印子、肩膀上两道係衣裳上之痕，随身。
#   ★「前门」「闩」「门板缝」「里门」「门框」「後屋」「窗纸」「架子当中那条道」「最底下那一层」「条案」「案沿」「凳」「凳子腿」「墙」係场上之设，不入册。
