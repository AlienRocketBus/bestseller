# 第419章 · 器物册（造式二代·合稿席立｜照 411、418 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—25行｜拍2=29—45｜拍3=49—73。骨记四（拍一）在拍1｜五（拍二）在拍2｜六、七（拍三接拍四、收）在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同镜前章 411 册：「档柜（柜）」「纸条（那一条）」（主=霍钧）「章匣（匣子）」（主=管档的）「那一册」「砚」（主=霍钧）照旧。411 册档柜之开口（霍钧这一面的门开着；419）於本章拍3 收：两面俱合。
#   ★新立三件，主=管档的（本章不出场，只其物）：「印泥」（档室案上那一盒）、「抽屉里那一块布（布）」（布上一个方的窝，章匣原搁之处，411:29 那一拉一推）、「档室那把椅子（椅子）」（四条腿底下地上四个窝；465 收「坐进那张椅子」）。霍钧那把椅子係他屋里之设，只在柜口里见一眼，不入册。
#   ★「来字」係纸条之面；「封皮」「封皮上糊着的那一张纸」係那一册之面；「门扣」係档柜之部；「盖子」係印泥之部；布上那一个方的窝係布之面：各随其物。
#   ★只一拍一见、去处当拍已书者不入册：「罐子」（拍3·案底下，糨子的酸味）、「扫帚」（拍3·立在门後头）。
#   ★「院门」「院墙」「屋门」「档室的门」「铁扣」「门槛」「门框」「案」「案沿」「案面」「抽屉」「小窗」「窗纸」「墙根」「墙角」「墙皮」「霜」「那一溜碎叶子」「碎的那一处一处」「地上那四个窝」係场上之设，不入册；「拇指」「指节」「手掌」「膝头」「袖口」「胸口」「鞋帮」「裤脚」係身上之物，不入册。
