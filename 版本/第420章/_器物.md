# 第420章 · 器物册（造式二代·合稿席立｜照 418、419 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行｜拍2=29—51｜拍3=55—81｜拍4=85—101。骨记一、三（日与接、拍一）在拍1｜四（拍二）在拍2｜五（拍三）在拍3｜六、七（拍四、钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 418 册与 413、416 册：「钥匙」主=门里那个人；「本子」「撕下那一页（那一页）」主=我；「左手边那一摞拓纸」主=钱满；「画墨道道的那一摞」「按着红指印的那一摞」「匣子」无主。418 册「钥匙」「画墨道道的那一摞」「按着红指印的那一摞」与 413 册「匣子」之出所书「420」，於本章收。
#   ★新立五件：「他照的那一张」（拍1 钱满从自己照的那一摞里抽出一张折了揣怀，白文到拍4 方以此名见）、「包里那一张」（拍3 白文作按着红指印的那一摞「最上头那一张」，到拍4 方以此名见）、「钢尺」「火柴盒（火柴）」主=钱满；「平石」无主（422；拍3 白文只作「石头」，两根指头底下那一块，随其物）。
#   ★「齿」係钥匙之部；「第一百四十八天那一张」「鼓着的那一处」「欠那一页」「缝线」係本子之部；「钩」「两道旧折痕」「撕开的那一边」係那一页之部；「那一方」「一道粗墨」係画墨道道的头一张上之画；「油布」「油布包」係按着红指印的那一摞之包；「两枚红指印」「十二息」「边上一行小字」係包里那一张上之痕；「盖沿」「茬口」係匣子之部；「一根」「第二根」「第三根」係火柴：各随其物。
#   ★「後门」「门槛」「祠堂檐」「祠堂门缝」「街口」「石堆」「钉」「门洞」「巷子」「墙」「锁眼」「漆皮」「门」「架子」「格子」「卷子」「签子」「横木」「最底下那一层」「乱脚印子」「小圆点」「印子」「窝」「後墙底下一道门」「门缝」係场上之设，不入册；「怀」「贴心口那一层」「外头一层」「膝盖」「膝头」「後腰」「肩膀」「後脖颈」「掌」「指头」「拇指」「食指」「指甲尖」「裤子」係身上之物，不入册。
