# 第四百二十章 不差
钥匙在那一方上，搁了一宿，又搁了一天，齿一直冲着我这一头。条案上别的东西挪过几回，它没有人挪。
四更，我把本子合上，揣进怀里，打了钩的那一页夹在里头。手伸过去，把钥匙拿了起来，铁是凉的。它盖着的那一方，在画墨道道那一摞的头一张上，画在最靠里那一排架子的底下。钱满从按红指印的那一摞上，揭下最上头那一张，卷起来，揣进了怀里。钢尺照旧别在他的後腰上。
出後门，七道门槛。祠堂檐底下，等两刻。檐底下那一块地上没有霜，只够站一个人，钱满的半边身子露在檐外头。两刻里，他换过一回脚。
街口两头都空着。白天站人的那两处，地上叫鞋底碾平的那两小块，比别处白一点，上头没有鞋。
到了石堆跟前，我往前过去两拃，站住了。街那边一家的窗纸还黄着，亮斜着铺过来，铺到我鞋尖上。我把本子掏出来，翻到那一页，凑到亮里。第四行上三个钩，末了那一个，挨着我按下去的那一点。我的眼睛到了石堆脚底下那道缝里，缝里有一星亮，是钉帽。
我出一口气，白的往亮里去一回。十口气出完，我把本子揣回怀里。往北，拐三回。
往北那一条街宽些。墙根底下的冻土上落着一层霜，霜底下一溜旧鞋印，鞋尖都冲着北，印子的边叫水泡软了，又冻住了。我挨着它走，一步一步落下去，落到第三步上，我的鞋尖出到了它前头。那一溜印子到了拐角上，也拐了进去。
头一回拐过去，两边的墙一下挤了过来，钱满的肩膀蹭着了墙皮，他侧过身子，跟在我後头。墙根底下开着一个门洞，黑的。门洞跟前的地上，霜缺了两小块。门洞里，低低的，亮起来一圈绿的点子，一闪，就没有了。
钱满的手在我後腰上搭了一下。
我没有停。
从门洞跟前过的时候，它离我的胳膊肘不到一拃。钱满在我後头，那一口气憋着，憋到拐过第二回，才出来。
拐过第三回，前头没有路了，是一道门。
＊
钱满划着了一根火柴。门上的漆一片一片起了皮，翘着，火一凑近，翘起来的边都亮了。锁眼在门板当中，比我的拇指甲盖小一圈。钥匙进去，我一拧，没有拧动。我把它往外退了一线，再拧，锁里响了一下，门往里让开了一道。
我把钥匙拔出来，攥在左手里。门里一股旧纸的气。架子一排挨着一排，往里去，也往上去。火柴的亮爬到半截就没了，再上头，还是一格一格的黑。钱满把火柴举高，亮才够着了房梁，格子里一卷挨着一卷，一直码到房梁底下。
钱满举着火柴走在前头。地上搁着一只匣子，盖张着。里头是空的，底上一层灰，当中一块方的，灰薄。匣子四边的灰，叫硬底的鞋踩乱了。他的脚从它旁边绕了过去，我也绕了过去。火柴烧到了头，他一捻，又划着了一根。
最靠里那一排，後头只剩窄窄的一条道，贴着後墙。後墙上有一道门，虚着一道缝，缝里进来的风贴着地走，火苗往这边歪。钱满把火柴往下一低。
道上的灰里，有一个印子。一个人侧着身子躺过，印子只有半个身子宽，从这一端到那一端，比我短一截。靠架子那一边压得深，往外那一边浅，浅到末了，跟四边的灰分不出来。挨着一根架子腿，灰上落着一层碎纸渣。那根架子腿上，离地一拃多高，蹭掉了一块灰，露着木头。
钱满的火柴从印子这一端照到那一端，又照了回来，在它上头停了一阵。他往後退了半步，背贴着後墙，侧着身子从它旁边过去。过到了头上，他才站住。他落一脚，我在他的鞋印里落一脚。
最底下那一格的底下，嵌着一块平石。钱满把火柴凑过去。石头面上光溜溜的，一个窝也没有。它正对着印子当中那一截。
我站在印子边上。膝盖弯下去一点，又直了回来。钱满那根火柴，一直烧到了他的指根，他没有捻。火苗舔着他的指甲盖，那只手举着，一动不动，等它自己灭了。
黑里，他又划着了一根。
我跪了下去。两个膝盖落进那个印子里，一个落在深的那一边，一个落在浅的那一边。里头的灰是实的，膝盖压上去，一点也没有往下陷。
＊
最底下那一格离地不到一拃。我把右手伸进去，手背蹭着了格子的底板，拇指和食指搁到石头面上，一捏。
石头面上没有窝沿挡着，两根指头一路滑过去，指头肚碰到了一块儿。
我捏着，等了一阵。底下只是一块凉石头。我松开，又捏了一回，两个指头肚又碰在了一块儿。
钱满跪在印子外头，离它的边还有一拳。他把怀里那一卷掏出来，摊在灰上，拿膝盖压住一头。另一头一个劲地往起卷。
我把手从石头底下抽回来。拇指落在左边那一枚红指印上，食指落在右边那一枚上。往起卷的那半张，叫两根指头按住，平了。
两枚指印底下，当中，有三个小字：十五下。
我把手抬起来，两根指头张着，一丝也没有挪。那一张一下子卷了回去，卷到了钱满手里。
我把这只张着的手送回那一格底下，落了下去。
两个指头肚底下，石头往下让了一让，让出两个浅窝，窝沿兜住了指头肚。
我按下去一下，两个窝跟着往下一让，手一松，又回来了。左手搁在大腿上，钥匙在掌心，拇指先弯了下去。第二下，食指。第三下，中指。第四下，无名指。第五下，小指，左手攥满了，钥匙在拳头里头。第六下，小指伸开。第七下，无名指。第八下，中指。两个窝一下比一下让得深。第九下，食指。钱满那根火柴就在这一下上灭了，他又划着一根，亮一起来，我的眼睛就在那两根指头上。第十下，拇指伸开，钥匙躺在摊开的掌心上。第十一下，拇指又弯了下去。膝盖底下那一块实的灰，凉上来了，上到了腿弯。第十二下，第十三下，第十四下，一下一根。第十五下，小指弯下去，左手攥成了一个拳。
整块石头在两根指头底下，往下一沉。
膝盖底下往当中去的那一道，远处跟着紧了一扣。
火柴灭了，钱满没有再划。黑里，我听着他出了三口气。两根指头还在那两个窝里。
第四口上，亮又起来了。他把那一卷在灰上又摊开，拿膝盖压住一头。纸边上，靠下头，有一行小字：外处认宽，校处认准。
我的眼睛在这一行上走了两回。
＊
两个窝底下，响了一声。那一声，比钱满划火柴还轻。
左手那个拳，我这才松开，钥匙揣回了怀里。
火柴的亮里，钱满捏火柴的拇指和食指，指肚上各鼓着一个白泡。他的指甲伸过来，从我拇指的边上起，横着推过两根指头当中那一截，推到我食指的边上。他又在纸上推了一回，从这一枚红指印，推到那一枚。两回，他的指甲走得一样长。指甲停在那一枚的边上，搁了一阵。
「不差。」他说。
他拿袖口在那一张上抹了一下，把沾上的灰抹掉了。
我把两根指头拿了起来。那一块石头，比四边的地矮下去了，矮下去的那一截，我拿拇指甲贴上去比了一比，正是一个指甲的厚。
他把那一卷揣回怀里，火柴换到了左手，凑低了。
钱满拿钢尺在平石边上刻了一道。
【本章亮点】
一·日与接：主线第一百六十八天，即一月十三日，与暗线第一百六十二日同日。白文本日之号零。起手接四百一十八收句。那一方上的钥匙搁了一宿又一天，齿一直冲着我这一头。条案上别的挪过几回，它没有人挪，等的是谁由一样不挪的物交出。四更是那一页头一行，今夜照它起身。我合上本子揣进怀里，手才过去拿钥匙，接四百一十八：一百零七那只压着本子的手。
二·魂（不说）：灰里那个侧躺过的印子，全章零字说是谁。钱满的火柴在它上头停一阵，他背贴後墙侧身绕过去。我踩着他的鞋印也绕。平石偏偏正对印子当中那一截。一根火柴烧到钱满指根的工夫，我站着，然後跪进去。绕在全章演了四回：门洞那一口气憋到第二回才出；匣子绕一回；印子绕一回；钱满始终跪在印子外头。读者从绕法里认出那是谁躺过的地方，我不知，叙者零说。远处紧的那一扣，零比零解。
三·拍一（路·往前）：照那一页一行一行办。出後门，七道门槛，祠堂檐底下等两刻。檐底下没有霜的那一块只够站一个人，钱满半边身子露在檐外，两刻里换过一回脚，以一回量其静。街口两头空着。白天站人那两处碾平的两小块比别处白，上头没有鞋。此以四百零四：五十一之物量今夜之空，人去了哪儿零说。石堆过去两拃站住，十口气。街那边窗纸的亮斜铺过来，我翻那一页。第四行上三个钩，末了那一个挨着我按下去的那一点。钩只作钩，主零认，守进化账四百一十六。眼睛从那一点到缝里一星亮，是钉帽，一眼即走。十口气由白气一口一口进亮里量出。往北那一条宽些的街，墙根冻土霜底下一溜旧鞋印，鞋尖冲北，边叫水泡软又冻住，收四百一十三：十九之未钉。我挨着它落脚，第三步上鞋尖出到它前头，那人步子比我短，由我的脚量出，主零认。印子到拐角也拐进去，路与页合。往北拐三回。墙根一个门洞，於我是头一回，作一个，守进化账四百一十七。门洞跟前霜缺两小块，与街口碾平那两小块上没有鞋前後一对，人在何处由两处霜与鞋交出，叙者零连。低低一圈绿的点子一闪没了，取四百零九：四十五之形，零人零声。钱满的手在我後腰上搭一下。我没有停。门洞离我的胳膊肘不到一拃，取四百零九：四十九攥臂之近，零书其事。前头石堆跟前照页停足十口气，此处页上无停字。读者自见我只在页上写停的地方停，反智之防落在前後两停上。钱满那口气憋到拐过第二回才出来，怕由一口气之长量出。
四·拍二（库）：拐过第三回，前头没有路，一道门。漆一片一片起皮，火一凑近翘起的边都亮。锁眼比拇指甲盖小一圈，用三百八十六：九十九之尺。头一拧不动，钥匙往外退一线再拧才响，锁之涩与四百零九：六十三同，零说谁拧过。钥匙攥在左手，为拍三留手。架子往里往上，火柴的亮爬到半截，举高才够着房梁。格子里一卷挨一卷，与四百一十八：一百零三那一角之画对上，零说。地上一只匣子盖张着，里头空的，当中一块方的灰薄，四边的灰叫硬底的鞋踩乱。四百零六：五十三那边的匣子是空的，今在眼前，叙者零说是谁去取的。钱满绕过，我也绕，收四百一十三：十一。火柴烧到头他一捻，是十八：三十三之手，此为平常一回。最靠里那一排後头，窄窄一条道贴着後墙。後墙上一道门虚着一道缝，风贴着地进来，火苗往里歪，收四百一十三：五、七之缝，零说谁从那儿出去。印子半个身子宽，比我短一截。靠架子一边深，往外一边浅，浅到末了与四边分不出。挨着架子腿落一层碎纸渣，那根架子腿离地一拃多高蹭掉一块灰，露着木头。此收四百一十三：五至十一，我只见形与物，零认其主。钱满的火柴从这一端照到那一端又照回来，停一阵，他退半步，背贴後墙侧身过去。他落一脚，我在他鞋印里落一脚。最底下那一格底下嵌一块平石，光溜溜一个窝也没有，正对印子当中那一截。我站在印子边上，膝盖弯下去一点又直回来，身子先停。钱满那根火柴烧到指根，他没有捻，等它自己灭。十八：三十三那一捻今夜不捻，前头平常那一回他捻了，两回一比，停之长由一根火柴量出。叙者零说我为何站。黑里又划一根，我跪下去。两个膝盖一深一浅，灰是实的，没有往下陷。躺过之久由膝盖量出，几夜零说。
五·拍三（叫绝·对标拍库第三十九拍，附第九、第十一拍）：最底下那一格离地不到一拃，右手伸进去，手背蹭着底板，拇食一捏。石面无窝沿，两根指头一路滑过去，指头肚碰到一块儿。三百九十二：一百一十三两根指头自己落进窝，今无窝可落，捏落了空。不认由手上交出，零说不认。我捏着等一阵，底下只是一块凉石头。松开又捏一回，指头肚又碰在一块儿：拍库第三十九拍又落了一回之式，身子不信，再做一遍，零报结论。不硬按。钱满跪在印子外头，离边一拳，摊开那一卷，膝盖压一头，另一头一个劲往起卷。我拇指落左边那一枚红指印，食指落右边那一枚，往起卷那半张叫两根指头按平。此守进化账四百一十八，先给纸一件活。指印底下当中三个小字：十五下。其数出数，不同三百九十四。手抬起，两根指头张着一丝没挪，那一张卷回钱满手里。张着的手送回去落下，石头让出两个浅窝，窝沿兜住指头肚，是认。一个窝也没有翻作两个窝，零解。长段数十五下。左手搁大腿上，钥匙在手心。一下弯一根，五下攥满，钥匙在拳头里。六至十下一下松一根，第八下上两个窝一下比一下让得深，十下又空了，钥匙躺在手心。十一起又弯，膝盖底下实的灰凉上到腿弯，十五攥成一个拳。四百一十六：二十七、三十七右手弯伸之数，今换左手，弯伸之後又弯，末了是拳。叙者零并。第九下火柴灭，亮一起来我的眼睛就在那两根指头上，睁眼由此交出。三百九十四：一百零七我没有数，今一下一下数，零说这一回。整块石头往下一沉。膝盖底下往当中去的那一道，远处跟着紧了一扣。三百九十二：一百二十三紧了一线，今紧了一扣，单位换作四百一十四：一百零九那一句之扣，叙者零比。方位只作往当中去，东南零见。脚底下换作膝盖底下，那一道从印子底下过，零说。火柴灭，钱满不再划，黑里他出了三口气，我两根指头没有离那两个窝，停之长由气数。第四口上又亮，他再摊那一卷。纸边靠下一行小字：外处认宽，校处认准。照录零解，眼睛在这一行上走两回，学名收四百三十六。认字承四百一十八：九十一卷末认上了。
六·拍四（对上号）与钩：两个窝底下响一声，比钱满划火柴还轻，是节点复常。三百九十四：一百一十一之句零照抄。左手那个拳这才松开，钥匙揣回怀里。火柴的亮里，钱满捏火柴的拇指和食指指肚上各鼓一个白泡，拍二那一根不捻之价，由两个泡量出，零说疼。钱满的指甲从我拇指边推过两根指头当中那一截，到食指边。又在纸上从这一枚推到那一枚，两回走得一样长，指甲停在那一枚边上搁一阵。「不差。」四百一十二：五十五差一线，今不差。他拿袖口抹掉纸上沾的灰，那张图之重由一抹交出，零说。原件之距在石上作了数，拓上那一线是另一只手，谁零说。我拿起手，石头比四边的地矮下去，我拿拇指甲贴上去比，正是一个指甲的厚，以我之尺量。他揣回那一卷，火柴换到左手凑低。钩：钱满拿钢尺在平石边上刻了一道。段案原字。钢尺先在拍一别在後腰，是三百八十四：八十七至九十五之手。刻在矮下去的那一块边上，所记何物零说，收四百二十二。
七·回话：大审限本章零笔，无。第五十九笔限四百二十三，门洞只一圈绿点一闪，零人零形，守，未碰。冷轮四百一十八依一零二七冷眼轮汰，不立签。悬念哨甲乙丙，那一捆与那个套留屋，本章零书，挂，限四百二十二以後下一哨主环。四百一十八软四：取钥匙处以画墨道道那一摞的头一张与按红指印的那一摞两名分开，钥匙从前者拿，钱满从後者揭，治。看官账、大问挂账限本章零。
八·人与声：钱满一句「不差。」，我零句。门洞那一圈绿的零句零形。四百一十九之物与事零进。老头、东头、刘二、门里那个人留屋，零书。她字白文零见，只以钩、钥匙、印子到场。
九·变：我从三百九十四闭着眼按到底不数，到睁着眼照图上那个数一下一下按，左手攥成一个拳。钱满从四百一十二指甲推出差一线，到今夜在石上推出不差，他手里那张图头一回在石上作了数。
