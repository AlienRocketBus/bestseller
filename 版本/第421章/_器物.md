# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—15行｜拍2=19—43｜拍3=47—79｜拍4=83—87。骨记四（起）在拍1｜五（拍一·撤）在拍2｜六、七、八（过、拍二·凳、刻道）与九之前半（睡）在拍3｜九之後半（钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 417 册：「匣盖裂下来的那一截（那一截）」无主；「刃」「鞘」「铅笔头」「找回来的那几张（一沓）」「车票（票）」主=她。417 册「鞋」本章白文零见，照旧穿在她脚上，不入册；「一盆水」「钳子」「筐」「包袱」「推车」「桶」随 417 之人去了，本章零见。
#   ★新立五件：「门楣那颗钉（钉）」主=头一处的点户；「凳沿那一抹白（一抹白）」无主（其来处读者握 411:35、:61、417:69、419:15 自合，册⛔名）；「煤斗子」主=添煤的；「木屑」无主；「铺盖卷」无主（候车之人所背）。
#   ★「挂灯的那一圈」「锈」「钉身」「钉子」係钉之部；「细棱」「那一道棱」「一线影子」係一抹白之部；「鞘口」「那一圈铜」係鞘之部；「刃尖」「柄」係刃之部；「道」「那半道」「新的这一道」「木纹」「光的那一头」係那一截之部与痕：各随其物。
