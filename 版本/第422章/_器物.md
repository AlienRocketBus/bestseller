# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—23行｜拍2=27—41｜拍3=45—69｜拍4=73—89。骨记一、三（日与接、拍一）在拍1｜四（拍二）在拍2｜五（拍三）在拍3｜六、七（拍四、钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 420 册与 418 册：「钢尺」「火柴盒（火柴）」主=钱满；「本子」主=我；「平石」「匣子」无主；「画墨道道的那一摞」无主（420 册别名作「画墨道道的头一张」，本章白文作「画墨道道的那一张」）；「碗」「公输那一卷（那一卷）」主=门里那个人；「套（那个套）」主=东头；「门边那一捆（那一捆）」无主，照 418 册。420 册「钢尺」「平石」之出所书「422」，於本章收。
#   ★新立二件：「黑麻绳（麻绳）」主=门里那个人（418:73 他解完之绳，418 册未立；本章他一个结一个结地解，又亲手绕上一道打结，立之）；「笔」主=我。
#   ★「一点粉」「尺角」係钢尺之痕与部；「第一百五十三天那一页」「抄的那一页」「点」係本子之部与痕；「卷背」「卷沿」「卷边」「卷尾」「卷头那两个字」「那三行大字」「小字」「方块」「栏」「钟点」「第一行」「第二行」「第三行」「那一截毛」「绒」係那一卷之部；「结」係黑麻绳之结；「笔尖」係笔之部；「麻线」「线头」「背带」「当腰那个扣」「末一个扣」「那一拃」係套之部；「柄」「柄上那个窝」係那一捆之部；「火」「一根」係火柴；「沿」「盖」係匣子之部；「石面」係平石之面。「那一道」各随其物：本子上往北去的那一道係本子之痕；钱满刻在平石边上、齐着地的那一道係平石边上之痕；套上抽到半截的那一道係麻线；膝盖底下往当中去的那一道係场上之设。
#   ★「钥匙」本章只作「钥匙搁过的那一方墨」之指，其物照 420 册揣在我怀里，零动；「那两枚红指印」係我两根指头记着之宽，其物（按着红指印的那一摞）照 420 随身物之末位零动：俱不入册。
#   ★「窗纸」「後门」「後屋」「条案」「凳」「凳子腿」「门框」「里门」「灯」「七道门槛」「祠堂檐」「石堆」「门洞」「那道门」「旧纸气」「架子」「格子」「卷子」「圆头」「最底下那一层」「灰」「灰里那个窝」「後墙底下那道门缝」「凉气」「霜」係场上之设，不入册；「袖子」「後腰」「膝头」「膝盖」「肩膀」「手背」「脚尖」「脚印子」「嘴唇」「眼睛」「指甲」「指甲尖」「指头」「指头肚」「拇指」「食指」「中指」「中指尖」「牙」「肚子」「右手」「左手」「泡」「燎了皮的气」係身上之物与其痕，不入册。
