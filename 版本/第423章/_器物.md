# 第423章 · 器物册（造式二代·合稿席立｜照 415、419、422 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 2 拍：拍1=正文5—61行（巷口、院里、霍钧屋里）｜拍2=65—81（车里）。骨记一至九在拍1｜十、十一（拍六叫绝、钩）在拍2。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 419 册（器以「他」线认 419 为上一同线章）与 411、415 册：「档柜（柜）」无主；「纸条（那一条）」「砚」主=霍钧；「章匣（匣子）」主=管档的；「那一册」无主（本章白文作「一册」）；「会签单」「签收」照 415 册无主；「底稿」即 415 册「空白的底稿」写了两行的那一张。
#   ★新立：「照抄的那一张」——他夜里照着抄的那一张；屋里白文作照抄的那一张，车里作今天这一张；两拍共见之字只「今天」（屋里「日子落的是今天的」即此张所落之日），故别名取「今天」验之，印其名照本名。「公文包（包）」「笔」主=黎东来（笔自他里兜出）。「匣里那一样（那一样）」——卡守②匣里是什么零书，册亦只作那一样，其主零书。
#   ★「笔帽」「笔杆」「笔尖」「笔尾」係笔之部；「推盖」「推痕」「亮的那一道」係章匣之部；「门扣」「门轴」「柜门」「柜口」「柜子那一头的门」係档柜之部；「封皮」「封皮上糊着的那一张纸」係那一册之部；「两枚红印」「那一枚」「这一枚」「那一道折」係会签单与照抄的那一张上之痕；「名字」「起笔」「棱」「那一块颜色深的地方」「边上起了毛」係纸背纸边之痕；「来字」係纸条之字。
#   ★「车」「车门」「巷子」「院门」「院里」「墙根」「碎叶」「隔壁那一间」「窗纸」「屋门」「案」「案沿」「磨白的那一块」「案角」「椅子」係场上之设，不入册；「大衣」「里兜」「领子」「手心」「指肚」「指节」「拇指」「食指」「无名指」「白气」係身上之物与其痕，不入册。
