# 第424章 · 器物册（造式二代·合稿席立｜照 418、420、422 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—25行｜拍2=29—39｜拍3=43—97｜拍4=101—117。骨记一、三（日与接、拍一）在拍1｜四（拍二）在拍2｜五（拍三，连悬念哨丙）在拍3｜六、七（拍四、钩）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 422 册：「套」主=东头（本章白文作「背带」）；「门边那一捆（那一捆）」无主；「碗」主=门里那个人；「画墨道道的那一摞（画墨道道的那一张）」无主；「本子」主=我。422 册「套」之出所书「424」，於本章收：背上了人。
#   ★新立七件：「按着红指印的那一摞（油布包）」（420 随身物之末位零动，今钱满塞进老头怀里）；「听针」主=钱满（382:71 以来，今贴门板一回）；「闩」主=门里那个人；「铁管」主=领头的那一个；「亮」主=拿亮的那一个；「照的那一张」主=钱满（420:91—93 他照的那一张，今叫领头的抽走）；「盆」主=端盆的人。
#   ★「扣」「末一个扣」「缠白麻线的那一截」「原先扣着的地方」「一道印子」係套之部与痕；「柄」「柄上那个窝」「底」係那一捆之部；「折过的两道印子」「两枚」「纸边」「纸毛」係照的那一张之部与痕；「白布」「一点绿」係看手的那一个腕上之物与痕。
#   ★「钢尺」「火柴盒」本章零见（「捏火柴的那两个指头肚」係指头之称），照 422 册零动，不入册；「钥匙」「她那一页」照 420 册揣在我怀里，零动，不入册。
#   ★「灯」「窗纸」「条案」「凳子」「里门」「门框」「前门」「门板」「门槛」「当中那一块凹」「巷子」「巷口」「墙」「石堆」「街口」「街边」「门」「岔口」「路」「地」「茬子」「霜」「日头」係场上之设，不入册；「衣襟」「衣裳」「领口」「怀」「大衣」「腿弯」「胳肢窝」「後腰」「腰眼」「胸口」「心口」「肩膀」「後脖颈」「耳根」「发根」「腕子」「手背」「指头肚」「泡」「筋」「白气」「汗」「一层白」「影子」係身上之物与其痕，不入册。
