# 执笔·丙之构思（物证路）

魂（物证路）：钱满按在怀外头的那只手当证人——护那张纸的那一按，正是把看手的人的眼睛领过去、停住的那一按；纸叫人抽走、手背挨一管，那双眼睛停在他手上，没有往刘二背上去；按下去是平的。
进化账所避：①[422]「多出一截」须先见原尺落在人身上——本章那一拃先在刘二背上见「贴」，与 422:81「耷拉」两回之差由物交，⛔空中比；②[423]认人之尺换手即相抵——钱满按胸之手、挨管之手、钩上之手，左右逐处钉死（挨管＝右手，钩＝左手，422:75 起泡亦右手两指）；③[420]照旧习做到之拍⛔叙者说「正好」——门槛那一凹由「背上的人一点也没有颠」交，⛔独行「正好。」（422:31 刚用过，⛔抄前章）；④[420]回到前章之地物位只准从原场来——门、闩、门槛、石堆、街口之位先 grep 原场。

① 读者读完最该记住的一拍：拍三之停——看手的那一个，眼睛停在钱满按在怀外头的那只手上（护那一按即露那一按）；其回声在钩：换左手按一按，按下去是平的。托法：拍一先把两处「按」并排摆给读者——老头两只手隔着衣裳按住油布包，钱满右手按自己怀外头——读者当它是护；拍三拿亮的照脸「一张脸一停，停得一样长」、照手也一样匀，先立流程之匀；匀到钱满那只手上断了，读者在节奏里先於叙者认出来；看手的停在第二个人身上，没有走到刘二背上——那两只按着原件的手没有人看。拍四⛔提那张纸，只写钱满右手垂着、手背比左手厚，末句换左手。

## 满分之问
甲（取）：顺事走，四拍各一种光，光定谁看得见什么——拍一灯（手上之事看得清：两处按、那一拃贴）→拍二灯吹了（只剩听针、脚尖、闩一声，以耳与身）→拍三人家的亮（拿亮的定照谁、照多久，照的匀与断即全拍之判）→拍四日头在前头起来（影子由前翻到後，汗冻一层白量一程）。物证首尾两按（拍一右手／钩左手），中间一按叫人读走。快慢：拍一慢而满（长段）；拍二短句连跳；拍三先匀後断，断处独行；拍四一长段放开走，末句独行收。
乙（弃）：开在街口当面，倒补背与门槛——犯接钩（拍一须接 422:89 那个窝）与「起手零回述」；且听针「听不见」之错数须先信後破：读者先见三人再读听针，错就成了明的，等於叙者点破（挂账⛔）。
丙（弃）：拍一拍二压成数行，全力慢镜拍三（一步一停、五感齐上）——卡判转章非爆章；拍三拉成十段即造高潮；且拍一那两按不立，拍三之停读者认不出「护即露」，叫绝只剩一记铁管。
丁（弃）：听针与背交叉（钱满门边听、身後背人）——钱满须亲手塞油布包，人分不开；且听针之读数在背毕之前落地则泄，在背毕之後落地即同甲。

取甲。另记两据：前文「拄」字於东头零见（grep 396—422），东头之物只有他那一捆与柄——故「拄杆在後」照前文之物写作「拿左边肩膀扛着他那一捆，走在最後头，柄从肩膀边上支出来」（右肩旧疤·D1 不背人）；听针前文之用法 202「针尖插进土里，耳朵凑到针尾上」、18:137 钱满自说「贴上墙，墙那头有人打个哈欠我都听得见」——本章抵在门板上，⛔叮（382:71 石上之叮）。章名「看手」（正文题 0 见）。

③ 最易写平、写俗、写成前几章样子的几处，各怎么写出只属於这一刻的：
- 门槛那一凹：414:57「他的脚照旧落进了当中那一块凹里」、422:31 独行「正好。」——今写我先空身跨过、脚没有碰着门槛；刘二背着人腿抬不过去，脚尖正落在当中那一凹里、往外一送人过来，「老头的头搁在他肩膀上，一点也没有颠」。空脚不找它，背着人的脚尖找着它——凹之来由由一空一负两只脚交，谁踩的零字，「正好」二字零。
- 闩：408:13「门里头，闩响了一声，又进了槽」——今灯先吹（408 屋里的亮过了街），门里伸出来一只手搭在门边上搭一会儿才带上，闩一声独行。
- 照脸：409 之亮「落在她脸上，她喘了三口」——今五张脸一张一停、停得一样长，匀是流程；匀到钱满手上断，独行「亮也不挪了」。
- 铁管：409:53「落下来，落在她左边肋下。是硬的」——今落在一只攥着的手上，那只手开了；管横、落、垂三态；其重不报，由手背横着一道印子「有铁管那么宽」交。
- 跟：414:29「响得还是不齐」——今後头三个人的「这一回是齐的」；亮在後头把我们的影子推到前头，到岔口脚步停、影子拉长淡没——停由影子交，⛔只靠回头。拍四我们几个的脚步「一重一轻的，不齐」。
- 刘二起身：199（拍库24）起到一半放下——今「一回就起来了」，零比。
- 东头换肩：115（拍库15）肩上那个卷子换了一边——今左肩扛那一捆「一回也没有换肩」，零比。
- 听针：382:71 石上叮、202 插土——今抵在木门板上，挪下去一截再听一回，读数是一下摇头，⛔叮。

④ 收句：「钱满拿左手在怀外头按了一按，按下去是平的。」落在这里：①公开量表那一格之读数（420:93 以来那一按→平）；②惯比失去活得长，且换了一只手——右手叫铁管关上了，左手照旧去找那一张；拍库34 交後身子按旧习落空之形，⛔抄其「摸空」，落在一按与一个形状上；③其前一段只写钱满右手与「他的左手也垂着，没有去捂它」——左手不去捂伤，去按怀，人在一只手的去处里；④拍四长段之後一句独行，节奏刹住；⑤⛔说那张纸是什么——读者握 420:91 短一线与贴着刘二背出镇的原件，平是丢，也是那一包出得了镇的价。

⑤ 第二件咬进来：听针之挂账——来处 18:137 钱满自说「我祖上传下来一根听针，铜的，三寸七，贴上墙，墙那头有人打个哈欠我都听得见」（grep 亲印）；其咬法：拍二读数「听不见」即拍三之一喜，三个人在街口站着，错数由事交、⛔点破、⛔别解。悬念哨丙咬在照本之物上——来处 412:47「他从自己那一摞里抽一张，蒙在包里的一张上。纸薄，底下的道道一根一根透上来」（grep 亲印）：拍三亮一抬，「纸薄」透出两枚指印、一笔一笔照的、一处墨重，格式与工夫由纸自己交，给谁零答。俱为一事之内，⛔出二事。
厚：卡问五守 3,500—4,300，执笔令主线带 2,500—3,500、⛔凑字——照令，厚由四拍各担一件後文要兑之物出；拍一添「钱满两指从碗里拿出来」（422:75 接）、「老头不搂脖子，身子一伏」（套之用）、「末一个扣勒在刘二胸口前头」「窝空着」，拍三添「往里按得更紧」（护即露之最狠一下）、手背那一道印子、从三人当中过去管就垂在我右手边，拍四添脚印比谁的都深、换肩、两指捏裤缝捏到这会儿——俱是事，⛔撒感官。
