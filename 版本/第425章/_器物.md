# 第425章 · 器物册（造式二代·合稿席立｜照 421、423、424 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—35行｜拍2=39—61｜拍3=65—75｜拍4=79—87。骨记一至五（日与接、魂、拍零、生火、换药与叠布）在拍1｜六、七（拍一窗口、捻）在拍2｜八、九（拍二师父、添柴）在拍3｜十、十一（刻道与钩、钩之字）在拍4。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 421 册：「匣盖裂下来的那一截（那一截）」无主；「车票（票）」「找回来的那几张（一沓）」「铅笔头」主=她。421 册此四件之出俱书去处在她怀里，本章自她怀里接着用，未离身。「刃」「鞘」本章白文零见，照 421 册在她左小臂上、左边袖口底下，不入册；「凳沿那一抹白」421 册之出所书「425」，本章白文零见（一半在她左边的袖子上，袖子本章零书），其接落在撕边那一点白上，叙者零并，不入册。
#   ★名与主承同框前章 423 册：「那一册（一册）」无主；「砚（砚台）」主=霍钧。423 册「档柜」「纸条」「章匣」「匣里那一样」本章白文零见，照 423 册关在柜里，不入册。
#   ★新立七件：「盆」「柴」「火柴」「木匣」「木匣盖上那一块布（一块布）」主=霍钧（木匣与那一块布照 268:557 原位，火柴照 405:57 在灶台上）；「肋下缠着的布（布）」主=她。424 册「盆」係镇上端盆的人之物，异线异物，不承。
