# 第426章 · 器物册（造式二代·合稿席立｜照 422、424、425 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—41行｜拍2=45—73｜拍3=77—103。骨记一至三（日与接、魂、拍一）在拍1｜四（拍二·叫绝）在拍2｜五与钩（拍三）在拍3。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 424 册：「套」主=东头（本章白文作「背带」）；「门边那一捆（那一捆）」无主；「本子」主=我。424 册「套」之出所书刘二背上，本章拍二仍在刘二背上，拍三东头解扣、收过来绕在他自己腰上。
#   ★名与主承 422 册：「钢尺」主=钱满（422 册之出：钱满插回後腰；424 册零见、零动）。本章拍二摸出又揣回，拍三摸到半路回来，所在白文不书，与 422:15 不抵。
#   ★新立一件：「东头腰上那一根（带子）」主=东头——夜里东头解下自己扎腰的那一根，给钱满吊那只右手；白文只作「一根带子」「那根带子，是灰布的」，谁的由物交出（东头的棉袄没有扎腰），叙者零书。
#   ★「结」係带子之部；「当腰那个扣」「扣」係套之部；「柄」「底」係那一捆之部。
#   ★「按着红指印的那一摞（油布包）」本章白文零见（只「老头的两只手隔着衣裳按在心口底下」），照 424 册在老头怀里，零动，不入册；「她那一页」白文零名，只以「贴心口那一层」「两道折痕」交出（420:15 揣进贴心口那一层），照 420 册零动，不入册；「照的那一张」本章零见（「纸毛」封在痂里係其痕），照 424 册在领头的大衣里，不入册；「听针」「火柴盒」「钥匙」本章零见（「捏火柴的那两个指头肚」係指头之称），零动，不入册。
#   ★「路」「地头」「地埂」「茬子」「天」「那一道灰」「一层白」「霜」「树」「树梢」「路头」「沿」「沙」「水」「水边」「印子」「一溜沙」「细细的一道」「亮」「日头」「影子」「风」係场上之设，不入册；「怀」「怀口」「胸口」「肩膀」「脖子」「腕子」「手背」「纹」「指头肚」「泡」「痂」「纸毛」「膝盖」「棉袄」「後襟」「衣襟」「後腰」「袖筒」「衣裳」「贴心口那一层」「两道折痕」「後脖颈」「耳根」「嘴唇」「白气」「两道沟」「胳膊肘」「脚尖」「嗓子」係身上之物与其痕，不入册。
