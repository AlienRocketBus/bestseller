# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—25行｜拍2=29—43｜拍3=47—67。骨记一至五（日与接、魂、拍一、远路、卡字撞原场）在拍1｜六至八（拍二收、册、匣）在拍2｜九至十二（拍三叫绝、她、跟、钩）在拍3｜十三、十四（物之计、守与回话）通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 425 册：「那一册（一册）」无主；「砚」「柴」「木匣」「木匣盖上那一块布」主=霍钧（425 册作「砚（砚台）」，本章白文只作「砚」，故不带别名；「木匣盖上那一块布」本章白文作「那块布」，在她肋下，零动）。425 册「匣盖裂下来的那一截」「车票」「找回来的那几张」「铅笔头」本章白文零名（只「她的手进了怀里，按了一按，出来了」），照 425 册在她怀里，不入册；「刃」「鞘」零名（只「到了左边袖口上，停了一停」），照 421 册在她左小臂鞘里，不入册；「盆」「火柴」本章零见，照 425 册在灶跟前、灶台上，不入册；「肋下缠着的布」本章零名，照 425 册在她肋下，不入册。
#   ★名与主承同框前章 423 册：「档柜（柜）」无主；「纸条（那一条）」主=霍钧；「章匣（匣子）」主=管档的（本章揣进霍钧怀里，其主照旧；那个人零名零在场，只锚於匣）。423 册「匣里那一样」本章白文零见（匣里是什么零说），随匣，不入册。
