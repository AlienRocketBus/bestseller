# 第429章 · 器物册（造式二代·合稿席立｜照 425、427、428 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—13行｜拍2=17—33｜拍3=37—67｜拍4=71—91｜拍5=95—105。骨记之拍名照开镜卡（拍零解、拍一印、拍二抄、拍三叠、拍四刻道），与「＊」所切之拍号不同数：骨记一、三（日与接、路）在拍1｜四（睡）与五之头（拍零之捧与看）在拍2｜二、五、六（魂、拍一叫绝、拍二抄）在拍3｜七至九（拍三叠、拍四刻、夜）在拍4｜十（钩）在拍5｜十一、十二（物之计、守与回话）与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 427 册：「那一包」「那一册（一册）」无主；「枕头上那块布」主=霍钧（本章白文作「布」，作别名格）；「章匣」主=管档的（本章白文零「匣」，只「他前襟那一块方的」，照 427 册在他大衣里贴胸口，零动，匣里零说，作别名格）。427 册「木匣盖上那一块布（那块布）」本章白文零名，照 427 册在她肋下，零动，不入册；「木匣」「砚」「档柜（柜）」「纸条（那一条）」「柴」本章零见，照 427 册留在霍钧那屋，不入册。
#   ★名与主承同镜前章 425 册：「匣盖裂下来的那一截（那一截）」无主；「车票（票）」「铅笔头」主=她。425 册「找回来的那几张（一沓）」本章白文零名，照 425 册在她怀里，不入册。「刃」照 421 册，主=她；「鞘」本章白文零名（只「左边袖口」「左边袖子里」），照 421 册在她左小臂上，不入册。
#   ★「封皮」「书脊」「签」「页」「末了那一页」「页角」「两道折痕」「光的那一块」「红印」「那一行」係那一册之部与痕；「结」「结尾巴」「角」「末了那个角」「那几道」係枕头上那块布之部与痕；「票背」「有字的那一面」係车票之部；「刃尖」係刃之部；「头一道」「末了那一道」「光的那儿」係那一截之部与痕。
#   ★「路」「土」「冻住的地」「土屋」「门洞」「门板」「墙」「草」「窝」「亮」「日头」「天」係场上之设，不入册；窝係那一包在草上压出来的，夜里他那只右手摸进去过，她又把那一包放回去，不入随身。「大衣」「胳肢窝」「前襟」「胸前」「胳膊」「右手」「拇指」「食指根」「指头」「指甲」「指肚」「手掌」「膝盖」「怀」「袖口」「袖子」「那口气」「白气」「眼睛」「脸」「鼻尖」係身上之物与其痕，不入册。
