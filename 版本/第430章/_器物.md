# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—11行｜拍2=15—33｜拍3=37—49｜拍4=53—61｜拍5=65—75。骨记三（拍一·後晌·尺）在拍1｜四（拍二·黄昏·笔）在拍2｜五（拍三·夜·手心）在拍3｜六（拍四·天亮）在拍4｜七（拍五·对·叫绝）与钩在拍5｜一、二（日与接、魂）与八至十四（人与声、变、量、回话、守令、交下、卡字撞原场之裁）及咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 428 册与 426、422 册：「钢尺」主=钱满（本章白文零「钢尺」，只「尺」「那把尺」，作别名格；428 册之出所书「430」，於本章收：黄昏笔滚下页边碰着它停住，黑里由他摸着横到我页上作尺边，拍五我拿下来搁在本子旁边）；「本子」「笔」主=我（422 册）；「东头腰上那一根（带子）」主=东头（426 册）。
