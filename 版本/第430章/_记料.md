   - 详记首行「sha1：」换成新正文之前十二位（`sha1sum 正文/xxx.md | cut -c1-12`）；所改之拍、要句与其行号、物之去向、在场之人之状、悬线之开与结随改；
   - `总览.md`：索引表该行之章名、线·日、一句之要；该站之段；若改动全书之末，① 之末两段；
   - `人物.md`：所涉之人之伤、所携、所知、所瞒、要事章号；
   - `物件.md`：所涉之物之易手与今在何处；
   - `悬线.md`：所开、所结、所欠与十之锚；正文差执毕者，自六之表中改状或删去。
2. **新写一章**（`工具/席/一章.js`）：照第六节之式写 `第N章.md`（含 sha1 前十二位），并同步更新四份总档：索引添一行、站段与一页之要之末、人物之至今、物件之今在何处、悬线之开结与接写之锚。
3. **闸**：`python3 工具/全书记忆.py`——`总览.md` 在即启：每一正文章须有 `第N章.md`，且其中含现正文 sha1 前十二位；缺即红「第N章无详记」、不符即红「第N章详记过期（正文 sha1 xxx）」。`python3 工具/全书记忆.py --自测` 验闸本身（全过 5/5）。**闸只验 sha1，不验内容**——内容之同改靠第 1、2 条，⛔不许只换 sha1 不改内容。
4. **⛔不许凭印象改档，不许扫读**：改前回原文逐字核；详记与详记、详记与总档相犯，回原文裁，两处一并改，并在该章详记末节记「总览席裁」或「某席裁」之由。
5. **⛔总档之说须回溯得到某章详记**：添一说须注章号；无章可注之说不许进总档。
6. **⛔名之律**：圣经之名（苏玄微、赵阙、樗里闩、枢）白文未书者，档中只作注；暗线床上那人不以「他」称；235 起暗线白文不书「沈鸢」之名（主线 291:455、374:65 由人口中叫出）。
7. **律⑮·动盘之禁**：旁有别席在写盘——不许 `git checkout`／`git stash`／`git reset --hard`／`git clean`／`git add -A`；只 `git add` 明路径。**律⑳**：须裁之事当场照「书更好看」裁并写其由，不许写「交作者裁」而停。

14｜## 满分之问
15｜写法甲（取）：事按本来次序，一个周期从头蹲到尾。午後（428 末那一回刚退）钱满蹲回原处，钢尺在他两脚当中，左手捂着那只手不去拿；我头一回掏本子，补第一百七十一天与下一页各一句，页上都没有钟点 → 半夜那一回到顶，钱满仰头冲北边，掏火柴盒，一只手压着盒子就没有手划了，盒子到我手里，我划，他左手的指甲在抄的那几栏里走，停在一行後头那一个上，压出一道凹（立「有」）→ 天亮钢尺落一层湿，一夜没人动 → 早上那一回上了印子，钱满看日头，从我页上拿走笔，塞进右手指头当中，合不拢，滑下去掉在钢尺上一响；左手捡起来的是笔，写，一个字比一个字往下，出了那一行，那只手露在风里冒白气；他停，掉过笔来递，我右手出袖筒接住；我把钟点写进一行里，他的眼睛跟着我的笔尖 → 夹着这一页翻回去，笔尖从点过的那一行往下，行行都在，到他夜里压的那一个，凹还在；翻过来翻回去，我写的比它又晚一刻；笔尖往下挪一行 → 钩。
16｜  其长：①「有」夜里由他的指甲立、「无」早上由我的笔尖撞，同一由头（找这一回在那几栏里那一行），手由他换到我；②早上他不先找那几栏、先要笔——他 422 走过两遍到末一栏末一行（422:19、:45），早知道底下没有，叙者不知，读者到钩才回头懂，零解；③数只一处，落在钩前一句。
17｜写法乙：从早上那一回到顶劈头写（握不住笔起手），午後与夜一句带过，对表收。弃：428 之钩（钢尺）要在拍一蹲回，劈头即断；「有」只能托前章（428 之教：没来之前须本章先有来）；一个周期之蹲没了长度，他半夜看星、一只手划不着火那一层整个丢了。
18｜写法丙：全章落在夜里，那一回在黑里到顶，递笔、接笔全凭手摸，天亮才看见他左手写歪的字。弃：黑里的递与接没有物证可看，叫绝之物（歪字与一行）拖到天亮，一拍劈成两半；早上那一回钟点又得再传一遍，同事两遍（坑⑧）；对表离那一回已远，数与钩隔开。

13｜## 满分之问
14｜甲（取）：当日顺叙一回到顶——钢尺搁了一後晌一夜起；他眼睛到我怀口，我掏本子、翻过空着的两页写日子；到顶，他左手摊开要笔，右手握不住，左手写歪，笔从捂着那只手的左手指缝里递来，我右手往前去、左手托着本子没来攥它，笔是烫的；我写进行里；风掀页，我翻回抄的那一页，拿起他的钢尺横在页上，一行一行往下，又晚一刻，再挪一行，他的指甲落下来，无行。放慢在握笔与递笔，收在无行。
15｜乙（弃）：先对表後补握笔（倒叙）——无行先出，「又晚一刻」只成追认，与卡序（先晚一刻後无行）相反；且读者先知笔已在我手，握笔不住之险全泄；兼犯坑㉘先说後数。
16｜丙（弃）：从夜里黑中数起——重走 428 一夜之等（⛔抄前章）；黑里无笔无字，握笔只能挪到天亮，前半章空耗。
17｜丁（弃）：天亮先翻抄的那一页找今天之行、见末一行底下空，再等到顶记——无行先现，叫绝倒成预告，握笔之痛落成过场。

7｜## 满分之问
8｜写法甲（顺叙·笔在天亮）：承钢尺，後晌快过，夜里那一回只是等，天亮那一回到印子上时钱满伸手要笔、笔落、递，我记，对，钩。弊：最险一拍埋到全章三分之二以後，前半一夜只有黑与声，必抄 428:13—23 之夜；笔落在天亮，白气、指头一一看得见，反倒成了把伤摆给人看。
9｜写法乙（倒插·从笔起）：开篇即天亮笔落，再回叙一夜，然後对表。弊：接钩之钢尺要先落页，倒插便断了 428:81 伸过来的那只手；回叙是讲不是演；笔一递，悬念先出，後半只剩查表，越走越松。
10｜写法丙（取）：黑里那一回笔就递了——黑里看不见手，只有手上的事：他要本子，接笔，笔碰着指甲响，落在我膝盖上，笔杆有一面是烫的；我递回去，他的左手不接笔，把我的指头往笔杆上拢紧，回到那只手上。那一回记不上。天亮我照他的嘴记下一行；拿他的尺压着行往下对，末一行比我记的早一刻，往下是白的。好在：①最险一拍提到全章前半，读者先站在上头；②黑里只用手、热、响，与 428 之夜（声、肘、凉）不撞；③他的手握不住，便替我的手握——拢指一下，不说一字，交了；④天亮那一段只管记与对，越收越紧，落在白上。

18｜③ 易平易俗处：天亮水上印子（428:35—51 已写透）今压成两三句，眼不在水上在笔上；夜里以声（428:13—23）今只留「不往前了」一意，余换手、烫、响、拢；钱满之伤今⛔再写伤本身，热只落在笔杆上，乌的⛔碰（436 零碰）；老头睁眼（428:79）加「又」、放在白沫子回头之前，零解；「第一百七十一天那一页还没有记」426、428 已两回原句，今⛔第三回，只写黑里翻到它、天亮它还空着、然後落字。

8｜## 满分之问
9｜甲（顺写·取）：後晌起，路头上那把尺面上的一道亮自己从尺根走到尺头、灭了（没人用的尺还在量时候）；黄昏钱满蹲回原处，我掏本子翻到第一百七十一天那一页；他左手拿笔先自己写，左手一道往下坠出了行，挪到右手，指头合不拢，笔从页上滚下路头沿，碰着那把尺停住；谁也不去捡；他左手捡起来递给我，笔杆是热的。天黑，他摸着那把尺横到我页上，把我左手翻过来在手心里写，我顺着尺边照写：头几行他没有抬头（是这两天他数下来的），夜里那一回他脸往北边去了一回才写。天亮：页上头一道歪的，底下一行一行顺着尺边。早上那一回照样写。翻表对。
10｜乙（倒起）：天亮对表开场，对到一半回叙黄昏掉笔、夜里手心写字。弃：本书事按本来次序走，回叙把掉笔那一下压成追述，对表也没了一步一步往下走的势。

3｜第四百二十八章　钢尺
5｜那一溜沙，一後晌都空着。谁也没有下去。日头过到了我们身後，影子从左手边挪到了身子前头，越拖越长，拖下了路头，一直躺到了沙上。刘二棉袄肩上那两道沟，一後晌也没有平。
7｜日头还没有落，远处那一道亮就宽了，一点一点往这边挪。要盯住一个地方看上好一阵，才看得出它近了一截。它往这边挪，那个声音也跟着往这边来，先是一点，後来连成了一片。那一溜沙叫它吃回去一大块，剩下的那一块，越来越窄。老头那只眼睛冲着它，跟着它往这边来。
9｜东头起来了，到了路头的沿上，弯着腰往底下看。那一捆插在路头底下的沙里，自己立着。他的眼睛从那一捆上起来，到了远处那一道亮上，待了一阵，回来了。他没有去拔它，回去蹲下，两只手揣回了袖筒里。
11｜钱满的左手离了那只手，把钢尺拿了出来，竖着，伸直了胳膊，拿尺头对着那一道亮。他眯起一只眼睛，比一阵，嘴唇动一阵，放下胳膊歇一歇，再举起来比。他比一回，那一道亮就近一截。吊着的那只手没有人捂，风一阵一阵扑在它上头。日头落下去，沙上那些影子一下子都没了。那一道亮还没有挪到跟前，天先黑了。他还举着尺，举了一阵，尺头上什么也对不着了，才把钢尺揣了回去。
13｜天一黑，眼前就什么也没有了，只剩下那个声音。它一点一点大起来，近起来。我的眼睛冲着前头，冲着早上那道印子在过的地方，睁着，跟闭着一个样。
15｜本子在我怀里，第一百七十一天那一页还没有记。这一夜，我们都没有躺下。刘二挨着老头坐下，背靠着他的背。老头那边的气，一夜都是匀的。钱满挨着我坐着，吊着的那只手搁在膝盖上，挨着我的胳膊肘，隔着两层衣裳，是烫的。黑里听得见每个人出气，长的，短的，没有一个是睡着了的那种。
17｜那个声音到了跟前，听着就在脚底下，一回一回的，上来，退回去。钱满那边有一点声音，是嘴唇碰着嘴唇，一下一下的。有一回听着比别的都近，我把脚往回缩了缩。後来，它每一回上来，都到一个地方，拖着声音回去。再上来，还到那儿，不往前了。钱满那边那一点声音，停了。
19｜袖筒里，我的右手往前去了一点。左手攥住它的腕子，把它攥了回来。
21｜後来那个声音退下去了，远了，小了。挨着我胳膊肘的那只手，越来越烫。到了後半夜，那一块忽然凉了。钱满把那只手挪开了，挪到了另一边的膝盖上，身子也跟着往那边歪了一点。我的胳膊肘一直凉着，我没有动。到天亮，那一块也没有暖过来。
23｜那个声音小到快听不见，小了一阵，再往後，大起来了。挨着我的那个身子，坐直了。水往回来了。
25｜天快亮的时候，我们身上落的不是霜，是一层湿。刘二从老头背後挪开，挪到了上风头，侧着身子蹲下，让开了老头那只眼睛前头。我起来，往前去，在路头上蹲下了。钱满也挪过来，在我左边蹲下，那只手搁在膝盖上，没有挨着我。
27｜＊
29｜天是从水那一头亮过来的。先能看见的是沙。沙上有一道印子，弯弯的，印子以下的沙是深的。印子上落着一溜碎东西，草棍，碎壳，一点一点黑的，顺着那一道弯过去。印子上下，沙是光的，一个脚窝也没有。
31｜昨天那一道，晒干了，认不出来了。我的眼睛搁了一後晌的那个地方，这会儿横着这一道。
33｜东头的眼睛先到了那一捆上。那一捆在印子上头，自己立着，水没有到它跟前。
35｜天刚灰的时候，水还在远处，等我看得清那一溜碎东西，它已经到了印子底下。它上来，退回去，一回比一回上得高。印子底下那一溜沙，一回比一回窄。日头从水上出来了，水上一道亮，从远处一直铺到跟前。
37｜天亮透了，他们的眼睛都睁着。东头的眉毛上挂着一层湿。钱满的嘴唇干得起了皮。我的眼睛到了他那只手上，他的左手捂上去，捂严了。手指缝里冒着一点白气。老头那只眼睛冲着那道印子。刘二的头往我这边转过来了，转到了我身上，待在那儿。我没有看他。
39｜钱满的左手从那只手上下来，摸出了钢尺，攥着，眼睛在那道印子上。手背上那一道乌的，比昨天宽了。钱满没有看它。我的眼睛回到了印子上。
41｜水往那道印子上去了。袖筒里，我的左手攥住了右手的腕子。
43｜这一回上来，白沫子离印子还有一截，退回去了。下一回近了，近到那一溜碎东西跟前，一根草棍叫它推了推，没有推动。再下一回，它没有退得那么远，跟着就上来了。这一下上得急，也薄，薄到边上那一溜白沫子都快没了，一直铺上去。
45｜它到了那道印子上，退回去了。
47｜左手攥着右手的腕子，等着它往前去。
49｜右手没有去。
