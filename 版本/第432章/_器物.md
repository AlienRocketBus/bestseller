# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—21行（夜·半笔）｜拍2=25—47（天亮·叫绝）｜拍3=51—61（那一捆·价）｜拍4=65—77（板子）｜拍5=81—95（胳膊·钩）。骨记三（拍一）在拍1｜四（拍二）在拍2｜五（拍三）在拍3｜六（拍四）在拍4｜七（拍五与钩）在拍5｜一、二与八至十四通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 430 册与 428、426 册：「钢尺」主=钱满（本章白文拍1作「那把尺」「尺边」，拍5作「那把尺」与「钢尺」；430 册之出所书「432」，於本章收：拍1 我拿过来横到第一百七十一天那一页上，拍5 钱满从那一页上拿起，插在沙上那几道断了的跟前）；「本子」「笔」主=我（430 册；「本子」之出所书「432」，於本章收：第一百七十一天那一页底下另起一行，前头空着，後头一道直的）；「东头腰上那一根（带子）」主=东头（430 册）；「套（背带）」主=东头（426 册；本章白文作「背带」）；「门边那一捆（那一捆）」无主（428 册；本章白文作「那一捆」）；「玉」主=我（408 册）。
#   ★本章新入：「墨」（拍5 我那支笔画在钱满胳膊上，承 402:97 我之笔写湿墨）；「饼」（拍3 那一捆里头摸出，前册随那一捆不另入，今掰、喂、卷，过手入册）；「板子」「麻」（拍4 同一回水扔上来）。
#   ★「尺边」係钢尺之部；「第一百七十一天那一页」「这一页」「那一页」「那一行」「前头」「後头」「後头我划的那一道」「抄着那几栏的那一页」「那几栏」係本子之部与痕；「笔尖」係笔之部；「柄」「柄上那个窝」「底」係那一捆之部；「当腰那个扣」係套之部；「断口」係玉之部；「布」係饼之裹，随饼；「黑东西」「缝」「那一块长的」「掐过的地方」係板子之部与痕；「线」「绺」「线头」係麻之所成，随麻。
#   ★「路头」「路头沿」「沙」「水」「那道印子」「草棍碎壳」「那几道（沙上一道一道细的）」「底下那个声音」「日头」「光」「天」「风」係场上之设与迹，不入册；「那只手」「袖筒」「右肩」「膝盖」「手心」「指甲」「指甲尖」「指头」「拇指」「领口」「肩膀」「棉袄」「头发」「脸」「眼睛」「嘴唇」「喉咙」「心口」「脚」「鞋底」「衣裳後腰上磨亮的那几条」「袖子」「袖口」「胳膊」「乌的」「小疙瘩」係身上之物与其痕，不入册。
