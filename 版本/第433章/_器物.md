# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—49行（後晌·纸与口授）｜拍2=53—61（夜·刻道）｜拍3=65—71（生火·钩）。骨记之拍名照开镜卡（拍零纸、拍一口授、刻道、钩），与「＊」所切之拍号不同数：骨记三（拍零）与四至八（拍一与後晌）在拍1｜九（刻道）在拍2｜十（生火）、十一（钩）在拍3｜一、二、十二至十四与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同镜前章 429 册：「那一包」「那一册」无主；「枕头上那块布（布）」主=霍钧；「章匣」主=管档的（本章白文零「匣」，只「前襟上鼓起来的那一块，比白天厚了」，作别名格；鼓起来的那一块係章匣与那一册之合）；「匣盖裂下来的那一截（那一截）」无主；「刃」主=她。
#   ★本章新入：「红纸（红的那一卷）」「白纸（白的那一卷）」（拍1 他买回，搂在胸前进门；卡之内部名「灯纸」白文零，只称两卷纸、红的那一卷、白的那一卷）；「炭」（拍1 码在灶口边上一块也没有动过，拍3 架进灶口着了）。
