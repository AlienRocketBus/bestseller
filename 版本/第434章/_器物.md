# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—27行（下沙·四歇）｜拍2=31—57（赶海的·平石·回水）｜拍3=61—71（火·喂·造匣）｜拍4=75—105（夜·叫绝）｜拍5=109—113（钩）。骨记三（拍一）在拍1｜四（拍二）、五（拍三）在拍2｜六（拍四）在拍3｜七（拍五）在拍4｜八（钩）在拍5｜一、二、九至十四与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 432 册：「钢尺」主=钱满（本章白文拍1作「那把钢尺」「那把尺」，零拔零挪，438）；「套（背带）」「门边那一捆（那一捆）」「东头腰上那一根（带子）」「板子」「麻」「本子」。
