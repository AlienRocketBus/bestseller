# 第436章 · 器物册（造式二代·合稿席立｜照 432、434、435 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 7 拍：拍1=正文5—19行（逼）｜拍2=23—45（推）｜拍3=49—55（等）｜拍4=59—69（翻·叫绝）｜拍5=73—77（验）｜拍6=81—103（回水·记·墨）｜拍7=107—117（梦·钩）。骨记三至八与拍1—6 一一相当，九（梦）、十（钩）在拍7｜一、二、十一至十七与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 434 册与 432 册：「钢尺（尺）」主=钱满（本章白文作「那把尺」「尺」「尺边」）；「本子」「笔」主=我；「墨」无主（432 册）；「绳」「麻」主=东头；「匣子」；「东头腰上那一根（带子）」主=东头，兜钱满右手。
#   ★本章之绳係东头自匣子板缝里抠出那点麻新搓的一根（比拴在匣子上的那一根细也短），434 册之绳仍拴在匣子上零动，作匣子之部；「板缝」係匣子之部；「尺边」「尺面」「尺脚」係钢尺之部；「那一页」「记水的那一页」「抄着那几栏的那一页」「前头空着的那一行」「那片白」係本子之部；「笔尖」係笔之部；「那一道墨」「那两道墨」係墨。
#   ★「路头」「沿」「坡」「坡脚」「沙」「湿沙」「水」「沟」「平石」「石面」「两个窝」「窝沿」「窝底」「两点亮」「三点亮」「影子」「日头」「眼（尺立过的地方）」係场上之设与迹，不入册；「袖子」「袖口」「袖筒」「胳膊弯」「褶子」「指头肚」「白印子」「手心」「凹印」「肩膀」「脊梁」「膝盖」「裤腿」「鞋底」「心口」「那只眼睛」係身上之物与其痕，不入册。
#   ★老头心口底下那一摞本章白文零名（只「他的手在心口底下」），照 424 册之位，不入册；背带、那一捆、饼本章白文零名，照 434 册之位，不入册。
