# 第438章 · 器物册（造式二代·合稿席立｜照 434、436、437 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—25行（臂·并一行）｜拍2=29—41（往外·匣与那一张）｜拍3=45—49（老头之脚·饼）｜拍4=53—71（停与回来·表末·叫绝之二）｜拍5=75—83（夜·钩）。骨记三（拍一臂）、四（拍二并一行）在拍1｜五（拍三上）、六（拍四）在拍2｜七（拍五）在拍3｜八（拍三下）在拍4｜九（夜与钩）在拍5｜一、二、十至十五与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 436 册：「钢尺（尺）」主=钱满；「本子」「笔」主=我；「墨」无主；「绳」主=东头（436 自匣子板缝抠麻新搓那一根）；「匣子」无主；「东头腰上那一根（带子）」主=东头，兜钱满右手。「东头那一捆（那一捆）」主=东头，承 400、402、404 册之名（436 册白文零名不入，今白文复出）。436 册「麻」已出（搓进了绳），本章白文零名，不入。
#   ★本章新入：「半截碎板子（碎板子）」（432:65 码在老头身後、434:63 拿去生了一小堆火，烧过的那一块地上扒出没烧完的半截）；「楔子」（自那半截掰成）；「油布包」主=老头；「那一张」（油布包里抽出，卡之内部名白文零，只作「那一张」）；「饼」（390:67 那一块）；两块石头同名，以本名分：「印子上头那块石头（石头）」压那一张，「刘二手里那块石头（石头）」砸楔。
#   ★「板子」「板缝」「缝」「匣子帮」「末了那一道」係匣子之部；拍2、拍3 之「带子」係匣上之绳带（匣子之部），与拍1 钱满吊臂之带子同名异物。「尺边」「尺头」係钢尺之部；「那一页」「记水的那一页」「抄着那几栏的那一页」「前头空着的那一行」「那一格」「那一道」「那片白」「小窝」係本子之部；「笔尖」係笔之部；「那一道墨」「那两道墨」係墨。
#   ★「路头」「沿」「坡」「坡脚」「背风那一面」「沙」「湿沙」「水」「水边」「沟」「沟沿」「平石」「两个窝」「印子（水上到顶留下的那一道）」「烧过的那一块地」「日头」「三点亮」「来的那条路」係场上之设与迹，不入册；「袖子」「手腕子」「胳膊弯」「乌的」「那一圈红」「皮」「指头」「指头缝」「白气」「出的气」「手心」「凹印」「指甲」「腕子」「膝盖」「鞋底」「心口」「那只眼睛」「衣襟」「胳膊肘」係身上之物与其痕，不入册。
#   ★刘二扒沙扒出、兜进衣襟的那几个，白文零名（只「扒出来一个」「咔咔地响」），不入册。老头心口底下那一摞照 424、436 册之位，白文只「油布包」「别的没有动」，那一张另入。
