# 第440章 · 器物册（造式二代·合稿席立｜照 438、439 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—43行（开·空背带一整日·回？）｜拍2=47—69（青页之来·它自己开了）｜拍3=73—119（读·叫绝）｜拍4=123—133（蜷·数名·钩）。骨记三、四在拍1｜五在拍2｜六在拍3｜七在拍4｜一、二、八至十三与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 438 册：「钢尺（尺）」主=钱满；「本子」「笔」主=我；「墨」无主；「绳」主=东头；「东头腰上那一根（带子）」主=东头，兜钱满右手；「东头那一捆（那一捆）」主=东头；「印子上头那块石头（石头）」；「那一张」。
#   ★本章新入：「背带」「杠」（前章已有之具，本章动之，入册）；「画匣子的那一张（上头那一层）」：438「那一张」本是两张粘在一处，本章自开为两张，有字的底下那一层承「那一张」之名，画匣子的上头那一层另入。
#   ★「那一兜」係背带之部；「绳圈」係那一捆之部；「记水的那一页」「抄着那几栏的那一页」「表末那一行」「小窝」「毛茬」「缝线」「页头」「小黑点」「後头白的一张」「刚抄的这一页」係本子之部；「笔尖」係笔之部；「底下那一层」「缝」「那个角」「两行」「那一溜小字」「头一截」「末了一截」「那个七字」係那一张之部。
#   ★「坡」「坡脚」「路头沿」「沿边」「印子」「沙」「湿沙」「水」「水边」「沟」「平石」「坑」「日头」「三点亮」「来的路」係场上之设与迹，不入册；「衣襟」「膝盖」「手心」「指甲」「拇指」「心口」「那只眼睛」「眼皮」「嘴唇」「胳膊肘」「裤腿」「那一层白」「那一道红」係身上之物与其痕，不入册。
#   ★438 册之匣子、油布包、饼、楔子、刘二手里那块石头，本章白文零名，不入：匣子承 438:65 在背风那一面坡上；油布包承 438:37 在老头心口底下；饼承 438:49 在东头那一捆里；楔子承 438:33 在匣子板缝里。
