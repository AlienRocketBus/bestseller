# 执笔·丙之构思（回声路）
魂（回声路）：她头一回不跟他，一个人照他走路的样子走到一处空门前；黄昏，那扇他让她先进的门叫他从外头闩上，她也照他的样子，一声不出。
进化账所避：437「防而零书，一章至多四迹」（她独行最易把他的诸惯逐样搬演成戒备之戏：本章只取走黑的一边、街口一拐、推门前看街两头三迹，且一迹只一句）；438「还是／仍所承之态须照原字」（袖口那一手、那一截之刻道照原场字）；440「等之拍须有路可回、有人不肯、有物在背後逼」（闩後那一坐：门在手边、她不叫不推、灯油一层一层下去）。

① 读者读完最该记住的一拍：拍四——黄昏外屋那扇门开了又合上，随即她这屋门外头的闩从外头插上，响一声；她没有叫，没有去推，攥着那一截坐着。托法：前三拍都让她做那个「开门的人」，且一声不出——白天她照他的样子走到一扇空门前、推开、进去、出来带上；在点下压号无一声；灯下一样做两回才落笔。整天门在她手里，末了门在别人手里；读者握 437:83「才推开了门，让她先进去」，叙者零连。

## 满分之问
甲·顺叙自晨：屋里只她一个，灶里火埋着；出门、去路三迹、到门、读空、压号、回、划道、写、黄昏闩。稳；而开头无险，三迹落在去程，回程只剩赶路，前半平。
乙·自那一处门前起：首拍即站在那扇门前（里头有没有人＝全章最险最不定之拍），去路只以日头与肋下一句量过；读空、压号；回程把三迹（不上近路、走背阴的一边、街口一拐）走成「回家不把人带回家」，读者自合其由；家门口照 437:83 看街两头、推门，独缺「让她先进去」，为拍四之闩先垫；进门、划道、写；黄昏闩。
丙·自闩响起倒叙一日，末回到闩：倒装造悬＝为吊而吊；且锚须接 437:85「她没有跟」，倒叙接不上。
取乙。甲不如乙：去程之平占了前半、回程无由；丙不如乙：吊不由事。
律⑳自裁一：段案「灯下」——前文她屋里零见油灯（433、437 之「灯」係放水之纸灯，已下水），添灯即器物凭空；改作她把灶里埋着的火拨开、添一块炭，借灶口的亮写。读者多得：那一处冷灶、这里活灶，同一个手背两样读数；且灶口之亮一点一点矮下去，即闩後那一坐背後之逼。
律⑳自裁二：段案「册子」——417 起她怀里无册（429:129 物之计无册），写之物照前文所立者取，⛔新造一册（下格定其物）。
律⑳自裁一（定，上一行「借灶口的亮」作废）：写时借窗上的亮（433:11 窗户冲着街），她⛔动他埋的火——回屋只拿手背试灰；窗上的亮一点一点退，即拍三之逼、拍四之暗。
律⑳自裁二（定）：写之物取「那一沓」（401:17 找头；417:81；421:85 票、那一沓、铅笔头、那一截）钱面那一头的白（403:31 之式）；页比日多以那一截量：拇指往回停在一道上，从那一道起一道一张排到末一道，手里还剩着——落「多」字，⛔数。
律⑳自裁三（定）：段案「外屋门开了又合上；随即闩」依常理读作他进了外屋、人在门外不走，与段案知之变「读者知他夜里出去」相抵；改排「外屋门开了→门缝底下进来一股凉→闩从外头插上，响一声→外屋门合上，凉断了」：一开一合、一闩，件数不增，读者自知他开门进来只为闩她、又出去了。
号之物（定）：照 401:31 门里压石之式（扁石、底下小坑、坐平、抹缝），号取那一处灶边剩下的一根引火的，她拿刃在上头刻一横一点（383:41 她册子封皮之记·叙者零连），⛔书给谁。
魂之定稿（门之所指照下改）：她头一回不跟他，一个人照他走路的样子走到一处空门前；黄昏，那间他让她先进去的屋子，叫他从外头闩上，她也照他的样子，一声不出。

③ 最易写平写俗处：空屋（⛔空荡荡、蛛网、落满灰——只给手背、塌成白的炭、锅印三样，一样一句）；回程（⛔「警惕四顾」——三迹各一句，以日头、肋下作尺）；闩响（⛔心一沉、愣住、攥紧拳——只给手：指头已在袖口、凉断、手落到那一截上）；写（⛔抄 403、437 之悬笔——这回停在第二样上是起身去自家灶前量两回）；压号（⛔抄 401:31 折两折、往右送一指、撒土——改作刃刻引火的、坑底一层白、鞋底蹭缝）。
④ 收句「拇指摸到末一道，再往前，是滑的。」：落段案之钩（坐着攥那一截）；末一道是昨夜的，今天这一道还没刻，刃在袖里，日子悬在她手上，推进 443（她坐一夜）；翻 437:5 拇指摸到末一道停了停；⛔解、⛔问句；「滑」⛔「光」（黑屋里「光」易读成亮）。
⑤ 第二件咬进来：外闩（段案裁一之八作本章之转，443 之因）；另一口咬在灶上——435:63「灰是她埋的，埋得平平的」、435:83「他把灰拨匀，添一块炭埋上了。」他在这一口灶里烧过那一沓点户单子，她今天在同一口灶上拿手背量两回，读者握灰之来历，叙者零连。

落稿前之定（改排）：取「甲之变」——起手仍「票在她左手里，背面朝上」，人在自家屋里，钉子上大衣不在（他已出门，零书去处）；补回出屋那一下决断（起草令角度三之①：手在门上搁一阵才拉开）与认路（岔口、石桥、井台、一扇一扇数门），乙之门前之险留作拍一之顶；家门口看街两头仍留回程。由：乙缺出屋之决、事担不起须厚。
拍表增：一之〇 出屋（她拨灰添炭再埋平、叠褥子角对角，为回来之验）；二之〇 起来眼过一屋（墙上钉子空着与家里那一颗同形，水缸冰，床板）；四之〇 上门板之声过去、过路脚步不停、天黑透外屋门一直没响，然後门开。
补一回（净重 2665 低於须厚 2900，所补皆真事⛔凑）：出这屋门外头那道闩她不碰（屋子看着像有人，与拍四同一道闩）、锁是带走的（锈断一圈）、别家门槛踩黑、泥地不留印、起来时手往墙上去又收回、鞋底蹭下的是那一处墙根的土、回来时那道闩还退在一边、划得轻、指头尖的白没有擦、身子挪向窗、字一新一旧、窗由灰变黑、刃贴腕（夜里本该刻这一道）、刻道硌手心。
