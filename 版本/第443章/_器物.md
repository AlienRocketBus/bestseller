# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）

#   ★名与主承前章册：「绳」主=东头、「灯」（442 册）；「纸包」「那一截」（441 册）；「门外头那道闩」即 441 册「她门上的闩」（441:91 黄昏他从外头插上）。

#   ★「坡」「坡顶」「沟」「沟沿」「水」「亮」「影子」「茬子」「墙」「街」「门」「门槛外头那块石头」「街沿底下的土」「门缝那一溜霜」「窗户上那一块没有白的」係场上之设与迹，不入册；「袖口」「裤脚」「胡子」「膝盖」「拇指」「食指根」「後跟」「手心」係身上之物，不入册（腕疤以段案点名入）。
