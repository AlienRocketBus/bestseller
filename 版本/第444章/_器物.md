# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 7 拍：拍1=5—31｜拍2=35—45｜拍3=49—61｜拍4=65—83｜拍5=87—103｜拍6=107—139｜拍7=143—157（正文行）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜八在拍6｜九在拍7｜一、二、十至十五与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 442 册：「背带」（白文作「背带」「那一兜」）；「灯」；「匣子」；「绳」主=东头；「东头那一捆（那一捆）」主=东头；「另一捆」主=我（本章白文只作「两捆」）；「本子」主=我；「麻」；「印子上头那块石头（石头）」。
#   ★本章新入：「绳带」（匣子上的，442 白文零名；本章东头勒、解，末了绕在他胳膊肘上）；「杠」（440 册有，442 白文零名，本章上我的肩）；「笔」（白文作「我的笔」「笔尖」）。
#   ★「那一兜」係背带之部；「绳圈」係东头那一捆之部；「扣」（我腰上那个扣）係绳之部；「匣子帮」「板缝」「匣子底」係匣子之部；「结」「长头」係绳带之部；「灯把」係灯之部；「抄着那几栏的那一页」「我那一行」「小窝」係本子之部。
#   ★「坡」「坡脚」「坡上那一溜脚印」「他踩过的那几个脚印」「沙」「水」「白边」「沟」「大沟」「沟底」「沿」「平石」「路头」「来的那条路」「三点亮」「口子」「平地」「上头那几户人家」係场上之设与迹，不入册；「指甲」「手心」「手心里的窝」「心口」「那只眼睛」「肩头」「後腰」「衣裳那几道亮印子」「吊着的那一只」「指节」「指头肚」「膝盖」「腰」「袖子」「胳膊肘」係身上之物与其痕，不入册。
#   ★442 册之「那一张（字的那一张）」「油布包」「钢尺」「画匣子的那一张」「柄上那个窝」「东头腰上那一根（带子）」本章白文零名，不入：字的那一张仍在老头心口底下油布里（拍7 他的手先到了心口底下按了一按·零名）；钢尺、画匣子的那一张承 442 在钱满那儿，交 446；带子兜着钱满右手（白文只作「吊着」）。
