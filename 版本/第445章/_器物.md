# 第445章 · 器物册（造式二代·合稿席立｜照 441、443 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—27行（他睡）｜拍2=31—55（誊页）｜拍3=59—91（去那一处·叫绝之上）｜拍4=95—127（回来·叫绝之下）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜一、二、七至十一与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同镜前章 441 册：「刃」「那一沓」「车票（票）」「铅笔头」「她的号（那一条白）」主=她、「那一处的闩（闩）」；承同线前章 443 册：「那一截」主=沈鸢、「门外头那道闩（闩）」（即 441 册「她门上的闩」）、「右手腕上那道疤（那一道）」主=霍钧。
#   ★本章新入：「门里摆法的石头（石头）」（拍3 原处卡在那道缝里，她零碰）；「他那双鞋（鞋）」（拍1 并排在床跟前，拍4 在他脚上）。
#   ★「这几天写的那几张」「原先那几张」「新写的」「末了那一张」「右手边那一摞」「钱面」「那块白」係那一沓之部；「鞘」係刃之部。
#   ★「窗户」「窗上那一层白」「床」「床沿」「被子」「被面」「桌子」「灶」「门」「门板」「门槛」「门框」「门後头」「门楣」「缝」「钩子」「槽」「街」「街口」「拐错过的口子」「巷口」「巷子」「墙」「墙皮」「霜」「日头」「炉灰」「车」「车轱辘」「担子」「门框上巴掌大一块」係场上之设与迹，不入册；「大衣」「袖口」「腕子」「拇指」「食指根」「胸口」「拇指肚」「指头肚」「膝盖」「左肩」「肩头那一道白」「嘴边的白」係身上之物与其痕，不入册（腕疤承 443 入）。
