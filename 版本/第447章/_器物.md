# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—17行（那一份与回执并页）｜拍2=21—43（扬字封套回章归卷）｜拍3=47—67（会签齐了·柜子那一行·叫绝）｜拍4=71—99（头一回签名·二百八十张）｜拍5=103—115（那一封进抽屉·钩）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜一、二、八至十二与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同镜前章 439 册：「扣押的那一份（那一份）」「公文包（包）」「笔」主=黎东来，「回执」无主；承 431 册：「卷皮」「扬字封套（封套）」「签收（黄的那一张）」「底稿」「抽屉钥匙（钥匙）」「章」，其中「签收」「底稿」主=黎东来照 431 册，余照旧不书主；承 415 册：「印台」「镇纸」「空白的底稿（底稿）」，照旧不书主。
#   ★本章新入：「扣押二百八十张（那一摞）」（拍1 新打出来压在镇纸底下，拍4 签发那一格张张写他的名字，拍5 送单子的人抱走）；「那几份」（抽屉最底下，即 277：581 之三份，415 册「照片」「那一卷」所在，白文只作那几份）；「测绘转上来的那一封（那一封）」（拍5 入抽屉最底下，未拆）。
#   ★「头一张」（在谁名下那一格打的是苏衍，清单只院子、屋子，底下的横线空着，日子跟那一份上改过的那一个一个样）係那一摞之部，随那一摞出门；「格子」「表头」「签发那一格」「日子那一格」「清单」「横线」係那一摞每张之部。
#   ★「在谁名下那一格」「会签那一溜」「霍钧那一栏」「清单」「日子那一格」「签发那一格」「那一处」「墙里那只柜子连里头的东西那一行」係那一份之部与痕（照 439 册）；「回执上那几行」「送达那一格」係回执之部；「封套上那张签」「报往那一格」「扬字」「封口」「浆子」係扬字封套之部；「当头那一页」即 431 册「照抄的那一张（校准那一张）」，在卷皮里，係卷皮之部；「印泥」「盖子」係印台之部；「章面」「章顶」係章之部；「笔帽」「笔杆」係笔之部；「单子」「寄件人那一栏」「收信人那一栏」「邮戳」「退信的条子」「糊口的浆子」係那一封之部。
#   ★「桌子」「桌角」「桌沿」「桌面」「椅子腿」「抽屉」「锁眼」「出门的那一格」「炉子」「门」係场上之设，不入册（抽屉之钥匙另入）；「大衣」「里兜」「胸口那一层」「食指」「指头」「指肚」「手掌」「嘴边」「白气」係身上之物与其痕，不入册。
#   ★439 册「车」本章白文零名，不入：439 末车到街口，其间之日零书，本章他在桌子跟前。
