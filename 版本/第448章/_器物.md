# 第448章 · 器物册（造式二代·合稿席立｜照 446、447 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—31行（门口）｜拍2=35—51（四见）｜拍3=55—87（入匣）｜拍4=91—105（量着了·叫绝）｜拍5=109—121（是我）｜拍6=125—131（钩）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜八在拍6｜一、二、九至十四通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 446 册：「匣子」（照旧不书主）「灯」「本子」主=我；「爷爷那把钥匙（钥匙）」主=我；「暗门（门）」；「信」；「画匣子的那一张」主=钱满。承 444 册：「绳带」「背带（带子）」。
#   ★本章新入：「先人」（地窖里那一具，一以来，页上之物）；「那一幅布（布）」（一：一百六十九那幅整布）；「血图（那一卷）」（一：一百八十三，白文只作那一卷）；「匣子的盖子（盖子）」（前文零见，行家记软处，其称交总编辑裁）。
#   ★「横档」「槽」「匣子帮」「盖沿」「刀口」係匣子与盖子之部；「孔」「补丁皮」「门口」係暗门之部；「结」「长头」「布角」「布边」係那一幅布之部；「黑衣裳」「红边」「革带」「两截腿」「裹腿的布」「布鞋」「针脚」「右手」「食指跟中指」係先人之部；「齿口」「柄」係钥匙之部；「灯把」「灯苗」係灯之部。
#   ★「门槛」「门框」「墙角」「台阶」「窝」「土壁」「棺」「棺沿」「棺壁」「人形」「方块」「土」「屋里」「墙」係场上之设与迹，不入册；「吊带」「心口」「衣襟」「後腰」「亮印子」「吊着的那只胳膊」「後脖颈」「腕子」「拇指」「指甲」「胸口」「怀」「鞋尖」「我这双鞋」「膝盖」係身上之物与其痕，不入册。
#   ★446 册「那一摞」「最後搁下的那一张」「油布包」「那一张（字的那一张）」主=老头，本章白文零名（只以纸压平的一溜方块与心口底下那一只到场），不入；「刀」「木屑」「柴垛」「垫底的木头」「院门上那把锁」本章白文零名，不入。
