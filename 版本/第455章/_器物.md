# 第455章 · 器物册（造式二代·合稿席立｜照 453、454 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—39行（放匀·叫绝）｜拍2=43—67（那声音·附叫绝）｜拍3=71—101（票）｜拍4=105（钩）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜一、二、七至十与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 453 册：「刃」主=她，本章白文零「刃」字，只作「是铜的」（鞘口那一圈铜係刃之部），别名取「铜」；「灶沿上那块砖（砖）」照 453 不书主；「盐罐子」本章白文作「盐罐」；「凳子（凳）」「她那只碗（碗）」照 453；「他那一碗」本章白文只作「那两只碗」，别名取「碗」；「车票（票）」照 451 册，主=她。
#   ★本章新入：「她夜里换下的衣裳（衣裳）」（两件：上头那件左袖里子磨亮一道；底下那件贴身穿的，心口襟子里头缝着一层兜，肘弯补过一块）；「他怀里那一册（那一册）」（拍2 手心底下隔着它，拍3 票背抄的是它里头那一行）。
#   ★「扣子」「袖子」「襟子」「兜」「里子」「下摆」係衣裳之部；「布」「布角」係砖之部；「小铁勺」「勺把儿」「罐口」係盐罐子之部；「凳沿」「凳面」「凳头」係凳子之部；「盆」係碗之所在。
#   ★「门」「门闩」「鞋」「铺」「铺板」「床」「床板」「床沿」「被子」「被头」「枕头」「窗」「窗纸」「灶」「灰」「柴」「墙」「街」係场上之设与身上之物，不入册（照 453 册）；「被头上那一点白」「被头靠枕头那一截湿了一小块」係迹，不入。
#   ★「纸」（拍1 纸响了细细的一声，一回只响一样）泛指她怀里诸纸，白文不分判纸、三折的那一张、对折的那一张、空封，不入；其去处白文零书，推挪进她换上的那一件里头（拍3 兜里只剩一张票），位交记席。453 册「封里对折着的那一张（对折）」「判纸」「那张纸（三折的那一张）」「门後那件棉袄（棉袄）」本章白文零名，不入；「那一截」「那一沓」「铅笔头」照 451 册，本章白文零名，不入。
