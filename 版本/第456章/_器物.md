# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—41行（书）｜拍2=45—59（池）｜拍3=63—147（当面·叫绝；钩在其末行 147）。骨记三在拍1｜四在拍2｜五、六在拍3｜一、二、七至十三通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。
#   ★名与主承同线前章 454、452 册：「钢尺」主=钱满；「本子」主=我（452 册承 450）；「绳」「杠」照 454 不书主；「薄的那一份（那一卷）」照 452 册，主=钱满。
#   ★本章新入：「县里的旧志（书）」主=钱满（白文作县里的旧志、一本厚的、书、那一块方的）；「书钱（那几张钱）」自薄的那一份上扯下，去摆摊的袖筒；「告示那根杆子（杆子）」（池子边上那一根，非 454 册岗亭那一根）；「告示」；「杆子底下那个圆铁盖子（圆铁盖子）」；「路灯那一圈里那个圆铁盖子（盖子）」（上头铸着一个字，阀）；「铁管（管子）」「他手里那点亮（那点亮）」主=三点亮之一（卡称，白文零名，作最前头那一点、一个人、他）。
#   ★454 册「拉白菜的三轮」「杆子」（岗亭那一根）「岗亭那人的棍」「天桥底下那一排摄像头」「公交站那块屏」「进站的那辆车」「钱满的证」「柜台上那个厚本子」「旅社那把钥匙」「房钱」本章白文零名，不入：证与旅社那把钥匙在钱满怀（零书），厚本子在柜台上，交466。「两捆」「灯」「爷爷那把钥匙」「信」「扣押那一张」本章白文零名，不入：两捆挂杠随杠走，灯挂我腕，余在我怀，位照 454。
#   ★「封皮」「书脊」「线」「折缝」「封底」係书之部；「胶带」「角」係告示之部；「阀」係盖子上铸的字；「那一卷钱」係薄的那一份之称。
