# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。

#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 455 册：「她夜里换下的衣裳（衣裳）」，本章白文作她那一方衣裳，夜里她又把身上的衣裳褪下来叠了搁上凳面，同名一格；「盐罐子（盐罐）」（「小铁勺」「小勺」「勺把儿」「罐沿」係其部）；「凳子（凳）」；「他怀里那一册（那一册）」主=他。承同线前章 461 册：「那一沓」主=她（本章白文零书其名，只作纸，册名作「那一沓（纸）」）；承 457 册：「布包」。
