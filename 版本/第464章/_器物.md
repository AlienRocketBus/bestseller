# 第464章 · 器物册（造式二代·合稿席立｜照 462、463 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—29行（贴墙）｜拍2=33—51（拱对拱·叫绝）｜拍3=55—59（一句）｜拍4=63—75（信封）｜拍5=79—89（开价）｜拍6=93—101（钩）。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名承同镜前章 462 册：本子、笔、绳、两捆（捆）、钥匙、暖水瓶；承 458 册：夹子、停运作业单、扣押那一张（458 册别名「那张纸」，本章拍5 白文作「我那一张」，取之）。
#   ★本章新入：「那一封」（447 抽屉里那一件，他左手自大衣里摸出，推过桌子当中，留在桌上，至 470 零动）；「他里兜那支笔（笔杆）」（447:75 那一支，只露一截）；「柄」（462 册入两捆之部，本章两拍点名，另立一行）；「本子里那封信（信底下）」（450:91 夹进本子那一页之信，扣押那一张夹在它底下）。
#   ★「铁夹子」「挂钉子的那个眼」係夹子之部；「别针」「小单子」「红章」「邮戳」「条子」「封口」係那一封之部；「签发」「疙瘩」「点」係停运作业单与扣押那一张之部；「单子」「那一摞」係停运作业单与其底下那几张。
#   ★「大衣」「鞋」「鞋帮」「鞋底」「鞋尖」「白衬衣」「袖口」「扣子」係他身上之衣；「门」「门把手」「门舌头」「窗户」「桌」「桌沿」「桌子腿」「床」「床沿」「床脚」「暖气片」「楼梯」「头一级」「小门」係屋中与楼中之设；「竹扫帚」係街上扫雪那人之物；俱不入册。
#   ★「拇指」「两根指头」「中指」「茧」「後腰」「嘴」「眼睛」「印子」係身上之尺，不入册。
