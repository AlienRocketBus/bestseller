# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 3 拍：拍1=正文5—41行（门边·判纸·影·面味）｜拍2=45—101（重缠·叫绝）｜拍3=105—125（东头·钩；钩在其末三行 121、123、125）。骨记三、四、五在拍1｜六、七、八在拍2｜九、十在拍3｜一、二、十一至十四通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 465 册：「那一沓」主=她；判纸（465 册零名不入，本章白文有名，入）。承 466 册：碗、绳、本子（她之镜，主作他）。
#   ★本章新入：「旧布（布）」（钱满右手那截几天没换的布，死结牙印，她解下，末了攥在她左手里，去处零书）；「布条（那一条）」（她里头那件襟子底边撕下的一条，热的，缠钱满右手，打她自己的结）；「吊带」（钱满吊右手之带：手出，搁得比它高一点，放回）。
#   ★刃（铜）、那一封、筷子、笔、柄、钥匙、县志，本章白文零名，不入，位照前章册（刃在她左小臂鞘里，白文只作「袖口那边」；那一封、筷子在桌上原处；笔横在本子上；柄在脚边那一捆上；钥匙、县志在钱满怀，白文只作「按着一样什么」）。「起笔」係三百八十三：五十九那一笔之起处，非器。
