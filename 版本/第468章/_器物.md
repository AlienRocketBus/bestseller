# 第468章 · 器物册（造式二代·合稿席立｜照 466、467 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—37行（罐·尺·窝；次叫绝）｜拍2=41—57（两本）｜拍3=61—81（海）｜拍4=85—113（一站·叫绝；钩在其末 113）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜一、二、七至十四通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 466 册：本子（主=我）、笔（主=我）、绳、碗、筷子；承 467 册：布条（钱满右手上那一条，本章白文作「布」）。
#   ★本章新入：「罐子」（东头天没亮提回，搁门里，罐口一丝白气，至章末没了）；「钢尺（尺子）」（460 插回池缝那一把，横在罐沿上，钱满揣进怀里至四百八十六）；「县志」（钱满怀里带出，翻过一页）；「一张纸」（她记日之散张，拍一已在她膝上，翻了个面搁在我那一本旁边，末了第一百八十六日；那一沓零出怀）。
#   ★466 册之柄、那一封、油泼辣子面，本章白文零名，不入，位照前章册（柄在脚边那一捆上；那一封在桌上我这一半；面已吃净）。467 册之判纸、那一沓（她袄一个扣子也没有解，零出）、旧布（467 攥在她左手里；本章拍3 她的左手手心朝上搁在膝盖上，空着，去处仍零书，段案之令）、吊带（白文只作「吊着的那只手」），本章白文零名，不入。刃、钥匙零名，位照前章册（刃在她左小臂；钥匙在钱满怀）。
#   ★「罐口」「罐沿」「白气」係罐子之部；「霜」「冰」「刻度」「尺尖」「当腰」係钢尺之部，钱满袄襟子底下「那直直的一条」即揣进怀里之钢尺；「书脊」「窝」「那一小块纸」「页边」係县志之部；「页头」「页脚」「格线」「那一行」「点」係本子之部；「末了那一点地方」「纸边」「铅笔字」係一张纸之部；「笔尖」「笔杆」「笔帽」「墨」係笔之部；「碗边」係碗之部；「结」係布条之部。
#   ★「灯」「门」「门把手」「门缝」「窗帘」「帘子」「桌子」「桌面」「床」「床沿」「床头」「墙」「被子」係屋中之设，不入；「影子」非物；「扫帚」係街上之声，不入。
#   ★「袄」「扣子」「袄襟子」「鞋」「鞋尖」「鞋面」係身上之衣；「手心」「掌根」「指甲」「指头肚」「腮帮子」「颧骨」「嘴唇」「肋」係身上之尺；俱不入册。
