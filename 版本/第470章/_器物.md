# 第470章 · 器物册（造式二代·合稿席立｜照 468、469 之式）

# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 5 拍：拍1=正文5—31行（无迹）｜拍2=35—55（碗下·叫绝）｜拍3=59—91（等与推表；叫绝第二落在其末 87、89）｜拍4=95—105（梦）｜拍5=109—123（西墙·十天；钩在其末 123）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜一、二、八至十五与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 468 册：本子（主=我）、绳、碗、筷子、罐子、县志（主=钱满）、一张纸（主=她，本章白文作「那一张纸」）、布条（钱满右手上那一条，本章白文作「布」）；承 466 册：那一封；承 461、469 册：路费（主=她，本章白文作「那一卷」）。
#   ★本章新入：零。
#   ★468 册之钢尺、笔，本章白文零名，不入，位照前章册（钢尺在钱满怀，至四百八十六；笔套帽搁在页脚上，拍3「起笔」係推表之动作，零名其物）。469 册之判纸、那一沓、铅笔头、那一方、勺、门闩、刃、黑铁链俱在她身上或异线那一间，本章白文零名，不入，位照 469 册。
#   ★「格线」「那一行」「第九行」「页头」「那几栏」「小窝」「三溜字」係本子之部；「线」「线头」「纸边」与拍2、拍3 我手里之「结」係那一卷之部；「碗底」「碗壁」「碗沿」「那一圈红」係碗之部；「罐口」係罐子之部；「页边」係县志之部；「绳头」係绳之部；钱满「手背上那个结」係布条之部。
#   ★「灯」「门」「门缝」「门把手」「门鼻」「窗帘」「桌子」「桌面」「桌沿」「床」「床沿」「墙」「西边那堵墙」係屋中之设；「楼道」「楼梯」「楼梯口」「头一级」「拐角那扇窗」「柜台」「後头那扇小门」「门轴」「煤场」「煤堆」「煤渣子」「壳」係场上之设；「坑」「坡」「梁」係梦中之象；「那一道亮」「日光」非物；俱不入。
#   ★「鞋尖」係身上之衣；「指头」「拇指」「手心」「手背」「脖子」「肩膀」「膝盖」「腿肚子」係身上之尺；俱不入册。
