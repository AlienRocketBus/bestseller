# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—25行（页头冰尺）｜拍2=29—45（找车）｜拍3=49—115（咬门·叫绝；钱满之余在其末 109—115）｜拍4=119—125（收拾）｜拍5=129—143（梦）｜拍6=147—155（醒；钩在其末 153—155）。骨记三在拍1｜四在拍2｜五、六在拍3｜七在拍4｜八在拍5、拍6｜九在拍6｜一、二、十至十九与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 470 册：本子（主=我）、绳、罐子、县志（主=钱满）、那一封、路费（主=她，本章白文作「那一卷」）；承 468 册：钢尺（主=钱满，本章白文作「尺子」）、笔（主=我）；承 462 册：杠；承 461 册之名：手机（零主）。
#   ★本章新入：钉子、饭盒（主=司机）、登记簿（主=戴套袖那人）、协查之纸（主=便衣，本章白文作「纸」）、钥匙串（主=戴套袖那人）、电话、那一捆。

#   ★「页头」「小黑点」「三溜那一页」「小窝」「昨天那一行」「页头没有写日子的那一页」「一双腿那一行」「大方块」「小的」「点」係本子之部；「笔尖」係笔之部；「钉尖」「钉身」係钉子之部；「罐沿」「罐口」係罐子之部；「绳头」係绳之部；「协查」「同行一人右臂吊带」「签发那一格」「那一笔」「疙瘩」「号码」「纸角」係协查之纸之部；「那一页」「住店的」係登记簿之部；「听筒」「话筒」係电话之部；「柄」「柄上那个窝」係那一捆之部；司机手里「筷子」係饭盒之部（与 470 册碗上之筷子异物，不入）。
#   ★「窗」「窗户」「窗框」「窗台」「窗外」「玻璃」「霜花」「窗帘」「帘子」「床」「被子」「被头」「被面」「门」「门边」「墙」「桌」係屋中之设；「楼道」「楼梯」「楼梯顶」「头一级」「柜台」「墙上那块板」「钩子」「後头那扇小门」「门轴」「玻璃门」「棉帘子」「煤场」「煤渣」「车」「车屁股」「车斗」「斗沿」「後轱辘」「牌子」「街」「路灯」係场上之设；梦里「泥」「水」「函」「案」「那张纸」与那只左手捏的「笔」係梦象；「霜」「冰」「白」「黄」「白气」「沙沙的声音」非物；俱不入。
