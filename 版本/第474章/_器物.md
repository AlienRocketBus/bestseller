# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 6 拍：拍1=正文5—23行（冰合刻·叫绝）｜拍2=27—41（出门）｜拍3=45—57（车资·叫绝）｜拍4=61—71（栏杆）｜拍5=75—85（盹与梦页）｜拍6=89—121（听针·叫绝；钩在其末 117—121）。骨记三在拍1｜四在拍2｜五在拍3｜六在拍4｜七在拍5｜八、九在拍6｜一、二、十至十八与咬合通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 472 册：本子、笔（主=我）、钢尺（主=钱满，本章白文作「尺子」）、钉子、罐子、绳、饭盒（主=司机）、钥匙串（主=戴套袖那人，本章白文作「钥匙」，挂回板上）、路费（主=她，本章白文作「那一卷」）、那一封、杠、那一捆；承 464 册：钥匙（四百六十二夜里塞进钱满手里那一把，本章白文作「那把钥匙」，挂回板上那个空着的钩子）。
#   ★本章新入：热包（段案之名，本章白文作「纸包」，主=钱满）、另一捆（东头背上）、卡（主=司机，本章白文作「一张卡」）、铜针（段案物之计之针，三寸七，主=钱满，本章白文作「针」）。
#   ★472 册之登记簿、协查之纸、电话、手机、县志，本章白文零名，不入，位照 472 册。
#   ★「页头」「三溜那一页」「昨天那一行」「那一行」「这一行」「页边」「页头空着的那一页」「上一回添的那一行」係本子之部；「笔尖」係笔之部；「冰」「霜」「冰沿」「那两道」「我那一道」係钢尺上之痕；「罐沿」「罐口」係罐子之部；「柄」「柄上那个窝」係那一捆之部；「线」「那一筒线」「结」「卷子」「卷心」「当中那几张」「钱」係路费之部（当中那几张抽出来作车钱，递进窗里，司机揣进袄里）；「油纸包」「油纸」「针尾」係铜针之部；「钩子」「一排钩子」係墙上那块板之部。
#   ★「窗帘」「缝」「窗台」「窗框」「被面」「被头」「门边」「桌」係屋中之设；「楼梯」「头一级」「柜台」「墙上那块板」「後头那扇小门」「煤场」「车」「驾驶楼」「窗玻璃」「窗沿」「门上的把手」「卡口」「岗亭」「栏杆」「後视镜」「长桥」「车窗」「道班」「院子」「院墙豁口」「水泥台」「台沿」「墙根」係场上之设；梦里「河」「人」係梦象；「白气」「雪」「壳」「脚印」「冰碴子」「热气」「蒸馍味」非物；俱不入。
#   ★「袄」「套袖」「袖口」「墨」「吊着的那只胳膊」「怀」係身上之衣与伤；「食指」「拇指」「拇指甲」「指甲」「手心」「膝盖」「耳朵」「胸口」係身上之尺；俱不入册。
