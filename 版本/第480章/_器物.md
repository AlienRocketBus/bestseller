# 式：器物名｜入=拍号｜用=拍号｜出=拍号（有主者加｜主=人名）
#   ★「出」只认去处，不认变、不认在场；有意留的开口写 出=拍号(开口:其由)。
#   ★拍以「＊」切，全章 4 拍：拍1=正文5—15行（头一醒）｜拍2=19—39（二醒·送）｜拍3=43—57（三醒）｜拍4=61—99（定·叫绝；钩在其末 99）。骨记之拍名照段案三拍：「拍一」统三醒（拍1、拍2 之 19—27、拍3），「拍二」即拍2 之 29—39（送），「拍三」即拍4。骨记三在拍1｜四、五在拍2｜六在拍3｜七在拍4｜一、二、八至十六与咬合行通章。
#   ★每一格之拍号，那一拍的白文里须真有其名；别名格：本名（白文之名）。器验只认别名一个。
#   ★名与主承同镜前章 478 册：本子、笔（主=我）、路费（主=她，本章白文作「那一卷」）、绳、钱满那一摞（主=钱满，本章白文作「那一摞」）、钱满那一页（主=钱满，本章白文作「那一页」）、镇口那辆车（本章白文作「那辆车」，谁的零说）；承 474 册：钢尺（主=钱满，本章白文作「尺子」）、罐子（本章白文只作「这一回没有罐子」，物在城里那家旅社窗台外头）。
#   ★本章新入：那块玉（我领口里；只拍1 一段，白文「玉」只此一行）。
#   ★478 册之那一捆、另一捆、杠、岗亭那张纸，476 册之吊带（本章白文只作「吊着的那只胳膊」），474 册之铜针、钉子、那一封、钥匙串、钥匙、卡、饭盒：本章白文零名，不入，位照前册。474 册之热包：本章白文只在送那一页上作一行「那一包」（四百七十四：三十七柜台後头递过来的纸包），物零动，不入，位照 474 册。

#   ★「炕」「窗框」「窗户」「玻璃」「窗台」「镇口那盏灯」「杆子」「墙」係场上之设；送那一页上「栏杆」「身上那一股」「钱满」「东头」「那一包」「那一卷」係所列之行；「霜」「冰」「白」「灰」「黄」「亮」「黑」非物；梦里「沟沿」「嘴」「台子」「石面」「凿印」「沿」「绳头」「绳」「石粉」「灯」「灯苗」「门」「门缝」「杠子」「长长的东西」「脚步」係梦象；俱不入。
