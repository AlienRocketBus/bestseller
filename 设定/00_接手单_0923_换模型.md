## 一·答：**不需要「交接」，因为这本书从第一天起就不是靠谁的记性在走的**

**★这一套机制之立身之本，就是「任何一坐随时可以死，而书不掉一格」**：

| 该记的东西 | 记在哪儿（⛔不在任何人的脑子里） |
|---|---|
| **此刻该干哪一件** | `python3 工具/自走.py`（它自己判 起／候／补／跑／庭，只印一行命令） |
| **一章跑到哪一段了** | `python3 工具/续跑.py`（十一段之第几段·带时刻·带凭据） |
| **书的全部事实** | `设定/00_镇冢秘术_唯一总圣经.md`／`设定/canon事实库.json`／`设定/01_…施工与伏笔回收表.md` |
| **欠了什么、限在哪一章** | `设定/大问挂账.md`｜`设定/分量欠账.md`｜`设定/看官账.json`｜`设定/无闸之卡账.md`｜`设定/合玉闸账.md` |
| **机制上栽过哪些跤** | `设定/机制体检账.md`（通例 1—67）＋**各器码内注**（逐跤逐条写在它治的那一行旁边） |
| **推不上去卡在哪一条** | `设定/推闸卡在哪一条.md` |
| **这十章庭上判了什么** | `设定/大审_至第357章.md`（十二席·逐笔落裁） |
| **挂着待办的活** | `设定/回修专案_大审0923之挂_限361362.md`（限361 二笔／限362 五笔） |
| **每一章为什么这么写** | `版本/第N章/_轮记.md`＋`设定/回执_*第N章*.md`（作业单／案席／封版席三种） |

⛔**而这不是巧合，是律**：`设定/00_作者常令_不停之律.md` 律⑫逐字——
**「报告不是交付：一回合里若只有『我看了什么、我打算怎么办』而没有一样东西落到盘上，那一回合等於没有。」**
★**即：本坐一整天所做的每一件事，都是先落盘再说话的。换谁来接，读盘即可，⛔不必读我说过的话。**
