## 一·宗旨（⛔其序即其轻重·2026-09-24 作者当面改定）

> ⭐⭐⭐ **作者令：「最高优先、最中央的东西，永远是小说的质量——要写成中国第一，让读者绝对上瘾，一看就停不下来，⛔不能有任何妥协。」**

1. ⭐⭐⭐**书要好看到让人放不下**——**这是一切机制之所以存在的理由。** 机制是手段，书是目的。
2. ⭐**书绝不丢**——**这是第一条的前提**（没有书就谈不上好书）：随时在 GitHub 上，任何一刻沙盒没了，一个字不少。
3. **机制自己越来越好**——**每逮到一处病，治这一族；而最要紧的病，是「让人放下书」的那几样。**

## 二·五层之环（`工具/自进化环.py`·每回合 `自走.py` 头一件）

### ⭐⭐⭐ L4 · 书之进化（最高优先·列在最前）
| 查 | 其律 |
|---|---|
| **读者席（大审）判出的每一处「让人放下书」，有没有流进落笔之前的开镜卡** | ⛔**只躺在大审档里的判，下一章照样再犯**——0924 亲数：大审之治「今天这一拍比昨天多了哪一线」在开镜卡模子里出现 **0 次** |
| **`设定/书之进化账.md`**：逐席之判 → 落在开镜卡哪一问 | ⛔**所登之问须在模子里逐字在**（登了而模子里没有，等於没落） |
| **棘轮 `设定/书之进化_棘轮.json`** | **「未落卡」之数只许往下走**——0924 立账：12 席｜落卡 7｜未落 4；**同日编辑之判落卡，底 4→3** |

**其落卡之问——开镜卡「⭐⭐⭐ 问八·上瘾四问」**（起草之前必答，答不出不许起草·自 364）：〔1119 死规之审·gates3：N≥473 去「答不出不许起草」，改「各问据实答；『无』须带由；⛔为答而造」；②位>2、③同线连两无只报 ⚠；N<473 照旧——据 设定/裁_1119_死规之审.md〕
| 问 | 来自哪位读者之判 | 机器之牙 |
|---|---|---|
| **①接钩** | 类型读者：356 末拍之钩，357 一字不接 | 所引须**逐字在上一篇同线之章之末拍里**（坑㉕） |
| **②读者的理由** | 评委：读者的理由迟至拍四 | 须落在**拍一或拍二** |
| **③结一笔**（＋兑现之位） | 悬念账席：十章开十八结二｜编辑：兑现藏在拍腹又被盖掉 | **同线连两篇「无」即红**；有结须写兑现之拍 |
| **④多一线** | 大审之治：今天这一拍比昨天多了哪一线 | **与上一篇同线之卡逐字同即红**（那就是「自动地写下去」） |

⛔**机器之限**：**它认得「答了没有、引得真不真、落在第几拍」，⛔认不着「那一钩接得好不好看」**——**好不好看，归读者席（大审／看官）去判；判出来的，再经 L4 流回落笔之前。这就是书的进化之环。**

**每一层都走同一条路：查 → 自修 → 验自修 → 修不了才报 → 报了就挂账（⛔不许再沉默）。**

### L0 · 保命（书在不在云端）
| 查 | 自修 | 验 |
|---|---|---|
| **云端存底枝 `备份/存底`** 有几章、几分钟前存过 | 逾 **30 分钟**未更新，或云端章数 < 本地 → **自存一回**（`存底.py --存`，**不走闸、秒级、含正在写而未提交的那一章**） | 存完**再从云端取回来数一遍**，⛔不拿本地之数充数 |

★**其底**：**存底枝**（滚动·保命）＋**章标 `章-N`**（一章封版一块碑·⛔不带 --force，覆不掉）＋**存底包**（`存底包.py`·当面送作者）——**三重，⛔任一重都不经过推闸。**

### L1 · 发布（主枝落後多少）

| 主枝 `claude/the-novel-review-4dtuit` 落後几笔 | 逾 **3 笔** → **自推一回**（⛔**走闸不绕**） | **同一因连 2 回修不好 → 判卡死，⛔当面报作者，不许默默往下写** |

⛔**本层之语写死**：**主枝落後是「成果未发布」，⛔不是「丢了」——书在 L0 里。**

## 四·诸律（`设定/00_作者常令_不停之律.md`）

| 律 | 一句 |
|---|---|
| **⑯** | **闸管「验收」，推管「不丢」，两件事不是一件事**；封一章即办三样（交提｜推｜送存底包）；⛔推被拦，存底包照送 |
| **⑰** | **一条清不掉的红，头一个该疑的是那把尺**；校尺後若改闸，**其价同日付** |
| **⑱** | **器上写下的话，须有一道器在读它**；写「待验」须同日登账并立负测 |
| **⑲**（本总纲立） | **哨不许只会报：能修者自修，修後自验，修不了才报，报了就挂账；同一因连两回即卡死，当面报作者** |

## 五·⛔此机制自己的病，怎么治（它也会坏）

1. **它每一道器都有负测**，**头一格须是旧式回灌**（证它不是陪跑）；
2. **它每一个限都写死在码里**，⛔**不随今日之数往上挪**；
3. **它自己逮到自己的病，一样登病族账**（今日「哨自己量错了东西」一族即如此登上）；
4. ⛔**它报的每一句，须分得出「丢了」与「未发布」、「伤」与「尺坏了」**——**一句假警比一句不报更坏。**

## 六·给往後每一坐的一句
> ⛔**「闸红着」看上去像一件该治的事；「尺坏了」「哨量错了」「写了没人读」看上去不像一件事——它们看上去就是「规矩严」。**
> **本机制之立，就是为让後面这三样，也看上去像一件事。**
