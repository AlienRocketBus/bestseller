## 乙·余章之六法（本纲之公法·凡起草席皆受其约）

**法一·按物排，不按限章排。**
大问表自己把方子写死了：「**其治不在补写一段回忆，在让它在手上再出现一回：
一个动作、一个数、一次比——不解释、不回忆、不说破。**」
按限章排，排出来的是「哪一章讲清楚地窖」；按物排，排出来的是「哪一章哪只手碰哪件物」。

**法二·排债之前，先查那件物在谁手上。物不在场的债，不许排在那一线。**
· 「寨里那些人」大问表记作「其线苏衍」，可挂着它的物（`286:481` 粮房第四本裁的册子）在**沈鸢**手上，
　且 `292:161`「寨里那一摞米账不在手边」；苏衍自第 110 章後无一件寨里的物被点过名。
· 「地窖」之物只剩那把系红绳的铜钥匙（`1:93`），在苏衍怀里。
**不查物就排债，排出来的章是「手上没东西可摸」。**

**法三·一件物，在同一段路上不担两样活。**
本书在场之物只六件（玉／本子／诺基亚＋分开的电池／悬赏原件／铜钥匙／她那本册子，另加钱满那张拓片）。
一件物连着两章担两趟活，读者当场看得出是作者在派活，不是这个人在过日子。

**法四·反动作。** 一件三百章前被收起来的东西，**今天原样倒着做一遍**，就是最省的还法。
祖案：`60:43`「我关掉诺基亚，**卸下电池**，把机身和电池分开裹进油布」——
那么还血图的动作是**合电池、按一下**。

**法五·两线之合，是一次比，不是一场相认。**
比的对象第 272 章早已备齐，且是**看一眼就分得出真假、比完谁也不用说话**的：

```
awk '/【本章亮点】/,0' 正文/镇冢秘术_第二百七十二章_两本都没合.md
→ 那本子是他自己订的……戳头一个眼的时候手不稳，位置偏了两分；
　后头两个眼他就照着头一个的偏往下排……三个眼是这么来的，不是量出来的，是将就出来的
→ 线是从铺上那条旧布抽的，抽出来的不齐，一段粗一段细
→ 书脊上也有眼。他数了一下，也是三个……她的线是一样粗的。
　一样粗就是有针。有针的人在屋里订，他在山里订
```

**三个眼对三个眼，两段线比粗细。** 一粗一细，对，一样粗。
★**且先看见的是钱满，不是他们两个**——两个当事人一动就要说话；
第三个人把纸推齐，一句不说，动作全在他手上，意思全在他们眼里。

**法六·钥匙十五章不许出现。**
`305` 亮点⑧逐字：「它挨着那个数，可它量不着那个数……十个挪下来，**一回也没有量着**」；
⑭「**而明天它在哪儿，他不知道**」。
**全书余下只许再量四回，一回比一回浅，末一回才量着。**
★**中间任何一席顺手让他摸一下钥匙，末了那一量就轻了。** 此条写进锁定行，约束所有席位。

## 丙·末一段（先写死，其余倒推）

全书的形，是第 107 章替自己埋下的一句：

```
awk 'NR==464' 正文/镇冢秘术_第一百零七章_无字.md
→ 他算过步、算过息、算过油和布、算过背几个，没有算过自己；
　本子上写下的每一个数，都是别人身上的。
```

**他一路替人记账，最後一笔记的是他自己。**
而记法，用的是本书自己的成法**原样反用**——同段末尾：
「写完在前头加了三个字：**他说的**。」
凡记别人身上的数，前头加「他说的」；**最後一页记自己身上的数，底下添「手摸的」。**

### 末一段（拟·落笔时其数须回息账核过）

```
天亮了。他把本子摊在膝上，翻到最后一页。
＊
前头每一行底下都有三个字。
＊
他把手指搭在自己腕子上，数了一回。
＊
九。
＊
写：第一日，九。
＊
底下添三个字：手摸的。
＊
笔搁下。这一页上头，还空着。
```

**零解释、零回忆、零说破，而读者当场懂它反的是什么。**
「这一页上头，还空着」接的是 107 章同段那一处空白——**没说清的人，是还能等的人**。
