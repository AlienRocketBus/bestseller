## 甲·四堵墙（不许撞·逐条带命令，撞了即是废案）

### 墙一·沈鸢那本册子里，**没有第二只手写过一个字**

```
awk 'NR==717' 正文/镇冢秘术_第二百六十五章_一片壳.md
→ 八十四页里头一页记一天，记的都是那只手（写了几道，怎么写的，走到哪儿慢）
awk 'NR==720' 同档
→ 八十四页她写了八十四回，回回写的是它，回回是她的手写的
awk 'NR==723' 同档
→ 三个多月，外头一样东西也没进过这本册子
```

**八十四页是她的手写的，写的内容是床上那只手。** 凡拟势写「他翻到八十四页，字比她的小一半」
（另一副笔迹）者，两章连根废——本轮第 1 份势即死於此。

### 墙二·她那本册子**自第 292 章（第九十七日）起已经写满**

```
awk '/【本章亮点】/,0' 正文/镇冢秘术_第二百九十二章_没有第十八行.md
→ 本章之一事：她今天要写第十八行，而这本册子没有第十八行了。
→ 其数：第八十五页｜第十七行对没有第十八行｜八十五减八十二剩三页对今天没得减

→ 八十五页十七行对没有第十八行｜四个角剩一个没折｜页边之字由二增至三
```

**她的记已经从「行」迁到页边、角、折痕上。** 凡写「第十八行」「第二十一行」者废——本轮第 4 份势死於此。
★**而这不是限制，是本书替自己备好的一样东西**：一个人记满了还要记，只好往边上写——
**余下诸章凡要她再记一样，先问「记在哪一格空上」。**

## 乙·余章之六法（本纲之公法·凡起草席皆受其约）

**法一·按物排，不按限章排。**
大问表自己把方子写死了：「**其治不在补写一段回忆，在让它在手上再出现一回：
一个动作、一个数、一次比——不解释、不回忆、不说破。**」
按限章排，排出来的是「哪一章讲清楚地窖」；按物排，排出来的是「哪一章哪只手碰哪件物」。

**法二·排债之前，先查那件物在谁手上。物不在场的债，不许排在那一线。**
· 「寨里那些人」大问表记作「其线苏衍」，可挂着它的物（`286:481` 粮房第四本裁的册子）在**沈鸢**手上，
　且 `292:161`「寨里那一摞米账不在手边」；苏衍自第 110 章後无一件寨里的物被点过名。
· 「地窖」之物只剩那把系红绳的铜钥匙（`1:93`），在苏衍怀里。
**不查物就排债，排出来的章是「手上没东西可摸」。**

**法三·一件物，在同一段路上不担两样活。**
本书在场之物只六件（玉／本子／诺基亚＋分开的电池／悬赏原件／铜钥匙／她那本册子，另加钱满那张拓片）。
一件物连着两章担两趟活，读者当场看得出是作者在派活，不是这个人在过日子。

**法四·反动作。** 一件三百章前被收起来的东西，**今天原样倒着做一遍**，就是最省的还法。
祖案：`60:43`「我关掉诺基亚，**卸下电池**，把机身和电池分开裹进油布」——
那么还血图的动作是**合电池、按一下**。

**法五·两线之合，是一次比，不是一场相认。**
比的对象第 272 章早已备齐，且是**看一眼就分得出真假、比完谁也不用说话**的：

```
awk '/【本章亮点】/,0' 正文/镇冢秘术_第二百七十二章_两本都没合.md
→ 那本子是他自己订的……戳头一个眼的时候手不稳，位置偏了两分；
　后头两个眼他就照着头一个的偏往下排……三个眼是这么来的，不是量出来的，是将就出来的
→ 线是从铺上那条旧布抽的，抽出来的不齐，一段粗一段细
→ 书脊上也有眼。他数了一下，也是三个……她的线是一样粗的。
　一样粗就是有针。有针的人在屋里订，他在山里订
```

**三个眼对三个眼，两段线比粗细。** 一粗一细，对，一样粗。
★**且先看见的是钱满，不是他们两个**——两个当事人一动就要说话；
第三个人把纸推齐，一句不说，动作全在他手上，意思全在他们眼里。

**法六·钥匙十五章不许出现。**
`305` 亮点⑧逐字：「它挨着那个数，可它量不着那个数……十个挪下来，**一回也没有量着**」；
⑭「**而明天它在哪儿，他不知道**」。
**全书余下只许再量四回，一回比一回浅，末一回才量着。**
★**中间任何一席顺手让他摸一下钥匙，末了那一量就轻了。** 此条写进锁定行，约束所有席位。

## 丙·末一段（先写死，其余倒推）

全书的形，是第 107 章替自己埋下的一句：

```
awk 'NR==464' 正文/镇冢秘术_第一百零七章_无字.md
→ 他算过步、算过息、算过油和布、算过背几个，没有算过自己；
　本子上写下的每一个数，都是别人身上的。
```

**他一路替人记账，最後一笔记的是他自己。**
而记法，用的是本书自己的成法**原样反用**——同段末尾：
「写完在前头加了三个字：**他说的**。」
凡记别人身上的数，前头加「他说的」；**最後一页记自己身上的数，底下添「手摸的」。**

### 末一段（拟·落笔时其数须回息账核过）

```
天亮了。他把本子摊在膝上，翻到最后一页。
＊
前头每一行底下都有三个字。
＊
他把手指搭在自己腕子上，数了一回。
＊
九。
＊
写：第一日，九。
＊
底下添三个字：手摸的。
＊
笔搁下。这一页上头，还空着。
```

**零解释、零回忆、零说破，而读者当场懂它反的是什么。**
「这一页上头，还空着」接的是 107 章同段那一处空白——**没说清的人，是还能等的人**。

## 戊·其价（诚实写·一份不写代价的势，是一份没想清楚的势）

1. **FS03 之改期已达 16 回**（`python3 工具/FS闸.py` 逐字），FS闸 已把 FS01／FS03／FS05
　列为「**改期逾二回者，须由人当场裁它还算不算一根活钩子**」。
　★**本坐今裁：三根俱仍算活钩，且 307／308／309 是它们各自的最後一窗，不再改期。**
　其由：FS03 之档自书「上第四弦那一下是本站唯一的窗，**再错过就是我赖账**」；
　而 FS01 与 FS03 在正文里共用同一件物（玉之温，`40:107`），故必须同段还，不可分。
2. **309 一按之险**：开一次机，同时动悬赏（追踪）与南边（FS05）两条线的风险面。
　**这是一个动作，但它不是一个小动作**——起草席须自觉，且不许拿它换消息，
　只许拿它换**一个数**（屏幕上还剩不剩那两层影像）。
3. **「寨里那些人」改线**：大问表记其线为苏衍，本纲改挂**暗线**（法二）。
　`工具/大问表.py` 之线对位一路须随改，否则它会一直报「未验」。
4. **FS18 只到「对上了」为止**，不给那三个失踪者的下落。
