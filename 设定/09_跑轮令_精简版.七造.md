## 〇之三·不可逆之事：先存，再办（**2026-08-30 作者授权，其条件即在此**）

★**可办者**：删章／删片段／改写已封版之章／force-push／清台账／覆盖回执——**凡先前须停下来问的，今皆可自办。**

**★★而「删了还取得回来」分三层，各有其处，不许混**：

| 层 | 何事 | 存在哪儿 | 怎么取回 |
|---|---|---|---|
| **一** | **逐轮之刀**（减法轮删句、删拍、并段、改字） | **本来就存得住**：每轮 `--存版` 存一份全文（`版本/第N章/vNN.md`） | 一条 diff 即得 |
| **二** | **整章／已封版之章／台账／回执／设定档** | **可逆册**：`--存` 之后再办 | `python3 工具/可逆.py --复原 R00xx` |
| **三** | **枝（force-push）** | **备份枝**：`--存枝` 造之，并**先推上 GitHub** | `git push --force-with-lease origin backup/RNNNN_日期:枝名` |

★★★**故第一层不必进可逆册**（进了反成噪音，册一噪就没人看）；**★★★★第二、三层一件也不许漏。**

★★**而第二、三层之条件只一样，一步不许省**：

1. **落刀之前先存。** 文件之事跑 `python3 工具/可逆.py --存 "其由" 路径…`；枝之事跑 `--存枝 "其由"`，造出备份枝并**先把备份枝推上 GitHub**。
2. **存不下来即不许落刀。** 器报「⛔ 这些路径不在」或「⛔ 未指路径」者，一律作未存；★而未存之刀，一刀也不许落。
3. **存毕须与落刀同一笔提交推上去。** ★★**推不上去，就当这一刀没落**——先 `--复原`，再想别的法。

★★★**而其册与其库**：`设定/可逆册.md` 逐笔记「号／时／类／其由／所存／复原之法」；`版本/_可逆库/` 存原物本身（**非 git 历史**，故 force-push 改写历史之后它照旧在）。
★★★★**而「完好无损」由器保，不由我记**：`python3 工具/可逆.py --验` 逐件核 sha256，**已接进全测——库一旦损，推送即拦**；★且库已损时 `--复原` 拒办且**不动现文**。

★**复原**：`python3 工具/可逆.py --册` 看有哪几笔 → `--复原 R0001`（逐件验 sha256）；★★枝之复原由 git 办。

★★★**而报里须写一行**：**「本坐办了不可逆之事 N 件，其号 R00xx，复原之法在册」**——★★★★没这一行，就是没办这道手续。

## 一·五铁则（前三则器每回自印）

① 一次只干一件事，干完发一个只做核查的调用，把它的输出原样贴出来。
② **此器没印的数，不许说。**「我以为」「应该已经」一律作未做。
③ 修不动的，报出来**并当场走可逆之路**；不许自造诊断，不许说「已定」。
④ 凡凭据，须由器自己落；人只跑命令，不写凭据。
⑤ **绿只及於器自印之项名。**未印之项，本轮报里一律记「未查」，不许记「已过」「全绿」。

★③之由：三度宣布「诊断已定」，三度是空的。★★④之由：那三度之后我又编过台账输出充「复核之凭」。「我方才验过」不是凭据，器落下来的那一行才是。
★★★**⑤之由（六造所加·最贵之一处）**：**一道闸的绿，只能证它自己认的那几样没事**；★而我把它读成了「这一项没事」，**而那一项根本不在它的判据里——它不是查过了判无罪，它是压根没查**。★★**其实证**：`跑轮.py` 存版处只印一行「✓无回退」，**而其下棘轮三类共八目**；第289章由此一路绿到第12轮：**听 15→12、视 56→52，八轮无一报**。★★★**故凡光绿而无项名之行，须当日改印项名**——**列「所守」，不列「不守」**（不守是开集，列不全）；★★★★**而一项要进「所守」这一行，须其负测里有一条「拿真犯过此项之原物回灌须报红」。**

## 三·怎么写（五条·闸拦不出好坏）

① **判须有身**：一层之判，须有一处手上之事可托。
　✗「每一行的主都是那只手。」
　✓「指头搁在第一行往下走。十三行走下来，每一行她都说得出自己那天站在哪儿。它一直在床上。」
② **数须能比**：出一个数，旁边得有第二个数跟它比；没得比的是垫字。
　✓「昨天我抬前头，三下才起稳。今天抬后头，两下。」
③ **器物须有来去**：入、用、出，缺一即伤。**其主人是第6轮·资源庭**（办头一遍逐件总账），第10轮·收官轮作复核。
　★**而令四之带（291第7轮改齐）**：**常章 2,500—3,500｜转章 3,501—5,999｜爆章 6,000 起**。
　★★**其上位之序**：**品由事定，带为其验**——问五之答由令一那一问（除主角之外今天谁的处境变了）定，**带只作复核，不作判据**；**凡品与带不合者，不许改品去就带**，须在开镜卡上写一行「品带相犯：<其由>」留档。
　★★★**其改之据**：**旧表之下，全书291章有99章（34%）在所有带之外，而全书净重中位3,691正落在3,500与4,000那道缝的正中**；★★★★**缝内三十九章逐章读过，三十六章判「转章之事」（92.3%），逐百字分格无梯度**——**4,000那个下沿是虚的：把一章判转章所要的那件事，在3,500那一行就已经发生了。**
④ **不说破**：其由不写「因为」，写那一物。
　✓「绳上那个弯，一夜就平了。」
⑤ **承前须实**：凡引前章之句、之数者，**先 grep 其原场，再落笔**。
　★而设定档不算原场——档里的数会陈；档与场不合者，**以场为准，且当场正其档**。
　★★**而回原场之窗不得只开近四章**（实证：286第4轮之窗只开到近四章，遂掘出一层凭空之料；第11轮开261之窗，一开即见七处犯基之伤）。
　★★★**其法**：凡本章要用的那件东西，**grep 它头一回出现的那一章**，不是最近一章。
　★★★★**而证「无」与证「有」是同一个动作**：**凡证他章无此句者，grep 之键须取自他章那一句，不许取自本章那一句**——**取本章之句必得零处，得零即断，那是自己给自己造一个不存在的对头。**

① 这一刀的旧文，原场里有吗？　② 新文过得了硬闸吗？　③ 改了之后全章之数往哪走？

★三问一条命令答完：`python3 工具/预检.py --代 N --旧 … --新 …`
★★**而每次存版必跑之趋阈闸（291第7轮立）**：**凡本轮令某数跨过一条有名之限而跨得勉强（余量≤此前之差的四分之一），存版当场拦停**——★**须在说明里写「非凑数：<其由>」方许落盘，而那一行连同其数一并落进台账**；★★**其由**：**补几个字把一个数顶过线，这一步过得了硬闸、抬得起净重、看起来跟正常落笔一模一样**——★★★**回灌全书：版际之比3147次、红68次＝2.16%，而275、276、283、284 四章落在3500线上余量0至2字，各自封了版而无一道闸出过声**；★★★★**令四那一句「墨随事重，不是墨随格子」，考的从来不是墨够不够，是肯不肯为了格子去添墨。**

★★**而预检之【定论】只算硬项**：软项（含棘轮之四字串三现）印在它上头，**只印不判**——**故落刀之後、存版之前，另跑 `python3 工具/棘轮预检.py N`，且须读它中间那两行，不许只读末一行。**

★★★**总纲一句：交接只许指路，不许判决。**
★★★★交接文档、上一坐轮记、他人之诊、器之一行——**皆是报，不是场**；报与场不合者，一律以场为准，且当场正其报。

## 六·闸之伤（**买得最贵**）

★**闸报红时，头一问不是「怎么修文」，是「红在闸还是红在文」。**

**★★而断之三步，一步不许省**：

1. **取二组数并列。** 只凭一次输出即断其因者，其断不作数。
2. **分清孤例在档还是在闸：数其群。**（实证：全账258笔，`clear` 只此一笔 → 孤例在档，改档不改闸。）
3. **改闸必同日立负测，且须以旧式回灌验。**★**一个只会说「零」的闸没有价值**；★★而一份在旧式下也全过的测，**它就是陪跑**。

★★★**而一道天天要绕的闸，错的是闸不是人**：改它，别绕它。
★★★★**但不许为了让自己那一笔过去而挖空闸**——判准只一条：**改后它还逮不逮得住它本来要逮的东西？**（此问由负测答，不由我答。）

**★★★★★而以上三步只在闸出声时管用。闸不出声者，另有一步，其时不在报红之日，在立闸／改闸之日**：

4. **写下判据的同时，写一行「它认哪几样，本书同类共几样」。**
　·**字表类**：先 grep 全书取其同类之全集（如四感、如本书自己的主动词）；**字段类**：逐格列出。**答不出这一行者，不许接进全测。**
　·★**而这一行须同日写成当日负测的头一项断言**——**不许只断言「它现在认的那几样是对的」**：一份负测把「只认嗅与沈鸢」断作正解，**遂替一道只守一感的闸签了两个月的字**。
　·★★**其红在哪一行说得出**：写下 `RATCHET_MAX = ('嗅','沈鸢')` 那一天若答过这一问，**四感一列即见只守一样**——**289 就不必封版之後再回修 v27**。
　·★★★**而这一步为何非人不可**：**机器不知道「嗅听触视」凑成一个叫「四感」的全集**，也不知道「抬托背扛挂贴甩盘蹲垫铺写点翻」是本书自己的主动词而「数」不是。**这一判是人下的。**

## 七·一疑（每轮必报）

每轮报末须答：**本轮我最不确定的是什么？**须具体到拍号或某一句，并写明「留第几轮判、拿什么判」。
★**而挂之前先问一句：那一轮的器验不验这一样？**——**验不着的，就是挂在空处；挂过去的判，两轮之后还是我自己判。**
★★一个肯说「这一处我拿不准」的轮，才是真跑过的轮。

---

## 八·不漏轮

★十三轮，每轮必到；不许合并、不许跳、不许只报末轮。
★★而「跑过」之凭据是**两样**：①`_轮记.md` 里有它那一条；②**那一条里有「本可问而未问」一行**——**本轮实无可问者，写「本可问而未问：无」**。**二者缺一，即「跑了等於没跑」**（器自报「★空轮」「★断号」「★缺报格」）。
★★★**其数由器合**：**按轮号合数，一轮拆数节者并作一轮，非按节**；缺者印红入「该修者」，不拦下一轮。
★★★★**而〇之三那一行「本坐办了不可逆之事 N 件」按坐核一回，不按轮。**
★**而第13轮判「没有」之轮，须当场补跑并各存一版**；其补跑之记，写进那一轮自己的 section，不许只挂在第13轮下。

## 九·报（每轮六事，其数皆须出自核查之调用）

**轮次｜伤（捕几治几，须具体到那一串）｜台账（版数·末版·净重·硬项·相符否）｜产出（掘出几层／翻案几处／落身几处／裁几处）｜一疑（拍号）｜远端（＝本地）**

★第四格专为第4、第12、第13轮而设：**报不出一个带数的产出，那一轮就是没跑**——哪怕全测全绿。
★★而**「本可问而未问」**之择，一并写进报里。

## 十·封版之序（一坐印「该跑封版之序」时）

`python3 工具/收.py --跑` 领路，而人须办者六样：
① **回执**（十六节；须写足「N章冷眼轮」六字）★**而本章未执者，须写「COLD-N·本章未执」之否决记**——**否决在先，签核在後；那六个字本身不作已执之凭。**
② **销旧须当场立新**：`ls 设定/冷轮_COLD{N}*.md` 复核其在，方许记入回执
③ **翻页八件套**：圣经双锚（**含把本章写进事件链**）／README／施工表§四＋本章行／SCHEMA插N+1／json状态卡＋brief／提示词开拍号／到期账／下一章开镜卡
④ **十一轮双眼**：`python3 工具/小说检察官.py --十一轮 N`——**器名即双眼**；★`跑轮.py` 吃同一个开关却**只睁左眼**，其产物是 `_总核.json`；★★**封版闸只认 `版本/第N章/_十一轮.json`**：**只见 `_总核.json` 即是单眼，那一章不许记「双眼皆过」，重跑此器。**
⑤ **看官五席**重跑（正文一改即过期）
⑥ **阅读器同步**：`python3 工具/同步全本阅读器.py`

★而圣经三样须**逐样写、逐样发一个只做核查的调用**，不许一次写三样。
★★**而一条命令不许既跑慢检查又落盘**：全测单跑一条，git 单跑一条；**凡一条命令被砍，下一步不许直接重跑，先 `git log -1` 问器它落没落。**

## 十二·实话（免得日后自欺）

**这套东西保的是地板，不是天花板。**★**而本令之立位（§二）说的是天花板**：**地板由闸保，天花板只有写的人够得着。**

它保这本书不会因为写崩、写乱、写飘、写重复、写丢、照着一份错报告动刀、或**照着一个错的闸去改对的文**而不成立——这地板很高，中国长篇塌在这上头的极多。

而天花板只在第二、三、四节：**那把尺、那五条写法、那三问。**
闸能保证你必须答；**答得好不好，是写的人的事。**
