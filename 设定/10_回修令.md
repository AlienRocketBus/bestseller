# 回修令（2026-08-19 立·作者亲令）

> **★本令之魂一句话**：**封版不是「这一章从此不许碰」，是「这一章暂时不用再看」。**
> **★★而全书任何一处都可以改——其前提只有一样：改了之后，整本书更好。**
> **★★★而其尺不是「能不能过闸」，是「拿给最好的小说家看，他会不会这么改」。**

---

## 〇·此令非今日新立（须先认这一笔账）

**★第六十六批（2026-07-19）早已立**：

> 封版≠不可改：**凡能令剧情更好之改动，正文完全可改，不必犹豫。**
> 「零回修」自此由荣誉降为默认（非必要不回修），让位於「更好即可改」。

**★★而它躺了一个月，一次没跑过。**
**★★★其由：它只是一段字——无刀、无闸、无入口。**
**★★★★而依批100所立之融入标准**：
> 机制融入的判据不是「能打印」，而是「**能拦住交付**」。**只喷字不设闸者，视同未融入。**

**★★★★★故今日之立法，不在重申，在补其刀与闸。**

## 一·为何非有此令不可（本书的上限卡在这儿）

**★十三轮之每一闸皆为章级**：四数、⑤、必答表、两两比、器物点名、死段查——
**★★它们只看这一章。**

**★★★而作者自己在191章立书级体检时已写过这一句**：

> 凡「一样东西在连续数十章里慢慢漂掉」者，**无一闸看得见**。
> 其证：沈鸢末次出现於第115章、苏衍於第101章——而这七十六章里每一轮之补裁皆书「判零处而合」；
> **★该判每一次都是对的，而合起来是错的。**

**★★★★故**：**章级的轮只能改句子，改不了弧。**
**★而弧要改，只能回头动已经封了的章。**
**★★没有回修令，这本书的上限就卡在「每一章都对，合起来不够好」。**

## 二·回修之二类（其别在「谁开的头」）

### 甲·随发现而起（★常态·随时可开，不必请示）

**★其形**：写第N章时发现第M章（M<N）有一处不对、或有一处本可以更好。
**★★而此为真小说家之常态**——**★★★写到二百章才看得清五十章那一处该怎么写，这不是失误，是长篇的正常光景。**

### 乙·书级专案（★由作者点头开启）

**★其形**：专开一轮通读全书，找「一样东西慢慢漂掉」那一类只有书级才看得见的问题。
**★★其刀为 `工具/书级体检.py` 六检＋通读。**

## 三·★★★★★回修之三问（答不出即不立案）

**①这一处不改，读者会在哪一段掉下去？**
　**★须指名段落。指不出具体的段，就不是质量问题，是手痒。**

**②改了之后，它服务的是这一章，还是全书？**
　**★只服务这一章的，等下一轮；★★服务全书的，现在就改。**

**③它牵动几章？**
　**★须跑 `python3 工具/回修.py --波及 N`，把实数贴进案里。**
　**★★牵连越多，凭据须越硬。**

**★★★而末了还有一问，此问不答，案不成立**：
**★★★★「全书因这一改，强在哪一处？」**
**★而其由：回修之令，为的是整本书；答不出这一句，改的就只是一章。**

## 四·回修之序（一步不可略）

```
①开案      python3 工具/回修.py --开案 N "为何要改"
②波及查    python3 工具/回修.py --波及 N         ← 动刀之前必跑
③动刀      （逐处改，改前改后并录入案）
④连带同步  亮点段／圣经入册条／下一章之锚／canon状态卡／施工表／到期账／阅读器
⑤复验      --改检 N → --补存 N → --十一轮 N → 全测
⑥验案      python3 工具/回修.py --验案 N        ← 封版闸据此放行
⑦提交推送
```

**★而第②步之所以在动刀之前**：**★★回修最险处不是「改」，是「改了上游，下游哪几章跟着塌，没人看得见」。**

## 五·回修之界（★而立界不是为了拦，是为了这本书写得完）

1. **★回修由「发现」触发，不由「想改」触发。**
   **★★而其由：一本书若任何一章随时都在重改，它永远写不完**；
   **★★★而真小说家之回修，是写下游时被下游照出来的，不是回头去翻旧账找茬。**
   **★★★★乙类（书级专案）例外——那是专门开的，由作者点头。**

2. **★★★★★回修不得挤掉往前写的工。**
   **★一笔回修若牵连逾十章，宜先立案记账，择时集中办**；
   **★★而不宜停下主线逐章追改。**

3. **★★canon 层之改（设定、人物身份、结局）不属回修，属改 canon**——
   **★★★须依第一铁律：先改唯一总圣经、换 CANON-ID、再同步下游。**
   **★★★★而回修只管「同一套 canon 之下，写得好不好」。**
