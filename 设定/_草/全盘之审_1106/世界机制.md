# 全盘设定之审·世界机制（1106·只读席之原报）

**一、终局分流有两套互相排斥的时序：「数息内八路同时松」对「随潮九股逐一放、每停一回」**
1. 题：climax 那几口气，圣经自己给了两种松法，承流之「储」也有两说，「数息」由何而来没有着落。
2. 等：甲
3. 证：
- 「同时松」一方：圣经:1367「苏衍要做的不是"接八条线"，而是"同时放开八路已经上好弦的闸"」；:1206「终局"松手"那一下，八路线同时合闸」；:1153／:1297「松手（八路通好的（暗）线一齐开）」；:1350「他只能撑数息」。
- 「逐一放」一方：圣经:821（D5 已裁）「认位之後总流随潮来……九股逐一放归」；:2815（十六）「把九股逐一经玄微放归天下」；剧情庭_D4:91「终局等潮，是对先人那一夜的改正」。
- 同一行自相打：:2549 既有「八路弦在此一次松开」，又有「苏衍等潮……分流时九股一股一股放，每停一回烧的是他自己」。
- 储量两说：:1192「它不是电池，不存电」；对 :1323「真正的储量空间在这一姓的活血」、:1349 同句、:1705「能吸、存、放」。
4. 读者在哪撞上：终卷分流那一页。写「等潮、一股一股」，就撞「只撑数息」——等潮要多久？写「一齐松」，就撞 D4／D5 已裁的「等潮」。两头都有 ERROR 级条款可援。
5. 改法：改在 9之补「★这里有一个必须回答的洞」一节（源头），其余各处照抄。
- ①立潮之物理：「认位接上，两千年悬在九路上的电顺私缆涌来，涌到顶自己往回翻（徐鼎那一手；还电台本照徐吐而造，F101）。顶上那几息＝承流；一翻＝分流之时。」
- ②立数息之源：「活血不囤，只过——像一口憋得住的气，憋得住几口就是几口。」:1192 与 :1323、:1349、:1705 一并统一为「暂过不存」。
- ③立松法：「弦已上，不用接线、只用松；但不能一齐松——八路同时放＝八处同时回压＝八座楼兰（先人『一凿到底』之错）。随潮之退一息松一股；每停一息，余股还压在他身上烧。」
- ④:1367、:1206、:1153、:1297 的「同时／一齐」改「逐一」；:2549 删「八路弦在此一次松开」；F074 之 note 同步。F074 forbid 第三式会误伤「逐一……送回八个」这种写法，宜收窄为禁「现场接」。「八个复常记号在同一夜响」可留。
- 闭环：数息洞原答（弦已上、只松不接）照旧；「为何不一齐松」由楼兰答；「等潮」与「数息」同落在潮顶那几口气里。
- 正文不动（终卷未写；1—427 无「一齐松」之文）。
6. 自信：高

**二、「停不下来」律反给敌方一条直路**
1. 题：三、8 写「认位后杀苏衍＝总流灌向赵阙」——那霍钧一刀即胜；赵阙也可以收令不调电。
2. 等：甲
3. 证：
- 圣经:1317「此时杀死苏衍、毁台或强行断路，不会安全停机，只会让总流按邪阵默认方向灌向赵阙，或在阵眼爆开。」紧接 :1319「所以赵阙……不能拔插头。霍钧也必须让苏衍活到分流完成」——前句给了直路，后句的「所以」不成立。:1337 同句。
- :1224「电得先由躺在调度指挥机器上的赵阙统统调到骊山；没人调电，插口是空的」——终局他收令，复流就无电可放。
- 十二步残旧未随 D5 改：:2383「连续认位、定向，主回路闭锁」（D5:821 已废「定向在人质之前」）；:2387「以这一姓的活血中的总流反冲赵阙台，亲手杀赵阙」（D5 已废「硬打杀赵阙」）。
4. 读者在哪撞上：人质局（D5 定在认位与定向之间）。「苏衍一死总流就默认归赵阙，押沈鸢干什么？」「赵阙见他要放归，不调电不就完了？」
5. 改法：
- 三、8 第三条改一句：「此时杀死苏衍、毁台或强行断路——总流已锁在这一姓的活血上，人一断，线上没人；网线传令不传电（6之补四甲），赵阙台一度也接不进，九路只能在阵眼回压炸开（楼兰之九倍），台上台下连他一起成灰。」删「灌向赵阙」。
- 补一句：「认位＝把那一夜卡住的仪式接着走；启阵之令那夜已下，收不回（收得回，他两千年前就收了，不会被钉）；总流随潮自来（D5）。他能动的只剩苏衍那一念。」
- :1337 同改；:2383、:2387 照 D5 改。
- 闭环：杀他＝同归于尽，霍钧、赵阙非保他活不可；人质成了唯一的牌，三、7「自愿」才有用。
- 正文不动。
6. 自信：高

**三、两人长生法：禹册写「二人同得不老」，正文 414 已写死「只够一个」**
1. 题：长生法到底成一个还是成两个，设定与已封版正文相反。
2. 等：甲
3. 证：
- 「两个」一方：圣经:973「一人居中调天下之气、一人做承接之"线"——气经线入身，二人同得不老」，同条「你我父子可同得不死」；canon F100①；:1226「赵阙许他"共同永生"（电也流过他、他也存得住、他也不死）」。
- 「一个」一方：圣经:881「这东西只能供一个人不死。而那个人，可以是任何人」（:1847、:1912 黎东来之讽全靠这句）。
- 正文：414:95「“找着了。只够一个。”」；414:101「“那一个，可以是任何人。”」；:1849 注此三句「⛔谎」。
4. 读者在哪撞上：禹册末片到苏衍手里，或启之考验漏出时——「禹册说两人都不老，赵阙 414 那句是谎吗？」是谎，破「⛔谎」；不是谎，禹册错。
5. 改法：只改禹册那一片（源头）。
- :973、F100①「二人同得不老」改：「二人缺一不可；不死的只一个——居中者。做线的只在线上时同不老：线一撤，老回去；不撤，便永远是一根线。」
- 片上画法改一笔：「两小人一线相连，只一个是满的」。
- 余皆自通：「共同永生」是真话限了语义，即 :1849「省略代价、限制语义」之实；414 三句俱真；三、9「新的中心劫持者」与之合。
- 正文不动。
6. 自信：高

**四、「同一道弦，两个用法」缺机理：成阵用不着暗线**
1. 题：弦的实物是回家的暗线；「不松是成阵」等于说成阵根本不需要弦——那赵阙为何巴不得他上弦？
2. 等：甲
3. 证：
- 「两个用法」之说：圣经:1042「可控的闸既能终局把电送回各片区（复流），也能全拨给私接户（成阵）——闸不修好，两条路都走不通。所以赵阙护着他修」；:1206「同一张拉满的弓……也可以全射给赵阙（成阵）」；:2414「松手是复流，不松是成阵」。
- 弦的实物只通回家：暗线＝:1204「从闸底绕接回本地干线道的老路」；:2404「把这一站的出口修成"随时能往外放"的待命状态」。赵阙往骊山的是他自己的私缆，:1124「全是他的线」。
- 正文已押：414:109「“你每安一处，我这儿紧一扣。”」；420:77「往当中去，远处跟着紧了一扣」。
4. 读者在哪撞上：卷五给学名那一下（:1075「也才看见自己这一路的活命账，同时是赵阙的成阵账」）。读者会问：「通暗线＝给赵阙挖墓，他图什么？」
5. 改法（能删不改）：用 :1431 已有的「校准两层」拆开。
- 第一层（号脉：这副身子吃透九种气性）是赵阙要的——不吃透，承流一接即烧，他就没有线。
- 第二层（出口待命）是苏衍要的。
- 两层落在同一枚血指印里，分不开。:1042 改为：「他要那副身子，就得放他一条条修出口。」
- :1206「也可以全射给赵阙」、:2414「不松是成阵」删，改「弓是他拉的，往哪儿射，是定向那一念」。
- 414「紧一扣」＝线又硬一分（第一层），不须动。
- 闭环：赵阙明知八个出口都是对方的退路，赌全押在定向，正合 :1098「真正的对抗只发生在两处」。
- 次选（是添）：立「活回路＝承流时每座鼎的兜底」，楼兰即那座暗线死着而崩的鼎。
- 正文不动。
6. 自信：中（缺：「总站」主文本①十段未读；若那里另有成阵须弦之机理，此条降级）

**五、觉醒机制两套并存，一套已与第 1 章正文相反**
1. 题：「触碰玄微之气开眼、合玉只是拼钥匙」与「玉＝唯一导体、守灵夜鼎能经玉入血、合玉＝觉醒物理面」两套并立，都是 ERROR 级。
2. 等：甲
3. 证：
- 甲套：圣经:1603「❌ 不是觉醒。开眼的是触碰玄微的气，不是合玉」；:1500「合玉当场既不赐予望气……更不开任何回路」；F070「第1章顺序必须是：触碰→只开眼→合玉」。
- 乙套：圣经:989「守灵夜合玉＝磁吸＋扣合＝电极闭合（觉醒的物理面）」；:1117「先祖体内那缕鼎能经掌心入玉、把契约程序完整走了一遍……注入其血」；F094「皮贴皮抽不动一丝=直触先祖不激活的总答案」；F092 禁「无玉触祖即立契；半玉可立契」。
- 正文：1:213「我的指头，碰到了他的手。」1:217「眼前猛地一花。」都在 1:255「两块残玉，合成了一整块」之前——碰手时两半未合，照乙套不可能醒。
- 连带三处：
  - 材料：:989「实为掺血之极坚水晶：硬近金刚石」「打造之初便是两半」，对 :1580「一块整玉，被公输解成两半」、:1582「玉是韧的，砸出来是崩口」。
  - 独承：F090②「每代只认血纯净度最近玄微之一人」，对 :1480「钥是偶发的，不是每代都有」、:1454「不会在谁死后"接班"」——按纯度排位，必然接班。
4. 读者在哪撞上：已写的第 1 章，对将来任何一处用乙套解释的地方——最可能是骊山认位，执笔会翻 F092 讲「契约程序」。
5. 改法：留甲套（与正文合），把乙套的程序挪到骊山认位。
- ①:989 删「觉醒的物理面」「掺血水晶」「打造之初便是两半」三句；保留「双契之血入玉、近赵阙越烫」。
- ②:1117、:408④—⑥、F092④—⑥改为：「守灵夜一丝电也没过——是同源认亲解了雾。契约程序要到骊山才走：完整玉入槽，九路之能经座心玉引、净（照玉中玄微契血之牌号）、送入他血，走完即契立、不可逆。」
- ③F094「直触先祖不激活」改「直触先祖不过电」。
- ④F090② 删纯度排位，改「钥偶发，同时至多一人（三、13）」。
- 闭环：认位之不可逆从规定变成物理；F092⑦「定向＝选哪份契血配型」正接终局。
- 正文不动。
6. 自信：高

**六、九桩终局账不闭：离乡之鼎回不了家；第九鼎身毁没毁两说**
1. 题：「八鼎变回禹之桩、各回各家」与「移鼎、铜根、离乡」之律相撞；第九鼎身的去留，一处说毁、一处说不砸。
2. 等：甲（横贯 E2、E5、E7、C）
3. 证：
- 「变回禹之桩」：十六 :2815「八鼎不熄、变回禹之桩，完整之玉留骊山作第九根桩」。
- 「移鼎」：:938「把数座鼎连根拔起押离本州（青沉沙海、冀徙贺兰、豫移骊山）」；:974「「连根拔起」（真有铜根）「离乡病上加病」」「一州之气只认一州之金」。
- 楼兰之脉两说：F066「楼兰……仍是雍州那条脉走出玉门关的远端」，对 图鉴:99「青鼎，本是镇守东海的那一座……押到了西域大漠」。
- 图鉴自打：图鉴:33「兖鼎埋进沙海……E1雍鼎在雍州＝唯一没离家的」，对 图鉴:23—27（荆、梁、徐、扬皆「在乡」，兖＝E6）。
- 第九鼎身：十六 :2815「毁第九鼎身」（:1839 同）、F041「鼎身被毁后加装古玉凹槽」；对 :1115「不砸一物，砸亦无谓」、F090「禁写……鼎身被砸碎/凹槽为后凿」。且 :414（第二十二批）已明令「砸鼎身说」作废，F096「历批作废件永禁复活」。

5. 改法：
- ①十六「变回禹之桩」改「各在其座为桩」；三、12 补一句：「离乡三鼎放归的是如今所钉之脉；青、冀二州两千年无桩，终局不补——与天平之缺同为自由之价（F106）。」
- ②F066 改「是青鼎被押去后改钉的那一道脉（雍脉西梢）」；图鉴:33「兖」改「冀徙贺兰」，「唯一没离家的」改「在乡诸鼎里最稳的一座」。
- ③照 :414 与 F096：十六 :2815、:1839 删「毁第九鼎身」；F041 括注改「座心圆玉被抠后之原位即凹槽」。D5「玉桩镇豫」读作「豫鼎得玉复为第九根桩」。
- 正文不动（正文鼎名零出，380、382、418 只泛称）。
6. 自信：高（矛盾）；改法取向中（若反取「鼎身毁」，须先答 :414「毁己路」）

**七、§三.5「为何两千年前不立刻复流」：前提已被总封版作废，窗口无人能读**
1. 题：答「为何等两千年」用的是已废的「中心池」，所等的「窗口」无人去读，且与家法相反。
2. 等：乙
3. 证：
- 前提已废：圣经:1002「中心池处于最满、最乱的高压期」，对 :1192「骊山不存电，骊山汇电」、F096 禁「山中囤能待放」。
- 窗口无人读：:1004「二〇〇六年，窗口终于出现」；但 :1115「两脉全部家法从此就一件事：别让这血醒」，:1073「老头只知规矩，不知原理」，F023 爷爷不知全貌；2006 之醒是误入（:1531「不是让他独自开地窖」）。
- 另一处冲突：:1226「反派boss躺中间充电位当充电宝」，对 :1182「插得上的那只手，都只长在这一姓的血里」。
4. 读者在哪撞上：E6、E7 知道玄微留了全套还电零件以后——「他当年为何不自己复流？他等的窗口谁去看？」
5. 改法：
- 删 :1002—1004；改 :1226 为：「还电要两个人：中间那位（立过契、身负那副功能）＋还电台上一具过过电的身子。两样都只有玄微一个——赵阙坐不进中间，玄微不能一身两用。所以他把中间那一位封进血里，自己留下当还电台。等的不是天时，是人；何时醒，跟谁是钥一样，他控制不了（三、13）。」
- 三钟（:2420、F075）删「窗口」一钟。
- 正文不动。
6. 自信：高（矛盾）；中（三钟减为二钟之取舍待作者）

**八、玄微生死两说，撞「续命／保尸／救活」三分律**
1. 题：先祖是活是死，圣经两说。
2. 等：乙
3. 证：
- 「活」一方：圣经:1550（:1643 同）「靠自己留下的一缕余温保持最低生机」；:1230「活死人」；:2391「玄微真正死去」。
- 「死」一方：:1558「他死了两千年，只剩一缕」；正文 1:209「一个死人摊开的掌心」、1:241「那只毫无温度的掌心」。
- 三分律：:1388「续命：只能延长一条尚未断开的生命」；:1389「保尸：只有短暂掌握九脉总流的苏衍，才能……」。
4. 读者在哪撞上：「玄微真正死去」一出——「他一直活着？那苏衍手握总流、玄微又有契，为何不续他的命，反把他烧尽？」反过来：「入体一截电就保了两千年尸，保沈鸢何须扣住天下总流？」
5. 改法：定「死」。
- 接 F195⑤「此後不言、目不再合」立一句：「那一年里断了气；两千年不腐，是入体那截电裹着一具刚断气、立过契的身子——书里唯一一具现成的保尸。」
- :1550、:1643「保持最低生机」改「保住不腐」；:1230「活死人」限于启阵至九站走完；:2391 改「那一缕放尽，两千年的身子当夜塌回两千年」。
- :1389 补半句：「有契之身，入体之电自裹；无契者须外扣总流。」
- 借机一拍：苏衍一路背着一具保尸，终局要不要把沈鸢做成第二具，答案就躺在身边的匣里。
- 正文不动。
6. 自信：中高（缺：D4 档是否另定玄微卒年）

**可更好看之处**

一、黄河暗账。离乡三鼎，使青、冀、豫三州两千年无桩；两千年黄河下游改道决口正落在这三州——史书归河政，暗账是鼎不在家，与「夏四百商六百周八百」同式。设定层加一句即可，E7「青」页或终局可用；正文零动；⛔推纪年。自信：中。

二、九股九息。全书一路在数气（E3 数息、413 她数到三百六十、420「十二息」）；终局一息松一股，九息九股，「数息」从此有了实数。末页之「九」（总纲「须是那一副尺量得出来的九」）可列为此数之候选，交剧情庭。自信：中。

三、启之考验之饵（随第三条）。禹的饵改为「这法子成一个。你要，爹让给你」——父亲以永生让子，启拒；与赵阙「那一个，可以是任何人」同题反答，四问一答更硬。自信：中。
