- **纸面、相抵、无机制的 29 条，几乎都在「守」这一层自身。** 病有四种：
  1. 守只验字。
  2. 守能不能活着，只靠一次触发，而且只看得见一个坐。总编辑之坐的 cwd 是 /home/user，而 `/home/user/.claude` 不存在，所以仓里的 `.claude/settings.json` 没有载入。本坐 `_器之迹.jsonl` 里，`链之检.py`（无参）的末一条迹是 11-16T13:12:23，此後再无。结果存底守的五分一存、续跑之守⑤ 的开件之闸、自决之守这三守一起停了三日，没有一个器发现。
  3. 量的来源断了，却把空量印成真数，红的变成绿的。
  4. 哨报出了红，却不入账，也就没有限、没有拦。

**制之核：一条主义之条，要「证、钟、拦、守守」四件都在，才算落实。**

| 件 | 义 | 今之病（证） |
|---|---|---|
| 证 | 行为之证：真跑的迹（_器之迹）、git 的提交、备份/报 的果、实量的数。「档里含某串字」不算 | 17 法的证只验串在（法用之守.py:787-813） |
| 钟 | 何时验，且那一刻真有器在跑 | 总编辑之坐的钟（钩）停了三日 |
| 拦 | 红了有去处：拦提交、拦派、到期、唤坐 | 费哨、囤灰普查红了只印（费哨.py:84-91；大审.py:558-559） |
| 守守 | 钟停了，有别的器看得见 | 巡只验存底守在不在跑（接棒守.py:1124-1133），不验钩 |

「一层一层落实」的意思是：总目标 → 主义 → 条 → 守 → 证 → 钟 → 拦，相邻两层之间各有一器验其链，链一断即红；最末再设守守与棘轮，让「守」本身也被验，而且只许越来越严。
