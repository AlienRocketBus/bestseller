## 六、操作之教训（下回别再踩）

1. **容器会重启**：後台任务全失，但盘上的文件与提交都在；工作流可 `resumeFromRunId` 从断点续（已完成的席直接用缓存）。每回重启後：重开存底环、续被停的工作流。
2. **额度会用尽**（周限／会话限）：席会报「hit your limit」而失；复位後以同一 Run ID 续即可。
3. **剧情庭 schema 之键须 ASCII**，否则 API 拒、诸席皆失——0927 因此出过假「守原」三份。
4. **十二新案互攻不收敛**（D1 二至四审皆卡在立得住 6.x）→ 用式「验」只验一份合成主案，两轮即过。

6. **总编辑复核**：每 48 小时须裁一条规（`python3 工具/总编辑复核.py --裁 <规名> 留|改|废 "<由>"`），否则推送被拦。
