**本席总见**

1. 最强处：人立在手与物上，不立在说明上——钉子与疤（108）、一根火柴（18）、桶与陶片（274—276）、红拇指（386—388）、「我没应」（384）、「哎」（387）；三种沉默之设计与暗线一家三口（381—387），够得上中国小说配角之上乘。
2. 最大之病：中段（约 181—370）人被账与量吞掉——主角成了一本只读自己的账，配角化成一根绳、一个数、一副肩、一张被量的身子；对白从前一百五十章每章约三十句跌到 301—340 每章 0.2 句；八十三句遮名只认出 39%，凭嗓认出只 10%。
3. 第二病：欲不在页上——三个反派之欲白文俱零（审_黎东来、审_霍钧、审_赵阙），沈鸢「执刑」「杀钥」白文零（审_沈鸢），主角 115—388 只有 388:65 一件自己起头的事（审_苏衍）。
4. 第三病：为护一个设定或一个悬念让人变笨——313 让担架上的东头下水、319 叫同行三百章的人「坡上下来一个」、272 认不出讨过名字的她：重度反智五条，五条都是书替设定或悬念付的账（第五节）。
5. 病根：叙者一嗓吞众嗓（苏衍之数与「不是……是」染进沈鸢暗线 217:179、霍钧 211 十八行）；设定在圣经里完成而不落页——W04 二百诊落白文只三十四，只在圣经者四十七，读者手里拿的永远是旧书。
6. 可治之证：380—388 九章已把人找回（东头「我没应」、刘二「拴住」、钱满的钢尺、测绘的红拇指）；本册之案多半是把这九章的法子倒灌回中段。

## 二、群像

**主线五人功能重叠否。**设计上不重：苏衍＝记与问；老头＝令、知、瞒；钱满＝手艺、价、嘴；刘二＝替人问、背、回去拿；东头＝等、不应、来背人而被背。执行上有三处重：①刘二与东头在 332—358 合成「两个抬杠的」，374:39—43 三句一递换嘴不辨（审_东头、审_刘二）；②钱满 171—380 哑後与老头、刘二同一节拍，360:143—149 遮名分不出（审_钱满）；③手势互借——老头 376:23 揣饼、隔衣按一下，刘二 382:99、384:47 一字不差照做，「两只手搭在膝盖上」老头、东头共用（100:129、356:11），白文无一句「学他」（审_老头）。判：⛔删、⛔并；各有一拍全书离不了（刘二回去背人、东头「我没应」、钱满 18 与 84、老头之瞒）。治在写法：手势归人（老头＝食指与灯，刘二＝桶与陶片，东头＝绳头与疤，钱满＝钢尺与针），借用须有「学他」一笔。

**三种沉默分不分得开。**意思上分得开：老头是知道而不说，身体漏底（386:125 托石的手一沉、388:111 指头一勾）；刘二是问一回就不再问（374:65—67），手替他说；东头是不知道而在等，被叫不应（161:59、384:77）。第四种是床上那人——沉默本身是她在做（201:23—25）。手势上混了（见上③）；暗线沈鸢 341 起「零心语」不是一种沉默，是一个空（审_沈鸢）。

**关系网。**最照人的三对：老头—东头（六十五拍，104→388；138 送光等脚）；刘二—东头（一百三十八拍；222:557「那他吃什么」、276 之桶、388:105「拴住」）；老头—刘二（九十一拍；105:31「别瞒着」→388 刘二把老头勾起的指头摊平——全书唯一当面碰着他的瞒而自己不知道的人）。空着的：苏衍—沈鸢（六十一拍，末拍 374；115 院门一别後二百七十章只 291、386 两处，爱线最饿）；沈鸢—霍钧（师徒，七拍止於 72；425 叫「师父」、437 河灯、451 判词无蓄）；黎东来—霍钧（同场零，只隔 277:81—93 一栏）；黎东来与任何人（同场至多一）；钱满—老头（一百四十一拍，18:85「圆上一桩叫你一声师父」三百七十章未收）；刘二—沈鸢（三拍，374:65 一问无来处）。

**反派之阵。**手法是三种恶：黎东来＝流程之恶（「按预案实施」五个字遮住两个多小时和一道拖痕，277:189—201）；霍钧＝欠之恶（气是借的，只算不救，268:329）；赵阙＝诱之恶（只等，拿真话当刀，10:97—99、14:139）。理在白文俱零，所以读者看见三种手法、一个空心——都是「冷而有法的老人」；黎、霍又同为短问（一问栏目，一问手），认声黎 1/8、霍 3/8，凭嗓俱零，且全书从未同页。本册之取把三理各落一页：黎＝只信纸而凭一纸信了不死（取十九）；霍＝那口气与那场火（取十七、十八）；赵＝不死药只够一个、那一个可以是任何人（取二十一）。灭霸之试②「凭智赢过」霍、赵仍缺——霍之一着待驳（十·二）。⛔添一个反派：黎东来升级即可担「半服之面」，管章的人已立（弃十七）。

**有无「活眼」之人。**活眼＝一双新鲜的眼，敢把别人不说的叫破、敢笑。前段有：钱满 18—76 之江湖口（「咋跟欠了印子钱似的」58:95、「搓下来的泥能捏个小人儿」57:69）；刘二替人问是一种道德之活眼而不轻；那孩子一句（381:91）；测绘是外人之眼而只两章。171 以後主线无一活眼，全书没有一个人笑。判：缺；先升後添——升钱满（346—388 黑市口已回：「前六张，一个人几天的活」346:95、「黑市上管它叫鼎」382:79），公输、东海、都市三站进城、进黑市、进罗家，正是他的地面。⛔添人（弃十六）。

**对白之密。**1—150 每章约三十句，多的是说书腔与讲义（老头 22 玉课、70、269）——多而不对；251—300 每章 2.9、301—340 每章 0.2，是全书最易弃书之段（审_苏衍、审_床上那人）；371—388 每章约五句（审_测绘那个年轻人记 5.3），句句有分量，然嗓认只一成，少而不认。判：要成「最受欢迎」，主线宜回到每章十至二十句、暗线三至八句；增量落在钱满（活眼）、苏衍（问）、沈鸢（公输站起她在主线之身）、黎东来（公输站起其镜）；老头、霍钧、赵阙少而更准；每章至少一句遮名可认之话（入开镜卡，见第九节）。

**何以如此。**
1. 凭嗓认得出的只两人：刘二（替别人问的六字短句，「那他吃什么。」222:557、「东头呢。」226:323）、赵阙（以「自己」为轴的平陈述，10:99、21:55、21:123）。可见嗓＝句式＋轴心词，不是词汇。
2. 苏衍、东头认声五成而凭嗓零——认的是事（「捎三封信」「我闺女喊过我」），不是人。主角之叙述腔全书最独，出口的话却无一个句式只属於他。
3. 全书一腔：短、无主语、句号收、逗号碎切（审_赵阙：沈鸢 9:169、老头 20:103、赵阙 10:71 同一断法）；叙者之「不是……是」渗入沈鸢暗线（217:179）与霍钧（211 十八行）。
4. 一人两副嗓，跨段取样自相抵：老头 22 讲义对 118 之令；黎东来 40 文艺腔对 365 栏目问；霍钧 41 格言对 268 问手。
5. 长段无声（301—340 每章 0.2），嗓没有长出来的机会。

**升嗓之法（谁该多开口、各开成什么样）。**
- 钱满（多开口，主线之活眼）：糙账＋比方＋价钱，「俺」可回；只说行话与钱，⛔一句正义。
- 苏衍（多开口）：记者之问——问一句、追一句、问出处（「你看见的，还是听说的。」一类）；「手摸的」至 510 ⛔出口——305:492 写、396:155—161 说不出、510 末页再写；496 照取二十二「看就是答，⛔出口」；问出处照留——问别人（大审397·#43 改）；问话从 10:81「是什么」长到 414「你要什么？」（取二十一）。
- 沈鸢（公输站起多开口）：定为她全书之式——问话不用问号（272:505「你那一本，一天一页吗。」、381:83），一句话办成一件事（381:75「她不行了。」、385:89）。其轴：问人（大审397·#65：霍钧、黎东来、沈鸢问话同形——不用问号——而异轴：霍钧问手与数、黎东来问栏、她问人）。
- 黎东来（公输站起多开口）：栏目问（365:45—97「几个人。」「拿什么量。」）＋条款式长句（365:229）；从不说「为什么」；删 40 文艺腔。其轴：问栏（大审397·#65）。
- 老头（少而准）：只给令与判、带土话，⛔原理词（取三）；「不知道」照留作刻度。
- 东头（少而准）：一句一事，⛔问；担事「我」起头；说事其句收在「没／不」上（123:243、384:77、394:173），铺垫之句不拘（384:73）；认人只 442「是我哥」；被叫名而应只两回——503 应老头一声（其字由 503 执笔定，⛔「哎」）、507「哎」；426—441 应老头报数以手、以绳，⛔开口；此前凡叫他名，⛔应；⛔为显此式添句。（大审397·#51 改）
- 刘二（照旧）：六字以内，替别人问；他已是全书之样。
- 霍钧（少而准）：只问手与数，⛔理由，⛔格言（41:178 那一路收）。其轴：问手与数（大审397·#65）。
- 赵阙（少而准）：只陈述，「自己」为轴，全书只一问「你试过吗」（取二十二）。

**下回之的（拟）**：全书认声六成以上、嗓认三成以上；主角五人嗓认三成以上；每人至少一句凭嗓可认。法照上，取样跨上回之末至彼时之末。

### 丁、已定之终与之如何接（只记接口，⛔设计）

余章总案已定：所求「父母怎么没的→走完→不替人定价」；知之阶 394 半知同弦、418 全、440 读到自己心里那五个字、442 苏家那一夜之凶、466 她家议灭他家、509 拆判词；拍——406 罪（交她一条已被钉的路，心里「天下等不起」）→408 先犯再许（纸背「好」、掌心「回」）→416 每个数旁一个钩、他另起一页「欠」，此页即末页→422「那也得走完」→462 地铁闸机不认→496「苏衍。回来。」头不动→500 承流九息，满头白→509 照她的日子写、六天⛔补→510 末页「第一日／九／手摸的」，「这一页上头，还空着」。

接口有四：
1. 末页之「欠」与「手摸的」要立得住，181—370 那本账不能只是病——它是弧之第一态（记一切）；416 是第二态（记下自己欠的）；509 是第三态（照她的日子写、⛔补自己的六天，「天」换成她的「日」）。所以 W11 治中段之账，宜压其重复，⛔拔其根。
2. 「不替人定价」须有前因可见：274 撂东头（取八「这个数我没改」）→272「她回得去」（取一）→406 交她一条被钉的路——三回掂人「走得了走不了」，到 496 他不定向换她，读者才认得是同一个人变了。
3. 「父母怎么没的」三百八十章空着，442 一夜答完——空档要有页上之「不问」之由或被拒之问，否则 442 像作者忽然想起。
4. 402—416 二人零句（余章 §二·11）——他对她之情在 115—402 若零，406 之罪与 416 之「欠」都轻；公输站之前须有他一侧之迹（⛔破二线律：只许他自己的物与身体）。

## 九、人物之问（定稿·入流程之三处）

### ①开镜卡「问·人物」（可直接粘入）

```
问·人物（执笔动笔前答，每问一两行）
一、认：本章在场之人，各凭什么被认出——嗓（句式、口头之轴）、手势、物？遮了名字，哪一句只有他说得出？没有的，补一句或删一句。
二、智：谁之智在本章受考？以他此刻之所知、所历，他会怎么做？若他做得比这差，页上有没有看得见的由？
三、反智：有无读者会觉得不合理之处——书替人失忆、聪明人在所长处无由看不见、众人为成一场同时变笨、反派凭主角犯蠢而赢？主角早期因无知之错不算，但他不知道什么、为什么不知道，须看得见。
四、变：主角此章比上一回同类之事，有何可见之变（所知、所信、所欲、所怕、思考之法）？读者能否说出「他从前会怎样、现在会怎样」？无变者，写明是有意之停（由）还是漏。
五、声：本章谁该开口而没开、谁说多了？
```

### ②记席「读之得」所添之问（可直接粘入）

```
读之得·人物（三问，各一行）
一、本章哪一句遮了名也认得出是谁？录章:行，并录凭什么认（嗓／手势／物／内容）。
二、哪一处读者会觉得人蠢、剧情不合理？录章:行与「蠢在哪」；分真反智与主角早期之无知（其无知看得见否）。
三、主角此章变了什么？一句「从前会……，现在会……」；没变，录「停」。
```

### ③大审「人物之审」一席之令（可直接粘入）

```
人物之审（大审之一席；主线五人各一席，余者合席）
读：人物链该段（自上回大审之末章起）、关系链中此人诸对、《人物之审·至第388章》此人之行。
量：照五尺各打十分——独特、智、动机之圆、记得住、弧；给一像（章:行）、一句判。
认声：取此人八句（跨段；不足八尽取），交认声席遮名混排、另席盲猜；记「中」与「凭嗓中」（只凭句式、口气猜中，不凭内容），算认声率、嗓认率，与基线比（全书 39%／10%；主角五人 44%／13%；此人见《人物之审·至第388章》第三节）。
反智：照作者 1015 之义分真与非；真者录章:行、重轻、治法。
落账：上回之诊与上回之取，逐条录：落／只圣／裁废／悬。
弧：此段他所知、所信、所欲、所怕、思考之法各有何变；停者录章段。
案：至多三条，每条标动旧文否、动圣经否、费、限；添删一人、改一条剧情之线、改圣经之核者，照动骨五问自答；交驳席二眼。
```

## 十、总编辑须裁者

**十·一｜272 认在 505 凭声（破床上那人庭六审 272 全章之锁）**
- 甲路·守锁：认在 309 後一行，用脸、用望气（取十二）。零开庭，三句即落；认人凭一张脸，平。
- 乙路·破锁：认在 272:505——她头一句话之後添三行：「问话，尾巴没有往上走。」「这么问话的，我只认得一个。」「名字是话头。我心里也不递。」（接 77:19、80:237、91:255「名字是话头，递出去，就是喂」，⛔新立规矩）；141「她脸上没泥」之前添「她脸窄了一圈，颧骨底下陷着。」（挡 309 不认之疑：脸窄、天才亮、想不到她会在这里）；1157 之後只添「楼兰出来那三个月，这只手上的布，是我换的。」（驳甲·沈鸢）。好在 272:505 一页一拍：读者跟他同时从她的说话法认出她——她全书唯一只属於她的嗓（问话不用问号，审_沈鸢）在最要紧的一刻立为认人之凭，认声之试她 0/8 凭嗓可由此翻。费：重开床上那人庭，开三处例外（141、505、1157）。
- 倾向：乙。庭不开则退甲。

**十·二｜霍钧 411 之一着（动骨，待乙眼）**
- 案：411 拆册之後⛔杀管章的人——当页让读者见他算了一半（案头 399 黎东来追来的那张病假条、那人的拇指、他数息、「走吧」）；465 那人自己走进派出所，黎东来一案由此立；读者回头才看出那一着是他下的：活人替他去咬黎东来，死人只会把黎东来引到他门口（驳甲·霍钧之改）。
- 五问：一得——411 不再读成放水（智三十五），灭霸之试②「凭智赢过」第一回落页；二先升——不添人；三费——旧文零，余章 411、419、465 三注；险在夺钱满之终（圣经⑧）——465 立案、472 钱满之账为证，分工须写明，且「备用」之由⛔在霍钧视角说出（不杀与瞒之裁、师兄师弟庭）；四独立之驳——只驳甲一眼，乙眼未驳，**不过**；五进——中上。
- 倾向：送乙眼；过则取。

**十·三｜余章 442 老头那一句与圣经七·3⑨**
- 余章总案（442）写老头当苏衍面说「杀你爸妈的人，是我师兄。我早知道他没死」；圣经七·3⑨（:1817）禁老头对苏衍说破；不杀与瞒之裁只说「东头认出其兄之时揭开」（驳甲·霍钧所指）。
- 甲路·照余章：痛快，读者当场得；破圣经硬禁，老头「到死不说」（审_老头：白文守得比圣经设想的还好）在 442 一句破完。
- 乙路：老头只说余章同拍已有的三件事实（二十年前那一夜之日；「那一夜你爷爷在塬上，他不知道」；「四十五年前送信的，是那七个里最小的」），「杀你爸妈的人是我师兄」由苏衍自己从这三件与 386:117「我见过一个」、东头那一声「是我哥」拼出，⛔老头说破。主角自己推出凶手——成长在页上；老头之瞒守到死。
- 倾向：乙。

**十·四｜钱满那声「师父」叫不叫（取六之终）**
- 甲·叫：一个词，夹在手上的活里，须在 503 前。收 18:85 之诺；险近俗套。
- 乙·欠到底：390「那声师父，先欠着」之後不再提；505 他头一回填土（埋老头），那笔欠由读者自己在铁锹上掂。更痛、可转述（「他到最後也没叫」）；「欠」本是他的账口（73:165「就欠着谁」先於 416），与 416 同骨，险在两个「欠」相叠。

**十·五｜283—379 暗线之量：压而不并（多章旧文）**
