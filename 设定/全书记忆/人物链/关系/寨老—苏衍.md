# 关系链·寨老—苏衍（17 拍，第 63—106 章）

> 甲之条提到乙之句，按章序（〔章·谁之条〕）。零 token 自章记「在场之人」并。

- 〔63·寨老〕从梁上取下油盐赊账薄册，把后几页和半截木匠铅笔借给苏衍（L63）；
- 〔63·苏衍〕之状：寨老疑「你们不是记者」，他接一句「我从前是」，并说清来意：「不是来写你们的怪事。 把寨老拢成一个「走」字的事一项一项拆开（L35）； 随寨老走三户：见证人一户一户分开问，已不在者先记她失踪前留给寨老的原话、再找邻屋核门响和脚印；
- 〔65·苏衍〕不拿寨老「约莫三个多月」往下记，请他找来两位头一夜也醒着的老人，三人分开回想，又翻赊账簿二月那几页（L9）；
- 〔69·寨老〕被苏衍叫去挪西头的人（L15）——其应白文不书。
- 〔69·苏衍〕不等第三声裂响，回头叫寨老：「先挪西头的人。
- 〔70·寨老〕苏衍说毕，他浑身一震，扑通就要跪，被钱满架住（L75）。
- 〔71·寨老〕与苏衍坐坪边点名（L7）；
- 〔71·苏衍〕之状：与寨老坐坪边重点三十七人、名后各画记号（L7）；
- 〔86·苏衍〕老头「寨老认得」不是有把握的话（L119—121）；
- 〔87·苏衍〕寨老不在寨里，明天才回；
- 〔88·苏衍〕寨老验人而三名皆否（L135—155）； 从门缝看寨老来人（L115）； 把寨老的话往回捋（L193—197）；
- 〔89·寨老〕日头刚偏从闲屋出来，拄棍从寨门那条道回去，一路遇见几个人——跟人说了什么，苏衍不知（L7）；
- 〔89·苏衍〕问「为什么」「寨老怎么说」（L183、L201）；
- 〔95·苏衍〕寨老要的是有人肯当着人说出那三个字（L75）；
- 〔103·苏衍〕进寨那一夜寨老头一句是「来领娃娃的那个后生，又来了」——那个娃娃是老头，老头跟寨老说是他孙子，叫他先别说（L262—272）； 听寨老那一句，没有动（L268）；
- 〔104·苏衍〕寨老旧衣裁过一回、再裁剩不下什么（L315—319）。
- 〔106·苏衍〕盖碗之布＝寨老旧衣按完血印剩下的一条（L471）。
