# 关系链·床上那人—沈鸢（36 拍，第 101—383 章）

> 甲之条提到乙之句，按章序（〔章·谁之条〕）。零 token 自章记「在场之人」并。

- 〔101·沈鸢〕说完退到门外，退出去以前往床上那人的手看了一眼，那一眼落在一竖加一横上（L97—101）。
- 〔201·床上那人〕三十来天前沈鸢从坡下背上来，那时还能说话，现在不能——不是哑，是不肯说（L15—17）； 本章头一回睁眼看沈鸢（L247）； 看了很久，抬手（抬到一半晃起来），落在沈鸢掌心上——不是握，是压，压一下收回； 沈鸢出门时手搭被子外，没动（L355）、掌心朝下——睡着了（L387）；
- 〔201·沈鸢〕三百比四十——她这三十来天是向着床上那个人的（L575—639）；
- 〔221·床上那人〕画完缝后眼珠对着沈鸢（L513）； 沈鸢把手放在边上——往前挪一点点，指尖搭上她手背：抬落三下，停，两下，停，一下（L667—709，有声：肉碰着肉）；
- 〔235·床上那人〕无名）：那一天把一本粮房的空账搁在沈鸢膝上的就是她——没问记多久；
- 〔241·沈鸢〕床上那个人身上的变一天一样，她照着它数日子比照着册子快（L165—169，门槛线见备审③）；
- 〔244·沈鸢〕（本章不书其名，「她」）： 所知：这些日子一睁眼头一件是看床上那口气（看在不在，比昨夜快了还是慢了）——不是谁教的：头一夜她没睡、睁眼听一宿，第二天一睁眼头一件就是往床上看；
- 〔247·床上那人〕被子的边压在身子底下（沈鸢昨夜掖的）；
- 〔253·床上那人〕本章所追：那一天把一本粮房的空账搁在沈鸢膝上的就是她（L145）；
- 〔255·沈鸢〕床上那个人躺着不动，盖不住的地方是脸和一只手（L89—105）；
- 〔265·沈鸢〕不是床上那个人到那天没了，是她的册子到那天没了；
- 〔273·沈鸢〕床上那一个翻不了（L281—297）；
- 〔286·沈鸢〕准的那一样跟床上那个人没有关系：它躺在那儿，不在这个数里头（L309—317）；
- 〔292·沈鸢〕床上那一口气：今天出的比进的长——昨天哪一下长她没听（L97—101）；
- 〔300·沈鸢〕床上那人左脚比右脚往外偏一个脚掌宽——昨天也这么偏，前天没摸（L169）；
- 〔302·沈鸢〕数床上那人那只手（L204—248）；
- 〔306·床上那人〕喝两口，第三口没下去，从嘴角流出来一点，沈鸢拿手背擦了（L265—281，白文「她的嘴」「她喝了两口」见备审①）；
- 〔306·沈鸢〕三是床上那人身上的数（L329—373，见备审①）；
- 〔308·床上那人〕喂药：沈鸢一只手从枕头底下伸进去，把她的头托起来一寸，另一只手把碗端平送过去；
- 〔308·沈鸢〕手从枕头底下伸进去托床上那人的头一寸，喂药数碗沿（L145—153）；
- 〔310·沈鸢〕手伸到枕头底下抬床上那人的头一寸喂药，数碗沿（L162—170）； 床上那人喝三口，末一口下去碗底还剩一点——昨天也是三口，昨天碗底见了（L174—182）；
- 〔316·沈鸢〕拿出床上那人的手看黑道（L180）； 再覆掌按床上那人手背挨热那一处：三（两回）（L244—292）； 第三口床上那人不接； 床上那人手背（挨到热那一处），按的是她一百零九天按东西一直用的那一下：回平三（两回都三）；
- 〔318·沈鸢〕托上去那一下床上那人的头自己往上顶了半分，顶完停住（L125）； 她（自己）昨天两下，床上那人今天也两下（L257—277）；
- 〔321·沈鸢〕要托後脑时两只手还是不够，碗放回地上（L65—77）｜托後脑喂水（L81—97）｜碗搁回地上、手空出来才去按那一行——按住时那一口已经喂完了（L105—109）｜把床上那人的手从被下拿出；
- 〔323·沈鸢〕斜过来，勺口贴缸底往前推，推过大半个缸底才满一勺（L57）｜一勺倒进罐、一勺倒进碗，没有再舀第三勺（L65—73）｜先端碗後摊册子——昨天换的次序照走一遍（L77—81）｜翻新沓（L85）｜左手按那一行，这一回行没有从指头底下跑（L93）｜要托起时一只手还是腾不出来（L97）｜一只手从床上那人脖子後头插进去托住後脑往上
- 〔325·沈鸢〕挪到第三根，床上那人的气变了一下——她停住手； 往回抽半寸再送，送得进去（L141）｜挪到第三根时床上那人的气变了一下：吸进去那一下比前头的短（L149）｜放轻後柴头挨柴头没有响； 柴头离墙还空着一线（L157—161）｜床上那人吸进去那一下又跟前头一样长了（L165）｜垛顶平了，手底下没再勾着东西（L169）｜缸抱不
- 〔327·床上那人〕长短今日不书）｜回平三（昨天二）——白往回收慢了一下（L237—241）｜指头还是沈鸢摊开的样子，一根没拢（L245）｜耳後枕印，今天一回按得住整道（L257）。
- 〔329·床上那人〕不具名、不开口）：缸搬到她床脚边，她没有动（L229）｜托後脑（沈鸢那只胳膊肘搁在缸沿上）（L269）｜头一口没接，水从嘴角下去一线，被手指抹回去；
- 〔329·沈鸢〕棱没塌（L197—209）｜床脚下那一块地空着——别处地上都有柴屑，那一块没有（L217）｜床上那个人没有动（L229）｜罐挪的时候里头没有一点响（L233）｜送回去还是三抱；
- 〔335·沈鸢〕「该数床上那个人了」——册子合上面朝下压膝，起身两手托着走，到门槛把册子面朝下扣在门槛里侧那一块平地上，笔横搁其上，不塞回被子角（L85—89）；
- 〔339·沈鸢〕纸拎起到胸口翻一半，眼角上床上那人的头偏过去了——她把纸放下，没把它摆正（L61—65）； 床上那人的头往一边偏过去了（L61，眼角上）；
- 〔341·沈鸢〕眼角上见床上那人头歪（L25）； 床上那人的头挡得住、留不住（L41）；
- 〔343·沈鸢〕床上那人扳正撒手，头停在正当中；
- 〔345·沈鸢〕床上那人脸正冲屋顶，没偏（L29）；
- 〔349·沈鸢〕床上那一身平着，下巴对着屋顶（L9）；
- 〔383·沈鸢〕手从门缝伸出去按那一抱柴，掌心潮，回床边拿指头肚在床上那人起皮的嘴唇上抹两回（L9—11）； 回屋喂四勺，记账，左手背搁到床上那人右手食指尖旁（L125—133）；
