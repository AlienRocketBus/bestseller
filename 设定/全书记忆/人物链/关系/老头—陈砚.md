# 关系链·老头—陈砚（7 拍，第 95—110 章）

> 甲之条提到乙之句，按章序（〔章·谁之条〕）。零 token 自章记「在场之人」并。

- 〔95·陈砚〕听老头说手语，眼睛动了一下（L31）；
- 〔97·老头〕之状：先按陈砚胸口，蹲着看苏衍数第二遍（L17—27）；
- 〔98·老头〕「陈砚。
- 〔98·陈砚〕认得老头照划之水号（L167）。 点十下：极慢，每下隔一息、两回隔两息，第七下指头在竹片上蹭一道，老头垫指后又点三下（L57—63）； 抬手往老头所划那三道上按一下——认（L167—169）；
- 〔101·陈砚〕老头只问一样便收（L201）；
- 〔102·陈砚〕（白文直书 1 处 L11）： 之状：老头把他的手放回被子掖了掖（L11）；
- 〔110·陈砚〕老头，我，还有他」（L333—335）。
