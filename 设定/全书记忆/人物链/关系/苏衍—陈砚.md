# 关系链·苏衍—陈砚（26 拍，第 95—136 章）

> 甲之条提到乙之句，按章序（〔章·谁之条〕）。零 token 自章记「在场之人」并。

- 〔95·苏衍〕其名陈砚（L345）。
- 〔96·苏衍〕站陈床边，门板过时蹲下唤「陈砚」，手放他手背上（L359—375）；
- 〔96·陈砚〕听苏衍唤「陈砚」眼睛动一下，不再动，眼睛没闭（L367—371）；
- 〔97·苏衍〕一个人回屋站着，想跟陈砚说点什么，说不出来（L261—271）；
- 〔98·陈砚〕苏衍喂汤至最后一勺（L429—431）。
- 〔100·苏衍〕所知：陈砚之息九（L21）； 陈砚说出来的东西一共五样、没有一句是整的（L213—217）； 进屋看陈砚，在床边站一阵，手在他手背上放一下没数，掖被角（L205—229）；
- 〔102·苏衍〕第四块石背五道＝陈砚山里刻的划法，磨成这样「得几十年」（L167—189）；
- 〔103·苏衍〕教爷爷前半句的人住的就是陈砚现躺的闲屋； 喂陈砚半碗（L41）；
- 〔103·陈砚〕（白文直书 2 处）： 之状：苏衍回屋时屋里那盏灯还剩一点火，他睡着，呼吸听得见（L384）； 苏衍进屋他没醒（L398）；
- 〔104·苏衍〕陈砚今天喝了半碗多一点（多的那一点没写，「写不下」L13—15）； 进屋坐床边，对陈砚慢说三家，到第三家想跳过——想起「他听得懂」、「听得懂的人，你替他挑着说，那是把他当死人」——就说了（L341—351）；
- 〔104·陈砚〕听苏衍说三家，说到西头门没开，眼睛从房梁移到苏衍这边一下，又移回去（L353—355）；
- 〔105·苏衍〕陈砚听「无喘息」时手往里收（L369—371）。 对陈砚说刘二、说水、说无喘息轮廓（L361—367）；
- 〔106·苏衍〕陈砚早上那半碗一口没动（L457—459）；
- 〔107·苏衍〕陈砚今天自己要汤、喝完一碗（L357—373）； 床边对陈砚说西头（L379）；
- 〔107·陈砚〕听苏衍说西头之事，说到「没有字」时眼睛从房梁转过来，落在苏衍这边一下（L377—383）。
- 〔108·苏衍〕对陈砚说东头（L405）；
- 〔108·陈砚〕听苏衍说东头、门闩、疤——说到门闩时，那只手在被子底下往外挪了一点，挪到被沿上，停在那儿（L405—411）。
- 〔109·苏衍〕端一双进屋搁陈砚床头凳上：「刘二的婆娘送来的……四双。
- 〔110·苏衍〕对陈砚说到姓罗停一下，终还是说了（L313—319）；
- 〔110·陈砚〕苏衍数完把那只手放回被子底下（L331）；
- 〔112·苏衍〕陈砚听「后天早上，我们进去」之应（L127—135）；
- 〔112·陈砚〕称「他」「屋里这一个」）： 所知：由苏衍得知油够了、架子绑好了、东头那人后天在寨门口等、「后天早上，我们进去」（L117、L127）。 苏衍语：「他等这两个字，等了不止十一天。
- 〔114·陈砚〕（本章白文不书其名）： 所知：由苏衍得知油装了两灯、盐分了、绳盘好了、明天早上天亮走（L169）。 之状：灯没点，屋里比外头暗，苏衍一进去就看见他睁着眼（L167）。
- 〔115·陈砚〕（本章白文不书其名）： 所知：由苏衍得知「天亮我们走」（L101）。 黑里被子往上挪了一点点，挪到胸口那儿——跟三天前说姓罗那一回一样，两回都在苏衍说完以后、都是他自己挪的（L111—119）。
- 〔126·苏衍〕陈砚之息当为第十八天、自己数错一回（L363—375）； 数陈砚之息、自纠（L361—375）；
- 〔136·苏衍〕陈砚今天第二十三天（L303）；
