# 人物链·秀的哥（第 89—93 章，在场 3 章）

> 一章一条，自章记「在场之人」并（之状、所知、所为、所瞒；L＝白文行号）。零 token；章记改则重并。

- 〔89·主〕（杨秀之兄）：天快黑才来，一身酒气，没醉，脚是稳的（L77）；沈鸢挡半步，他看她一眼，不绕不硬往前，站住等她让（L79—81）；进屋不看床上那人，一眼也没看；看屋里的东西——墙角那副横杆少一根的背架、钉子上那盏灭了的马灯、桌上那堆剪下来的旧衣——一样一样看过去，看得比谁都久，最后停在那堆衣裳上（L85）；「这是他身上剪下来的？」「是。」伸手翻，翻到针脚歪处停住：「自己缝的。」「是。」把布放下，手在裤子上擦了擦（L87—97）；「我婆娘要是也这么缝过一回，……我也认了。」——「这句话我到现在还记得」（L99—101）；说完就走，走到院子当中站住，回身冲屋里把腰弯下去，弯得很深，直起来不看众人，径直出院门（L103—107）。
- 〔91·主〕（杨秀之兄）：前天弯过腰（89:103），今天站得很直，「算我」（L43）；「寨里有的是人」（L155）；「你可以教」（L163）；喉咙动了一下，没有出声（L167）。
- 〔93·主〕（杨家；寨老称「秀家的哥」L25）： **之状**：「他不认人了……我们走到一个岔口，他说他听见有人在里头喊他的名字。我们两个什么也没听见」（L203）；「他一叫，我们就往回跑……跑了很久，看见外头的光」（L223）；「没找……就是往有风的地方跑」（L229）；抓住老头胳膊：「他还有救没有」「那屋里那个呢」（L275—283）；长长出了一口气（L313）。
