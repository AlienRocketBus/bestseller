# 人物链·陈（第 91—94 章，在场 3 章）

> 一章一条，自章记「在场之人」并（之状、所知、所为、所瞒；L＝白文行号）。零 token；章记改则重并。

- 〔91·主〕（床上那一个；本章之称：他、那个人、床上那一个 L261；苏衍唤「陈」L267）： **所知**：认出了自己的姓（L271）。 **之状**：第十天早上自己把下巴往前送，一口一口喝完一整碗，喝完喘了一阵，眼睛还睁着（L5—7）；听见「陈」眼睛睁开，看苏衍很久——「像是有一样东西，隔了很久，重新回到他身上」（L269—275）。
- 〔93·主〕（屋里那一个；本章只一处书「陈」L393）：本章未出场于前台；老头「他跟屋里那个一样了」（L281）；后生之床「离陈那张床，隔着两尺」（L393）；夜里其气与后生同拍（L421—427）。
- 〔94·主〕（白文书「陈」9 处）： **所知**：看见了那块竹片（L265）。 **之状**：手指往上抬不到一寸落下，第二回更短，第三回不再动——「今天他连一道也画不出来」（L265—277）。
