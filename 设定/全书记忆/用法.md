# 全书记忆·用法

> 0927 作者令：「通读一回就要全书记住，以後直接调取，不必每回再读。」`设定/全书记忆/` 就是这一回通读之所记——以後一切审、改、续写都凭它调取。**错一处、漏一处，後面全跟着错**；故下文第五节之律一条也不许松。

## 一、这里有什么
- **逐章详记**：`第1章.md`……`第380章.md`（N 係阿拉伯数字）。每份一章：正文档名、sha1、字数、线与日、在场之人、物、按拍之事、要句（带行号）、新知、悬线、记录者所见之差（备审）、一句之要；有总览席之裁者，末节另有「总览席裁」。
- **四份总档**：`总览.md`（一页之要｜按站｜逐章索引）、`人物.md`、`物件.md`、`悬线.md`；及本档 `用法.md`。
- **两份器生之档**（⛔手改；唯封版 --後 重生）：`剧情链.md`（诸章详记串成之链）、`剧情全图.md`（W907·1119 作者令「一眼……定位哪里有问题、哪里可升级」：图首「一眼」｜⓪源之鲜｜①脊｜②未闭之环｜③漏之热｜④可升之位｜⑤逐章一行；每条带源 档:行）。
- **其来**：`工具/席/全书记忆.js` 两段——「逐章详记」（每十章一席，逐字读正文）与「总览」（逐份读详记，合成总档，裁详记之间相犯）。

## 二、怎么调取
| 要查 | 去哪儿 |
|---|---|
| 某一章发生了什么、谁在场、带着什么、原句在第几行 | `第N章.md` |
| 某一章在全书的位置、前後章、章名、哪一天 | `总览.md` ③ 索引表（以「\| 312 \|」检索其行） |
| 一站之事、读者到那一站知道什么、欠什么 | `总览.md` ② |
| 全书一页之要、今之末、下一章 | `总览.md` ① |
| 某人：首见、伤、至今所携所知所瞒、要事章号 | `人物.md`；某一章之细→该章「在场之人」 |
| 某物：首见、易手、今在何处 | `物件.md`；某一章之细→该章「物」 |
| 未结之线、到期、下一章之锚、剧情庭之待执、圣经待改 | `悬线.md` |
| 某一处正文之差怎么裁的 | `第N章.md`「记录者读时所见（未改正文，备审）」＋末节「总览席裁」；跨章者→`悬线.md` 六 |
| 全文检索 | `grep -rn "关键词" 设定/全书记忆/` |
| **全书一眼**：书至何处、八站之脊、今站之弧、未闭之环（逾限／将到／待核）、漏之最热、可升之最要、源之病——**二稿、大审、总编辑每回之前先读（开段之席之读待真章演练·质之铁律）其「一眼」（十余行·约二分钟）** | `剧情全图.md` 首节「一眼」；某一环之全条→②与附②；某章之全（悬线之开欠、诸账之条、诸源之链）→`python3 工具/剧情全图.py --章 N`；某一线之迹（所现之章、最长之默、诸账之条）→`--线 词`；图旧否→`--验`（旧只 ⚠：待下一封版随）。错在源则改源，⛔改图 |

- **引用之式**：「211:89」＝正文第 211 章白文第 89 行（以 `awk 'NR==89' 正文/…第二百一十一章….md` 亲印为准）；「211②」＝第 211 章详记备审第②目；「冲突N」＝`悬线.md` 六之第 N 条；「圣经:9551」＝`设定/00_镇冢秘术_唯一总圣经.md` 第 9551 行；「总纲:825」＝`设定/02_余章之势_总纲.md` 第 825 行。
- ⛔详记里的行号是写记时之行号；正文改过之後行号会走——引用前以 `awk` 亲印一回。

## 五、⛔规矩（全书记忆之律）
1. **正文一改，当场同改**：不论改一字、一拍、改章名、并章、删章，该章 `第N章.md` 与四份总档（总览／人物／物件／悬线）**当场**同改——
   - 所改之拍、要句与其行号、物之去向、在场之人之状、悬线之开与结随改；**⛔手换详记首行之「sha1：」**（`sha1sum` 手换即越过残片之比）——改毕跑 `python3 工具/全书记忆.py`：所记 sha 之稿与现白文比，所删之句已不在详记正记则器随 sha，仍在则红列「第N章 详记:行 ← 原片」（★1119 总编辑复核「全书记忆」→改）；
   - `总览.md`：索引表该行之章名、线·日、一句之要；该站之段；若改动全书之末，① 之末两段；
   - `人物.md`：所涉之人之伤、所携、所知、所瞒、要事章号；
   - `物件.md`：所涉之物之易手与今在何处；
   - `悬线.md`：所开、所结、所欠与十之锚；正文差执毕者，自六之表中改状或删去。
2. **新写一章**（`工具/席/一章.js`）：照第六节之式写 `第N章.md`（含 sha1 前十二位），并同步更新四份总档：索引添一行、站段与一页之要之末、人物之至今、物件之今在何处、悬线之开结与接写之锚。
3. **闸**：`python3 工具/全书记忆.py`——`总览.md` 在即启：每一正文章须有 `第N章.md`；sha 只认首节「- 正文档：…｜sha1：<十二位>」之格（缺格、位数不合即红·⛔子串）。所记 sha 与现正文不符：取所记 sha 之稿（`版本/第N章/*.md`，否则 git 史中本章正文之 blob）比白文——旧稿之句（以标点分、≥8 字）现白文已无而仍见於详记正记（在场之人、物二头及其下缩进之子行；发生了什么、要句、本章之新知；备审之注行与行首「**…备审…**」「**…席裁…**」之注块⛔算）者红「第N章 详记:行 ← 原片」；无则器随 sha（零 token）；所记之稿无处可取亦红。`--拦章 N`（封版 --後）他章之残片只报⛔拦本章之封；`--只查`（全测）⛔写；`--通扫` 以详记史上所记诸 sha 之稿通比（一回之清）。`python3 工具/全书记忆.py --自测` 验闸本身。**闸只比所删之原句，不验意之同**——内容之同改仍靠第 1、2 条；⛔只换 sha1 不改内容（还账、记落 --重填 已改调本器：「换」类之同句器换，余者残片即红）。（★1119 总编辑复核「全书记忆」→改）
4. **⛔不许凭印象改档，不许扫读**：改前回原文逐字核；详记与详记、详记与总档相犯，回原文裁，两处一并改，并在该章详记末节记「总览席裁」或「某席裁」之由。
5. **⛔总档之说须回溯得到某章详记**：添一说须注章号；无章可注之说不许进总档。
6. **⛔名之律**：圣经之名（苏玄微、赵阙、樗里闩、枢）白文未书者，档中只作注；暗线床上那人不以「他」称；235 起暗线白文不书「沈鸢」之名（主线 291:455、374:65 由人口中叫出）。
7. **律⑮·动盘之禁**：旁有别席在写盘——不许 `git checkout`／`git stash`／`git reset --hard`／`git clean`／`git add -A`；只 `git add` 明路径。**律⑳**：须裁之事当场照「书更好看」裁并写其由，不许写「交作者裁」而停。

## 六、逐章详记之式（`工具/席/全书记忆.js`；⛔一栏不许空，确无者写「无」）
```
# 第N章《章名》
- 正文档：正文/xxx.md｜sha1：（`sha1sum` 之前十二位）｜字数约
- 线与日：主线／暗线；天字式或日字式之第几日；在哪一站、何地
- 在场之人：（逐一，含其此刻之状：伤、所携、所知）
- 物：（本章出现之要物，及其去向——谁拿着、放在哪、用掉没有）
## 发生了什么（按拍，逐拍一两句，写到能凭此复述全章）
1. …
## 要句（原句照录，3—6 句：本章最重之拍、人物之要话、日後要回收之句，各注行号）
## 本章之新知（读者在本章新知道了什么；人物新知道了什么——二者分开）
## 悬线（本章开了什么、接了哪一章的什么、还欠什么——注章号）
**记录者读时所见（未改正文，备审）**：（正文之差，每目带其裁：改／删／补／不改，并注行号）
**总览席裁（0929）**：（有则列；与上文备审相左者从此）
## 亮点（1015 立：本章最好的二三拍——拍号、原句、好在哪；据行家评之拍库之分与盲读之所记，⛔另读）
## 读之得（1015 立：精读之心得——⛔死读，逐问作答，各一两句；无则写「无」）
- 好在哪：读者在哪一拍被抓住、为什么（据盲读之 remember、行家之 why）
- 欠在哪：哪一拍虚、哪一处读者会卡或会弃（据盲读之 confused／misread、逻辑审之 soft）
- 人会不会这样做：所需之物就在手边而不取、能做而不做者，书里有没有其因（★1015 大审逮 381 断水而井在十九步外——精读未逮）
- 两线之铰：读者会不会把两线之人、物、日连错（★1015 大审逮「反向之家谱」——精读未逮）
- 与前後之勾连：接了哪章之什么（章:行）、给哪章埋了什么（限第几章收）
- 日後改书须留意：此章若动，牵动何处（章号、物、数）
## 一句之要
```
- 写毕自核：凡人名、数目、日号、物之去向，回原文再对一遍。
- ★**读之法之进化**（1015 作者令「读不能死读书，读的效果要越来越好，也要越来越省」）：每回大审（十章一回）之录册，逐笔添一栏「该章之读之得提过否」——未提者即**读之漏**；每回大审算读之漏率（须一回比一回低），每一类漏归一问添入上「读之得」之清单；记席之费逐章由费审记，⛔读得更细而费升（其省由 工具/记料.py：诸账一档汇齐）。剧情链（工具/剧情链.py）由诸章详记串成，封版即重生。
