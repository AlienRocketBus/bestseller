# 剧情庭 D6：暗线沈鸢照看约二百章的「床上那个人」
**裁：守原。**（已写：女，四十来岁，寨里管粮的，洞口附近寻得，左瘫不语。）

## 四席之判
| 席 | 判 | 所提之案 |
|---|---|---|
| 一 | 守原 | 无 |
| 二 | 守原 | 无 |

| 四 | 守原 | 无 |

## 由
- 依《选剧情之律》唯一之尺——「哪一个让整本书更好看」：四席各自独立审 A（杨秀）、B（霍钧旧事知情人）、C（合一）、D（管粮记账人）诸案，皆未提出能证明「改后确比原作更好看」之具体逻辑与方案，故依庭规不改。
- 原设之力在「不说」：一个说不出话、只剩呼吸的人，二百章里由沈鸢一勺一勺喂着，本身已是「留住的只是身体」之无声镜像；贴上确切身份（杨秀／证人／账本），反把这层沉默变成情节道具。
- B、C、D 皆使照看变查案，功能与 D8 所定沈鸢得知真相三步（E6—E8）相叠，徒增一条并行线索而无新揭晓。
- A 与已写之 63:35／71:31／201:65／201:15 相抵；按律已写之文不为否决之由，但 A 所得之意（知情之择）原设已可由沈鸢照看之体验自然承载，改之所得不足以抵改文之价。
- 依《立得住之律》：诸案未立得住者不用。

## 结论
床上那人维持现设，身份不另指定；不改正文。
