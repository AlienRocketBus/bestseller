# 题 D4：玄微如何走过九站（治「当场瘫痪」与「亲脚走九站」之相抵）
读：圣经中「玄微」「瘫」「樗里」「楼兰」相关段（grep 玄微、瘫、亲脚）；E2 楼兰诸章（约 41—60）正文中切崩一事；设定/设定评审_0927_决策包.md D4。
诸案：
- **现文**：圣经言玄微亲脚走九站、又言启阵当场瘫——二者相抵，须择或改。
- **A　樗里先祖背着瘫痪之玄微走完九站**：「亲脚」改「亲背」；血图之线一人背一人所走；樗里存在之由即「背」，与老头、霍钧、师父之「背」贯通；晚揭图上脚印是别人的；楼兰：玄微之意、樗里之手，切得比料的宽，罪分两家。（五席中四席首选；逻辑审称与 E2 正文「玄微亲手切崩」相抵——⛔依选剧情之律，此只算改文之价）
- **B　瘫痪改为渐进**：先亲走九站，後才瘫。
- **C　勘查亲走（逻辑审）**：启阵前他以勘查者之身亲脚走过九站；楼兰那一刀係其反悔後有意切坏；瘫在骊山当场；此後樗里奉命背他出山。
