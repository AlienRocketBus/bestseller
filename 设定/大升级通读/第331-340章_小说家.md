# 大升级通读·第331—340章·小说家席

> **席**：小说家——全中国最顶尖的小说家。看手艺：白描准不准、人物是不是这个人、潜台词、每一拍写得好不好、哪一句是虚的、哪里落了套。

## 〇、十章之总判（先说结论）

**这十章在写什么。** 主线五章（332、334、336、338、340，苏衍第一百二十四至一百二十八天）：330 已落「动身」，一行四人（我、刘二、东头、钱满）走半日到坡根一间有人住的土屋，然後在这屋里收拾了四天——掀开柜上一样蒙着布的方东西，指头戳进两个骨节深的灰；数出二十一张白纸，拿七张垫平门槛上一道凹；把挪出一线的柜送不回原处；脚尖顶着门槛往外送捆时明白了那道凹是怎么蹭出来的——第一百二十八天才真下坡：钱满落在十一步外、专走不留印的硬土、袖子里藏一样三指长的硬东西。暗线五章（331、333、335、337、339，沈鸢第一百一十七至一百二十一日）：她一步没离那间屋——墙根一道口子，整根柴送进去不见阻，黑里有「两块不一样的黑」，柴头带出一段吃进木纹的青；缸见了底；她算出床上那个人挪到门槛要「四趟」；写下「端不动」又划掉；棱外那根柴四周的土圈当着她的面往里退；床上那人腕上数四、手背数三；土下一道压实的细槽两头不收口；头托正了又歪，她不再托。

**手艺上，这十章有二十来拍放进中国第一的小说里一分不亏。**「她手上一直等着的那一顿没有来。」（331:133）——把「空」写成手上落空的预期；「新添的那一横比原先那一横黑。头一格那个二，两横一个色。」（333:57）——拿墨色写日子；「她的手接着往上挪，挪过手背，挪到被角那一线上停住，隔着一线没有落下去。停了那一下，手从原路退下来。」（335:109）——怕知道，一个字不说；「笔尖上那一点墨攒到了尖上，攒成一个圆的，圆的底下往下坠了一坠，没有掉。」（337:129）；「我把那一只脚放回去，脚尖对着那一小块，慢慢落下去，落到底。……我又落了一回。」（338:110）——脚替脑子懂了；「第三步我没有探，整只脚平着下去，下去那一下腰往前抢了一线」（338:198）；「他站着。一只脚在前头，没有落下去。」（340:153）。这支笔在触觉上、在「拿身体当尺」上，是真有东西的。

**剧情上，这十章是原地，而且把本来有的戏埋掉了。**
1. **事少**：约二万七千五百字，真往前推的事数得出十六件（第二节①），四章装得下。主线「动身」落在 330:187，而 332—338 四章住在一间屋里收拾、重裹、挪柜、量凹——人为什么不走，十章无一字；东头 336:58 已上了肩，第二天（338）一队人还在屋里。
2. **利害被埋**：暗线其实有一场生死——水在 331 见底（331:185—193），送柴的人十三回没来（335:9），地在动（335:5）、墙底下有东西（331:145），床上那个人一天比一天衰（335:109、339:89），她算出「四趟」（331:433）——这是「一个人要不要、能不能把一个将死的人拖出一间要塌的屋」的戏。书不许它成戏：331 之後 333、335、337、339 四章无一口水、无一次喂、无一次去找水，也无一个「走」或「不走」的动作。主线的利害（圣经三·6之补「活路账」：不走即被九股拉力慢煮）整块不见——他在屋里多待了三天，身上无一丝拉力。
3. **谜而无问**：墙根那一对黑、吃木纹的青、当面退的土圈、压实的细槽、反茬木楔、柄上拇指窝、门槛上脚尖顶的凹、磨白的扣眼、两骨节深的灰、钱满袖中之物——十样线索，没有一个人对任何一样起过一个念头。悬念要的是读者心里能说出口的一个「问」，这里只有「物」；物越多，读者越学会不问。
4. **人不像人**：331—340 十章零对白（自 325 至 345 连二十一章零引号；311—345 三十五章里出声的只有 315、324 两处）。至此它已逼出人不会做的事：记者住进有人的屋，推人家柜、掀人家的布、把指头戳进人家的东西，不打一声招呼（332）；向同伴伸手求一把被默默让开，不问一句（340）；执刑人出身、走过墓的她发现睡觉那面墙底下是空的、空里有东西，抽出柴就去舀水（331）。
5. **账写进了书**：「我没有量它。」（338:29）是冷轮之账；334 刘二把担子撂在铺开的油布正当中，是为「咬合」（每章须被打断一回）造的打断；331 墙根、332 蒙布之物是 FS03、FS05 的「还清」，纸上读者认不出它们是还账；两线各有一个「那六天」的格（330:109、333:57）。这一批句子不为读者落，读者读到只觉「这里有个什么，我没懂」。

**判（一句）**：句子里有真金，章节是原地踏步。**十并为四**：331 重写（并 333 之「端不动」）｜332、333、334、337 并｜336 并（只取「柜挪不回去」一拍）｜335 修（并 337、339 之要拍）｜338 重写（为 332—338 合章之体）｜339 删（只移「没有再托第二回」一拍）｜340 修。详第五节。

## 一、逐章

### 第331章《横过来》｜暗·第一百一十七日｜约 2,190 字·108 拍

**发生了什么**：灶灰底下的火熄了，吹三回才起一星；取柴回来被自己立作尺的那根柴绊了，拔起重立，指背量出新旧两洞相距「正好一指」。抱柴起身，柴梢蹭落墙根一线土，她发现一道横口子，整根柴送进去不见阻，脸贴下去看，黑里有「两块不一样的黑」，隔两个指节；柴抽出来，头上一截湿，青吃进木纹抹不掉。缸见底，刮三回凑半勺喂床上那人三口；缸立起来提不动。她把罐、勺、碗、册子、笔五样摆到门槛，册子上发现今天这一样「没有地方」可记，把册子横过来写下头一个数「三」（五样、一只胳膊拢两样＝三趟）；再兜住床上那人的肩往门槛挪一段，量出两掌多小半掌，还要三段——「床上那个人，四趟」。**她在算搬走。**

**最好之处**
- 331:133「柴梢抵到口子上，偏了一线，没有进去。她把柴身转了转，梢头找着那一道，往里去。头一寸走得涩，柴身在她掌心里一顿一顿地挪；过了那一寸，涩没有了。她手上一直等着的那一顿没有来。柴身从掌心里一节一节走完，走到柴根，她的手跟到墙根上，指节抵住土。她把食指往里送，第一节也进去了。指背蹭着上头那一道硬的，凉。」——全块最好的一段触觉。「等着的那一顿没有来」，空是从手上知道的，不是从眼上。
- 331:161「她拿拇指从上头抹过去。抹了两回，抹不掉。青走进木头的纹路里去了，顺着纹路两头出去。」
- 331:221—225「碗边上的水落到低一线。那一线贴在碗壁上，一圈没有断。……她端起来，从那一线起接着往下倒。」——水在碗里自己少下去，是这间屋子的钟。
- 331:241「第二口停了一停才接。水在她嘴角那一处挂住，没有下来。」
- 331:361「她把册子横过来，转了个九十度。」与 331:409—433「这样的一段，从这儿到门槛，还要三段。……床上那个人，四趟。」——以一道算术收住一个人命，是这十章里唯一一个读者合上书还记得的结尾。

**写得不好或只是过关**
- 331:33「柴要取。」、331:181「水要舀。」、331:257「缸要立起来。」——三处待办式题头，把人写成一张清单；到第三处读者已听见作者在排程。删去，动作自己会说。
- 331:145—153「低处有两块地方的黑，跟别处的黑不一样。／两块中间那一段，跟她并起来的两个指节一般宽。／她把柴抽出来。」——全章最大的一件事（睡觉那面墙底下是空的，空里有一对东西），她的身子没有一丝回应：不退、不屏息、不回头看床、不堵口子、不把床挪开，抽出柴就去看柴头。这不是克制，是缺席。克制是「有反应而不说」，这里是没有反应。
- 331:297—309「门槛这一边这一处，五样。／缸那一处，一样。／圈里那一堆。她没有走过去。／垛那一头空着。」——四拍盘点，一拍一件事也没有。
- 331:313—325 垛上缸印、手按进去翻上一股味——又一回测量，与本章之事（走不走）不挨。
- 331:333—341「底下那一行，头一格里那一个二还在。／第二格空着。她在第二格里写了一个一。／第三格还是空的。」——读者不知道这一行记的是什么，三句是三个空格。
- 形制：108 拍、每拍二十来字，一句一「＊」。「＊」本是换场之号，在这里隔开「灰底下不红了。」这样的半句，读来像诗行不像小说；节奏被切成等长的碎步，真该停的地方（墙根那一对黑）反而停不出来。

**拖沓与绕圈**：门口日课（331:9、13）与 329、333、335 逐章同构；喂三口（331:229—249）同 329:269—277；「一。二。三。四。／跟昨天一样。／被角照旧盖过手腕。」（331:421—429）同 329:301—309、333:241—257；褥印量掌（331:401）後来 339:89、341:37 两度重量。

**bug**
1. **人称撞车**：331:233「一只手垫到她後脑底下」、331:241「水在她嘴角那一处挂住」、331:401「放下的时候她的头往一边偏，她拿手托回来，托到正。她肩底下那一块褥子露出来一截」、331:413—417「挪回她躺着那一处。／她的手还在被子底下。」——两个女人同一个「她」，一句三个「她」指两个人；全章最要紧的两拍（喂水、试挪）恰是最难读的两拍。
2. **断水无下文**：331:185—193 缸见底、碗水到不了印，是断水之始；此後 333、335、337、339 四个暗线日（第一百一十八至一百二十一日）白文无一口水、无一次喂、无一次去找水（逐章检「水／喂／碗／口／嘴」，333 只有空罐空碗，余三章零）。床上的人三四天不进一口水而她不急、不找——立不住⑤（人不这样做），且其果（床上那人之衰）与其因（断水）书里不让挨上。
3. **还了账、没还书**：墙根口子账上记 FS03「还清」，白文无一字能让读者想到 40:107「撑开了一道缝」；读者得到的是一处新的怪，不是一笔旧账的兑现。而这处新的怪 333—339 只剩那根青柴，口子本身再没人看——立了不收。
4. 331:333 与 331:353：「底下那一行，头一格里那一个二」与「底下那几行，每一行的头一格记的都是屋里一个地方」——同章之内「头一格」一处是数、一处是地名。细抠可解（最底一行另是一种账），读者无从解：这本册子的格局从未交代。
5. 331:9「一百一十七天」与 331:5「第一百一十七日」同章两个量词，且与主线之「天」撞字。
6. 331:69—97「她挪开半步……推一次，正好一指」——挪了半步而两洞只隔一指，须读者自己想明白「半步」是人挪不是柴挪（小疵）。

**判：重写**（并 333 之「端不动」入本章末：兜肩、挪一段、量两掌多小半掌之後，她在横过来的那一页上写「端不动」，划掉，底下写「四趟」。墙根那一对黑须落一个她身上的回应；断水须成为她算「四趟」的因。）

### 第332章《合不回去》｜主·第一百二十四天｜约 2,720 字·58 拍

**发生了什么**：离水边上坡，沙换碎石；刘二牵绳走前半步；东头背三处里的两处；钱满绕开路口一块刻字的碑、眼不往上去。「我」空手比了比自己拇指第一个骨节。午後到一间靠坡的土屋，门帘、门槛磨出一道凹。卸包，又按了一遍本子後头那块板（与 330 同），重裹油布，怀里木楔顶着扣子按不平；屋里的人从背後过，帘缝一线光落在手底下。要一张桌子摊东西，桌那头柜上一样方东西蒙布占着；推不动，掀布角，下头一层平灰，指头按到第二个骨节不见底，坑不塌；按一掌、抹一道，灰上两个印；布角折痕由一道成两道。再裹一遍油布；东西摊上桌看一眼，灰落到纸上擦出一道；分绳，让钱满先过；末了回柜前把布盖回——「底下那两个印，我盖在里头」。

**最好之处**
- 332:23「我拿拇指在自己拇指第一个骨节上比了一下。比的时候手里是空的。」——不写他想那件家什，只写手里空。本章潜台词最准的一句。
- 332:35「屋里比外头暗，暗到我要在门口站一会儿，眼里才走出东西来。」
- 332:75「扣到一半，屋里的人从我背後过去，肩膀蹭到门帘。帘子甩了一下，光进来一线，落在我手底下那一格上，又收回去了。」——一个人只以光写出来，好。
- 332:111—119「指头一直进到第二个骨节那儿，底下也没有顶回来的东西。……坑边上的灰没有往里塌，坑口那一圈还立着。我等了一会儿，还是立着。」
- 332:261「我把布盖回去，盖得跟掀之前一样齐。底下那两个印，我盖在里头。」——一个记者头一回替自己掩一样东西；人就在这一个「盖」字里。

**写得不好或只是过关**
- 332:43「跟昨天一样，鼓的是那一头。」——先报结论，再以 332:51—59 几乎逐字重走 330:69—75（「左边这一头按下去……进得去的还是那一头……压上手掌，压了一会儿再合」），二十行只多出「今天进去以前要停一停」八个字。
- 332:63—67 与 332:171—187：一章之内裹两遍油布、按两回扣子（330 已两遍）。
- 332:123—125「板那一头压过会合。／这一样不合。」——作者替读者做的对照，句法是警句，不是手上的事。
- 332:151—157「一道。／折过一回。」——账。
- 332:191—211：为这张桌子推柜、掀布、戳灰，桌子到手，铜看一眼、纸翻一页、合上。**本块最可惜的一个空位**：「我要把剩下的那两样摊开来看一遍，摊开要一张桌子那么宽」（332:81）——读者以为要看图、要知道往哪儿去了，结果什么也没有发生。
- 332:215—239 看路、分绳、「我把肩上空出来的那一处让开，让他先过」——站位读者得画图才懂，而画出来也没有意思。

**拖沓与绕圈**：板之两头（330:69—75 → 332:39—59）；三层裹布（330 两遍 → 332 两遍）；钱满「脚往路当中偏出一脚宽，过去了才偏回来。眼睛没有往那上头去」（332:19）→ 334:81 同句式 → 338:37「他没有看图」；柜（332 → 336 → 338 三章）。

**bug**
1. **东头之身**：332:17「东头背的是石头这一边那三处堆里的两处」——东头六十六（D1 五审），285—303 躺担架，离担架不过二十来天，上坡背两处；而二十三岁的「我」背一处，刘二只挂一盘绳（332:13）。圣经东头档记「首回负重 332:17（轻的两处）」，白文无「轻」字，亦无那根杆（「杆子只管坡与负重」）。量不配、人物走样。（332:13—19 係 D1 护句，只许补不许删——其治见第五节 B1。）
2. **屋里有人而人不见**：332:75 屋里有人，而「我」推人家的柜、掀人家的布、把指头戳进人家的东西、留下掌印，不看主人一眼、不问一声；此後 334、336、338 在这屋里又住三天，主人再不出现。立不住⑤。
3. **灰之量**：332:105—119「一层灰盖在上头……指头一直进到第二个骨节那儿，底下也没有顶回来的东西」——布蒙着的东西上积灰两个指节深，常理不可能（蒙布之下，几十年也积不出一分）。若那是一匣香灰／炉灰，白文须让人看得出是匣是灰；否则本章之魂「多久没有人伸手」立在一个假数上。
4. 332:27「那一样还留在石头东边，柄上的磨窝朝上，位子没有挪。」——人已走开一日路，「位子没有挪」是他此刻不可能知道的。
5. 332:231「他站在门槛外头那一只脚往里收了收，两只脚都在门槛外头了。」——方向字反了。

### 第333章《头一格》｜暗·第一百一十八日｜约 2,620 字·66 拍

### 第334章《一张是一天》｜主·第一百二十五天｜约 2,640 字·45 拍

**发生了什么**：门口铺油布、压四角，摆要带的东西；木楔在怀里不在列。数没写过的纸，数到十四，坡根有响、刘二把担子撂在油布当中，挪开重来，数到二十一。钱满绕过油布、手按腿边空处、不看。量门槛那道凹：红绳量到小指第二个骨节；纸一张一张叠进去，第七张平了。本子上写两行，又起头写「它是哪一天磨的」，写到第三个字划掉。想起那件家什柄上的窝，「也是这样一个窝。两天了」。重裹油布，点身上各处；七张垫凹、十四张进油布；东头掂担子、挪半个巴掌、上肩又卸；油布扎好，七张压在结底下——「一张是一天」。

**最好之处**

- 334:119「……叠到第七张，指头推过去平了。手掌整个按上去，按不出高低来。」
- 334:135「第六行我又起了个头，写它是哪一天磨的。写到第三个字笔停住了。……我把这一行划掉」——他一辈子写别人的事都有日期，头一回碰到一样没有日期的东西；这一停是人。

- 334:81 钱满绕油布、「一只手落到腿边上，按在先前立着那一卷的那一处。那儿空着。」——後半句逐字同 330:115，第三回。
- 334:89「我先前进出这个门，脚从上头过去过多少回，没有数过。」——到这屋才一天，「多少回」是替 338 埋的，埋得露。

**拖沓与绕圈**：裹布（330、332 → 334 → 336、338、340）；钥匙「齿口朝外」（334:93、115 → 336:70、338:134、340:65—73）；**门槛之凹：332 见、334 量深、336 比宽、338 量形——一道凹四章。**

1. 334:35「数到十四，坡根那一头有响。」——响是什么，白文不交；紧接刘二「把肩上那一副撂下来了」（334:39），撂在油布当中，与「坡根那一头」不是一处。两件事还是一件事，读者分不清；若是一件，刘二何以从坡根背着担子回来，亦无一字。

### 第336章《换到那一头》｜主·第一百二十六天｜约 2,730 字·30 拍

**发生了什么**：要把 332 挪出一线的柜送回原处。推不动；抬起一头，柜脚下露出一条干净的地，刮两边、刮那一条——一边有、一边无。「天上的位置到了。怀里那一样要在这个时辰办。办它的时候手不能是这个样子。」放下柜，出门拿墙根干草把手搓干净，解开油布「取出来」，又裹好。回来送柜：柜脚落下压住干净那一条的一头、另一头露出；挪过去，露的换到另一头；挪回来又换回去；不推第三回。柜面旧界离墙差一线，抹柜面抹出深浅又按回去。席、碗、灶灰、柴垛那一根；「柜脚外头露出来的那一截，比门槛上那一道凹窄。」

**最好之处**
- 336:13「我松了手，柜自己往回坐了一点，坐回它顶住的那一处。这样推不回去。」
- 336:98「我停手。没有推第三回。我一只脚往前挪了半步，挪到摊开那一块的边上。脚底往前蹭了半下，蹭到它的边就收住了。」
- 336:106「抹过的地方和没抹的地方，深浅不一样。我停住手，没有往下抹。……按平以後那一块跟旁边还是不一样，只是不那么齐整了。」
- 336:119「屋里这一头，柜坐在那儿，跟它原先那一处差着一线。」
- 本章之魂是好的：借住人家，动过的东西送不回原样，越想抹平越留痕——全书「每个人都在用自己认为正确的方式，毁掉最想保护的人」落到一只柜上。

**写得不好或只是过关**
- 336:46—50 与 336:66：时辰之约立起，其事为空——「我解开外头那一层，取出来。三层裹好，收回怀里，扣上内袋。」取出来什么、办了什么，一字无。

- 336:78—94 柜挪三回——头一回就够了。
- 336:111「席靠在门边。碗扣着。」——重 336:9。

**bug**
1. **时辰之约是假悬念**：336:46「天上的位置到了。」、336:50「怀里那一样要在这个时辰办。」——前三百三十五章从未立过这一时辰之约；本章与 338:54—62 两度立约，两度所「办」皆空。到 340:61「歇下来我先办怀里那一包……两样都在」读者方悟所办不过是一日一查——一件日常查验被写成神秘之约。
2. **不走之因**：336:58 东头「那一副已经上了肩……挪完他站着不动」、钱满「一只手搭在自己那个包上」——一队人第一百二十六天已上肩待走；而 338（一百二十七天）还在屋里，340（一百二十八天）才下坡。330 已「动身」，332—338 住了四天，为何不走（病？雨？等人？）全块无一字；且与全书之行路引擎相抵（活路账：不走即受九股拉力慢煮，三档「麻—烫—击穿」）——他多待三天，身上无一丝拉力之迹。

4. **屋主人**：332 有「屋里的人」，本章住第三天，挪柜、掏灶灰、倒灰於墙根，主人无迹。

**判：并**（只取「抬柜—露一条—挪一回换一头—不推第三回—差着一线」一拍入 338 合章；时辰之约、搓手、柜挪三回、「另外一层」诸句删。）

### 第337章《两头不收口》｜暗·第一百二十日｜约 2,850 字·43 拍

**发生了什么**：她蹲到门槛外铺着白纸处，左膝挪半寸，膝下土走了一线——膝下有一道：齐边、不翻土。拇指甲验：那一道里甲尖进半分就停、甲缝空；挪出一指宽，甲尖自己往里进，甲缝满——那一道是压实的。顺着它走：绕一块半埋的石头让开半指又回原线，钻进柴堆底；另一头穿过她昨天跪过的两个膝印，进到坡根她「不该去」的草里。脚跟顶脚尖量十二步，两头都没有收口。自己的脚印把它踩断七八截，她抹平，那一道还在。回屋取册子，翻过四个名字、空着的一格，翻到她事先画好还空着的格子。跪回纸前，笔悬、墨在笔尖攒成圆珠不落——「然後笔在她手里横过来了」：横拉一道线，不注量法。册子塞回被子角，那个窝按平又鼓回来。「纸上那一道线，画到纸边就停住了。那一道槽没有停在那儿。」

**最好之处**
- 337:21「膝头底下便分出两半来：靠外那一半顶着膝盖骨，顶得硬；靠里那一半是空的。空的那一线不宽，正在膝头当中。」——膝先知道，眼後知道。
- 337:45「顶了一息，两息，手指头上那一圈白从甲根漫到指节，土还是没有再下去。……甲缝是空的。甲尖上一道亮。」与 337:57 两处对照——拿指甲试压实与否，是追踪者的手艺，贴她的出身（走墓、执刑）；**全块唯一一处「量」同时是「本事」的地方。**
- 337:69「石头那一面挡住了它，它绕着石头往外让了半个指头宽，让过去又回到原先那一条上，没有断。」
- 337:97「她的脚印平了……那一道还在，从抹平的那一片底下横出来，两头接着原先那两截，一线也没有挪。」
- 337:117「那些格子是她自己画的，一格一格排下去，每一格的宽都一样」——她替没来的日子先画好了格子，一句写尽她这个人。
- 337:129—133「笔尖上那一点墨攒到了尖上，攒成一个圆的，圆的底下往下坠了一坠，没有掉。……然後笔在她手里横过来了。」
- 337:173 收句——以纸之有尽对槽之无尽。

**写得不好或只是过关**
- 337:9 擦手日课；337:109 取册一段几乎逐字重 335:17。
- 337:37「那一道比手指窄」——比手指窄、压得实、边齐、绕石让半指、穿柴堆、钻草：人踩不出比手指窄的道，兽也不走这样直。书不给一个可以猜的方向，读者连「错猜」都猜不出，悬念便落空。给她一个念（哪怕猜错），读者就有了可以跟着验的东西。
- 床上那人全章只剩「被子角那个窝按平又鼓回来」（337:161）——前一章刚数出腕四手背三，今天她不去摸腕，书也不点一句她不去摸：是回避还是遗忘，读者分不出。若是回避，要写出「手到了床边没伸进被子」这一下。

**拖沓与绕圈**：笔横纸当中「两头出纸一样多」（335:173 → 337:5、25、149）；取册、塞册同句式；「在裤子上擦」；本章之「顺那一道走」到 339:13—25 又走一遍。

**bug**
1. **断水第四日**：零水零喂。
2. 335 手背三之後，本章每日必做的数腕一事整个消失，无一字交代。

**判：并**（入 335。留膝陷、甲验、十二步两头不收口、事先画好的空格、笔横过来、末句。）

### 第338章《多落的那一回》｜主·第一百二十七天｜约 2,900 字·50 拍

**发生了什么**：前天扎好的那一捆，早上拖到门口靠门框立着；点一遍，底下那张纸还翘；柜不再推，柜脚那一条「我没有量它」。扫地、倒灶灰。空手出门看下坡的路，回屋。「天上的位置到了。怀里那一样要在这个时辰办。」解开油布外层，那一捆往门框上歪倒，他一手把解开的包按在胸口，一手扶捆；捆角卡在框上，他脚尖顶住门槛往外送，送出去了。抬脚，门槛上留一小块湿，正落在凹底最低处——他把脚放回去，对着那一小块慢慢落到底，又落了一回。裹好油布；拿木楔、拿指节量凹，写两行。掀帘出门，帘底只凹那儿空一线。上肩、调两回肩带，下坡两步；刘二放下自己的背带去和东头一头一个抬那一副；钱满从包里取一样东西握着，又收进袖子；门槛上那一块湿的收了。

**最好之处**
- 338:9「拖的时候不敢提，提起来结那一面朝下，压着的那一摞就走位。」——实在。
- 338:78「外头那一层已经解开，里头两层是松的，松的那两层里头的东西是硬的，落一回就要重新对边。」——两件事抢一双手，写得有分量。
- 338:86「胸口那一处压得实，衣裳底下那一层慢慢热起来。」
- 338:98—110「腰弯着，脚尖底下是门槛，脚跟是抬起来的，整个人的分量压在脚尖那一小块上头。……我没有直起腰。我把那一只脚放回去，脚尖对着那一小块，慢慢落下去，落到底。脚抬起来，那一小块还在原处，边跟凹口的边齐。我又落了一回。」——**主线本块最好的一拍**：这道凹不是走出来的，是有人一趟一趟用脚尖顶着往外送重东西蹭出来的；那一「多落」就是他懂了，一个字不说破。
- 338:178「落齐以後底下贴着门槛，只那一道凹那儿还空着一线。我没有去堵它。」
- 338:198「空手下坡是脚掌先落……第三步我没有探，整只脚平着下去，下去那一下腰往前抢了一线，我拿手撑住膝盖才站住。」——身体的知识，一个字不虚。

**写得不好或只是过关**
- 338:25—29「昨天它在两头来回换过位，我没有量过它换了几回，也没有量过两头各剩多少。今天我从它旁边过了两趟。／我没有量它。」——账上有一条冷轮，白文就报一句「没量」：叙述者向读者报告自己没做的事，是账簿漏进了小说。
- 338:54—62 时辰之约第二遍，逐字同 336，所办仍空；「东西露在手上」——何物，不说。
- 338:142—166 木楔量、指节量、「两个不一样」、再拿木楔比指节「过出一线」——刚才那一「多落」的懂，被这一段量数冲淡了；读者不知道比的是那只脚与「我」的脚、那只手与「我」的手，还是什么。
- 338:37「他没有看图。」——钱满的第四个同一否定。
- 338:186 肩带放一格、收半格——与 340 之扣眼一大段重。

**拖沓与绕圈**：时辰之约（= 336:46—50）；裹布、扣眼（338:126、170）；钥匙（338:134、170）；柜（338:21—29）；门槛凹之第四量。

**bug**
1. 338:54—62 空约（见 336 bug 1）。
2. **两度出门**：338:194—206 已下坡两步、众人从身边过去、钱满「走过门槛外头」——即已离屋；340:5—13 翌日又自「坡口」起身、「出去的次序是自己排出来的」。其间一夜宿在何处，白文无；读者会以为 340 是 338 之重写。
3. 338:190 刘二放下背带去和东头抬「那一副」——刘二自己那一副何在（334:39 他有「肩上那一副」）？担子之数由三而二，谁的并入了谁的，无一字。圣经东头档称 338:190「杆成杠」，白文无杆。
4. 338:62「东西露在手上」——何物不说，同 336 之病。

**判：重写**（为 332—338 合章之体：以「借宿一间有人住的屋、为东头的腿住下四天」为一事，蒙布之物、七张纸、柜挪不回、「多落的那一回」为其四拍，末出门。删两度时辰之约、「我没有量它」、木楔指节之量；338:186—204 为 D1 护句，照义留。）

### 第339章《掉个头》｜暗·第一百二十一日｜约 2,740 字·39 拍

**发生了什么**：她在门槛里站了一会儿才下去；指头顺那一道又走一遍到柴堆（伸进柴底两节，前头没了），眼跟着走另一头到草边。门槛上那张纸摆不正，手掌摸出纸底下门槛一处凹。捏起纸时眼角看见床上那人的头歪了；进屋托正、挡住，再数：腕四、手背三；量肩下褥印：两掌再多半掌（331 是小半掌）；头又歪过去，她没有再托。出来把纸掉头重摆，躲开那处凹，重画一道线——这一回手腕没往下顺，线画不到纸边；把多出的纸折两折。册子上「门槛」那一行的数划掉另写；最底一行头一格那个数前，笔尖让出格线点了一点；指头搭过门槛「多落了两下」。册子塞回。「门槛上那一处不平，还在昨天摆纸的那一头。」

**最好之处**
- 339:9「她从屋里出来，在门槛里头站住，没有下去。站了一会儿，下去了。」
- 339:61「纸起来到她胸口那么高，翻过来一半。眼角上，屋里床上那个人的头往一边偏过去了。」——余光里出事，节奏准。
- 339:89「……两掌，再多半掌。被角她没有动。手从褥子上抬起来。她的头又过去了，挨在刚才手掌挡住的那一处上。枕的那一块跟着让出来一道，跟她捋平之前一样。没有再托第二回。」（「她的头」之「她」指床上那人）——前面每天托正，今天托了又歪，她不再托：放弃，一个字不说。块内暗线第二好的一拍。
- 339:145「笔尖往右让，让出了格线，在格线外头点了一点。点的时候笔尖压下去顿了一顿才起来，墨在纸上洇开一圈。那个数一个字没动。」

**写得不好或只是过关**
- 339:13—25 顺那一道再走一遍——337 全走过，今日所得只「膝印昨天软、今天按不出坑」一样。
- 339:37—57、97—125 纸：摆、推、摸门槛、翻、掉头、送、画、端到光里看两道线、折两折、压——这一章的「事」是一张纸掉了个头，读者须随她把纸翻四回。339:117 纸背透光看两道线——作者要的「够不着的是她自己添的那一个动作」太远，读者拿不到。
- 339:149「搭过门槛，指头多落了两下」——暗线用「多落」应主线 338 之「多落的那一回」，是作者隔着两条线对读者眨眼；二线不通消息，文字却互相押韵，巧而露。

**拖沓与绕圈**：顺槽而行（← 337:65—89）；取册、塞册（339:129、153）；数腕（339:77、85）；**与 341:17—41 几乎逐拍同**（门槛凹、头歪、托正、量褥「两掌，再多大半掌」、头又歪、不托）——339 与 341 是同一章写了两遍。

**bug**
1. **人称撞车最甚**：339:69「她进屋。她的头偏在一边，脸朝着墙那一头」——前一个「她」是沈鸢，後一个是床上那人，相隔四字；339:73「她的手从被子底下进去，摸到她手腕」；339:89「她肩底下那一块褥子……她拿手掌按上去……她的头又过去了」。本块最痛的一拍（她放弃托头）恰在最难读的一段。
2. **断水第五日**：零水零喂；床上那人手背三、头托不住、褥印一天长一截——衰有了，因不给。

**判：删**（只移「托正—又歪—没有再托第二回」一拍入 335 合章之末日，人称改清；余删。）

### 第340章《十一步》｜主·第一百二十八天｜约 3,180 字·43 拍

**发生了什么**：下坡，队形自己排出来：刘二、东头抬一副在前，「我」背捆，钱满最後。换肩、调肩带，数肩带上七个扣眼，磨白的是第三个——「白的那一个眼比这一捆老」。钱满与他之间总是十一步（拿石数两块半）。歇时查怀里那一包（纸与关机那一部）、钥匙四格、红绳两圈；本子上写「十一／两块半」。到一处拐，右手按着没扣死的扣，左手四指竖起点人：中指压住重在一条线上的刘二东头，数成三个；松了右手重点，四个——扣一松，捆坠了。他伸手向钱满求一把，钱满侧身让开，袖里一样硬东西从他手背上蹭过：三指长、一指宽、一头两道棱一头圆，卡在腕骨上一寸。本子上又写两行。再看：十一步，而两块半石只合十步；钱满站着，一只脚在前没有落下去。坡底：钱满一路走在硬土边上，九步里只四个印，头一个比末一个浅。

**最好之处**
- 340:9「出去的次序是自己排出来的。……没有人说过谁走哪一处，走出十来步以後就是这个样子。」
- 340:17「下坡跟平地不一样：平地上捆往下坠，下坡上捆往前推。走了二十来步，我把身子往後仰了一线，捆就不推了。」
- 340:45 末句「这一捆是三天前扎的，白的那一个眼比这一捆老。」
- 340:101—109 数人：中指压住重在一条线上的两个人，数成三个，重点一回，四个——以一个视差写出「队里少了一个」的错觉，而那一松手正是扣松、捆坠之因（340:113）：**数对了人，手上那一件就办砸了。**
- 340:125—129「袖子里头那一样顶出来，从我手背上蹭过去。……它贴着我的手背压过去，手背让下去一线，隔着袖子它一线没有让。」
- 340:153「他站着。一只脚在前头，没有落下去。」——一个人在看你，写出来的只是一只脚。
- 本块主线唯一有「人与人」的一章：数错、扣松、伸手被让开、袖中物一蹭——四件事连成一串，都是真动作，且咬得住。

**写得不好或只是过关**
- 340:33—45 扣眼一大段（数眼、说白、说上回放在第几个、这回收到第六个、背带与肩带之辨）三百余字，只为一个「比这一捆老」。（此段在 D1 护句 340:5—59 之内，一句不许压掉；其长只能靠删护句以外的 340:61—77 与 340:141 之日课来抵。）
- 340:61—77 查包、查钥匙、查红绳——日课第七回。
- 340:21、41、141「上肩，走三步，站住。捆没有晃。」一章三遍（338:186 已一遍）。
- 340:121「卸捆之前我空着那一只手往他那一头伸过去，要替他接那一头。手伸到半途，够着的是一段空的路。他那里没有那一头。」——谁替谁接哪一头，读者须读三遍：钱满手上没有担子，「替他接」不通；本意当是向他求一把手。
- 340:149「这一样东西叫什么，本子上没有一个字。」——作者自己在本子上替读者按了一下铃；342 又来一遍。
- 340:165—173 脚印：九步四印、头一个浅、头一个刮不出土末一个刮得出——是有人先走过这条硬土，还是钱满越走越沉？读者得不到方向。

**拖沓与绕圈**：查包、钥匙、红绳（← 330、334、336、338）；刘二捋背带（= 336:58）；「上肩，走三步」×3；数人「四个」在 342 原样又数一遍（下游之病）。

**bug**
1. 340:121 语义颠倒（见上）。
2. 340:5—13 与 338:194—206 两度出门（见 338 bug 2）。
3. 340:25「起身以後我抬了一眼。他跟我之间有十一步。」——前一拍主语是「我」，「他」指钱满要到下文才定；此处宜点名一次。
4. **往哪儿去、为什么去**：下坡头一天，本章无一字；总纲「339—344 为什么动身之答须在这一段落到实处」，本章未动；活路账之身迹（拉力）仍零。

**判：修**（留队形、换肩、扣松、数人、袖中物、「一只脚没有落下去」；改 340:121；删护句以外之查包日课（340:61—77）与护句外那一遍「走三步，站住」（340:141）；340:5—59 护句一句不动；添一处活路账之身迹，或一句非说不可的话。）

日课本身不是病——一个人在绝境里靠日课撑住，是真的。病在**日课占了篇幅而不变**：好的日课每一回都要有一处不同，那一处不同才是这一天；这十章里多数日课原样重来，读者学会了跳，跳惯了，连 335:109 那一处真变（手背三）也会一起跳过去。

### ③ 二线同形
两线同时量一道门槛凹（主 332／334／336／338，暗 339:49—53、341:17）；同有横压在柴堆顶上的一根（336:9、111 ↔ 331:165）；同有「多落」（338:110 ↔ 339:149）；同用指甲、指节、手掌当尺。镜像若是艺术，要让读者看出是镜像而有所得；现在读者只觉得两条线越写越像同一条。

### ④ 「那一」之密，物名之失
十章「那一」718 次，每千字 26 次（第 100 章每千字 6.5 次）；「一线」91 次。物都叫「那一样」「那一道」「那一截」「那一处」，一词多指，读者手里的物名越来越少——336:29「露出来的是一条长的……两边挨着它的，是另外一层」即此病之极：不说「灰」、不说「干净」，就只剩「一条」和「另外一层」。

### ⑤ 一句一「＊」
331 一百零八拍、每拍二十字；第 100 章全章不分拍，照样是白描，照样克制。「＊」原是换场之号，如今隔半句——读者的眼每二十字被截一回，快慢全被切成等长，真该停处（墙根那一对黑、手停在被角）反而停不出来。此形为数拍之器而设，不为读者。

### ⑥ 收章同币
331:433 床上那个人，四趟。｜332:261 底下那两个印，我盖在里头。｜333:265 头一格那一溜，还在里头。｜334:191 一张是一天。｜335:177 笔底下头一回有纸，字还没有。｜336:123 柜脚外头露出来的那一截，比门槛上那一道凹窄。｜337:173 那一道槽没有停在那儿。｜338:206 那一道凹口朝着外头，两头往上收。｜339:157 门槛上那一处不平，还在昨天摆纸的那一头。｜340:173 这九步里的印子是四个，头一个比末一个浅。
——十章十个「一物一比」的定格。真往下拉人的只有 331、337、340 三句；其余七句是同一枚铜钱，读到第三枚，读者已听得出它的声音。

### ⑦ 人称撞车
暗线两个女人同一个「她」：331:233、241、401、413—417；333:237；339:69、73、89。0925 改「他→她」时只换了字，没有换句法——凡两人同句处，床上那人须作「那个人」「床上那个人」。

### ⑧ 零对白、零念头
十章零对白；第一人称而无一念，第三人称限知而无一念，两线声口因此毫无分别。第 100 章有一句「我忽然想起一件事」、一句「油是寨里匀的。这一点点油味，是从每家嘴里省下来的那三罐里头来的」——一句念、一句来历，物就有了分量。这十章把念与来历一概删尽，物便只剩尺寸。

### ⑨ 为器、为账之笔
338:25—29「我没有量它」（冷轮）｜334:35—59 断在十四接在十四（咬合）｜331 墙根、332 蒙布之物（FS03／FS05 之「还清」）｜330:109 与 333:57 两线各一个「那六天」（主账复提）｜340:149「这一样东西叫什么，本子上没有一个字」｜339:149「多落了两下」（隔线押韵）｜331:9、333:9、335:9 路名式。——这些句子在账上都是绿的，在读者那里都是空的。

## 三、读完这十章，读者手里握着什么（reader_holds）

依分量排：
1. **钱满袖子里是什么**——三指长、一指宽、一头两道棱一头圆、硬，卡在腕骨上一寸；他为什么一整天落在十一步外、专走不留印的硬土、伸手求一把他侧身让开、一只脚悬着不落地看着前头三个人？他在防「我」，还是在替谁数这一队？——**本块唯一一个读者自己问得出口的问。**
2. **床上那个人还能撑几天，她走不走**：水 331 见底，送柴的人十三回没来，腕上四手背三，头托不住，肩下褥印一天长一截；她算过「四趟」，写过「端不动」又划掉。细读的人握着「她会不会拖着一个将死的人离开」；多数读者只握着「床上那个人好像不太好」——书没有把这个问递到读者手上。
3. **她屋底下是什么**：墙根口子里两块不一样的黑、湿、吃进木纹的青；土圈为什么当面退；那一道压实的细槽从草底下来、到哪儿去。读者握着的是一团「怪」，不是一个问。
4. **这条路上先走过的是谁**：反茬木楔、柄上拇指窝、门槛上脚尖顶出来的凹、磨白的扣眼、比这一捆老的肩带、硬土上头一个浅的旧印——读得极细的读者拼得出「有一个人一趟一趟背着重东西从这道门出去过」，一般读者拼不出。
5. **沉在底下、十章未碰**：老头去了哪儿、还在不在（311:29「老头去了下游，灯提走了」之後其名不见，一队人离开 E4 无一人回望）；他们往哪儿去、为什么非去不可（玉、血图、九个点、鼎、爷爷、活路账——十章零现，玉只在 330 一现）；沈鸢查父母之案；床上那人是谁。读者是凭三百章前的记忆撑着，这十章没有往这些问上添一两重量。

## 四、这十章缺了什么（missing）

- **揭晓：零。** 账上 FS03（331 墙根）、FS05（332 蒙布之物）记「还清」，纸上读者认不出它们是还账——40:107 的门缝、57 章的电视，隔了二三百章，只剩「两块不一样的黑」「一层厚灰」。十章没有一件事让读者比读之前多知道一样东西。
- **代价：零不可回。** 主线最大的损失是一只柜送不回原处、七张纸垫了人家门槛、一截木楔被带走——都是象征，不是代价。暗线床上那人在衰，但书不许它成为代价：没有一刻她必须在「走」与「守」之间付出什么，也没有一刻她为省一口水给床上的人而自己渴。
- **前迹：**
  - 为什么动身、去哪儿：E5、第五个点、「九个，我们在第五个」——一字无（总纲钉「339—344 为什么动身之答须落到实处」，339、340 未动）。
  - 活路账（九股拉力：麻—烫—击穿）：他在屋里多待三天，身上无一丝迹；行路之引擎整块熄火。
  - 屋里多待四天之因：无（东头之腿、天候、等人——皆可，而一样没有）。
  - 老头缺席：无一念、无一回望；330 末揣走的木楔是唯一的指向，此後十章不再被想起。
  - 东头之身（六十六、离担架二十来天、背三处之二上坡）：无迹、无果。
  - 屋主人是谁、蒙布之物是什么：无。
  - E5「气路暴露在地表」须在到站前先露一处错认之迹（总纲 353—360），下坡头一天毫无预兆。
- **真拦主角之力：零。** 十章里挡着他的只有扣舌、柜脚、翻边的纸、倒下的捆。无追兵、无人祸、无天候、无饥渴、无伤病、无内讧；钱满之疑刚起即收进本子上两行字里，没有逼出一个人的选择。暗线拦她的（断水、地陷、那一对黑、床上的人挪不动）全在，而书不让它们拦——她不试着出去，所以也就没有被拦。
- **人与话：** 四个男人同行五天一句话没有；记者进人家屋、动人家柜、戳人家的东西不问一声；她守着一个将死之人，没有一个念头落到纸上（除了「端不动」三个字）。
- **身体：** 两线的吃、喝十章缺席（主线的饼、水，暗线的水）。
- **主角之异能：** 望气十章零用——他本可以一眼看出那层灰是不是「死」的、那道凹上有没有别人的气、下坡时气往哪边走。

### B. 因之补（立得住；一个因撑几处）

1. **东头之腿——一个因撑三处**（现实常理；与 D1 五审之「东头六十六、离担架二十来天」相合；不释其年，只写其果）：332:17 照留（护句：他硬背两处上坡——这是东头的脾气），到屋卸担後写一个果——「东头卸下背上那两处，在墙根底下坐了，两只手一直按在小腿上。夜里他脱鞋，鞋口在脚背上勒出一道。」於是：①屋里住四天有了因（不是收拾收出来的四天，是等一双腿消肿）；②刘二後来和他一头一个抬那一副（338:190、340:9）有了因；③下坡「前头那个下脚慢」（340:13）有了因。圣经东头档之「杆」须随 D1 执行在 332 补上（杆子管坡与负重）。
2. **断水为钟**（暗；只用已写之物，不碰 D6 之身份）：331 缸见底 → 碗底那一点她不喝；新三首日起她唇上起皮（一处动作即可：舔一下，舔不湿）；她每天往坡根那一处「不该去」的草边多走一步——那一道压实的细槽正是从那里来。**她量的一切於是有了一个为什么：她在量「走得出去走不出去」。**
3. **老头**（守「其下场一字不许说破」）：330 出站时补一个回望的动作（看一眼坡上）；此後每歇一回，他摸一下怀里那截反茬木楔。读者便知他心里有一个不在队里的人，而一个字没有说破。
4. **蒙布之物与 FS05**：二择一——（甲）真还：那东西就是一台电视（方的、蒙布、积灰），屋主夜里掀布开一回，荧屏上一条本地新闻、一个基金会出钱的勘察队往西北去（黎东来之迹，照总纲「360 前只以痕、物、数现形、本人不出场」）——「为什么东头腿没好就得走」有了外力，E5 之人祸（383—392 勘察队）有了前迹；（乙）若不愿动，宁在账上撤销 332 之「还清」，不许拿一层灰冒充还账。（此条动伏笔账，须过剧情庭。）
5. **活路账之身迹**：新二住到第三夜，给一处身上之迹（三档之第一档「麻」即可：手心里一阵往西北拉的麻，或玉的凉偏向一边——照 FS01 温度语法）。与 B1 相顶：腿没好，身上在催——这一顶就是走的时辰，不必再有「天上的位置到了」。

### D. 不许动者
- D1 护句：332:13—19、334:171—177、338:186—204、340:5—59——并章、压句时一句不许压掉、不许改义。
- 五审之数（东头六十六等）照录；不许添一句替谁之年作解。
- 床上那人之身份（D6 待重开）：本改一字不预示；只动水、动作、人称。
- 「二线不通消息」：两线之镜像留给读者自见，不许用隔线押韵之字眼（339:149「多落」）。
