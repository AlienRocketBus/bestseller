# 并发闸（批107·2026-07-30 立法）

## 一·立法之由（实况，非假想）
2026-07-30 凌晨，本仓库上出现**两路并发写作流**。证据为提交时间线交替：
04:24 我·100章第4轮升华庭｜04:26 别路·100章第4轮在场庭｜04:28 我·第5轮在场＋内面｜
04:31 别路·第5轮减法轮｜04:32 别路·100章收官终版v11｜04:35—36 我·第10轮＋收官终版v13｜
**04:43 别路·第101章《第二样》封版**。
其后本闸负测又照出：别路此刻**正在跑101之十轮精进**（版本/第101章 已有 v01—v03）。
**双绿闸与棘轮闸只对"当前文件"负责，拦不住"另一路刚改过而我不知道"。故立此闸。**

## 二·闸之形态（工具/十轮精进.py 内，命令面仍走检察官单一入口）
`concurrency_check()`：
- 读 `版本/_并发指纹.json` 所记之上次 HEAD；与当前 HEAD 比。
- **HEAD 前进 → 报"检出别路提交"**，列出该区间之提交（含作者名）与涉及文件，并出处方。
- **工作区有未提交改动 → 一并报**（可能来自别路）。
- 报毕更新指纹。
**挂钩两处**：①检察官 `--开拍`／`--验收` **前置自动运行**；②`--存版` 之首自动运行。
**故作者仍只说"续"与"挑刺"，无须记新命令。**

## 三·并发三条硬规矩（本闸之实体，违则可毁他人之工）
1. **禁 `git add -A`**：并发时须**逐路径 add**（只 add 本轮自己所改之文件）。
   证据：立法当日我以 `git add -A` 提交并发闸，顺带提交了别路之 `版本/第101章/v02.md、v03.md、_台账.json`。
2. **禁 `git reset --hard`**：并发时若别路有未提交改动，此命令**直接销毁之**。
   证据：立法当日撤负测时我用了它，本次未出事仅因别路之物已在基线内。**撤销须用 `git revert` 或只删自己所造之文件。**
3. **改前必查、同段必并轨**：闸报"检出别路提交"时，**先读其所改之处**；
   若与本轮拟改**同章同段**，不得直接覆写，须先并轨（取末版为底、逐项回补，与十轮精进之择优铁律同法）。

## 四·负测记录（立法当日·通过）
造一笔以 `OtherStream` 为作者之提交 → 闸报：
"⚠检出别路提交！……· 335e01e OtherStream 另一路：改了设定与正文｜⚠涉及文件 10 个……**处方**：先读别路所改之处再落笔；若与本轮拟改同段，须先并轨，不得直接覆写。"
并同时报出脏工作区。**检出＝True。** 负测后以 `git reset --hard` 复原——**此动作本身已列入第2条禁令。**

## 五·尚未解决者（如实记）
- 本闸能报"别路已提交"，**不能报"别路正在写而未提交"**（未提交之改动与我自己的无法区分）。
- 两路对**同一章**各自跑完十轮者（如100章：我之v13、别路之v11），**正文只留最后写入之一版**；
  本闸只能提示，**并轨仍须人工裁定**。
- 若欲根治：**只留一路写作**，或为每路分设分支、以合并代替直写。

## 六·批108修：指纹须按写作流分档（2026-07-31 · 本闸自身之缺陷，实况打穿后所补）
**缺陷**：批107所立之指纹为**两路共用一档** `版本/_并发指纹.json`；
而别路每跑 `存版` 亦调用 `concurrency_check()`，**顺手把基线刷成它自己的 HEAD**；
待本路再查，"上次记录"已是别路刚提交那一笔，**遂永远显示"✓无别路提交"——闸子被它自己的机制抹平**。
**实况**：本路以为仍在101章作业，闸子连报三次"无别路提交"；
实则**别路已推进至第103章**（102章十轮定案、103章《没来得及》封版并已跑第1轮，且清了FS07与100B两笔全书最老之账）。
**此为四条坑中最隐蔽者：闸子不是没报，是基线被写坏了。**
**处方（已实施）**：
- 指纹改为**按流分档** `版本/_并发指纹_<流号>.json`；
- 流号取自环境变量 `ZM_STREAM`；未设则读 `版本/_本流号.txt`；再无则为 `anon`。
- 本流号已落盘：`版本/_本流号.txt` = `streamA`。**别路应各自落一个不同的流号，否则二流同号仍会互抹。**
**负测（通过）**：本流建档 → 以 `ZM_STREAM=streamB` 跑一次 → 本流基线 `7c45c77` **未变**，且别路自有其档。
**由此再补一条硬规矩（第4条）**：
4. **闸之状态文件不得共用**。凡"记录上次看到什么"之档，**必按流分档**；
   共用即互抹，而互抹之闸比没有闸更坏——**它会让人以为已经查过。**
