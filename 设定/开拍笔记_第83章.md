# 第83章 开拍笔记（作业令＋设计令）
**日历链＋宿营（P07）**：78＝X+1第一天（宿刻痕壁下凹石）｜79＝X+2第二天（宿第四处刻痕·拖痕起点）｜80＝X+3第三天｜81＝X+3同日｜82＝X+3夜起、主体X+4＝超期第一天｜**83＝X+4夜起、主体X+5＝欠着走的第二天**。
**在役规矩＋落点（P16）**：灯照脚前三步（落·油将尽）｜一路不出声（落·仍守）｜三十步叩壁（落·沈鸢续代）｜五十步一印（**落·剩一根，仍不动，并写明为何此刻仍不动**）｜不呼名（落·仍无名）｜衔木铃制（落·仍在役，故其只能以手写字）｜胸灯归背人者（落·在钱满颈）｜两人一组不许拉开（落）｜到界它就停（77立·本章兑现）。
**证据线（P15）**：①灯油余量②界的位置③他写在钱满背上的那个字。**收尾前对质**：字义不解，作为总悬念。
**设计令**
1. **章魂一句**：这个字，是说他自己，还是说里头还有一个。
2. **三记必中之拳**：招五跨章回声兑现（落点＝76苏衍在本子上写下的"活"字，由那人亲手写回来）｜招四以物代言（落点＝不能出声，字写在背他的人身上，经钱满的皮肉转述）｜招八留白止笔（落点＝字义不解，收章即止）。禁同族已核。
3. **收章句候选三条**：①这个字，是说他自己，还是说里头还有一个。②他把那个字，写在了背他的人身上。③我在本子上写过这个字。今天它自己找回来了。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟簇过密（不超三组）／**亮点段破折与五逗（P19机器已拦）**。
5. **删章之问**：删掉此章，"他要说的那句话"永无着落，且76那个"活"字失去唯一回声，青溪后半段失去引擎。
**G·五件事**：①第五天明记（欠着走的第二天）②灯油见底之危③过界（兑现77"到界上它就停"）④他在钱满背上写字，钱满一笔一笔转述，主角在心里拼出"活"⑤收章留白：这个字指谁。
**G·两处慢镜头**：①认字全程②过界那一步。
