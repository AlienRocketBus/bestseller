# 第86章 开拍笔记（作业令＋设计令）
**日历链＋宿营（P07）**：83＝X+5（宿界外坳里，灯吹熄）｜84＝X+6上午灯灭、晌午出缝口｜85＝X+6下半天下山，天擦黑宿坡坳、不许生火｜**86＝X+7第七天，天未亮启程，日中前后望见寨子（本章不宿）**。
**在役规矩＋落点（P16）**：不呼名（落·仍无名）｜衔木已解而其口未能言（落）｜两人一组（落·下坡队形沿85）｜血印剩一根与灭灯同挂腰上（落）｜**不许生火（85立，本章给出因由，销PLOT-85A）**｜见壳记位不动（本章无壳）。
**证据线（P15）**：①老头禁火之由②溪水（85"下头有水"之兑）③寨门那盏灯。**收尾前对质**：三线在"望见灯还亮着"一处合拢。
**设计令**
1. **章魂一句**：说好三天的灯，烧到了第七天。
2. **三记必中之拳**：招五跨章回声兑现（落点＝77"这盏留下……它得烧满三天""点到把人背出来那天"，且明写"挪到从道上回头能看见的地方"，今日正由那条道回望）｜招二情感账目化（落点＝三天的油对七天，多出来的四天是谁添的，可算）｜招八留白止笔（落点＝灯底下站着人，不写是谁，收章即止）。禁同族已核。
3. **收章句候选三条**：①说好三天的灯，烧到了第七天 ②那盏灯还亮着，亮了七天 ③灯底下站着一个人。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟簇过密（不超三组）／亮点段破折与五逗（P19先自检）／章号入正文／沈鸢挤出（P20：收尾前点数四人出场处数）。
5. **删章之问**：删掉此章，77长明灯之约失去唯一兑现处，"不许生火"之由永悬，回寨一段无落点。
**G·五件事**：①第七天天未亮启程，老头给出禁火之由（不是怕它，是怕寨子怎么看这个活着回来的人）②遇溪，四人饮水（85"下头有水"兑）③洗净其脸，四人仍不认得（守定名门槛）④转过山嘴望见寨子，寨门那盏灯还亮着⑤算账：说好三天，今天第七天，多出的四天油是谁添的；收章灯底下站着一个人。
**G·两处慢镜头**：①溪边饮与洗脸②望见那盏灯。
