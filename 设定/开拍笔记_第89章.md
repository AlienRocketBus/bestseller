# 第89章 开拍笔记（作业令＋设计令）
**日历链＋宿营（P07）**：86＝X+7第七天望见寨子｜87＝X+7同日埂后｜88＝X+7夜抬入闲屋、X+8第八天寨老验人｜**89＝X+8第八天续，日中至入夜，宿闲屋**。
**在役规矩＋落点（P16）**：不呼名（**本章起可称"姓陈的"，但名仍未得**）｜其口未成字（落·限90）｜长明灯（**落·本章须交代去留**）｜见壳记位不动（本章无壳）｜血印零、未开之指一根（落·无用）。
**证据线（P15）**：①三家之反应②灯油之实账③谁去添。**收尾前对质**：三线合于"灯点到什么时候才算完"。
**设计令**
1. **章魂一句**：说好点到把人背出来那天。人背出来了，可不是他们的人。
2. **三记必中之拳**：招九漏洞翻主题（落点＝77之约"点到把人背出来那天"字面已兑而实质未兑，此缝即本章全部张力）｜招二情感账目化（落点＝油之实账，寨子三个月的存油还剩多少、一天一盏烧多少、三个人要点到哪天）｜招十同一动作两代人（落点＝苏衍替爷爷那笔家账去添油，与老太太替儿子添油同一动作）。禁同族已核。
3. **收章句候选三条**：①这一回添油的，不止她一个了 ②说好点到把人背出来那天，人背出来了，可不是他们的人 ③我把油倒进去的时候，手是抖的。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟簇过密（不超三组）／亮点段破折与五逗（P19先自检）／章号入正文／沈鸢挤出（P20）／整句复述（81、87两犯）。
5. **删章之问**：删掉此章，"三家未得人之后果"与"长明灯之去留"两条门槛无解，77之约悬空，苏衍那笔家账无落点。
**G·五件事**：①第八天消息传开，三家来人，三种反应（不一味欢迎亦不一味排斥）②有人提出灭灯，理由是油的实账，不是怨③寨老与老头各自的裁断④苏衍接了添油这件事，因其家账⑤章末：添油的不止她一个了。
**G·两处慢镜头**：①三家来人各自的看与走②苏衍第一次往灯里添油。
