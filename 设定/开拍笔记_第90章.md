# 第90章 开拍笔记（作业令＋设计令·四笔到期账同章）
**日历链（P07·须先画）**：抵寨＝农历五月二十六｜71—77数日（寨中）｜78＝进山第一天｜79第二天｜80第三天（寻获）｜81同日｜82第四天｜83第五天（过界）｜84第六天（出缝口）｜85同日下半天｜86第七天（望寨）｜87同日埂后｜88第七天夜抬入、第八天寨老验人｜89第八天（三家来人）至天明｜**90＝第九天，日间至夜，宿闲屋**。凡写日子一律对此链，禁再出现"五月二十几"式断言。
**在役规矩＋落点（P16）**：不呼名（**本章可称"姓陈的"，名仍未得**）｜其口成字（**本章到期，须付**）｜长明灯去留（**本章到期，须付决议或明写改期之由**）｜见壳记位不动（本章无壳）｜血印零、未开之指一根（落·无用）。
**证据线（P15）**：①他写的字②灯之决议③安点之筹备。**收尾前对质**：三线合于"他写出来的那句话，把灯的账也一并结了"。
**设计令**
1. **章魂一句**：三遍不是三遍。是三个人。
2. **三记必中之拳**：招四以物代言（落点＝他不能出声，以炭在门板上写字，字成而话未出口）｜招二情感账目化（落点＝三遍之解＝里头还有三个，与寨中所失三人对不上，是另外三个；数目本身即恐惧）｜招九漏洞翻主题（落点＝灯之决议本无解，而"里头还有人"一出，灯不必再议——它自己有了理由）。禁同族已核。
3. **收章句候选三条**：①三遍不是三遍，是三个人 ②这盏灯，不用再议了 ③他写完最后一笔，手就落下去了。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟簇过密（不超三组）／亮点段破折与五逗（P19先自检）／章号入正文／沈鸢挤出（P20）／整句复述（81、87、89三犯）／凭印象报日期（P07十犯）。
5. **删章之问**：删掉此章，四笔到期账全部违约，"活"字三遍成死结，安点无从启动，青溪后十章失去引擎。
**G·五件事**：①第九天，其腮筋松，能张口一线但仍不成声（成字非成声）②钱满取炭，架子那块竹片作板，教他以指蘸炭写③他写的第一个字仍是"活"，写完停住④主角追问三遍，他伸三指，又在"活"字旁边画了三道竖——**三遍＝三个人**⑤此数与寨中所失三人对不上（岩生、长贵、秀已由寨老定为不在其中）：**里头另有三个活的**；灯之议因此不必再议；老头当夜起草进山第二趟之筹备（安点之筹备迹象）。
**G·两处慢镜头**：①教他写字与他写出第一笔②三道竖出现之后全屋的反应。
