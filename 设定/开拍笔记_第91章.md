# 第91章 开拍笔记（作业令＋设计令）
**日历链（P07·先画）**：抵寨＝五月二十六｜78进山第一天…84第六天出缝口｜85同日｜86第七天望寨｜87同日埂后｜88第七天夜抬入、第八天验人｜89第八天｜90第九天（三道竖）｜**91＝第十天，日间至夜，宿闲屋**。全章零日期断言，只写"第十天"。
**在役规矩＋落点（P16）**：不呼名（**本章可称"姓陈的"**）｜其口未能言（落·只成字不成声）｜长明灯（90已定，本章不复议）｜血印零、未开之指一根（落·无用）｜见壳记位不动（本章无壳）。
**证据线（P15）**：①他手反倒凉（90埋）②资源实账（油、粮、布条、人力）③寨中出人与否。**收尾前对质**：三线合于"第二趟不是想不想去，是拿什么去"。
**设计令**
1. **章魂一句**：不是不想去。是拿什么去。
2. **三记必中之拳**：招二情感账目化（落点＝把第二趟摊成一张清单：油多少、粮多少、布条零、人手几个、几天；每一项都对不上）｜招三自破其规付代价（落点＝老头七十七章立"空着手也得走"，此刻他自己不许人走，须付代价）｜招八留白止笔（落点＝他手更凉，主角仍不说，收章即止）。禁同族已核。
3. **收章句候选三条**：①不是不想去，是拿什么去 ②账摆在桌上，谁也没有伸手 ③他的手比昨天更凉了。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟簇过密（不超三组）／亮点段破折与五逗（P19先自检）／章号入正文／沈鸢挤出（P20）／整句复述／凭印象报日期（P07十犯）／F107禁抖族（P17三犯）。
5. **删章之问**：删掉此章，第二趟成了凭热血开拔（违门槛），资源账断线，老头"空着手也得走"之自破无处落。
**G·五件事**：①第十天，其人喝汤能咽而手更凉②寨老召集议第二趟：谁去、拿什么去③老头把账摊在桌上（油／粮／布条／人手／天数），每一项都对不上④寨中有人愿去，老头不许；他自破七十七所立"空着手也得走"，代价是被人当面顶回⑤夜里他一个人坐在灶前，主角发现他在算另一本账（第一趟的死限是三天，这一趟没有死限——因为里头那三个已经撑了三个月）。
**G·两处慢镜头**：①摊账全程②老头独坐灶前。
