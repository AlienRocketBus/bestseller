# 第96章 开拍笔记（作业令＋设计令·三笔到期账并为一轴）
**日历链（P07·先画）**：92第十一天｜93第十二天｜94第十三天｜95第十四天｜**96＝第十五天，日间至夜，宿闲屋**。全章零日期断言，只写"第十五天"。
**在役规矩＋落点（P16）**：其名已得（**本章须唤"陈砚"，防重蹈有姓不称**）｜其力将尽（落）｜第二趟四条件（落·本章因数已足而只差人与油）｜床距—息数F136（落·抬回屋后须还那一息）｜沈鸢立位外移（**95遗留观察项，本章须给落点**）。
**证据线（P15）**：①后生之息与陈之息②那三个数被用来做什么③"替它喘一口"之答。**收尾前对质**：三线合于"把那三个数用出去，就得先把一个人送回去"。
**设计令**
1. **章魂一句**：那三个数，是拿另一个人的命换的。
2. **三记必中之拳**：招九漏洞翻主题（落点＝"那三个数之用"本以为是给第二趟指路，翻出真用：老头拿它算出后生该被送去哪儿——离陈越远，后生越活；而离陈越远，陈越快被抽空）｜招二情感账目化（落点＝一尺一息之表，反向用在后生身上，算出"送多远"）｜招八留白止笔（落点＝送走之后，两人各自的数不再报，收章即止）。禁同族已核。
3. **收章句候选三条**：①那三个数，是拿另一个人的命换的 ②他被抬走的时候，陈的手动了一下 ③屋里剩一张床了。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟不超三／亮点段破折五逗半角（P19）／章号入正文／沈鸢挤出（P20·须给其立位落点）／整句复述（P21·6次）／凭印象报日期（P07·10次）／F107禁抖（P17·3次）／**净重上限3300（P13·94已犯第三次）**。
5. **删章之问**：删掉此章，三笔到期账全违约，失神者悬置，那三个数沦为道具。
**G·五件事**：①第十五天，后生之息由十一升为十二（因陈被抬出院子那半日之隔）②老头以三数之表反算：后生离陈多远才能回到常息③寨中议：送后生去哪一家——三家皆不肯，唯孤老太太肯④"替它喘一口"之答：老头答钱满——不是替它喘，是它拿他的喘去认路；送远了，它就认不着他⑤后生被抬走，屋里剩一张床；陈的手在他被抬过门口时动了一下。
**G·两处慢镜头**：①反算之表与议送何处②后生被抬出、陈的手动。
