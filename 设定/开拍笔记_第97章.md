# 第97章 开拍笔记（作业令＋设计令·两笔到期账）
**日历链（P07·先画）**：93第十二天｜94第十三天｜95第十四天｜96第十五天（送走后生）｜**97＝第十六天，日间至夜，宿闲屋**。全章零日期断言，只写"第十六天"。
**在役规矩＋落点（P16）**：陈砚之名（落·续唤全名）｜其息续降（落·屋中止余一人而它取得更快，96已埋）｜第二趟四条件（落·油与人未足）｜三数为尺F138（落·不得作指路）｜路上四条（96新立，落·钱满未归无从验）。
**证据线（P15）**：①其息今日之数②他还有用之用③他何以宿她家。**收尾前对质**：三线合于"他有用，是因为他记得的东西还没被拿完"。
**设计令**
1. **章魂一句**：他还有用，说的是它，不是我们。
2. **三记必中之拳**：招九漏洞翻主题（落点＝"他还有用"众人一直以为说的是对第二趟有用，翻出真意：是**它**觉得他还有用，所以拿得慢；等它拿完了，人就没了）｜招五跨章回声兑现（落点＝陈砚何以宿她家——因二月末寨中无人肯留过路人，唯她开门，与96"没有人开门"成对）｜招八留白止笔（落点＝老头说完那句就出去了，不解释）。禁同族已核。
3. **收章句候选三条**：①他还有用，说的是它，不是我们 ②那句话不是夸他，是给他记的日子 ③她开过两回门。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟不超三／亮点段破折五逗半角（P19）／章号入正文（96刚犯）／沈鸢挤出（P20）／整句复述（P21·6次）／凭印象报日期（P07·10次）／F107禁抖（P17·3次）／**净重上限3300（P13·96已第四犯）**／术语裸奔（批105新机器）。
5. **删章之问**：删掉此章，两笔到期账违约，"他还有用"沦为口号，陈砚与老太太之关系断线。
**G·五件事**：①第十六天，屋中止余一人而其息掉到十（96送走后生后它取得更快）②主角追问"他还有用"，老头给出真意③老太太来喂汤，主角问出陈砚何以宿她家④她答：二月末那两夜，寨里没有一家肯留过路人；她开了门⑤两回开门对上：二十年前无人为她开，如今她替别人开了两回（陈砚一回、后生一回）。
**G·两处慢镜头**：①今日测息与老头之答②她说二月末那两夜。
