# 第99章 开拍笔记（作业令＋设计令·两笔到期账＋安点开工在门口）
**日历链（P07·先画·凡补场必先看时标序）**：95第十四天｜96第十五天｜97第十六天｜98第十七天（接得五百步与水）｜**99＝第十八天，日间至夜，宿闲屋**。全章零日期断言，只写"第十八天"。
**在役规矩＋落点（P16）**：陈砚之名（落）｜其息九（落·今日之数）｜F140两样东西未明（落·不得凭空补）｜三样等不齐（落·**本章须给先后**）｜路上四条（96立，落）｜本子余一半（98立，落）。
**证据线（P15）**：①岩生之兄之由②三样之先后与安点之开工③其息今日之数。**收尾前对质**：三线合于"先动的那一样，是最不像动的那一样"。
**设计令**
1. **章魂一句**：他要的不是他弟弟。他要的是那条道还有人走。
2. **三记必中之拳**：招五跨章回声兑现（落点＝89他问"进去多深"、把一千步在心里走一遍；今日他自己带工具来，其由由此而出——他弟弟已无望，他要的是道不断）｜招二情感账目化（落点＝三样之先后由老头列成序：油最慢、人已到、他的日子最快，故先动之项＝在他还能点的时候把路接完，而安点须与接路同时开工）｜招八留白止笔（落点＝安点开第一锹而不写成，收章即止）。禁同族已核。
3. **收章句候选三条**：①他要的不是他弟弟，是那条道还有人走 ②第一锹土 ③三样里头，先动的是最不像动的那一样。
4. **本章禁用**：解说腔／告知式／陈词／替读者划重点／顿悟不超三／亮点段破折五逗半角（P19）／章号入正文／沈鸢挤出（P20）／整句复述（P21·6次）／凭印象报日期（P07·11次）／F107禁抖（P17·4次）／术语裸奔（批105）／**净重上限3300（P13·98已第六犯）**。
5. **删章之问**：删掉此章，两笔到期账违约，安点逾期（限100），岩生之兄成工具人。
**G·五件事**：①第十八天，其息九未再落；接路又得一句（第一样东西：石头）②岩生之兄带工具来，自陈其由（89他就问过进去多深；他弟弟三个月，他不信还活着，他要的是那条道往后还有人会走）③老头列三样之先后：油最慢（十来天）、人已到、他的日子最快（一天一格），故须并行④安点开工：在寨门柱下那道横痕处下第一锹，量得七步之桩位（92—94所定）⑤收章：第一锹土翻出来，底下是湿的。
**G·两处慢镜头**：①岩生之兄自陈②第一锹土。
