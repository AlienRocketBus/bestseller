# 方案（1009 立·作者令「每一环都要先精准确定它能做成，再去实施；⛔猜」）

每开一件工作流（`工具/工作流账.py --开 W`）之前，先在此立 `W.md`（`python3 工具/方案.py --模板 W 题`），逐环写：做什么、谁办（脚本／模型及其为何）、**确证**（实据：费账之键、Run、试：命令及其果、自测）、时、费、败则。
尚未确证者列入「未确证」并写其「试」——小样实测确证了，移入逐环；**未确证有一条，即⛔开**。`工具/方案.py --验 W` 守，`--开` 先验之。

★1021（坑㊱·W60）：凡改一把尺（取章、取镜、取线、计数之法），方案之「坑之检」须列其诸消费者之 grep（旧函数名、旧尺之调用处）；分席以档时，同义之改归一席，或令诸席 import 同一把尺（⛔另抄）。
