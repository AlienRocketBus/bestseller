# 裁 · **「差须为六」与「六与七交替」并不相犯 —— 那是两种配对，不是两条律**

**裁者**：本坐（0918·346 之席在跑·⛔本裁不动一字白文、不动一道闸之判据）
**其账**：**342、343、344、345 四席逐章原样转交**，其语皆作「口径相犯，只报未代裁」——**今日裁之。**

---

## 一·**两处之文（逐处亲印）**

- **`总纲:281` 硬验③**：「**每章封版之日 `日差哨.py` 所印之二线差须为六**；**差不为六即是本表错了，当场改本表，⛔不许改那一章**」
- **`圣经:7408`**：「**其差在 6 与 7 之间交替，取决於与哪一篇比**」，并自书其真律：
  「**暗线之章，其日＝紧接其前那一篇主线之日 − 6**」（318/321/323/325 四篇皆合）

## 二·⛔**判：不相犯。**

★**其据係本坐今日逐行读 `工具/日差哨.py` 之码（`:92—99`）**：

```python
if 线 == '主':
    上主 = 日                       # ★只在主线之章上更新
...
else:                               # ★暗线之章
    row['日差'] = 上主 - 日          # ⛔「上主」＝紧接其前那一篇主线之日
```

⛔**即：`日差哨` 所印之「差」，只在暗线之章上算，且它拿的正是「紧接其前那一篇主线之日」。**
★**故 `总纲:281` 硬验③（其判据即此器）与 `圣经:7408` 所书之真律，⛔是同一条。**

★★**而「六与七交替」说的是另一种配对**：
**拿章号相邻的两章去减**（342主129 与 343暗123 得 6｜**343暗123 与 344主130 得 7**）——
⛔**这一种配对，盘上没有一台器在量它**；**它是一个读表的人用眼睛减出来的数。**

> ⛔**故这四回所报的「相犯」，是把两种配对的数摆在一处比**——
> **同一批日号，换一种配对，本来就该得出不同的数。**
> ★**此係本日第五回见「两把尺」之族**，而其形最隐：
> **前四回是两台器各有一把尺；这一回是一台器一把尺，而读它的人心里另有一把。**

## 三·★★★**而这一裁真正要紧的，是它解开的那一条**

⛔**本坐今日起先以为**：**硬验③「差须为六」把书锁死在「主暗相间」这个节奏上**
（`总纲` 丁表 346—360 十五章，逐章 主／暗／主／暗，一日一跳，**一处变化也没有**）。
★**而读完码之後，判其不然**：

> **硬验③所要的只有一样：每一篇暗线之章，其日＝紧接其前那一篇主线之日 − 6。**
> ⛔**它一个字也没有说「主线与暗线须一章一换」。**

★**其验（本坐当场算一回）**：
- **今之排法**：346主131 → 347暗125（131−125＝**6** ✓）
- **若连排两章主线**：346主131 → 347**主**132 → 348暗126（**132−126＝6** ✓）
　——⛔**硬验③照旧过**，`日差哨` 亦无「变」可报。

> ### ⛔**故落一条写死的**：
> **「主暗相间」是 `总纲` 丁表的一个排法，⛔不是一条律。**
> ★**书若要在某一处连排两章同线（或三章），只须把其後那一篇暗线之日按「前一主线之日 − 6」落下去**，
> **硬验③、`日差哨`、`圣经:7408` 三处同时过。**
> ★★**而其价须当面写明**：**连排两章主线，暗线那一头就空了两章**——
> ⛔**那一头是一个躺着的人与一个数日子的人**；**空两章，读者再回去时，她那一头的数须跳两格**，
> **这不是坏事，而它是一件须当场想清楚的事，不许顺手就排。**

## 四·**本裁不做的三样**

1. ⛔**不改 `总纲` 丁表 346—360 之排法**——**那是排势那一庭的事，且 346 此刻正在跑**；
   ★**本裁只把「它排得动」这件事写在这儿**，**交 `大审_347之备.md` 之问一（「不匀」该由什么来出）当场用。**
2. ⛔**不改 `圣经:7408` 与 `总纲:281` 任何一字**——**二者本不相犯，无可改。**
   ★**只在此立一条读法**：**凡再有人报这一处「相犯」，先读 `日差哨.py:92—99`，再决定报不报。**
3. ⛔**不动 `日差哨.py` 一行**——**它是这三处里唯一一个把话说清楚了的。**

## 五·⛔**本坐当面认一样**

★**本坐今日起手时，也是先看了那两句话，判它们相犯**；
⛔**是读了码才知道不相犯**——**而那四席报它的时候，多半也只看了那两句话。**
> ★**故补一条，与本日 `体检账 八十五` 同族**：

> ⛔**「这两条律，是不是同一台器在量？若是，它量的是哪两样东西之间的差？」**
> **答不出，那一报只是两句话摆在一处，不是一处相犯。**
