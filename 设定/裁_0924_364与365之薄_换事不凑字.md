# 裁·0924·364 与 365 之薄：换事，不凑字（总编辑当场裁·律⑳）

## 其实
- 364（主线）净重 2192＜主线带 2500；365（暗线）净重 1957＜暗线带 2300。
- 二章之救章，深掘三路各三席**皆判死、皆有据**：白文里凡还能往下挖的一层，都已落成动作或物；再补只能落成一句想法或判词。
- 365 深掘物路之言最准：「本章低於下限，是真伤；照裁不许凑字，**治法只有换一件更大的事**，不在物路补得上。」
- 窗 360—364 认欠额已满（363 占）；豁免须在落笔之前，⛔事後补豁免即是给自己开後门。

## 所以不取的三条路
1. ⛔凑字（撒感官、添长气、硬补一问一答）——假料比薄更伤书。
2. ⛔事後补「短章豁免」——闸让自己过。
3. ⛔改认欠额——放宽闸。

## 所裁
**二章之薄，其根不在字，在事：一章只担一件小事。治法是回修时各换进一件真正更大的事（或让第二件事咬进来），由回修令开案重写其事之骨，而不是在原骨上加字。**
- 先治 365（距界最远·1957／2300）：黎东来那一头只有「一张桌子一通电话」——须有第二件事咬进来，且那件事须在 362—364 已立之局里找得着来处（不许凭空造）。
- 再治 364。
- 两章回修之前，⛔主枝照旧推不上去——**这是应有的红，不是闸的病**；书的备份每刻都在存底枝。

## 此裁之验
回修後之章：①净重入带；②新事逐拍有前文之据（awk 亲印）；③删掉新事，章断一样东西（答得出断什么）；④十一轮照过。任一不过，即此裁未办完。
