# 裁·0925·FS01（玉·门後之物总线）：不判废，限改挂 382（总编辑裁·改单#G0925-07）

## 其实
`裁_0924_伏笔_FS01_FS05_限365落空之裁.md` 写死：「368 仍不开油布里那两样，当场判废，并落笔明写『这一样再没有人提起过』」。368 封版，未开油布。

## 其判
照字面当判废。**而 FS01 是「两半玉合一之秘／门後之物总线」——第1章所植、全书之骨**（`裁_0913`：「判：活，且是全书之骨……一条总线的限不该挂章号」）。
为守一条「防逐章拖挪」之规而把全书主心骨判死、在正文写「再没有人提起过」——**是规矩毁书**。0924 之裁的病根不在玉，在**把限挂在走不到它的章上**（365 暗线镜、368 係一指之沟之章）。

## 所裁
1. **不判废**。canon `FS01.status` 仍 open。
2. **限改挂 382**：总纲 371—382「诊」段，「风大，灯用不成——他改用夜里的玉温与雾」（`总纲:411`、`总纲:675`）——**玉以旧器新用回场，正是它该回来的地方**。
3. **代价写死**：371—382 主线诸章若无一章以玉温为诊器，382 当场交大审专裁（⛔不再逐章挪限，⛔不再由单章之席自改其限）。
4. 0924 之裁关於 FS01 之一段，照其自书「FS01 之限若再改，本裁即作废」作废；其 FS05 判废之一段不动。
