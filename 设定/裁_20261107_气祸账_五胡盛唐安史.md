# 裁 · 2026-11-07 · 气祸账：五胡・盛唐・安史・五代（总编辑定·作者 1107 令）

**作者之令（1107）**：大唐盛世亦与赵阙有关——他想方设法把中华气运调到最好，衍出盛世；五胡乱华、五代十国是气乱到极处；大唐由盛骤衰、本该更久，是气突然流窜、流向出了问题，致安史之乱；须与中华几回大厄完美相连，逻辑闭环绝对完美，剧情特别好看。

**须守之旧账（⛔撞）**：①赵阙只有调度权、无使用权，理得了气、理不了人（圣经:965、:967；裁_20261106_赵阙之升华 一、段十三）——汉末大乱他攥着网，天下照样「十裁一在」；②鼎定地、不保一姓：改朝是人事，桩在则乱几年即定（:971·G1107-02）；③冀鼎随蒙恬之军押往贺兰，「亡秦者胡也」是他借卢生之嘴（:976）；④离乡之鼎病上加病（名随铸、不随地）；⑤调度替代不了维修，老的是他改上去的泵头与接口（:969）；⑥他是守财奴，自己的锚定余力只在秦末与几回自放里花（:930）；⑦E5 贺兰（冀鼎）已写：漏成筛子、风哨、草木一圈疯一圈枯，苏衍找暗线总口一次引通（:1293）。

## 一、总钥：两种厄，一个地址

**人祸**：网好、人乱——乱有尽，天下终归一（汤武之际数年；汉末三国九十年而一统——他攥着网，理得了气、理不了人）。
**气祸**：网坏、地乱——长，数代、割地、南北裂；**每一回都落在同一个地址：冀，与胡。**
离乡之鼎有三，三尊三命：**豫鼎**移骊山，就压在他台下、在他手底，中原之心他亲手攥着；**青鼎**沉沙海，漏出去的气落在没人的沙里——只腌死了一座城（楼兰），喂不了谁；**冀鼎**押贺兰，押进了胡地——**三尊里唯有这一尊，漏出去的气落在活人堆里，喂的是另一群人。**从此冀脉无钉，贺兰有鼎不认地。中华两千年里最长的两回大裂，都从这一道伤口裂开；他当年借卢生之嘴说的「亡秦者胡也」，不是应了一回，是应了一千五百年。

## 二、四回（时序；⛔推纪年於正文之外另造）

1. **汉末·乱起於冀（他读错的第一个兆）**：黄巾起於冀州钜鹿。他以为是人——这一回确是人祸为主（旧账①不改）；他记住了地名，没看懂。
2. **五胡·贺兰头一回漏**：他改上去的泵头五百年头一回松，贺兰站漏——漏处草木一圈疯一圈枯（E5 已写之相，回看即通）：草疯那几年胡马肥、胡人繁，往南压；恰逢晋室八王自乱（人祸开门），五胡入而天下南北裂二百七十年。他攥得住八站，攥不住一个漏的。「亡秦者胡也」第二回应验，应的是中原。
3. **盛唐·调到最好（他唯一一回不当守财奴）**：**为何在此时**——裂了二百七十年，天下等不起（他的第一句信）；隋一统是人事，他看见了一个机会：**他要一个证据**——证明一只不死、看得清的手，能给天下一个禹的桩给不了的「最好」。他学会了绕——修不了漏，就把八站开到最满：贺兰漏出去的往回吸，余下诸站之气一并往中原推。网从没这么顺过：贞观、开元，天宝十四载户口五千二百九十一万，史上最多。**他没花自己一分余力，花的是机器**：那只五胡年间就松过的泵头，被他当最满之力的总阀使了一百多年。（作者所言「洪荒之力」＝八站全开、贺兰一阀独扛。）
4. **安史·最好那一天断**：天宝十四载冬，贺兰那只泵头断了。被他往回吸了一百多年的冀脉之气失了阀，倒灌回冀北——就在那一个冬天，范阳起兵，起兵的是个胡将。九年後户口一千六百九十二万：他在台上数，十存其三。此後河朔三镇割据百五十年（气淤冀地、无人能钉）→ 五代十国（网碎十余块）→ 燕云十六州——冀之北——整块割给契丹，入胡四百年。**冀，交给了胡。地址一字不差。**

## 三、闭环（为何此账让全书更好）

- **驳他最狠的一刀，由他最得意的一回给出**：他信「天下要一只不死、看得清的手」；那只手把天下调到最好的那一回，换来史上最惨的一回。禹的桩不调——稳交给桩、不用人攥（F099）；他的手调到最好，就是把一只老阀用到断。补「书怎么驳他」①（不死的手修不了网）之实证，⛔说教，靠数。
- **此後他再不调最好，只调够用**：宋富而弱、燕云不复；八鼎因此老得慢些，却停不下来——即今之催命钟（:969）。
- **E5 已写零返工而得新义**：贺兰漏成筛子，是天宝那一断之疤；苏衍 390—395 一次引通暗线总口，是一千二百年来头一回有人到站修了这一道（调度替代不了维修·:969）。读者回看即通。
- **与亡秦账、立鼎账同一义**：秦亡、五胡、安史，三回「本该长久」而骤塌，皆非天命，皆是那一道伤口；改朝是人事，裂土是气事。
- **终局即愈**：终局离乡三鼎各以他当年改道之线反接回本州之脉（圣经 D5·机制-6）——**冀之气两千年来头一回回到冀**；伤口是他开的，缝它的线也是他当年铺的。读者至此回看：五胡、安史、燕云，原来都在等这一针。
- **与主题**：他是全书唯一答「要」的人；他的「要」，最好的一天也只撑了一百多年，断的那一天之後九年，户口少了三千六百万（户口之减含逃散、隐户，⛔写作死数）。苏衍终局留下的是一根玉桩、不是一只手（D5、F106）。

## 四、正文之载（交段庭·⛔此刻造）
- **禹贡九州之冀**：两河之间，今河北、山西、京津俱在其内——范阳、燕云皆冀地（鼎名随禹贡、不随後世州名）。
- **主载：古卷段十三（理网）**——旧裁「禁逐朝写」照守，**唯许一场：天宝十四载冬那一断**（他感到贺兰那一阀断、冀北之气倒灌，台上数数，十存其三）。502 前字禁照旧（⛔秦、赵阙、始皇、禹、邯郸、大梁、泗水、会稽、荧惑），朝名、年号以象代：最满的一年的仓、一个胡将、一个冬天、一个数。**交 471 段剧情庭**（与 G1107-02 洞②亡秦账之象同段，前後相接：秦末之乱 → 他理网 → 调到最好 → 断）。
- **辅载**：「亡秦者胡也」由 486 钱满引史（已排）——段庭可令其後一笔落「冀」「胡」之地址（⛔解）；贺兰之草一圈疯一圈枯可由知者（老头或罗）一句回声。**交 471、481 段庭酌定**。
- 数据只入设定之暗账；正文所用之数须核史（天宝十四载 891 万户、5291 万口；广德二年 293 万户、1692 万口——《通典·食货七》《旧唐书》）。
