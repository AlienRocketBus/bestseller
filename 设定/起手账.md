# 起手账 —— ⛔**二十二章，头一句是同一句话的二十二个样子**

> **立於 2026-09-18（本坐立·其式承 `设定/外声账.md`：⛔一个「觉得」不算答，先给它一把量得出来的尺）**
>
> ★**立此账之由**：**`大审` 评委席之判逐字**——「**338 头十拍无一处给出『还要读下去』的理由；书死在第7拍。**」
> ⛔**而那一判是读出来的，不是数出来的**；**一句读出来的判，下一席可以说「我不觉得」，於是它一年也办不成。**
> ★★**故本坐今日只做一件事**：**把「头一句长什么样」这一件，逐章数一遍。**

---

## 一·**其数（⛔器亲印，非抄册·逐条可复跑）**

**其法**：取每章白文头一个非空、非「＊」之行，问它是不是以 `第〈汉数〉天／日。` 起手。

| 段 | 以日号起手 | 占比 |
|---|---|---|
| 1—99 | 3／99 | **3%** |
| 100—199 | 3／100 | **3%** |
| 200—299 | 29／100 | **29%** |
| 300—326 | 22／27 | **81%** |
| **327—348** | **22／22** | **100%** |

★**末尾连续二十二章，一章不缺。**
**其前那一章（326）之首句係**：「**本子昨夜压在那件叠起来的衣裳底下。今早我先摸着的是布，布是凉的。**」
——**即这一条不是从头就有的，它是在三百章上长出来，而後把别的形吃光的。**

## 二·⛔**而须先把两样分开，不然这一账立错**

★**「第N天／日」这个数本身，不是排场，是在役定式**：
**主线之天数与暗线之日数是两条走不到一处的线，其数正是读者手里那一把「他们差了几天」的尺**
（`体检账` 之「在役定式对排场」一分：**其逐字之恒常本身即是量器者，不是戏已演完的场面**）。
⛔**故本账所问者，不是那个数，是它後头那一句。**

★★**而那一句，二十二章之形逐条摆出来**（本坐逐章亲读，非机数）：

| 章 | 日号之後那一句 |
|---|---|
| 330 | 水停在昨天那一线上，没有再往下去 |
| 331 | 棱外头土里那一根还立着 |
| 334 | 屋外头这一块平地是硬的，昨天踩上去的脚印还在 |
| 337 | 门槛上那一页纸还铺着，笔横在纸当中 |
| 339 | 纸还铺在门槛上，那一道线起手那一头的墨干了 |
| 341 | 门槛上那一张纸还铺着，空白的那一面朝上 |
| 343 | 门槛上那一张纸还铺着，空白的那一面朝上，前天那一道浅印还在 |
| 345 | 被子角那个口子还塌着 |
| 347 | 门槛上那一张纸，折过来的那一头还盖着 |

⛔**其形一句话**：**日号＋一样东西此刻的状态（多半带一个「还」字）。**
★**即：二十二章之内，读者在读到第一个句号之前，就已经知道第二句要说什么了**——
**不是知道内容，是知道形状。**⛔**而一个读者一眼认得出形状的开头，它给不出「还要读下去」的理由，
因为它先给了一个「我知道接下来是什么」。**

## 三·**这一条何以长成这样（⛔不骂它，先认它办成了什么）**

★**它办成了三件真事，一件也不许抹**：
① **两条线之日数逐章对得上**（主线天／暗线日，一章一格，读者自己数得出来差几天）；
② **「还」字那一路正是本书之骨**：**一样东西昨天什么样、今天什么样，是这本书量时间的唯一办法**；
③ **暗线那几章之物（门槛上那一张纸）逐章只动一分**，**其不动本身即是那一章的事**。
⛔**故本账不判它「该删」——删了它，上头三件当场全塌。**

## 四·⛔**而其价，逐条摆在明处**

· **二十二章，无一章之头一句是一件正在发生的事**；**逐章皆是「一件东西现在什么样」。**
· **一个形用到第二十二回，它就不再是形，是一张表格**；**而表格没有人会往下读第七拍。**
· ★★**最要紧的一处**：**`大审` 所判「书死在第7拍」，其根不在第7拍，在第1拍**——
  **第7拍之所以死，是因为第1拍已经把这一章的节奏定成了「点名—量—记」。**

## 五·**本账所问者一句（⛔交 `大审` 352 之庭，本坐不代下判）**

> ⛔**「这二十二章里，有没有一章，它的头一句本可以是一件正在发生的事，而本书选择了去量一样东西？」**
> ★**其答之式，⛔只许两样**：
> · **「有」——则须指出是哪一章、那件正在发生的事是什么**（⛔一个章号加一句实话，不许写「多半有」）；
> · **「没有」——则须答：一本书连着二十二章没有一件事发生在头一句上，这是它的骨，还是它的病。**

★★**其限 352**（与 `外声账` 之问、`大问挂账` 爷爷第二笔同章而不同科，不相犯）。
⛔**并写死一句，免它变成账上第三条永远在挂的话**：
**352 那一庭若不答，本账须在其後头一个无席之窗当面裁，⛔不许第二回只写一个「停」**
（此係 `外声账` 立时同一条自限，其文在案）。
