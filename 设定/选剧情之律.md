# 选剧情之律（0927·作者令立·永久）

⛔作者原话之要：「作废标准不是『正文写了、和正文对不上就作废』……要对比哪个剧情更好……一切皆可改。前提是这个剧情能让这本书更好看、成为中国第一的小说。」


> ★**1007 作者死规矩：圣经是工具，随时可改**。「与圣经相抵」不是否决之由，只记改设定之价；凡更好看、逻辑连得上之剧情，改圣经以就之。内容无禁区（唯「鼎心」一词）。详 `设定/00_作者常令_不停之律.md`。

## 一、唯一之尺
⛔**改的目的是让书升华**（0927 作者令）：改不是修补错误到及格，是发现错、去掉错、让这本书更好——所裁之案须让这一处明显胜原文，配得上中国第一的小说；只改对、不升华之案不取。〔1119 死规之审·docs17／docs22：「95 分以上之境」随升华之闸 1119 废，其意存（常令:414）〕
两个剧情摆在一起，只问：**哪一个让整本书更好看**（读者更放不下、更震、更信、前後更紧）。
- **已写之文不是否决之由。** 「与第 N 章相抵」只算「改文之价」：记下要改几章、几处，供取舍时掂量，⛔不许单凭它作废一个更好的剧情。
- **立得住是底线，不是加分**（`设定/立得住之律.md`）：无论新旧，立不住的都不用；而「和已写的对不上」不等於立不住。
- **过得去不够。** 评审不许满足於「这个能圆上」，须问「有没有更好看的」，并真去想出来。

## 二、⛔审原与守原之律（0927 作者再令·三令）
- **原剧情也要审。** 许多是最初草定，不一定好；每席以满分为尺严审，并**各自独立出三个朝满分去的改法**（改式与新式皆然），⛔不许敷衍。原剧情与诸改法同场比，择最好者。
- **既定剧情默认不改。** 改，必须证明改後比原来更好看、更精彩、更立得住；证不出，守原。⛔不为改而改——已定之剧情乱改会出事。
- 要改者须交**详细之逻辑与方案**：改在哪、改後怎么走、对照原文逐点说读者在哪一刻比原来更放不下，以及立得住之据与改文之价。
- 机械之门：一案须 诸席立得住均 ≥7、好看均高於现文 ≥1、过半席独立判「胜现文」，方得入裁；无一过门即守原。
- 新想之剧情（下一步走向）：每席独立出**三个**真不同之最好方案，择其最好者。

## 三、谁来审——剧情庭（`工具/席/剧情庭.js`）
五席，皆尽全力（effort:max），**各自独立**，看不到他席：
1. **小说家**：全中国最顶尖的小说家。
2. **总编辑**：一本中国第一的小说之总编辑。
3. **顶尖读者**：读过最多好小说、最挑的读者。
4. **剧本师**：全中国最顶尖的剧本师——冲突、目标与阻力、转折与代价、高潮是否一步步逼出。
5. **挑刺王**：逐案攻其最致命之刺，并参加复评。
流程：独立出案（改式：守原或至多三案带详证；新式：每席三案）→ 挑刺王逐案攻 → 五席独立复评打分（不看出自谁）→ 机械之门 → 裁。

## 四、何时跑（⛔必须跑）
1. 凡动大设定、主线剧情、人物命运、揭晓次序者，改前必过（式：改）；总编辑自提者一样过。
2. **每十章一段之势**：自第 381 章起，每段（381—390、391—400……）动笔之前，先过一回剧情庭，定这一段之走向，落 `设定/剧情庭_势_第N段.md`（N＝段首章）。`工具/剧情庭之关.py` 验：段内已有章封版而无此档者红；`--章 N` 於动笔前验（`工具/造式验.py N --料` 调之）。
   - ★1015 进化（W43·虫洞）：本段已有段案（`设定/段案/`，据余章总案所立）者，以「式：段」审之——默认守原；小说家、剧本师二席各出三案，挑刺王一席并攻全池，总编辑、顶尖读者二席（未出案）独立复评，机械之门不降（立得住均≥7、好看均高现案≥1、过半判胜），裁席落档、改段案与余章总案之行，⛔提交（主环提交）。六席代旧式二十二席；题档 `设定/剧情庭题/势_第N段.md` 只点档与行（⛔抄料）。无段案之段仍用「式：新」。★1021 进化（W60·X11·W43 二因之治）：式段之裁席⛔亲改诸档——只写裁档与改之单 `设定/_草/<W>/剧情庭单.json`（[{档,原,新,由}]：原恰一见、⛔跨行、⛔改行数），主环 `改单.py --立` 後 `改单.py --施单 <单> --落 --号 <单号>` 器施；式段须传 args.W，题档首行须写「料：设定/段案/_料_<起>-<止>.md」（`工具/段料.py` 所汇；缺即⛔开）。
   - 自注「此裁无效」之势档，须有「代裁：」一行点出真裁之档（俱在盘上），方算有势。

## 五、圣经随裁（0927 作者令：圣经不是一成不变的）
圣经为书服务，随书之最好而变：凡裁定改了剧情，**当场**改圣经（势之裁改总纲），写「据 剧情庭_xxx」；落後之设定、不能让书成中国第一之设定，一概可淘汰。`工具/圣经随裁.py` 入全测：裁了而圣经未随即红，推不上去。
