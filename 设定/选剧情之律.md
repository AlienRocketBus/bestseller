# 选剧情之律（0927·作者令立·永久）

⛔作者原话之要：「作废标准不是『正文写了、和正文对不上就作废』……要对比哪个剧情更好……一切皆可改。前提是这个剧情能让这本书更好看、成为中国第一的小说。」

## 一、唯一之尺
两个剧情摆在一起，只问：**哪一个让整本书更好看**（读者更放不下、更震、更信、前後更紧）。
- **已写之文不是否决之由。** 「与第 N 章相抵」只算「改文之价」：记下要改几章、几处，供取舍时掂量，⛔不许单凭它作废一个更好的剧情。
- **立得住是底线，不是加分**（`设定/立得住之律.md`）：无论新旧，立不住的都不用；而「和已写的对不上」不等於立不住。
- **过得去不够。** 评审不许满足於「这个能圆上」，须问「有没有更好看的」，并真去想出来。

## 二、⛔守原之律（0927 作者再令）
- **既定剧情默认不改。** 改，必须证明改後比原来更好看、更精彩、更立得住；证不出，守原。⛔不为改而改——已定之剧情乱改会出事。
- 要改者须交**详细之逻辑与方案**：改在哪、改後怎么走、对照原文逐点说读者在哪一刻比原来更放不下，以及立得住之据与改文之价。
- 机械之门：一案须 诸席立得住均 ≥7、好看均高於现文 ≥1、过半席独立判「胜现文」，方得入裁；无一过门即守原。
- 新想之剧情（下一步走向）：每席独立出**三个**真不同之最好方案，择其最好者。

## 三、谁来审——剧情庭（`工具/席/剧情庭.js`）
五席，皆尽全力（effort:max），**各自独立**，看不到他席：
1. **小说家**：全中国最顶尖的小说家。
2. **总编辑**：一本中国第一的小说之总编辑。
3. **顶尖读者**：读过最多好小说、最挑的读者。
4. **剧本师**：全中国最顶尖的剧本师——冲突、目标与阻力、转折与代价、高潮是否一步步逼出。
5. **挑刺王**：逐案攻其最致命之刺，并参加复评。
流程：独立出案（改式：守原或至多三案带详证；新式：每席三案）→ 挑刺王逐案攻 → 五席独立复评打分（不看出自谁）→ 机械之门 → 裁。

## 四、何时跑（⛔必须跑）
1. 凡动大设定、主线剧情、人物命运、揭晓次序者，改前必过（式：改）；总编辑自提者一样过。
2. **每十章一段之势**：自第 381 章起，每段（381—390、391—400……）动笔之前，先以「式：新」过一回剧情庭，定这一段之走向，落 `设定/剧情庭_势_第N段.md`（N＝段首章）。`工具/剧情庭之关.py` 验：段内已有章封版而无此档者红。
