# 选剧情之律（0927·作者令立·永久）

⛔作者原话之要：「作废标准不是『正文写了、和正文对不上就作废』……要对比哪个剧情更好……一切皆可改。前提是这个剧情能让这本书更好看、成为中国第一的小说。」

## 一、唯一之尺
两个剧情摆在一起，只问：**哪一个让整本书更好看**（读者更放不下、更震、更信、前後更紧）。
- **已写之文不是否决之由。** 「与第 N 章相抵」只算「改文之价」：记下要改几章、几处，供取舍时掂量，⛔不许单凭它作废一个更好的剧情。
- **立得住是底线，不是加分**（`设定/立得住之律.md`）：无论新旧，立不住的都不用；而「和已写的对不上」不等於立不住。
- **过得去不够。** 评审不许满足於「这个能圆上」，须问「有没有更好看的」，并真去想出来。

## 二、谁来审——剧情庭（`工具/席/剧情庭.js`）
四席，皆尽全力（effort:max），各自独立：
1. **小说家**：全中国最顶尖的小说家——看这个剧情能写出多好看的场面、人物能不能立起来。
2. **总编辑**：一本中国第一的小说之总编辑——看全书之势、前後之接、揭晓与代价之布局。
3. **顶尖读者**：读过最多好小说、最挑的读者——只问「我会不会放不下、会不会骂、会不会拍桌」。
4. **挑刺王**：专挑逻辑与剧情之刺，⛔不给情面；每一个方案都要找出它最致命之处。
每席⛔**不只评，必须提改**：给出能让这一处更好的方案或改法，且须是反复想过、确比现有诸案好看的；想不出更好的，要说明想过哪几条路、为何不如。

## 三、怎么审（三轮）
1. **独立评＋提案**：每席对诸方案（含「现文」）逐一评「好看」「立得住」，并各提至少一个更好之案。
2. **挑刺与复评**：把所有方案（含新提）合一；挑刺王逐案攻其最致命处，另三席据之复评、并改良最强之案。
3. **裁**：总编辑之裁席择最好看而立得住之一案（可嫁接诸案之长），写明：为何它最好看、挑刺王之刺如何治、改文之价几何；落 `设定/剧情庭_<题>.md`。

## 四、适用
凡动大设定、主线剧情、人物命运、揭晓次序者，皆过剧情庭；⛔总编辑自提者一样过，不许因是自己所提而放行。
